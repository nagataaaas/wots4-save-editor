# 侍道4 セーブデータエディタ

[Steam版「侍道4」](https://store.steampowered.com/app/312780/4/?l=japanese)のセーブデータを、ブラウザで編集できる非公式ツールです。

**https://wots4-save-editor.nagata.pro**

![侍道４ セーブエディタ](public/og-image.jpg)

## 特徴

- インストール不要。ブラウザでページを開き、セーブファイルを選ぶだけで使えます
- セーブファイルはブラウザの中だけで読み書きし、サーバーへは送信しません
- 読み込んだときと保存したときのセーブをブラウザに残し、サイドバーの「復元」からいつでも戻せます
- ファイルの大きさは変えず、決まった位置の値だけを書き換えます。範囲外の値は、上級者モードをオンにしない限り受け付けません

## 編集できるもの

| まとまり   | 内容                                                                                 |
| ---------- | ------------------------------------------------------------------------------------ |
| 主人公     | 所持金・侍点・名前・活力・HP・現在地・難易度、容姿と装飾品の着け方、侍評価や各種記録 |
| 武器       | 帯刀・武器袋・刀箪笥の武器（刃・鍔・柄・銘・魅力・攻撃力・耐久など）                 |
| 道具       | 手持ち・箪笥・重要品                                                                 |
| 容姿・特典 | 装飾品の所持、顔・髪型・服、特典の解除                                               |
| 世界       | 阿弥浜の状態（治安・日数・門・施設など）、NPC・勢力の状態、イベントの進み具合、道場  |
| 流派       | 技の覚え状況、流派の修練度・段、俺流                                                 |
| その他     | なりわい、夜這い、流通（閲覧のみ）、生データ（16進でのバイト編集）                   |

まだ解析中の項目もあり、ゲーム内で反映を確かめていない値も含まれます。

## 使い方

1. ゲームを終了し、セーブファイル `S4-DATA_00`〜`S4-DATA_04` を見つけます
   - 場所は通常 `<Steam のインストール先>\userdata\<ユーザーID>\312780\remote\` です
2. [エディタ](https://wots4-save-editor.nagata.pro) を開き、編集したいセーブファイルを選びます
3. 値を書き換えて保存します
   - Chrome・Edge では、サイドバーの「上書き」で開いたファイルに直接書き込みます。セーブフォルダによってはブラウザが書き込みを許さないことがあり、そのときはセーブを別のフォルダにコピーして開き、上書きしたあとで元の場所に戻してください
   - そのほかのブラウザでは、サイドバーの「保存」でファイルをダウンロードし、元のファイル名にしてセーブフォルダのファイルと差し替えます

Steam クラウドが有効だと、差し替えたファイルがクラウド上の古いセーブで上書きされることがあります。うまく反映されないときは、そのゲームの Steam クラウド同期を一時的に切ってから差し替えてください。

## 注意

- 本ツールは非公式のファンメイドツールで、ゲームの開発元・販売元とは関係ありません
- セーブデータの編集は自己責任で行ってください。データの破損やゲームの不具合について、作者は責任を負いません。必ずバックアップを取ってから使ってください
- Steam版のセーブにのみ対応しています。PS3版・PS4版などのセーブは扱えません

## 不具合の報告・要望

[Issues](../../issues) へお寄せください。セーブが読み込めない・ゲームで読めなくなったなどの報告では、どの画面で何を変えたかを書いていただけると助かります。

## 開発

TypeScript + React + Vite で作った静的サイトです。パッケージマネージャは pnpm を使います。

```sh
pnpm install
pnpm dev     # 開発サーバー（http://localhost:5173）
pnpm test    # テスト（Vitest）
pnpm lint    # Lint（oxlint）
pnpm build   # dist/ に静的ファイルを出力
```
