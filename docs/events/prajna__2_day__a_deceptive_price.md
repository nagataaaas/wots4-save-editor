# 欺きの代価（A Deceptive Price）

## 流れ

1. 2日目昼、町の居酒屋に入ると導入が流れる（`0x36B9`（通し番号 17）= 2）。赤城に近づくと仕事を頼まれる
   - 攘夷と敵対中（`0x3788`（通し番号 224）= 1）は、「…仲間に入れてくれないか」で頼みの場面へ進む
2. 「いいだろう」で引き受けると `0x36B9` = 3、攘夷との敵対状態が解ける。小暮と代官所へ向かう
3. 代官所で剣崎らと戦う。選び方で戦い方が分かれる
   - 「行くぞ！」：小暮と一緒に戦う（小暮は4割で退く）。剣崎らを倒すと `0x37A0`（通し番号 248）= 0 → 500 文
   - 「…ここは 任せてくれ」：一人で戦う（`0x37AE`（通し番号 262）= 1）。剣崎を倒すと `0x37A0` = 1 → 1500 文。
     戦いの途中で小暮が加勢すると（`0x37AE` = 0）小暮と一緒の戦いに切り替わり、500 文になる（🔶 加勢する条件）
4. 赤城に報告して成功（`0x36B9` = 4）。攘夷の友好ポイント1
5. 剣崎との戦闘から逃げると失敗（`0x36B9` = 5）し、攘夷と敵対する
