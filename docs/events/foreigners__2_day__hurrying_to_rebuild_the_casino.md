# カジノ再建を急げ（Hurrying to Rebuild the Casino）

## 流れ

1. 2日目夜、カジノが閉じているとき（`0x375E`（通し番号 182）= 1）に港へ行き、カジノの外にいる J.J に近づくと、カジノを建て直しているところだから見物して行くかと誘われる（外国と敵対していず、`0x36C1`（通し番号 25）が 0 以下のとき）
   - 断ったあと（`0x36C1` = 2）にもう一度近づくと「キミはやっぱり退屈なんだろう？」となり、同じ誘いを受ける
   - 外国と敵対している（`0x3787` = 1）と「ボクに謝りに来たのかい？」となる。「すまなかった」で許してもらえ、同じ誘いを受ける。「そんなわけあるか！」か無言で追い返される（敵対したまま）
2. 誘いに乗ると `0x36C1` = 3・外国との敵対状態 0 になる。J.J が夜中に再建している理由を話していると、赤城・小暮と般若党が再建を妨げに来る。J.J に手を貸してくれと頼まれる
3. 「任せろ」か無言で、赤城・小暮・般若党との戦闘になる（無言のときは赤城に「覚悟しろ」と言われる）
   - 赤城か小暮の体力が1割まで減ると、般若党は退却して成功（`0x36C1` = 4）。カジノが開き（`0x375E` = 0）、J.J から 3000 文をもらう
   - J.J は体力が4割まで減ると戦線を離れる
   - 戦闘中に場を離れようとすると「まだ終わってないよ」と呼び止められる。「そうだったな」で戦闘に戻る。「さらばだ！」で逃げて失敗。外国・攘夷の両方と敵対する
4. 「もう帰る時間だ」を選ぶと、J.J にあきれられて失敗（`0x36C1` = 5）。町へ移される
5. 抜刀して J.J に近づくと「おっと！ 危ないじゃないか」と言われる。「すまない」で納刀して終わる。「地獄で遊んでろ」（外国と敵対中は抜刀して近づくだけで）、または J.J・海兵隊・用心棒を攻撃すると、J.J は下がり、海兵隊・用心棒との戦闘になる。全滅させても逃げても失敗
