# 罠を破れ（Break the Snare）

## 流れ

1. 3日目夜、真実が成功している（`0x36CE`（通し番号 38）= 4）とき、港に入る（`0x3768`（通し番号 192）= 1）と、般若党が茂呂を襲っている（`0x36D0`（通し番号 40）= 3）
2. 戦闘の中で赤城・小暮に話しかけて止める。制限時間は 60 秒。茂呂の体力が 0 になると斬られる
   - 赤城に話しかけるたびに選択肢が出る。止める答えを3回続けると説得成功（🔶 回数の数え方。下の表）
   - 茂呂を斬る側の答えを選ぶ、小暮に3回話しかける、茂呂に一太刀でも当てると、般若党と一緒に茂呂を斬る戦闘に変わる（🔶）
3. 説得に成功すると、赤城たちが罠に気づく。現れた魔鱗組と戦い（赤城・小暮は4割で退く）、勝つと成功（`0x36D0` = 4）
   - 攘夷 +1・敵対が解け、幕府の友好度 −・敵対、1500 文。茂呂は生き残る
4. 説得に失敗して茂呂が斬られる（制限時間が過ぎたときも）と、茂呂の状態 `0x3752`（通し番号 170）= 1。
   [仕組まれた襲撃](prajna__3_day__planned_raid.md)の後半（三姉妹・魔鱗組との戦闘）に入り、勝つと仕組まれた襲撃の成功（`0x36CF`（通し番号 39）= 4、攘夷 +1、幕府の友好度 −・敵対、1500 文）になる
   - 般若党と茂呂を斬る戦闘を経たときは `0x36D0` = 5。説得の途中で時間切れ・茂呂が斬られたときの `0x36D0` は 3 のまま（🔶）
5. 戦闘の場から出ようとすると「こっちじゃなかったか」／「無関係なんだよ！」。「無関係なんだよ！」で失敗（`0x36D0` = 5）、茂呂の状態 = 1（保留量が 10 以上のとき）

## 選択肢

赤城への選択肢は、話しかけた回数で変わる（🔶 1回目→2回目→3回目の順）。

| 場面 | 選択肢 | 結果 |
|---|---|---|
| 赤城（1回目） | 「刀を納めろ！」 | 説得が続く |
| 赤城（1回目） | 「茂呂 茂！覚悟！」 | 般若党と茂呂を斬る戦闘 → 失敗 |
| 赤城（2回目） | 「これは罠だ！」 | 説得が続く |
| 赤城（2回目） | 「絶対に逃がさんぞ！」 | 般若党と茂呂を斬る戦闘 → 失敗 |
| 赤城（3回目） | 「朱美は幕府の密偵だ！」 | 説得成功 → 魔鱗組と戦闘 |
| 赤城（3回目） | 「今だ！茂呂を叩き斬れ！」 | 般若党と茂呂を斬る戦闘 → 失敗 |
| 小暮 | 「無意味だ！やめろ！」／「騙されているんだ！」／「ど どうしたものか…」 | 3回話しかけると般若党と茂呂を斬る戦闘 → 失敗（🔶） |
| 戦闘の場から出る | 「こっちじゃなかったか」 | 戦闘に戻る |
| 戦闘の場から出る | 「無関係なんだよ！」 | 失敗（`0x36D0` = 5） |

## 未確認のこと

- 🔶 説得の回数の数え方：`0x37AE` が 1・3・5 で説得が進み、2・4・6 で失敗する。止める答えで +1、斬る側の答えで +2 になるとみられる
- 🔶 茂呂に一太刀当てると、茂呂を斬る戦闘に変わる
- 🔶 説得の途中で時間切れ・茂呂が斬られたとき、`0x36D0` が 3 のまま残る。そのあと仕組まれた襲撃の後半に勝つと `0x36CF` = 4 になる
- [A] の「【真実】さえ通っていれば、茂呂を斬ってもエンディングには影響しない」は、茂呂の状態 `0x3752` が 1 になっても真実の状態 `0x36CE` = 4 が残ることと合う（🟢）。ただし茂呂が死ぬと幕府ルートには入れない
