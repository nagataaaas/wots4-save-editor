# 真実（The Truth）

## 流れ

1. 3日目夜、売国奴を斬れが成功している（`0x36CB`（通し番号 35）= 4）とき、墓場に入ると、朱美が三姉妹と話しているのを見る（`0x36CE`（通し番号 38）= 1）。
   「赤城たちは今夜港へ行きます 茂呂を斬ってくれるでしょう」。港の取引は罠だった
2. 朱美に近づくと選択肢が出る（下の表）。問い詰めると、朱美が「正体を知られてしまったからには」と正体（まだら）を現し、戦闘になる（`0x36CE` = 3）
3. まだらとの戦闘に勝つと成功（`0x36CE` = 4）。朱美の状態 `0x3750`（通し番号 168）= 1 になり、朱美はいなくなる。報酬・勢力の変化はない
4. 見逃すと失敗（`0x36CE` = 5）。「夜道は危険だ 送ろう」を選ぶと朱美を送る場面になる（下）

### 朱美を送る場面

[夜の墓場で](prajna__3_day__at_the_cemetery_in_the_night.md)と同じ場面。

1. 朱美を町まで送る。時間帯 = 2（🔶）、朱美の好感度 `0x3793`（通し番号 235）+1、時間帯を進める保留量 +10、`0x379B`（通し番号 243）= 1
2. 茂呂の状態 `0x3752`（通し番号 170）= 1 になる。茂呂は港の襲撃で死に、幕府ルート（[公儀の剣](shogunate__4_day__imperial_sword.md)）に入れなくなる
3. 好感度（+1 したあと）が 10 以上なら「部屋まで送るよ」／「礼には及ばん」が出る。「部屋まで送るよ」で、その夜にまだ約束がなければ朱美と夜這いの約束になる
