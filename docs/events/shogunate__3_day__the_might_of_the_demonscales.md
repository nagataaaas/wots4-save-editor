# 魔鱗組の力（The Might of the Demonscales）

## 流れ

1. 大老 鬼怒川怨仙のあと、3日目昼に代官所に入ると、魔鱗組に職を追われた岡っ引きたちが愚痴をこぼしている（状態 1）。「どうした？」「関係ないか…」のどちらでも話は同じ
2. 代官所で琴吹光に話しかけると、鬼怒川の命で市中巡察に出るところで、加勢を求められる
   - 「手伝わせて貰おう」：状態が 3 になり、幕府との敵対が解ける。三姉妹も巡察に加わる
   - 「ただの見物だ」：状態 1 のまま終わる（もう一度話しかけられる）
   - 「貴様らの思い通りにはさせない」（幕府と敵対中は話しかけただけで）：「怪しい奴が目の前にいたぞ」と琴吹・魔鱗組との戦闘になる
3. 琴吹・魔鱗組との戦闘で琴吹の命が 4 割を切ると、鬼怒川が「魔鱗組に入りませんか」と勧誘する
   - 「ぜひ加えてくれ」：状態が 3 になり、巡察に加わる
   - 「断る！」：魔鱗組との戦闘になる。20 人斬っても、逃げても失敗
   - 琴吹・魔鱗組との戦闘から逃げても失敗
4. 町で般若党の一団を、琴吹・三姉妹と一緒に全滅させる。琴吹・三姉妹は命が 4 割を切ると戦闘から外れる
5. 赤城・小暮が現れる
   - 攘夷の友好度（`0x3782` − `0x3785`）が 3 以上だと、赤城に仲間扱いされて選択肢が出る。「違う！こいつらに はめられた！」を選ぶと赤城・小暮の側について琴吹・三姉妹と戦い、[血で血を洗う戦い](prajna__3_day__washing_blood_with_blood.md) の結末に移る（下の「寝返り」）
   - それ以外は赤城・小暮と戦う。赤城か小暮の命が 1 割を切ると般若党は引き上げる。琴吹・三姉妹は命が 3 割を切ると戦闘から外れる
6. 代官所に戻ると成功（状態 4）。1500 文

### 寝返り

「違う！こいつらに はめられた！」で赤城・小暮の側につき、琴吹と三姉妹を倒すと、血で血を洗う戦いの成功として扱われる。
このとき `0x36C7`（通し番号 31、血で血を洗う戦い）が 4、攘夷 +1、攘夷の敵対を解く、幕府 −1、幕府と敵対、1500 文になり、このイベントの状態は 3 のまま残る。
