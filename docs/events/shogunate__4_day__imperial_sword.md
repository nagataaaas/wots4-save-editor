# 公儀の剣（Imperial Sword）

## 流れ

1. 4日目以降の昼、幕府ルートに入れる状態（`0x3789`（通し番号 225）= 1）で代官所の中の琴吹に近づくと、剣術大会の会場の自慢をしたあと、大老から直々の指名があったので出場してほしいと頼まれる
   - 初めて（`0x36D2`（通し番号 42）が 0 以下）：「大会はもうすぐ始まる」から頼まれる
   - 一度保留したあと（`0x36D2` = 2）：「おう 来たか」「剣術大会の重み 十分考えたか」から頼まれる
2. 引き受けると成功（`0x36D2` = 4）。外国（`0x378A`（通し番号 226））と攘夷（`0x378B`（通し番号 227））のルート分岐が 2 になり、幕府ルートが確定する
3. 保留すると `0x36D2` = 2 になり、また琴吹に近づくと頼み直される
4. 抜刀して琴吹に近づくと「待て 剣術大会はここではないぞ」と止められる（🔶 抜刀が条件）。ここで斬りかかると、琴吹との戦闘になる
5. 戦闘が始まると失敗（`0x36D2` = 5）し、幕府ルートのルート分岐（`0x3789`）が 2 になる。琴吹の体力を 4 割まで減らすと「うお……今日は厄日だ」で終わる。戦闘からは逃げられる
