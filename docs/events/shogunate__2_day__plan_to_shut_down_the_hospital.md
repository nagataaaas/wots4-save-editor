# 病院廃業の企て（Plan to Shut Down the Hospital）

## 流れ

1. 2日目昼、病院が開設中（`0x375D` = 1）のときに代官所で三姉妹に話しかけると、仕事を頼まれる
   - 断ったあと（状態 2）は「あら またいらしたんですの」から選び直せる
   - 幕府と敵対中は「あたいらに詫びでも入れに来たのかい」と言われる。「すまなかった」なら許されて頼みに戻る。「謝る気などない」だと追い払われて失敗
   - 話の最中に三姉妹へ近づきすぎる・攻撃する、武器を抜いて「服を脱げ」と答える（敵対中は武器を抜いただけで）と、「曲者ですわ」と代官所の百人斬り（斬る上限 100 人）になる。百人斬っても逃げても失敗
2. 「いいだろう」で状態が 3 になり、幕府との敵対が解ける。奥座敷で、英国の病院の運営資金を幕府が負担させられるので、運ぶ一行を襲って奪ってほしいと頼まれる
3. 街道で千両箱を運ぶ一行を待ち伏せる。メリンダが生きていればメリンダが、死んでいれば新しい隊長が一行を率いる
   - 一行を攻撃するか、隊長に呼び止められて「千両箱を寄越せ！」（新しい隊長には「ただの盗賊だ」）と答えると戦闘。勝つと千両箱が手に入る。メリンダの一行に勝つと、メリンダの峰打ちの点数が +2
   - 千両箱を持ったまま戦闘から逃げても、持ち帰った扱いになる
   - 何もせずに一行を通すと、千両箱は病院に渡る
4. 代官所で三姉妹に報告する
   - 「奪ってきたぞ」：病院閉鎖。褒美に「報酬だ」で 3000 文、「遊んでいこう」で拷問の場面へ、無言なら金なしで幕府の友好ポイント2
   - 「残念だが盗賊に奪われた」：病院閉鎖。千両箱の 5000 文が自分のものになるが、幕府の対立ポイント3、幕府と敵対、三姉妹の拷問のポイントは 0 に戻る
   - 千両箱がない：「逃げられた…」「いい女だったので…」のどちらでも、病院は開設のまま、500 文
   - どの報告でも状態は 4（成功）になり、外国の対立ポイント1、外国と敵対
