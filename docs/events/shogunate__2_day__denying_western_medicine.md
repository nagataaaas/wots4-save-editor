# 西洋医学お断り（Denying Western Medicine）

## 流れ

1. 2日目昼、病院が閉鎖中（`0x375D` = 0）のときに代官所で三姉妹に話しかけると、頼みがあると言われる
   - 断ったあと（状態 2）は「あら またいらしたんですの」から選び直せる
   - 幕府と敵対中は「許しを請いに来たのかい」と言われる。「すまなかった」なら許されて頼みに戻る。「謝る気などない」だと「お仕置きが必要」と拷問の場面へ送られ、失敗
2. 「いいだろう」で状態が 3 になり、幕府との敵対が解ける。奥座敷で、英国が幕府に病院の資金援助を求めているので開業を邪魔してほしいと頼まれる
3. 居留地の病院前で、開業に反対する町人と海兵隊がもめている。町人に助けを求められる
   - 「任せておけ」（または答えない）：海兵隊と戦闘。全滅させると町人が病院を占拠し、メリンダが生きていればメリンダが現れて戦闘になる。勝つと町人が「医者がいなかったら開業はできん」と喜ぶ
   - 「死ぬのはお前らだ！」：海兵隊の側につく。そのまま立ち去ると失敗（幕府 −1、幕府と敵対、チップ 500 文）。その後に海兵隊を斬ると海兵隊（メリンダが生きていればメリンダも）との戦闘になり、全滅させても失敗（外国 −1、外国と敵対）
4. 代官所に戻ると三姉妹が褒美をくれる。「報酬だ」で 1500 文、「遊んでいこう」で拷問の場面へ、無言なら褒美なしで幕府の友好度が 2 上がる。どれも成功（状態 4）で病院は閉鎖のまま
5. 話しかけるときに武器を抜いていると「武器を仕舞いなさい」と言われる。「黙れ小娘！」（敵対中は即座に）で拷問の場面へ送られ、失敗。三姉妹の拷問のポイントは 0 に戻る
