# 小公女と大老（The Little Public Servant & The Big Minister）

## 流れ

1. 3日目昼、居留地の領事館の前にいるローラと J.J に近づくと、J.J が「ローラ様のお供を探していた」と声をかけ、ローラが大老の招きで代官所へ向かうので護衛してほしいと頼む
2. 「引き受けよう」で `0x36C6`（通し番号 30）= 3 になり、外国との敵対状態が解けて代官所の会食の場面へ進む。「今は忙しい」で断ると `0x36C6` = 2 になり、その場は終わる
3. 断ったあとに近づくと「おお！ 天の助けだ！」となり、「引き受けよう」／「駄目だ忙しい」をもう一度選べる
4. 外国と敵対している（`0x3787` = 1）ときは「何しにここへ……？」「侘びを入れに来たとでも言うのかい？」となる。「すまなかった」を選ぶと通常の依頼（「引き受けよう」／「今は忙しい」）に進む。「何となく来てみただけだ」を選ぶと追い返され、`0x36C6` = 2、敵対したまま
5. 会食：代官所で鬼怒川怨仙と三姉妹（万由・千佳・百合）が江戸前海鮮鍋でもてなす。鬼怒川・ローラ・三姉妹それぞれに問いかける選択肢が出る（台詞が変わるだけ）。鬼怒川は最後に「明日はもっと大きな鍋をご覧にいれましょう」と言う
6. 領事館に戻り、J.J とローラに礼を言われて成功（`0x36C6` = 4）。外国の友好ポイント が 1、ローラの好感度が 2 増える
7. 抜刀して近づくと「武器を仕舞いたまえ」と言われる。「すまない」で納刀して終わる。「八つ裂きにしてくれる！」を選ぶか、ローラ・J.J を攻撃すると失敗（`0x36C6` = 5）。戦闘にはならない。外国と敵対していると、抜刀して近づいただけで失敗の場面になる
