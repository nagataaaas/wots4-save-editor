# 伯爵に刺激を（Down for the Count）

## 流れ

1. カジノが閉じている2日目夕に黒船の船内へ入ると、その場で始まる（話しかける必要はない）。状態が 0 なら J.J が「カジノも無くて毎日やることも無くてさ」「退屈で退屈で死にそうなんだ」とこぼす導入。1 以上なら J.J に近づくと「なんだ またキミか……」から始まる
2. J.J への選択肢。寿司屋の店主が生きているか（寿司屋の状態 `0x37F9`（通し番号 337）が 1 でないか）で、2つ目の選択肢が変わる
3. 「ここにいても何も変わらんぞ」：J.J が散歩に出る（`0x36F3`（通し番号 75）= 3）。J.J について港を歩き、決まった地点まで連れて行く。区間ごとに制限時間がある（🔶 3分・3分・6分）
4. 寿司屋の前で J.J に「なんだいここは？」と聞かれ、選択肢。寿司屋に入ると、寿司の刺激に J.J が涙を流して感激し、「キミこそ最高の友だ」。成功（`0x36F3` = 4、J.J `0x3758` = 4）
5. 案内の途中で時間切れになる、J.J が遠くへ行きたくないと帰る、などで中断すると `0x36F3` = 2 になる。船内に入り直すと再開できる
6. 案内の途中で J.J を攻撃すると J.J との戦闘になる。決着がつかずに終わる（🔶 J.J が降参する）か逃げると `0x36F3` = 2 に戻る [A]。J.J を倒すと失敗（`0x36F3` = 5、J.J `0x3758` = 1）
7. 船長室で J.J に斬りかかったときも同じ戦闘になる。寿司屋の店主が死んでいるときは、戦い始めた時点で失敗（`0x36F3` = 5）

## 変化する内容

状態の変わり方：ほかのイベントは「断ると 2、引き受けると 3」で、3 からは戻らないが、このイベントは断ると 1 になり、3 から 2 に戻ることもある。

| 場面 | `0x36F3` | 条件 |
|---|---|---|
| 船内に入る | 変わらない | 0 なら導入、1 以上なら「なんだ またキミか……」 |
| 断る（「酒でも呑んでいろ」「黒船でも沈めるか！」） | 1 | 寿司屋の店主が生きているとき |
| 散歩に出る／生きている店主のもとで J.J と戦い始める | 3 | |
| 案内の中断・戦闘の決着なし・逃走 | 2 | |
| 寿司屋で寿司を食べる | 4 | |
| 店主が死んでいるときに戦い始める／J.J を倒す | 5 | |

開始条件が「2 以下」なので、1・2 のあいだは何度でも船内からやり直せる。

| 対象 | 変化 | 場面 | 確度 |
|---|---|---|---|
| J.J `0x3758`（通し番号 176） | 4（友になった） | 成功 | 🟢 |
| `0x3769`（通し番号 193） | 1（意味は ❓） | 成功 | 🟢 |
| J.J `0x3758` | 1（死亡） | J.J を倒したとき | 🟢 |
| 真ルート `0x378E`（通し番号 230） | 2 | J.J を倒したとき、小暮が死んでいれば | 🟢 |
| 時間帯を進める保留量 | +10 | 成功・J.J を倒したとき | 🟢 |

- 寿司屋の状態 `0x37F9`（通し番号 337）は、寿司屋の店主を殺すと 1 になる（[scenario-flags](../save_format/chunks/scenario-flags/README.md)）。このイベントでは書き換えない
- 寿司屋の店主が死んでいると寿司屋へ案内する道がなく、成功できない
- カジノの開閉 `0x375E`（通し番号 182）は前の周回から引き継がれ、真ルートでは2日目夕までに変わる場面がない（🟢）。周回の始めにカジノが開いていれば、このイベントは起きない
