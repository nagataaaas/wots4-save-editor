# 東国の騎士（The Eastern Knight）

## 流れ

1. 4日目以降の昼、領事館に入ると、ティータイム中のローラと J.J（伯爵）に迎えられる。メリンダが生きていればメリンダも同席する（`0x3759`（通し番号 177）が 0 のとき）
2. 伯爵が「今日はいよいよ剣術大会だね」と、外国の立場での大会参加を誘う
3. 参加を決めると成功（`0x36D3`（通し番号 43）= 4）。幕府・攘夷のルートが閉じ（`0x3789` = 2、`0x378B` = 2）、外国ルートで剣術大会に進む
4. 保留すると `0x36D3` = 2。もう一度領事館に入ると伯爵が「決めたかい？」と聞き直す
5. 武器を構えて伯爵・ローラに近づくと「危ないではありませんか」と言われる。「大会前の試し切りだ！」を選ぶと、ローラが退き、伯爵（メリンダが生きていればメリンダも）との戦闘になる。このとき失敗（`0x36D3` = 5）になり、外国ルートが閉じる（`0x378A` = 2）
   - 伯爵は体力が4割まで減ると戦線を離れる。メリンダは体力の減り・峰打ちで戦線を離れる
   - 戦場から出ても戦闘は終わる（逃走）
