# カジノ再建断固阻止（Put an End to the Casino's Reconstruction）

## 流れ

1. 2日目夜、カジノが閉じている（`0x375E`（通し番号 182）= 1）とき、神社で赤城に近づくと、再建中のカジノを襲う誘いを受ける
   - 攘夷と敵対中（`0x3788`（通し番号 224）= 1）は下の表の選択肢になる
2. 誘いに乗ると `0x36C3`（通し番号 27）= 3、攘夷との敵対状態が解ける。出発前に赤城・小暮に話を聞ける。赤城に「急用を思い出した」と答えると失敗（`0x36C3` = 5）
3. 港へ向かう（`0x3768`（通し番号 192）= 1）。再建中のカジノの外で伯爵と戦う。赤城・小暮は味方で1割で退く
4. 伯爵の体力を1割まで減らすと成功（`0x36C3` = 4）。カジノは閉じたまま（`0x375E` = 1）。攘夷 +1、外国の対立ポイント・敵対、1500 文
5. 伯爵との戦闘から逃げると失敗。カジノが再建され（`0x375E` = 0）、攘夷・外国の両方と敵対する
6. 戦闘の前に般若党に斬りかかると寝返ったことになり、伯爵の側で赤城・小暮と戦う。赤城・小暮の体力を1割まで減らすと失敗（`0x36C3` = 5）。
   カジノが再建され（`0x375E` = 0）、外国との敵対状態が解け、伯爵から 3000 文。攘夷の対立ポイント・敵対
