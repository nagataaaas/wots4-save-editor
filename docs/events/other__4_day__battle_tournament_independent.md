# 剣術大会（無所属）（Battle Tournament (Independent)）

## 流れ

1. [剣術大会開催](other__4_day__battle_tournament_opens.md) の会場の場面のあと、公儀の剣（`0x36D2`）・東国の騎士（`0x36D3`）・志士の刀（`0x36D4`）のどれも 4 でないと、`0x36DA`（通し番号 50）が 3 になり、無所属の対戦表で始まる（🟢）。根無し草（`0x36D5`）が 4 の場合も、どれも 4 でない場合も同じ
2. 1回戦：山賊の親玉の凶衛門
3. 2回戦：風来坊の五兵衛と愛犬ギンパチ。勝つと幕間の場面に移り、時間帯が夕になる（🔶）
4. 3回戦：上から順に、最初に当てはまる相手（🟢）
   1. 堂島（`0x375A`）が 0 で、堂島の職（`0x3799`）が 0 → 人斬りの堂島軍二
   2. 先生（`0x375B`）が 0 で、先生の職（`0x379A`）が 0 → 謎の女剣士
   3. 朱美（`0x3750`）が 0 → 暗闇脳天のまだら（幕府側の3回戦と同じ試合）
   4. どれでもない → 暗闇脳天のとぐろ（幕府側の3回戦と同じ試合）
5. 結末
   - 3回戦に勝つ：`0x36DA` = 4。表彰式で [覇者となる](other__4_day__we_are_the_champions.md)（`0x36DB` = 4）のあと、選択肢なしで [魔鱗組として](other__ending__as_a_demonscale.md) になる
   - どの試合でも、負ける・降参する：`0x36DA` = 5。[最後通告](other__ending__final_warning.md) へ

各試合の終わり方は3通りある（🟢）。相手を斬って勝つ、峰打ちで勝つ、負ける。どれがどの終わり方かは台詞からの判断（🔶）。

## 選択肢

試合中に相手に話しかけると、次の3つから選べる。

| 場面 | 選択肢 | 結果 |
|---|---|---|
| 1回戦（凶衛門） | 「かかって来い！」「降参する」「勝負あったな」 | 「降参する」で負けになるとみられる（🔶）。ほかの2つの効果は ❓ |
| 2回戦（五兵衛） | 「かかってこい！」「降参する」「勝負あったな」 | 同上 |
| 2回戦（ギンパチ） | 「待て！」「お手！」「お座り」 | ❓ |
| 3回戦（堂島軍二） | 「かかって来いデブ！」「降参する」「勝負あったな」 | 同上 |
| 3回戦（謎の女剣士） | 「本気で来い！」「降参する」「…雌雄は決した」 | 同上 |
| 3回戦（まだら・とぐろ） | [剣術大会（幕府）](shogunate__4_day__battle_tournament_shogunate.md) と同じ | 同上 |

## 変化する内容

| 対象 | 変化 | 場面 | 確度 |
|---|---|---|---|
| `0x36DA`（通し番号 50） | = 3 | 大会の開始 | 🟢 |
| `0x37AB`（勝ち抜いた試合数） | = 1 → 2 → 3 | 各試合に勝ったとき | 🟢 |
| `0x36DA` | = 4 | 3回戦に勝つ | 🟢 |
| `0x36DA` | = 5 | どの試合でも負ける | 🟢 |
| `0x37F7` | = 1 | 3回戦でまだらに勝つ | 🟢 |
| 時間帯 | 夕 | 2回戦のあとの幕間 | 🔶 |
