# 臆病風（Loss of Nerve）

## 流れ

1. 剣術大会以降、神社の奥へ行くと、赤城が「臆病風に吹かれやがって」と逃げ出す党員を見限る場面になる。小暮らは斬るべきだと言うが、赤城は「刀が錆びる」と見逃す
2. 赤城は残った者で代官所を襲い、囚われた同志を救うと宣言し、主人公に手を貸すよう頼む
3. 党員が逃げ出すときと、代官所を襲うと告げたあとに、主人公に選択肢が出る（下の表）。どれを選んでも赤城の返事が変わるだけで、結果は変わらない
4. 「よし 早速出発だ！」で成功（`0x36E1`（通し番号 57）= 4）。逃げた党員の人物が消え、そのまま[同士救出](prajna__after_tournament__mutual_rescue.md)が始まる
5. 「準備をしてくる」で保留（= 2）。神社へ戻ると「来たか……」「準備はいいな」と同じ二択になる

## 選択肢

| 場面 | 選択肢 | 結果 |
|---|---|---|
| 党員が逃げ出すとき | 「どうした？」 | 赤城の返事が変わるだけ（「釜茹でに怖気づいたのだ」） |
| 党員が逃げ出すとき | 「裏切り者には死だ！」 | 赤城の返事が変わるだけ（「虚しいだけだ」）。戦闘にはならない |
| 赤城が代官所を襲うと告げたあと | 「まだ同志がいるのか？」 | 赤城の返事が変わるだけ（「処刑を待っている同志が大勢」） |
| 同上 | 「よし！行って来い！」 | 赤城の返事が変わるだけ |
| 同上 | 「裏切り者は皆殺しだ！」 | 赤城の返事が変わるだけ（「臆病者のことは捨て置け」） |
| 協力の依頼 | 「よし 早速出発だ！」 | 成功（`0x36E1` = 4）。そのまま同士救出へ |
| 協力の依頼 | 「準備をしてくる」 | 保留（`0x36E1` = 2）。神社に戻ると再び選べる |
