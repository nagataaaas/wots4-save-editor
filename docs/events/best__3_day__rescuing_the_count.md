# 伯爵救出（Rescuing the Count）

## 流れ

1. 3日目夜、代官所内の拷問部屋に近づくと始まる。三姉妹が J.J を拷問しており、そこへ代官所の者（琴吹とみられる 🔶）が三姉妹を呼びに来て、三姉妹は場を離れる
2. 吊るされた J.J に話しかけられ、選択肢が出る（結果は台詞が変わるだけ）
3. 手柄を立てて褒美の拷問を受けたい人間豚たちが立ちふさがり、`0x36F9`（通し番号 81）= 3 になって人間豚5人との戦闘になる
4. 勝つと J.J が礼を言う。続いて、鬼怒川と三姉妹が「お楽しみは沢山用意してある」と話す場面になる
5. J.J は領事館に運ばれてローラに迎えられ、さらに病院へ移される。先生が療養を勧め、同じ病室の赤城と顔を合わせる
6. 赤城との会話で選択肢が出る（結果は台詞が変わるだけ）。最後に J.J が寿司屋に弟子入りした話をして終わり、成功（`0x36F9` = 4）
