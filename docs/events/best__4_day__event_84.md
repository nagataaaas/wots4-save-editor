# （名前不明）

仮の名前：**ローラに付き添え**（場面の内容から付けた。ゲーム内の名前ではない）

## 流れ

1. [人間湯通しの恐怖](best__4_day__a_day_at_the_spa.md)が終わると、時間帯を夕にしてこの場面が始まる。始まった時点で `0x36FC`（通し番号 84）= 4、ローラの状態（`0x3757`（通し番号 175））= 2 になる
2. ローラ・茂呂・小暮が公開処刑について話す。ローラは「御大老様に断固 抗議すべき」と言い、小暮が「もはや黙らせるしかない」とほのめかすのを止めて、自分が鬼怒川を説き伏せに行くと言って出て行く
3. 茂呂が「心配だ」「おまえさん ついてってくれ」と主人公に頼み、選択肢が出る
4. どちらを選んでも、茂呂に「相手はあの鬼怒川だ」「しっかり準備して行くんだぞ」と送り出されて終わる。ローラは代官所に向かい、[ローラの決意](best__4_day__lauras_determination.md)が起きるようになる

## 選択肢

| 場面 | 選択肢 | 結果 |
|---|---|---|
| 茂呂の頼み | 「わかった」 | 「頼んだぜ」と送り出される |
| 茂呂の頼み | 「代わりに頼む」 | 「こんな時冗談を言わんでくれ」とたしなめられ、送り出される |

どちらを選んでもフラグは同じ（🟢）。
