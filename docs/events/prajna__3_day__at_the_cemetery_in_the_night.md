# 夜の墓場で（At the Cemetery, In the Night）

## 流れ

1. 3日目夜、売国奴を斬れが成功していない（`0x36CB`（通し番号 35）≠ 4）とき、墓場に入ると、朱美が墓参りに来ている
2. 話しかけると選択肢が出る（下の表）。送らずに別れると成功（`0x371C`（通し番号 116）= 4）。何も変わらない
3. 「夜道は危険だ 送ろう」を選ぶと失敗（`0x371C` = 5）になり、朱美を送る場面になる（[真実](prajna__3_day__the_truth.md)で朱美を見逃して送るときと同じ場面）
   - 朱美を町まで送る。時間帯 = 2（🔶）、朱美の好感度 `0x3793`（通し番号 235）+1、時間帯を進める保留量 +10、`0x379B`（通し番号 243）= 1
   - 茂呂の状態 `0x3752`（通し番号 170）= 1 になる。茂呂は港の襲撃で死に、幕府ルート（[公儀の剣](shogunate__4_day__imperial_sword.md)）に入れなくなる
   - 好感度（+1 したあと）が 10 以上なら「部屋まで送るよ」／「礼には及ばん」が出る。「部屋まで送るよ」で、その夜にまだ約束がなければ朱美と夜這いの約束になる

## 選択肢

| 場面 | 選択肢 | 結果 |
|---|---|---|
| 朱美に話しかける | 「こんなところで何をしている？」 | 「お墓参りに……」。次の選択肢へ |
| 朱美に話しかける | 「墓参りとは奇遇だな」 | 成功（`0x371C` = 4）。朱美は帰る |
| 朱美に話しかける | 「さては墓場泥棒だな」 | 成功（`0x371C` = 4）。朱美は帰る |
| 朱美に話しかける | 答えない | 成功（`0x371C` = 4） |
| 「何をしている？」のあと | 「夜道は危険だ 送ろう」 | 失敗（`0x371C` = 5）→ 朱美を送る |
| 「何をしている？」のあと | 「気をつけて帰るんだぞ」、または答えない | 成功（`0x371C` = 4） |
| 朱美を送ったあと（好感度 10 以上） | 「部屋まで送るよ」 | 朱美と夜這いの約束（その夜にまだ約束がないとき） |
| 朱美を送ったあと（好感度 10 以上） | 「礼には及ばん」 | 何もない |
