## 流れ

1. 導入（誰に、どこで声をかけられるか）
2. 参加を決める・依頼を受ける
3. 進行（移動・会話・戦闘）
4. 結末（成功・失敗それぞれ）

## 選択肢

| 場面 | 選択肢 | 結果 |
|---|---|---|
| 導入 | 「〜」 | 参加する（`0x36A8` = 2） |
| 導入 | 「〜」 | 断る（イベントは起きない） |

| 人物 | 〜が死亡 | 〜を斬ったとき | 🟢 |
