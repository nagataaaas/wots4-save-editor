# 簀巻き日和（All Wrapped Up）

## 流れ

1. [阿弥浜港争乱](other__prologue__amihama_harbor_skirmish.md) で般若党に命乞いをすると、簀巻きにされて転がされた場面から始まる
2. 堂島の職 `0x3799` が 1 なら、誰も来ずに馬車に轢かれてゲームオーバー
3. 助けを呼ぶ選択肢を3回選ぶと堂島が通りかかる。呼ばずにいるとゲームオーバー
4. 堂島とのやりとり（下の表）。最後に「何でも差し上げますので…」を選ぶと、堂島が手持ちの武器をすべて持っていき、縄を解いてくれる（`0x36AA` = 4）
5. 段階は阿弥浜港争乱の結末で 100（1日目 昼）になっている。このあと昼に港へ行くと [嵐のあと](other__1_day__after_the_storm.md) が起きる

## 選択肢

| 場面 | 選択肢 | 結果 |
|---|---|---|
| 簀巻きのまま | 「助けてくれー！！」「おーい！誰かー！」 | どちらでも1回と数え、3回目で堂島が来る |
| 同上 | 無言 | 馬車に轢かれてゲームオーバー |
| 堂島「何やってんだ？」 | 「助けてください」 | ただでは助けない、と言われる → 次の選択肢 |
| 同上 | 「お前もどうだ？」 | 断られる → 次の選択肢 |
| 同上 | 無言 | 手遅れになりゲームオーバー |
| 堂島の返事のあと | 「何でも差し上げますので…」 | 助かる（`0x36AA` = 4） |
| 同上 | 「助けろボケ！」 | 口のきき方をたしなめられる → 最後の選択肢 |
| 同上 | 無言 | 馬車が来るぞと急かされる → 最後の選択肢 |
| 最後の選択肢 | 「何でも差し上げますので…」 | 助かる（`0x36AA` = 4） |
| 同上 | 「ほっといてくれ…」、または無言 | 堂島が去り、ゲームオーバー |

## 変化する内容

| 対象 | 変化 | 場面 | 確度 |
|---|---|---|---|
| `0x36AA`（通し番号 2） | 4 | 助かったとき | 🟢 |
| 武器 | 帯刀・武器袋の武器をすべて失う（13本分の枠を空にする） | 助かったとき | 🟢 |
| `0x36A9` 阿弥浜港争乱 | 5 のまま | | 🟢 |

## 未確認のこと

- 🔶 2周目以降に人だかりを避けて嵐のあとを見たあとは、阿弥浜港争乱もこのイベントも起こせない（騒乱の場面の港に戻れないとみて書いた）

- 🔶 堂島の職 `0x3799` の値 1 の意味。[A] の「堂島が鍛冶屋になっていない場合に助けてもらえる」と合わせると、1 は鍛冶屋になった状態とみられる
- ❓ 武器を取られたあと、堂島が持っていった武器が店などに出るか
- [A] は「馬車に撥ねられるとゲームオーバー（チャートに残らない）」としている。ゲームオーバーの経路では `0x36AA` を変えないことと合う
