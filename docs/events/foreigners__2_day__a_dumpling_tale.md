# お団子物語（A Dumpling Tale）

## 流れ

1. 2日目夕、領事館の中でローラに近づくと、メイドから聞いた「お団子」を食べに茶屋へ連れて行ってほしいと頼まれる（外国と敵対していず、`0x36BC`（通し番号 20）が 0 以下のとき）
   - 断ったあと（`0x36BC` = 2）にもう一度近づくと「あ 戻って来て下さったのね」となり、同じ頼みを受ける
   - 外国と敵対している（`0x3787` = 1）と「な 何しにここへ」となる。「すまなかった」で許してもらえ、同じ頼みを受ける。「また会ったね子猫ちゃん」で失敗
2. 引き受けると `0x36BC` = 3 になり、茶屋の場面に移る。ローラが団子を食べていると浪人3人が絡んでくる
3. 浪人への返事（または無言）のあと、浪人3人と戦闘。浪人は体力が少しになると戦線を離れる（死なない）。全員を倒すと次へ
   - 戦闘中に場を離れようとするとローラに「待って下さい！」と呼び止められる。「今行くぞ！」で戦闘に戻る。「自分の命は自分で守れ！」で逃げて失敗
4. 浪人の兄貴分が仲間を連れて仕返しに来て、兄貴分と浪人3人との戦闘になる。この戦闘からは逃げられない（「逃げるなよ」と戻される）。敵は体力が少しになると戦線を離れる
   - 全員を倒すと、最後の場面へ
   - 命乞い（「どうか ご勘弁下さいませ」）すると、所持金をすべて奪われる。ローラが謝り、使いを呼んで終わる。成功扱い（ローラの好感度は変わらない）
5. 最後の場面：ローラの好感度（`0x3792`）が 3 以上で外国と敵対していなければ、ローラが手を繋いでほしいと言う場面になり、好感度 +3。そうでなければ団子の味が忘れられないと言う場面になり、好感度 +1。どちらもまた茶屋へ連れて行ってほしいと頼まれて成功（`0x36BC` = 4）
6. 抜刀してローラに近づくと（敵対していないとき）、悲鳴をあげられる。「すまない」「これは失礼した」「言うことを聞け」のどれでも納刀して終わる
7. 外国と敵対中に抜刀して近づく、またはローラを攻撃すると、ローラが「い いや 誰か」と叫び、海兵隊との戦闘になる。決着がつくか逃げると失敗
