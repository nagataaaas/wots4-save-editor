# 辻斬りを辻斬る（Killing Casual Killing）

## 流れ

1. 1日目夜、居留地の領事館の中で J.J に近づくと、頼みがあると持ちかけられる
   - 初めて（`0x36B3`（通し番号 11）が 0 以下）：「おいでなすったね」から、辻斬りを逆に斬ってほしい、侍同士の斬り合いを見たいと頼まれる
   - 一度断ったあと（`0x36B3` = 2）：「おっと やる気になってくれたのかい？」
   - 外国と敵対中（`0x3787`（通し番号 223）= 1）：「キミの評判はすこぶる悪いようだね」。「すまなかった」で謝ると頼みの場面に進む
2. 頼みを受けると `0x36B3` = 3 になり、外国との敵対状態が解ける。J.J と夜の街道へ行く
3. 街道で辻斬りが次々に襲ってくる。J.J は見ているだけで襲われない。戦闘の前に J.J への問いかけの選択肢が出る
4. 戦闘の途中で J.J が「なんだい もうギブアップか」と加勢することがある。加勢したあとの J.J は味方で、体力が減ると戦線を離れる（死なない）
5. 辻斬り10人をすべて倒すと成功（`0x36B3` = 4）。J.J から礼として 1500文を得る
6. 戦闘の場から出ようとすると J.J に「ノー！まだ終わってないよ！」と止められる。「終わりだ！帰る！！」で逃げると失敗
7. 抜刀して J.J に近づき「呼んでみろ臆病者！」を選ぶか、J.J に斬りかかると、J.J が「辻斬りが出たぞー」と叫んで去り、海兵隊との戦闘になる。この戦闘は勝っても（100人斬っても）逃げても失敗
