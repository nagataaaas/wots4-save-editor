# 最後通告（Final Warning）

## 流れ

1. 剣術大会のどの試合でも、負けるか降参すると始まる。時間帯は夜（`時間帯` = 2）、段階は 420 になる
2. とぐろが現れ、もう無用の者だからこの地から去れ、と告げる
3. 選択肢（下の表）
   - 従う：とぐろが「素直なことが長生きの秘訣」と言って去る。`0x36DC` = 4 のあと、主人公は阿弥浜を去り、周回が終わる
   - 逆らい続ける：とぐろが「後悔してももう遅い」と言って去る。`0x36DC` = 4、`0x37A8` = 1、
     幕府・外国・攘夷のルート分岐（`0x3789`〜`0x378B`）をすべて 2 にする。主人公は阿弥浜に残る

## 選択肢

| 場面 | 選択肢 | 結果 |
|---|---|---|
| 「この地から去れ」 | 「言われずともそうする」 | 去る（周回が終わる） |
| 同上 | 「指図するな！」 | 「指図ではなく忠告だ。本当にそれで良いのか」と念を押される → 2回目の選択肢 |
| 同上 | 無言 | 「聞こえなかったのか」と繰り返される → 2回目の選択肢 |
| 2回目 | 「分かったよ」 | 去る（周回が終わる） |
| 同上 | 「うるさい！黙れ！」、または無言 | 逆らう（ルートがすべて閉じ、阿弥浜に残る） |
