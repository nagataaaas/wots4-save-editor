# ガイジンとゲイシャ（Gaijin & Geisha）

## 流れ

1. 2日目夜に大通りの旅籠の前で茂呂茂に話しかけると、異人の要人を接待するので護衛してほしいと頼まれる
   - 断ったあと（状態 2）は「本当に忙しいのか」から選び直せる
   - 幕府と敵対中は「どの面下げて 俺の前に来た」と言われる。「すまなかった」なら許されて頼みに戻る。「謝って欲しいならそう言え」だと、要人が気分を悪くして宴がお開きになり失敗
   - 武器を抜いていると要人に「そいつをしまえ」と言われる。「呼んでみろ」と答えるか茂呂・要人を攻撃すると「辻斬りだあああっ」と騒がれ失敗
2. 「引き受けよう」で状態が 3 になり、幕府との敵対が解ける
3. 旅籠の座敷で芸者遊びの最中に般若党が斬り込んでくる。要人を守りながら全滅させる。戦場の外へ出ようとすると般若党に止められ、逃げられない。茂呂は命が 4 割を切ると戦闘から外れる
4. 結末
   - 全滅させる：要人は「今のもショータイムですか？」と喜ぶ。成功、1500 文、幕府 +1、攘夷 −1、攘夷と敵対
   - 要人が殺される：茂呂が「国際問題は必至」と嘆いて終わる。状態は 4 になるが、金も友好度の変化もない
