# 琴吹光探検隊（Hikaru Kotobuki's Explorer's Club）

## 流れ

1. 1日目夕に大通りで琴吹光に話しかけると、部下が誰も生きて帰らなかった謎の洞窟を探検しようと誘われる
   - 断ったあと（状態 2）に話しかけると「やはり戻ってきたな」から選び直せる
   - 幕府と敵対中（`0x3786` = 1）だと「何か言うことはないのか？」と詰め寄られる。「すまなかった」なら許されて誘いの選択肢に戻る
2. 「面白そうだな」で状態が 3 になり、幕府との敵対が解けて洞窟へ向かう
3. 洞窟では琴吹たちの列について進む。途中で何度か選択肢が出て、帰ると言うと失敗。周回数が 4 以上だと「そんなことより急ごう」「走っていくぞ」が加わり、選ぶと最奥まで飛ばせる
4. 最奥で酒盛りしていた般若党（赤城・小暮はいない）と戦う。全滅させると成功（状態 4）、1500 文。戦闘中に戦場の外へ出ようとすると琴吹に止められ、「やってられるか！帰る！」で逃げると失敗
5. 話しかけるときに武器を抜いていると「武器を納めろ」と言われる。「試し切りさせろ！」と答える（敵対中は即座に）と琴吹・岡っ引きと戦闘になり、全滅させても逃げても失敗。琴吹は命が 4 割を切ると戦闘から外れる
