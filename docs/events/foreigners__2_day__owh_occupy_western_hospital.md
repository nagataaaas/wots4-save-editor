# 病院占拠事件（OWH (Occupy Western Hospital)）

## 流れ

1. 2日目昼、病院が閉鎖中（`0x375D`（通し番号 181）= 0）なら、居留地でローラに近づくと「お侍様 良いところにいらっしゃいました」と助けを求められる（`0x36B7`（通し番号 15）が 0 以下・外国と敵対していないとき）
2. 「いいだろう」で依頼を受ける（`0x36B7` = 3、外国との敵対状態 `0x3787` = 0）。幕府の援助で建てた病院が、開業直前に反対派の住人に占拠されたので、住人を傷つけずに立ち退かせてほしいと頼まれる。「今は忙しい」なら `0x36B7` = 2 でその場は終わり、もう一度近づくと「助けて下さるのですね？」から同じ選択肢になる
3. 外国と敵対中（`0x3787` = 1）に近づくと「あ あなたは……！」となる。「すまなかった」で謝ると依頼の導入に戻る。「お前に下げる頭はない」を選ぶと「あなたには失望しました……」で失敗
4. 病院へ行くと、住人が雇った用心棒が立ちはだかる。堂島がまだ無事で職に就いていない（`0x375A`（通し番号 178）= 0 かつ `0x3799`（通し番号 241）= 0）ときは、用心棒の代わりに堂島が出てくる
5. 用心棒（堂島）と戦闘。用心棒・堂島は体力が一定まで減ると戦線を離れる（死なない）。倒すと住人との話し合いになり、選択肢で決着が分かれる（下の表）。どれを選んでも成功（`0x36B7` = 4）で、病院が開設になる（`0x375D` = 1）
6. 抜刀したままローラに近づくと（外国と敵対していないとき）「失礼した」／「さあ脱げ！」の選択肢が出る。「さあ脱げ！」を選ぶか、ローラ・医師・看護婦を攻撃すると、海兵隊3人との戦闘になる。外国と敵対中に抜刀して近づいたときは選択肢なしで戦闘になる。この戦闘は全滅させても逃げても失敗
