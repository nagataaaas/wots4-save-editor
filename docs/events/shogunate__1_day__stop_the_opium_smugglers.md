# 阿片密売を阻止せよ（Stop the Opium Smugglers）

## 流れ

1. 1日目夜に港で琴吹光たちに近づくと、今夜ここで阿片の取引があるので密売人を捕らえるのを手伝ってほしいと頼まれる
   - 断ったあと（状態 2）は「なんだ またおぬしか」から選び直せる
   - 幕府と敵対中は「おのれ 出たな悪党！」と言われる。「すまなかった」なら許されて頼みの選択肢に戻る。「暑苦しいやつだ」なら追い払われる（状態は変わらない）
2. 「引き受けよう」で状態が 3 になり、幕府との敵対が解ける。琴吹の説明の途中で琴吹たちに斬りかかると「さては密売人どもの回し者だな」と琴吹・岡っ引きとの戦闘になる
3. 取引の場面で琴吹が名乗り出るが、西洋人の商人は治外法権を理由に逮捕を拒む。琴吹に声をかける選択肢が出る
4. 結末
   - 見逃す：取引の場面の選択肢に答えないか、「悪は斬るべし！」のあと「面倒は御免だな」を選ぶ（または答えない）と、琴吹は「拙者は見なかったことにする」と諦める。成功、500 文
   - 斬る：「悪は斬るべし！」→「斬った罪は全て被ろう…」で商人と用心棒の浪人との戦闘になる。商人・浪人を自分から攻撃しても同じ戦闘になる。全滅させると成功、1500 文。外国の友好度 −1、外国と敵対
   - 取引の場面で琴吹・岡っ引きを攻撃すると「敵は身内にいた」と琴吹たちとの戦闘になり、失敗
5. 琴吹たちとの戦闘は、全滅させても逃げても失敗（幕府 −1、幕府と敵対）。琴吹は命が 4 割を切ると戦闘から外れる。商人との戦闘から逃げても失敗
