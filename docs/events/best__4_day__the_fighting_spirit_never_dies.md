# 士魂は屈せず（The Fighting Spirit Never Dies）

## 流れ

始まると時間帯が夜になり、`0x36FE`（通し番号 86）= 3 になる。三姉妹が「いい玩具が手に入りましたわね」と主人公を拷問部屋に吊るす。
ここで `0x3760`（通し番号 184。朱美に関わる名前を持つフラグ 🔶）が 1 かどうかで流れが分かれる（🟢）。

### `0x3760` が 1 でないとき（拷問を受ける）

1. 三姉妹の拷問を3回続けて受ける。順番は百合（吊り）→ 千佳（石抱き）→ 万由（水車）。それぞれ拷問の操作の場面になる
2. 3回目のあと、三姉妹は「お手上げですわ」と音を上げる
3. 大通りの処刑台の場面になる。鬼怒川がローラを釜茹でにしようとし、琴吹が「処刑中止」「公使様を解放しろ」と逆らって捕らえられそうになる（琴吹は「拙者の花道」と刀を抜く）
4. 拷問部屋に戻り、三姉妹が「あなたには死んで頂きますわ」と襲いかかる。武器なしで三姉妹との戦闘になる（時間か三姉妹の体力で区切られる）
5. 茂呂と小暮が「助太刀いたす」「俺もやるぜ」と駆けつけ、2人と一緒に三姉妹と戦う。三姉妹を全員倒すと戦闘が終わる（三姉妹はそれぞれ最期の台詞を言う）
6. 成功（`0x36FE` = 4）。小暮に声をかける選択肢のあと、小暮が「あんたの道具だ」「丸腰じゃ戦えんだろ」と取り上げられていた道具を返す
7. 茂呂・小暮と一緒に代官所内から出ようとすると、[ローラ奪還](best__4_day__rescuing_laura.md)が始まる

### `0x3760` が 1 のとき（まだらに助けられる）

1. 拷問は起きない。暗闇の中で三姉妹が檻に閉じ込められる（「いやああっ……ここから出して……」）
2. まだら（魔鱗組の『暗闇脳天』の女）が主人公を連れ出し、「早く着替えて」「公使様が危険なの」と急かす。選択肢が出る（台詞だけ変わる）
3. 大通りの処刑台の場面（上の 3 と同じ）
4. 茂呂・小暮が「無事だったのか」「急げ ローラさんが危ない」と合流し、成功（`0x36FE` = 4）。そのまま[ローラ奪還](best__4_day__rescuing_laura.md)へ移る
