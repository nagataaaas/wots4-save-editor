# 大老暗殺計画（Plot to Assassinate the Chief Minister）

## 起きる段階と条件

このイベントは、隠しルートの途中で `0x378E`（通し番号 230）が 2 になると起きるようになる（🟢）。
2日目昼・夕・夜、3日目昼・夕・夜、4日目以降（剣術大会前）の7つの段階のどれでも、次の条件は同じ。

- `0x36FB`（通し番号 83）が 3 以下（まだ終わっていない）
- 三姉妹見参が成功（`0x36EE`（通し番号 70）= 4）
- `0x378E` = 2
- 大通りにいる（時間帯は問わない）

`0x378E` を 2 にする場面（隠しルートの失敗）は次のとおり（🟢）。

| 段階 | イベント | 2 になる場面 |
|---|---|---|
| 1日目夜 | [再起の望み](hidden__1_day__praying_for_recovery.md) | 戦闘で小暮が死んだとき（`0x374F` = 1） |
| 2日目昼 | [怒りの矛先](hidden__2_day__the_sting_of_hatred.md) | 成功したとき |
| 2日目夕 | [伯爵に刺激を](hidden__2_day__down_for_the_count.md) | 失敗したとき、小暮が死んでいれば（`0x374F` = 1） |
| 2日目夕 | [運命のルーレット](hidden__2_day__dice_of_destiny.md) | 成功したとき、小暮が死んでいれば（`0x374F` = 1） |
| 2日目夜 | [闇討ち](hidden__2_day__strike_in_the_dark.md) | 失敗したとき |
| 3日目夕 | [傷心の帰国船](hidden__3_day__the_sad_boat_home.md) | 成功したとき（戦闘がない場合を含む） |

1日目夜に 2 になった場合は、2日目昼から起きる。2 になった次の段階から、大通りへ行けば起きる。

## 流れ

1. `0x378E` = 2 の状態で大通りに入ると、琴吹が「もう我慢の限界だ」「御大老様の御命を頂戴するぞ」と打ち明ける。集まった仲間を紹介し、「準備が整ったら またここに来てくれ」と言う。`0x36FB` = 3、段階 = 400 になる
2. もう一度琴吹に近づくと「これが最後の戦いになるだろう」「準備はいいか」と聞かれ、選択肢が出る
3. 「全て整った！」を選ぶと、「御大老様は代官所の奥座敷にいる」と代官所へ移る。時間帯が夜になる
4. 代官所内の奥座敷で琴吹が「御命頂戴つかまつる」と斬りかかり、鬼怒川・魔鱗組との戦闘になる。味方は琴吹と、状態が 0（生存）の小暮・茂呂・J.J・メリンダ
5. 鬼怒川の体力を削りきると「おのれっ……まさか……この私が……」と倒れる。とどめの場面のあと、琴吹たちが「これで我らは大罪人だ」「阿弥浜の地には平和が訪れた」と語る
6. 成功（`0x36FB` = 4）。鬼怒川の状態（`0x3756`）は 0 になり、そのまま結末の[大老は生きていた](hidden__ending__the_chief_minister_lived.md)へ移る

琴吹を攻撃すると、琴吹は「気分が悪い……出直してくる」と去る。フラグは変わらず、大通りに入り直すとまた琴吹がいる（🔶）。

## 選択肢

| 場面 | 選択肢 | 結果 |
|---|---|---|
| 琴吹の「準備はいいか」 | 「全て整った！」 | 代官所の奥座敷へ（`0x36FB` = 3） |
| 琴吹の「準備はいいか」 | 「もう少し、待ってくれ」 | 「拙者はここで待っている」。何も変わらない |
| 琴吹の「準備はいいか」 | 「指図するな！」 | 「臆病者に用はないぞ」と言われる。状態は変わらず、あとでまた話しかけられる |

## 変化する内容

| 対象 | 変化 | 場面 | 確度 |
|---|---|---|---|
| イベントの状態 `0x36FB` | = 3 | 導入・「全て整った！」 | 🟢 |
| 段階 | = 400 | 導入 | 🟢 |
| 時間帯 | = 2（夜） | 代官所に乗り込むとき | 🔶 |
| 人物 | 鬼怒川（`0x3756`（通し番号 174））= 0 | 鬼怒川を倒したとき | 🟢 |
| イベントの状態 `0x36FB` | = 4 | 鬼怒川を倒したとき | 🟢 |
| 所持金・勢力の友好度 | 変わらない | — | 🟢 |

失敗（`0x36FB` = 5）になる場面はない（🟢）。
