# 大老と三姉妹（The Chief Minister & The Three Sisters）

## 流れ

1. 大老 鬼怒川怨仙のあと、3日目夕に代官所で琴吹光に話しかけると、鬼怒川が会いたがっていると言われる
   - 後回しにしたあと（状態 2）は「御大老様はまだ奥にいらっしゃるぞ」から選び直せる
   - 幕府と敵対中でも「どういうわけか御大老様はおぬしを気に入っておられる」と同じ選択肢になる
2. 「会ってみるか」で状態が 3 になり、幕府との敵対が解ける。奥座敷で鬼怒川に拝謁する（土下座の操作がある）
3. 鬼怒川に連れられて拷問塔に入ると成功（状態 4）。幕府 +1。代官所の奥・拷問塔の門が開き、以降出入りできるようになる
4. 拷問塔では三姉妹が攘夷志士を責めている。鬼怒川に感想を聞かれる（どちらを選んでも結果は同じで、見学の許可をもらう）
5. 拷問塔の中で三姉妹のだれかを攻撃すると、拷問の場面へ送られる

## 選択肢

| 場面 | 選択肢 | 結果 |
|---|---|---|
| 琴吹（初回） | 「会ってみるか」 | 奥座敷へ（`0x36C9` = 3） |
| 琴吹（初回） | 「後で行く」 | 後回し（`0x36C9` = 2） |
| 琴吹（後回しのあと） | 「会おう」／「後で行く」 | 奥座敷へ／後回し |
| 拷問塔で鬼怒川 | 「素晴らしい！」／「趣味じゃない」 | どちらも見学の許可をもらう（台詞だけが違う） |
