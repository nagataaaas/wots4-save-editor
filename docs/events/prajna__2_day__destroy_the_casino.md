# カジノを破壊せよ（Destroy the Casino）

## 流れ

1. 2日目夜、カジノが開いている（`0x375E`（通し番号 182）= 0）とき、神社で赤城に近づくと「今夜 異人の賭博場を襲う」と誘われる
   - 攘夷と敵対中（`0x3788`（通し番号 224）= 1）は「何しに来た」と迎えられる（下の表）
2. 誘いに乗ると `0x36C2`（通し番号 26）= 3、攘夷との敵対状態が解ける。赤城・小暮への問いかけ（下の表）は台詞が変わるだけ
3. 港のカジノで伯爵と用心棒4人を相手に、般若党と一緒に戦う。用心棒4人を倒し、伯爵の体力を1割まで減らすと成功（`0x36C2` = 4）
   - カジノが閉じる（`0x375E` = 1）。攘夷 +1、外国の対立ポイント・敵対。居酒屋の朱美のもとで祝い、赤城から 1500 文
4. カジノで戦闘の前に赤城・小暮・党員に斬りかかると寝返ったことになる（「貴様 裏切ったな」）。攘夷と敵対（`0x3788` = 1）し、伯爵の側で般若党と戦う。
   赤城・小暮の体力を3割まで減らすと般若党が退き、失敗（`0x36C2` = 5）。カジノは開いたまま（`0x375E` = 0）、外国との敵対状態が解け、伯爵から 500 文
5. 神社で般若党と戦闘になり（下の表）、全員を倒すか逃げると失敗し、攘夷と敵対する
