# 将の器（Ability to Lead）

## 流れ

1. 神社の奥で小暮に話しかけると、般若党が赤城の留守中の守りを相談している場面になる（`0x36F1`（通し番号 73）= 3）
2. 小暮への選択肢（どれを選んでも話は先へ進む）。般若党は町へ同志集めと武器の買い出しに出る
3. 般若党が戻ると、同志は2人しか増えず、刀ばかり大量に買い込んで金を使い果たしている。小暮への選択肢（どれを選んでも同じ）
4. 魔鱗組が神社に攻め込んでくる。小暮・般若党と一緒に魔鱗組と戦闘（小暮は倒れても死なない 🔶）。2段階の戦闘で、それぞれ一定数を倒すと終わる（🔶 10人・15人）
5. 戦いのあと、般若党の仲間は「赤城さんが良くなったらまた呼んでください」と小暮のもとを離れる。成功（`0x36F1` = 4）
6. 会話の途中で小暮に斬りかかると「貴様 死にたいか」と小暮との戦闘になり、倒すと小暮が死ぬ。失敗（`0x36F1` = 5）
