# 祝 病院開業（Hooray! The Hospital's Grand Opening）

## 流れ

1. 2日目昼、病院が開設中（`0x375D`（通し番号 181）= 1）なら、居留地の病院でローラに近づくと「心配なことがあるのです」と頼まれる（`0x36B8`（通し番号 16）が 0 以下・外国と敵対していないとき）
2. 「いいだろう」で依頼を受ける（`0x36B8` = 3、外国との敵対状態 `0x3787` = 0）。幕府から病院の運営資金が届くが、途中の街道に盗賊団が出るので使いの者を守ってほしいと頼まれる。「今は忙しい」なら `0x36B8` = 2 でその場は終わり、もう一度近づくと「力を貸して頂けるのですね？」から同じ選択肢になる
3. 外国と敵対中（`0x3787` = 1）に近づくと「何しにいらしたのですか？」となる。「すまなかった」で謝ると依頼の導入に戻る。「愚かな異人娘を見に来た」を選ぶと「あなたは最低です」で失敗
4. 街道で運搬の一行に会う。メリンダの状態が 0（`0x3759`（通し番号 177）= 0）ならメリンダが護衛の隊長で、メリンダが死亡していれば新しい隊長と海兵隊が護衛している
5. 「手を貸そう」で盗賊団との戦闘（味方は隊長・護衛）。盗賊を 25 人倒すと撃退になり、居留地に戻ってローラから礼を言われて成功（`0x36B8` = 4）。病院は開設のまま
   - メリンダが同行する戦闘でメリンダの体力が尽きると、メリンダは死亡扱いになる（`0x3759` = 1）
6. 「千両箱を寄越せ」を選ぶと、護衛（メリンダ、または新しい隊長と海兵隊）との戦闘になる。全滅させると千両箱を奪って失敗。病院が閉鎖になり（`0x375D` = 0）、ローラの好感度が 0 に戻る
   - メリンダは体力が尽きると戦線を離れ、死亡扱いになる（`0x3759` = 1）。峰打ちで倒したときは戦線を離れるだけで、峰打ちの点数が +2
7. 戦闘から逃げると失敗。千両箱を持って逃げたときは千両箱を奪ったのと同じ結果になる
8. 抜刀したままローラに近づくと（外国と敵対していないとき）「失礼した」／「動くと殺すぞ」の選択肢が出る。「動くと殺すぞ」を選ぶか、ローラ・患者を攻撃すると、悲鳴が上がって失敗。外国と敵対中に抜刀して近づいたときは選択肢なしで失敗になる
