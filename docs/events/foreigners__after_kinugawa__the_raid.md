# 討ち入り（The Raid）

## 流れ

1. ローラが死んだ（`0x36E5`（通し番号 61）= 5）か、船上でローラと別れた（`0x36EC`（通し番号 68）= 5）あと、代官所の門の外で門番に近づくと「何用だ？」と聞かれる
2. 「御大老の御命 頂戴仕る」で「狼藉者だ 出会え 出会え」となり、`0x36ED`（通し番号 69）= 3。門番・同心6人・魔鱗組9人と門前で戦う。戦場から出ると逃走で戦闘が終わる
   - `0x36ED` = 3 のまま門の外に来ると、門前の戦闘から再開する
3. 代官所の中に入ると（`0x36ED` = 3 のとき）、中の場面になる。琴吹と戦い、倒すと奥への門が開く。戦闘から逃げることもできる
   - `0x3751`（琴吹、通し番号 169）が 1 のときは、奥への門が初めから開いていて、場面が変わる
4. 2階で三姉妹が待ち受ける。大老は江戸に行って留守だと告げ、主人公を生け捕りにしようと襲ってくる。三姉妹はそれぞれ倒れるときに台詞を残す
5. 三姉妹を3人とも倒すと門が開き、`0x36ED` = 4（成功）。そのまま[侍一直線](foreigners__ending__samurai_straight.md)の結末に移る（所定の場所に着くか、180 秒たつと始まる）

|---|---|---|
| 門番に話しかける | 「御大老の御命 頂戴仕る」 | 門前の戦闘（`0x36ED` = 3） |
| 門番に話しかける | 「いや…何でもない」 | 何も変わらない（あとで話しかけ直せる） |

| 2階の戦闘 | 三姉妹を全員倒す | 成功（`0x36ED` = 4）→ 侍一直線 |

勢力の友好度・所持金・門の値（`0x37FA`・`0x37FB`）は変わらない（🟢）。

## 未確認のこと

- ❓ 門番を斬らずに「いや…何でもない」を選んだとき、位置の分からない値が 6 になる。三姉妹を倒したときは同じ値が 5 になる。意味は分からない
- ❓ 琴吹を倒しても `0x3751` は変わらない（🟢）。`0x3751` が 1 になる場面と、そのときの中の場面の違いは要ゲーム内確認
- ❓ 戦闘から逃げたときに失敗（5）になる場面はない。逃げたあとの扱いは要ゲーム内確認
- 🔶 侍一直線へ移る条件（場所と 180 秒）は、場所がどこかを含めて要ゲーム内確認
- [A] は討ち入りの発生条件を書いていない。ローラが死ぬか別れるかしないと起きない（夕暮れの船上で共に行けば海外雄飛で終わる）（🟢）
