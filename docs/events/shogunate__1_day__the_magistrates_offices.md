# 代官所の面々（The Magistrate's Offices）

## 流れ

1. 1日目昼に代官所の門へ行くと、門番が「港で見たという浪人はお前か」と声をかけ、代官のもとへ案内すると言う
2. 「頼もう」で状態が 3 になり、奥座敷へ案内される。「断る」なら状態が 2 になって終わる（同じ時間帯にもう一度話しかけると「またお前か」から選び直せる）
3. 奥座敷で琴吹光・茂呂茂・三姉妹（万由・千佳・百合）と顔を合わせる。琴吹・茂呂・三姉妹にそれぞれ話しかける選択肢があるが、どれを選んでも結果は変わらない
4. 顔合わせが終わると成功（状態 4）。報酬の金はない
5. 門前で武器を抜いたまま話しかけると、門番に「武器を納めろ」と言われる。「黙れ！死にたいか！」と答えるか門番を斬ると、同心・岡っ引きとの百人斬り（斬る上限 100 人）になる。百人斬っても、マップの外へ出て逃げても失敗（状態 5）
