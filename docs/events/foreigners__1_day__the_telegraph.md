# 電信あり（The Telegraph）

## 流れ

1. 1日目夕、居留地でローラに近づくと、電信機の実験を見ないかと誘われる
   - 初めて（`0x36B0`（通し番号 8）が 0 以下）：「お侍様 ようこそ」から誘われる
   - 一度断ったあと（`0x36B0` = 2）：「あ またいらしたのですね」から誘われる
   - 外国と敵対中（`0x3787`（通し番号 223）= 1）：ローラが「あ あなたは……！」とおびえる。「すまなかった」で謝ると、改めて誘われる
2. 誘いに乗ると `0x36B0` = 3 になり、外国との敵対状態が解ける。茂呂と港へ行き、ローラが打つ文字の受信を待つ（茂呂への問いかけの選択肢は台詞が変わるだけ）
3. 届いた文字は「助けて」。ローラのもとへ駆けつけると、般若党3人がローラを襲っている
4. 茂呂と一緒に般若党3人と戦う。茂呂は味方で、体力が減ると戦線を離れる（死なない）。戦闘の場から出ようとすると般若党が「逃すかっ」と立ちふさがり、逃げられない
5. 般若党3人を全滅させると成功（`0x36B0` = 4）。ローラと茂呂に礼を言われ、1500文を得る
6. 失敗するのは、導入でローラに危害を加えたとき（下の表）。ローラは逃げ去り、`0x36B0` = 5、外国と敵対し、ローラの好感度が 1 減る
