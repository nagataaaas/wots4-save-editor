# 小公女謁見（Audience with the Littlest Public Servant）

## 流れ

1. 1日目昼、居留地の領事館の前にいるメリンダに近づくと、「公使様が奥でお待ちかねだ」と案内を申し出られる（`0x36AD`（通し番号 5）が 0 以下のとき）
2. 「よろしく頼む」を選ぶと `0x36AD` = 3 になり、領事館の中で謁見の場面になる。「いや 結構だ」を選ぶと `0x36AD` = 2 になり、その場は終わる
3. 断ったあとにもう一度メリンダに近づくと「またお前か……領事館に何の用だ？」となり、「公使に会いたい」で謁見に進む
4. 謁見：英国公使ローラ・リータと J.J が、攘夷志士の襲撃を恐れていることを話し、護衛を頼む。途中で3回、ローラ・J.J・メリンダに問いかける選択肢が出る（結果は台詞が変わるだけ）
5. 謁見が終わると成功（`0x36AD` = 4）。外国の友好度 + が 1 増え、外国との敵対状態が解ける
6. 抜刀したままメリンダに近づくと「武器を納めろ！」と言われる。「これはすまない」で納刀して終わる。「指図するな！」でメリンダと海兵隊3人との戦闘になる
   - メリンダは体力が一定まで減るか峰打ちで倒れると戦線を離れる（死なない）
   - 残りを全滅させるか、戦闘から逃げると失敗（`0x36AD` = 5）。外国の友好度 − が 1 増え、外国と敵対する

| 場面 | 選択肢 | 結果 |
