# 船上の侍（Samurai On Board）

## 流れ

1. 周回を始めると、小舟の上で始まる。船頭に「お侍さん 阿弥浜は初めてで？」と聞かれる
2. 1周目は最初に操作説明が出てから選択肢になる。2周目以降はすぐ選択肢になる
3. 船頭が阿弥浜の近況（黒船、般若党、幕府の役人、攘夷と開国の争い）を語り、黒船が見えたところで港に着く
4. 港に着くと、このイベントは成功（`0x36A8` = 4）。人だかりに近づくと [阿弥浜港争乱](other__prologue__amihama_harbor_skirmish.md) が始まる
   - 1周目：段階は 0（序章）のままで、ほかのイベントは起きない。阿弥浜港争乱は避けられない
   - 2周目以降：段階が 100（1日目 昼）になる。人だかりに近づかずに地図を移ってから港に戻ると、[嵐のあと](other__1_day__after_the_storm.md) が起きる

## 選択肢

どれを選んでも、操作説明の画面が出るかどうかが変わるだけで、フラグは変わらない（🟢）。

| 場面 | 選択肢 | 結果 |
|---|---|---|
| 船頭に話しかけられる | 「…そうだが」 | 船頭が近況を語る |
| 同上 | 「…急いでいる」 | 船頭が謝り、主人公の独白へ |
| 主人公の独白 | 「何をしたものか…」「阿弥浜はどんな所だろうか？」「金はどうやって稼ごう？」 | それぞれ操作説明の画面が出る |
| 説明のあと | 「問題ない」「…もう黙れ」 | 船頭の返事が変わるだけ |

| 対象 | 変化 | 場面 | 確度 |

## 前後のイベント

- 前：なし（周回の開始）
- 次：[阿弥浜港争乱](other__prologue__amihama_harbor_skirmish.md)（人だかりに近づく）／[嵐のあと](other__1_day__after_the_storm.md)（2周目以降、人だかりに近づかずに地図を移り、昼に港へ戻る）

- 🔶 発生条件の「`0x36A8` が 0 以下」に、周回の開始時の `FF` が含まれるか（`FF` を −1 として比べているとみられる）
- 拷問塔の扉 `0x3762`・`0x3763` の見た目（どちらが入口・拷問部屋の扉か）は要ゲーム内確認（[scenario-flags](../save_format/chunks/scenario-flags/README.md)）
- ❓ `0x37C1`・`0x37C2` の意味（ほかに値が変わる場面が見つかっていない）
- `0x37A9`（通し番号 257）は周回数ではなく、通常のプレイでは使われない（🟢）。周回数は [stats](../save_format/chunks/stats/README.md) の `0x0B8C`
