# 語学所開設（The Language School Opens）

## 流れ

1. 2日目夕、語学所が開設中（`0x375F` = 1）のときに町の語学所前で茂呂茂に話しかけると、講師の護衛を頼まれる
   - 断ったあと（状態 2）は「ひょっとして引き受ける気になったのか？」から選び直せる
   - 幕府と敵対中は「お前さん 相当嫌われてるぜ」と言われる。「すまなかった」なら許されて頼みに戻る。「黙れ国賊」だと失敗
   - 武器を抜いていると「馬鹿な真似はやめろ」と言われる。「問答無用！」と答えるか茂呂を攻撃すると（敵対中は武器を抜いただけで）「犬死はごめんだぜ」と失敗
2. 「いいだろう」で状態が 3 になり、幕府との敵対が解ける。何を教えているか・目的・誰を護衛するかを茂呂に質問できる（結果は変わらない）
3. 授業が終わった講師を、宿泊先の大通りの旅籠まで護衛する。途中で赤城・小暮と般若党が襲ってくる。赤城・小暮・茂呂は命が 4 割を切ると戦闘から外れる
4. 結末
   - 講師が旅籠に着く：語学所は開設のまま、1500 文、幕府 +1
   - 講師が殺される：語学所閉鎖、500 文。幕府の友好度は上がらない
   - どちらも状態は 4 になり、攘夷の友好度 −1、攘夷と敵対
