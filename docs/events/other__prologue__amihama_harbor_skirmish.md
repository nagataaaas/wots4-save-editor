# 阿弥浜港争乱（Amihama Harbor Skirmish）

## 流れ

1. 導入：[船上の侍](other__prologue__samurai_on_board.md) のあと港の人だかりに近づくと始まる。1周目は黒船の会議（ローラ・三姉妹・J.J.・茂呂）と港の騒ぎ（琴吹・メリンダ・赤城・小暮）の場面が流れる。
   2周目以降は会議の場面を飛ばす（`0x37FC` = 1）。導入を終えると `0x36A9` = 3
2. 朱美に「見てないで何とかして」と頼まれ、般若党と戦う。進み方は周回数と選択肢で決まる（下の「チュートリアルの進み方」）。
   1人ずつの戦いは3回あり、その間にローラたちが小舟で港へ向かう場面が挟まる
3. 赤城がローラを捕らえる。この場面に入るとき、6つの出口のフラグ（`0x3767` ほか）を 0 に戻す。主人公の行動で分かれる
   - 赤城かローラを攻撃する → 4a へ（「娘から手を離せ」と同じ）
   - 赤城に近づく → 選択肢（下の表）
   - 何もしない → 琴吹が割り込む（4b へ）
4. 分岐
   - 4a 「娘から手を離せ」：赤城が手下に任せ、般若党4人と戦う（`0x3788` = 1）
     - 30秒以内に4人を倒す → 赤城と戦う。続けてメリンダ、琴吹と3連戦（下の「3連戦」）
     - 30秒以内に倒せない → そのまま4人を倒すと結末 B
   - 4b 琴吹が割り込み「一緒にあいつらを倒そう」と言う。選択肢（下の表）で味方する側を決める
     - 「助太刀いたす」：琴吹・同心と組み、赤城・般若党と戦う（`0x3788` = 1）。赤城の命を4割まで減らすか、般若党4人を倒すと結末 C
     - 「犬は好かん」または無言：赤城・般若党と組み、琴吹・同心と戦う（`0x3786` = 1、`0x3788` = 0）。琴吹の命を4割まで減らすか、同心4人を倒すと結末 D
     - どちらでも、味方の赤城・琴吹は命が1割まで減ると戦いを抜ける
5. 結末（下の「結末」）

### チュートリアルの進み方（`0x37AA`）

| 周回 | 朱美への返事 | 戦い方 | `0x37AA` | 確度 |
|---|---|---|---|---|
| 1周目 | （選択肢なし） | 1人ずつ3回。朱美の助言つき | 1 | 🟢 |
| 2周目 | 「何をすればいい？」 | 同上 | 1 | 🟢 |
| 2周目以降 | 「口出し無用」 | 1人ずつ3回。助言なし | 2 | 🟢 |
| 3周目以降 | 「まとめて相手をしてやる」 | 般若党6人とまとめて戦う（10人倒すか5分で次へ）。`0x3788` = 1 | 0 | 🟢 |

### チュートリアルの助言

チュートリアル（`0x37AA` = 1）の戦いの始めに6つの出口のフラグを 0 にし、戦いの中で次の状況になると朱美が助言して、そのフラグを 1 にする。1 になった助言は二度出ない。
どの状況とどのフラグが組になるかは、助言の並びからの推定（🔶）。フラグが 1 になること自体は 🟢。

| 状況 | 朱美の助言 | 1 になるフラグ |
|---|---|---|
| 戦いが3分続く | しっかりして、と励ます | `0x3767`（通し番号 191） |
| 2回攻撃を受ける | 攻めるだけでは駄目、と言う | `0x376D`（通し番号 197） |
| 命が8割まで減る | 危ない、と言う | `0x3774`（通し番号 204） |
| 命が4割まで減る | 足元にアイテムを3つ置く（種類は ❓） | `0x3776`（通し番号 206） |
| 武器の耐久が9割まで減る | 気をつけて、と言う | `0x3777`（通し番号 207） |
| つま斬りのゲージが半分たまる | 今よ、と言う | `0x377A`（通し番号 210） |
| 3回目の戦いに勝つ | 褒める。`0x3776` が 0 なら説明の画面を出して 1 にする | `0x3776` |

### 3連戦（「娘から手を離せ」で4人を素早く倒したとき）

| 段階 | 相手 | 次へ進む条件 | フラグ |
|---|---|---|---|
| 1 | 赤城と般若党（大砲の2人を含む） | 赤城の命を1割まで減らす | 大砲の2人を倒すと `0x379F` = 1、`0x3788` = 1（戦いは続く） |
| 2 | メリンダ（「ジョーイ 覚悟」と割り込む） | メリンダの命を1割まで減らす | 戦い始めに `0x3787` = 1 |
| 3 | 琴吹（助太刀に来る） | 琴吹の命を1割まで減らす | 戦い始めに `0x3786` = 1 |

3連勝したとき `0x379F` = 1 なら大砲の結末、0 なら結末 A。
