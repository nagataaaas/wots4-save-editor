# 願い虚しく（Wasted Wish）

## 流れ

1. 剣術大会のあと、領事館に入ると、ローラと J.J（伯爵）が般若党と魔鱗組の抗争を話している。伯爵は優勝を祝い、外で一服すると出て行く
2. 伯爵は外で三姉妹との結婚を夢見て浮かれているところを攘夷志士に斬られ、「攘夷……に……やられ……たよ」と言い残して死ぬ
3. ローラが伯爵の死を嘆く。主人公の返答で分かれる
   - 「伯爵の仇をとろう…」「これでは彼も死に切れまい…」：ローラは報復を止め、般若党の赤城烈斗に会談の手紙を届けてほしい（会談に応じるなら中央広場で待つ）と頼む。重要品の手紙を得て `0x36E0`（通し番号 56）= 3
   - 「しばらくそっとしておくか」：`0x36E0` = 2 でその場は終わる。次に領事館へ来るとローラとの会話からやり直す
4. 神社に行くと洞窟前に般若党の門番が立ち、神社の門が開いている（`0x36E0` = 3 のとき）。門番に手紙を渡す
5. 領事館のローラに報告すると「では 参りましょうか」。段階が 510、時間帯が夕になり、大通りの場面へ移る
6. 大通りでローラが赤城に話し合いを求めるが、赤城は「話す必要は無い」と拒み、戦闘になる
   - 味方：メリンダ（死んでいれば新隊長）・海兵隊・パツキン隊。敵：赤城・般若党、小暮（`0x374F`（通し番号 167）が 0 のとき）
   - 前半：敵を10人倒すか、赤城・小暮の体力を半分まで削ると、般若党が大砲を持ち出す
   - 後半：大砲の般若党も含めて全滅させるか、360 秒たつと終わる。赤城は倒れると「志士の魂は不滅……」と言い残す
7. 戦闘が終わるとそのまま[鬼怒川の魔手](foreigners__after_tournament__kinugawas_evil_influence.md)の場面になり、そこで `0x36E0` = 4（成功）になる

- ❓ 戦闘中に小暮を倒した場面で `0x374F`（小暮）が 0 になる。死亡を表す 1 ではない。意味は分からない
- ❓ 「伯爵の仇をとろう…」を選んだとき、位置の分からない値が 5 になる。意味は分からない
- [A] は「剣術大会で小暮を峰打ちにしていれば小暮も敵」と書く。大会で斬ると小暮が死に、このイベントに出ないという意味とみられる。小暮が出るのは `0x374F` = 0 のときで、0 以外なら別の人物が代わりに出る（🟢）。
  ただし[剣術大会（外国）](foreigners__4_day__battle_tournament_foreigners.md)の3回戦では、斬って勝っても `0x374F` は書き換わらない（🟢）。大会で斬ったあとのセーブで `0x374F` が 1 になっているかは要ゲーム内確認
- [A] は「大砲の砲撃手も倒す」と書く。大砲を持ち出した後半は、全滅のほか 360 秒たっても終わる（🟢）
- 大通りの戦闘から逃げたときの扱いは分からない（失敗 5 になる場面はない）。要ゲーム内確認
