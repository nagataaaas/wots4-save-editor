# ライジングサン（Rising Sun）

## 流れ

1. 2日目夜、カジノが開いているとき（`0x375E`（通し番号 182）= 0）に港のカジノに入り J.J に近づくと、「キミはボクと同じ種類の人間だ」と誘われる（外国と敵対していず、`0x36C0`（通し番号 24）が 0 以下のとき）
   - 断ったあと（`0x36C0` = 2）にもう一度近づくと「戻ってきたね？」となり、同じ誘いを受ける
   - 外国と敵対している（`0x3787` = 1）と「謝罪でもしに来たのかい？」となる。「ああ すまなかった」で許してもらえ、同じ誘いを受ける
2. 誘いに乗ると博打の場面になる（何度か台詞を選べるが結果は変わらない）
3. 赤城・小暮と般若党が「悪の巣窟の元締め」を斬りに殴り込んでくる。J.J に相手をしてみるかと聞かれる
4. 「腕がなる…」か無言で、`0x36C0` = 3・外国との敵対状態 0 になり、J.J・用心棒・ディーラー・客の側について、赤城・小暮・般若党3人との戦闘になる（無言のときは赤城に仲間割れと見なされる）
   - 赤城か小暮の体力が1割まで減ると、般若党は退却して成功（`0x36C0` = 4）。J.J から 1500 文をもらう
   - J.J は体力が4割まで減ると戦線を離れる
5. 「知らん！無関係だ！」を選ぶと、J.J に見限られて失敗（`0x36C0` = 5）。外国の対立ポイント が 1 増え、外国と敵対する
6. 抜刀して J.J に近づくと「そんな殺気立ってないで」と言われる。「それもそうだな」で納刀して終わる。「売上金をよこせ」（外国と敵対中は抜刀して近づくだけで）で用心棒2人との戦闘になる。外国と敵対するが、イベントの状態は変わらない
