# 武士の魂（The Samurai Spirit）

## 流れ

1. [領事館斬り込み](prajna__after_tournament__raiding_the_consulate.md)で J.J を倒すと、続けて始まる（`0x36E7`（通し番号 63）= 3）
2. 代官の琴吹が三姉妹と魔鱗組を連れて現れ、英国との戦争を招くと赤城を責める。赤城は戦争こそ攘夷の炎を燃え上がらせると譲らず、戦闘になる
3. 琴吹・万由・千佳・百合の4人を倒すと勝利。魔鱗組の雑兵も出る
4. 4人を倒すと成功（= 4）。赤城たちは「ついに勝ったぞ」と喜ぶが、赤城は英国が攻め寄せて来ると言い、そのまま結末の[攘夷の炎](prajna__ending__the_flames_of_prajna.md)へ続く

戦闘中に赤城・小暮の体力が減ると、二人は戦闘から外れて見物に回る。戦闘の場から離れようとすると、立ち去るかどうかを聞かれる。

## 選択肢

| 場面 | 選択肢 | 結果 |
|---|---|---|
| 戦闘の場から離れようとしたとき | 「逃げるが勝ちだ」「やってられるか」「用事を思い出した」「さようなら」「逃げる！」のどれか（毎回ランダムに1組） | 戦闘から離れる（その後の扱いは ❓） |
| 同上 | 「まだまだやれる！」「かかって来い！」「こっちじゃなかった」「間違えた」「なんのこれしき」のどれか | 戦闘に戻る |
