# 大老　鬼怒川怨仙（Chief Minister Onsen Kinugawa）

## 流れ

1. 3日目以降（4日目以降を含む）に、まだこのイベントを見ていなければ、大通りに入ったときに始まる。時間帯は問わない
2. 町人たちが大老の噂をしているところへ「下に 下に」と行列がやって来る。鬼怒川怨仙が琴吹に迎えられ、
   魔鱗組と自分が治安回復に当たると告げる
3. 行列の間に、ヤジを飛ばす選択肢が2回出る（フラグは変わらない。鬼怒川の反応が乱数で変わる）
4. 行列の前で刀を抜くと、同心に咎められて選択肢が出る（下の表）
5. 鬼怒川が、翌日この広場で剣術大会を開き、勝った者を魔鱗組に取り立てると告げる。赤城・小暮、J.J. がそれぞれ反応して終わる（`0x36C4` = 4）
6. 失敗：斬りかかると魔鱗組10人・同心2人と戦闘になる。全員倒すか、逃げるか、地図の外へ出ると終わり、
   `0x36C4` = 5、幕府の友好度 − +1、幕府と敵対（`0x3786` = 1）

成功・失敗のどちらでも、段階 400（4日目以降）の昼に起きたときは時間帯を夕に進める。

## 選択肢

| 場面 | 選択肢 | 結果 |
|---|---|---|
| 行列（1回目） | 「よ！大老！」「いいぞー！」「偉そうだぞー！」 | 鬼怒川が反応するだけ |
| 行列（2回目） | 「よ！待ってました！！」「金返せ！！」「帰れ！帰れ！」 | 同上 |
| 刀を抜いて咎められる | 「失礼いたした」「冗談だ」、または刀を納める | 何も起きずに続く |
| 同上 | 「隙ありー！」、または無言のまま | 魔鱗組・同心と戦闘（失敗） |
