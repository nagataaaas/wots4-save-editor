# 講師ご到着（The Lecturer Arrives）

## 流れ

1. 2日目夕、語学所が閉鎖中（`0x375F` = 0）のときに町の語学所前で茂呂茂に話しかけると、英国から来る講師の護衛を頼まれる
   - 断ったあと（状態 2）は「おっ 気が変わったのか」から選び直せる
   - 幕府と敵対中は「俺に何か用か」と言われる。「すまなかった」なら許されて頼みに戻る。「悪趣味な帽子だな」なら追い払われる（状態は変わらない）
   - 武器を抜いていると「何の真似だ」と言われる。「死ね！茂呂！」と答えるか茂呂を攻撃すると（敵対中は武器を抜いただけで）「馬鹿かこいつは」と失敗
2. 「暇だ」で状態が 3 になり、幕府との敵対が解ける。語学所について茂呂に質問できる（「語学所とは何だ？」など。結果は変わらない）
3. 港で講師を迎え、町の語学所まで護衛する。途中で赤城・小暮と般若党が襲ってくる。メリンダが生きていればメリンダも護衛に加わる
   - 赤城・小暮は命が 1 割を切ると引き上げる。琴吹・茂呂も戦闘に加わり、命が 4 割を切ると戦闘から外れる
   - この戦闘でメリンダが死ぬことがある（`0x3759` = 1）
4. 結末
   - 講師が語学所に着く：語学所開設、1500 文、幕府 +1
   - 講師が殺される：語学所は閉鎖のまま、500 文。幕府の友好度は上がらない
   - どちらも状態は 4 になり、攘夷の対立ポイント1、攘夷と敵対
