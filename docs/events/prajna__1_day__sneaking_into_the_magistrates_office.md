# 代官所潜入（Sneaking into the Magistrate's Office）

## 流れ

1. 1日目夜、神社で赤城に近づくと「代官所に忍び込んで武器弾薬をごっそり頂く。奪った武器の数だけ報酬をやる」と誘われる
   - 攘夷と敵対中（`0x3788`（通し番号 224）= 1）は「何しに来た」と迎えられ、謝ると改めて誘われる
2. 参加すると `0x36B4`（通し番号 12）= 3、攘夷との敵対状態が解ける。般若党と代官所へ向かう（盗んだ武器 `0x37AC`（通し番号 260）= 0）
3. 蔵に入ると潜入が始まる（`0x37AF`（通し番号 263）= 1）。制限時間は 3 分。蔵の武器の木箱を運び出しの場所まで運ぶたびに `0x37AC` +1
4. 終わり方は3つ
   - 3 分が過ぎる、または木箱を持たずに運び出しの場所へ戻って「よし！帰ろう」を選ぶ（`0x37AE`（通し番号 262）= 1）→ 成功（`0x36B4` = 4）。盗んだ数で報酬が決まる
   - 見張りに 3 回見つかる（`0x37AD`（通し番号 261）が 3）、または見張りが運び出しの場所に来る → 「曲者だッ」と捕り方に囲まれる。幕府の友好度 −・敵対。退却して失敗（`0x36B4` = 5）、100 文だけ渡される
5. 終わったあとの場で般若党に斬りかかると、般若党 25 人との戦闘になる。攘夷の友好度 −・敵対。成功していても `0x36B4` = 5 になる
6. 抜刀して赤城に近づいて「お前は死ぬべきだ」を選ぶ、敵対中に「さっさとくたばれ！」を選ぶ、般若党に斬りかかると、神社で般若党と戦闘になる。
   赤城・小暮は4割で退く。全員を倒すか逃げると失敗し、攘夷と敵対する
