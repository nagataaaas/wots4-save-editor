# 刃・鍔の ID のゲーム内確認

- 日付：2026-10-05
- 目的：資料ごとに食い違う、または資料にない刃・鍔の ID を、ゲーム内の表示で決める（U-10、U-13、特殊武器の刃）
- 環境：Steam版、0x48BB0

判定前の状況：
- U-10：未登録パーツの名前と ID が元の Claude ノート（Cheat Engine テーブル [CT] 由来）と ChatGPT ノート（数値規則からの推測）で食い違っていた（貫誠 55／59、ID 296 が浮雲小太刀／凍雲小太刀、焔魔 308／307、竹富士の刃 3）
- U-13：[TS] で確定した刃 304〜316（D-14）と、Claude の CSV の残りの行（焔魔 308、立奈美 310、見栄春 311、大天狗 312、イプスカリバ 315）が重なっていた。
  案A：CSV の 305〜316 全体が +1 ずれている ／ 案B：個別に決める

## 結論

- 特殊武器の刃は 0x00〜0x0B の12件ですべてとする（ユーザー判断 2026-10-05。0x0C 以降はない）
- 竹富士は特殊武器の刃 0xFF0003。[CT] の「竹富士の刃＝3」は特殊武器の刃の下位16ビットで、通常の刃 3 は不採用
- U-13 は案A：[CT] の刃 305〜316 は +1 ずれている。焔魔 307、立奈美 309、見栄春 310、大天狗 311、イプスカリバ 314
- [CT] の 308＝焔魔、鍔 362＝夜葬は誤記。夜葬の鍔は 359
- U-10 は [CT] の値を採用（貫誠 55、ID 296＝浮雲小太刀）。貫誠・浮雲小太刀の名前はゲーム内で未確認
- 霊禍の鍔は 340（[CT] と一致）
