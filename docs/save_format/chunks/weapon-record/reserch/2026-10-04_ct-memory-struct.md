# Cheat Engine テーブルの構造体との対応

- 日付：2026-10-04
- 目的：Cheat Engine テーブル [CT] の武器構造体のフィールドを、セーブの武器レコードに対応づける
- 環境：ユーザー提供の `WayOfTheSamurai4.txt`（Cheat Engine 7系、Shinkansen 系の "Char Info" テーブル。Steam V1006）

## サンプル

| ファイル | 操作 | ベースからの差分 |
|---|---|---|
| — | 実行中メモリの構造体の定義を読んだだけ。セーブは使っていない | — |

## 差分

[CT] のメモリ構造体（実行中メモリ。セーブとは並びが違う）：

| メモリ内オフセット | 内容 | 型 |
|---|---|---|
| +0x2E | 刃 | u16 |
| +0x30 | 不明（刃と同じID表を使う） | u16 |
| +0x32 | 鍔 | u16 |
| +0x34 | 柄 | u16 |
| +0x3C | 攻撃力 | u16 |
| +0x3E | 最大耐久 | u16 |
| +0x40 / +0x42 | 質（現在／最大） | u16 |
| +0x4A〜+0x54 | 魅力1〜3（ID / 個数） | u16 |
| +0x58 | 現在の耐久 | u16 |
| +0x5C | 耐久回復の累積 | u32 |
| +0x64 | 武器名 | 文字列 |
| +0x8C | 銘の文字列 | 文字列 |
| +0xB6 | 銘ID | u16 |
| +0xDC | 斬殺数 | u16 |
| +0xDE | 斬殺数（魂技） | u16 |

セーブ（+0x00〜+0x9F）との対応：

| 比較 | メモリ | セーブ | 一致 |
|---|---|---|---|
| 刃〜柄 → 攻撃力の距離 | +0x2E → +0x3C（0x0E） | +0x08 → +0x16（0x0E） | ✅ |
| 攻撃力 → 最大耐久 → 質 → 質の最大値の並び | +0x3C〜+0x42 | +0x16〜+0x1C | ✅ |
| 攻撃力 → 魅力1の距離 | 0x0E | 0x0E | ✅ |
| 現在の耐久・耐久回復の累積・銘・斬殺数の並び | — | — | 一致しない |

## 結論

- メモリの +0x30（刃と同じID表を使う不明な値）はセーブの +0x0A（X）に当たると考えられる（🔶）。[CT] がクルセイダーの刃を 313（0x139）としているのは、X の値 0x139 を刃として載せた可能性がある
- 後半（現在の耐久〜斬殺数）はセーブで別の順序に直列化されている
- メモリの +0xDE「斬殺数（魂技）」から、セーブの +0x9E を魂技による斬殺数と推定した（🔶）
- [CT] はフィールド一覧と ID 表としてだけ使う
