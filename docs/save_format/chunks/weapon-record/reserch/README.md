# 武器レコード に関する調査

- `./2026-10-04_ct-memory-struct.md`: Cheat Engine テーブルの実行中メモリの構造体と、セーブのレコードの並びを比べた。前半（パーツ〜魅力）は相対位置が一致、後半は並びが違う
- `./2026-10-05_title-bytes.md`: 銘「人斬り」のバイト列を調べた。`6A 01 00`（ほかの19種と同じ規則）で、[TS] の `00 6A 01` は誤り（U-2）
- `./2026-10-05_weapon-type.md`: 武器種の位置を調べた。+0x1E の u8（U-8）
- `./2026-10-05_signed-values.md`: 攻撃力・耐久・質を負の値にし、斬殺数を上限まで上げた。i16 と u16 と判明
- `./2026-10-05_sheath-x.md`: パーツ領域の X を調べた。X は鞘の ID で、刃で決まる（U-3）
- `./2026-10-05_blade-ids.md`: 特殊武器の刃、刃 ID 300番台、霊禍・夜葬の鍔をゲーム内で確かめた（U-10、U-13）
- `./2026-10-07_complete-ids.md`: 完成武器ID の表をサンプルのセーブで確かめ、[TS] の表のずれ（31・94 以降）を直した。浮雲小太刀・凍雲小太刀の名前の入れ替わりを直した。夜葬の鍔は 362 と確かめた（U-10、U-15）
- 買い物・帯刀の切り替え・峰打・二刀流の差分（+0x86・+0x8A の発見）は stats chunk の README を参照
