# 武器種の位置

- 日付：2026-10-05
- 目的：武器種（0＝刀、1＝槍、2＝爪、3＝拳銃、4＝ライフル。値は Wiki [W-PC]）がレコードのどこにあるかを決める（U-8）
- 環境：Steam版、0x48BB0

判定前の案：案A：+0x00〜+0x05 のどこか ／ 案B：独立したフィールドはなく、完成武器IDや刃IDから導く。
Wiki の「武器名の1行上の +0xC」をレコードに当てはめると、帯刀[0] では魅力2の個数（+0x2A）になり矛盾した。

## サンプル

| ファイル | 操作 | ベースからの差分 |
|---|---|---|
| `sample/S4-DATA_02 copy 2` | 帯刀に刀・槍・拳銃を置いた | — |
| `sample/` の全サンプル | 武器レコード全件を読んだ | — |

## 差分

| 位置 | 値 | 解釈 | 確度 |
|---|---|---|---|
| 帯刀[0]〜[2] `+0x1E` u8 | 0（刀）・1（槍）・3（拳銃） | 武器種 | ✅ |
| 全サンプルの `+0x1E` | 槍のレコードだけが 1 | | ✅ |
| `+0x1F` | 常に 0 | | ❓ |

## 書き込みの確認

- 5種（0〜4）を書き、ゲーム内でそれぞれの武器種として表示されることを確認した

## 結論

- 武器種は +0x1E の u8（U-8 の案A・案B どちらでもなかった）
- エディタでは上級者モードでだけ変更できる。パーツと合わない武器種にしたときの動作は ❓
