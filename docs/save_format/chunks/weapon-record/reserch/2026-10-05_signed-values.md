# 数値フィールドの型

- 日付：2026-10-05
- 目的：攻撃力・耐久・質・斬殺数を [TS] どおり u16 として扱ってよいか確かめる
- 環境：Steam版、0x48BB0

## サンプル

| ファイル | 操作 | ベースからの差分 |
|---|---|---|
| `sample/` のコピー | 攻撃力・耐久（現在・最大）・質（現在・最大）の型を [U] が確かめた（操作の詳細は記録なし） | — |
| `sample/` のコピー | 斬殺数を 65535 にして、ゲーム内で1人斬った | +0x9C |

## 差分

| 位置 | 前 → 後 | 解釈 | 確度 |
|---|---|---|---|
| `+0x16`・`+0x18`・`+0x1A`・`+0x1C`・`+0x92` | — | 符号付き（i16）と [U] が判断 | ✅ |
| `+0x9C` | 65535 → 0 | 1人斬ると 0 に戻った。u16 | ✅ |

## 結論

- 攻撃力・最大耐久・質・質の最大値・現在の耐久は i16（−32,768〜32,767）。[TS] は u16 としていた
- 斬殺数は u16（0〜65,535）
- +0x9E は斬殺数と同じ u16 と推測（🔶、未確認）
- エディタは通常モードではゲーム上の範囲（攻撃力 ≤ 500、耐久 ≤ 2000、質 ≤ 21）、上級者モードでは型の範囲まで許可する
