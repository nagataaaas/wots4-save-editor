# パーツ領域の X（鞘）

- 日付：2026-10-05（区切り方の決着は 2026-10-06）
- 目的：パーツ領域 +0x08〜+0x0F の区切り方と、刃と鍔の間にある値 X の意味を決める（U-3）
- 環境：Steam版、0x48BB0

判定前の案：
- 案A：[TS] 準拠（刃 3 B＋鍔 3 B＋柄 2 B。既知パーツだけを3バイト値で書く）
- 案B：2 B×4 で刃・鍔・柄を u16 で書き、X は保持
- 案C：案B に加えて X を規則で計算

8バイトを u16 LE ×4 で区切ると自然に読める（元の ChatGPT ノートの仮説）：

```text
一文字： 45 00 | 5C 00 | 7F 00 | 7E 00
         0045  | 005C  | 007F  | 007E
         刃 B  | X     | 鍔 G  | 柄 H
```

[TS] の刃の値 Y、鍔の値 T からの換算：

```text
B = Y & 0xFFFF
G = (T >> 8) & 0xFFFF
X = ((Y >> 16) & 0xFF) | ((T & 0xFF) << 8)
```

| 名前 | B | X | G | H |
|---|---|---|---|---|
| 中道刀 | 0006 | 0018 | 000D | 000C |
| 一文字 | 0045 | 005C | 007F | 007E |
| クルセイダー | 0138 | 0139 | 00A1 | 00A0 |
| なまくら刀 | 013B | 0018 | 013D | 013C |
| 珍比羅 | 0147 | 0146 | 0148 | 0149 |
| 陸奥守吉行 | 0157 | 0158 | 015A | 0159 |
| 虎徹 | 0164 | 0161 | 015C | 015B |

[TS] の定義から見た X の規則（🔶）：通常系（B＝0x3F〜0x52）では `X = B + 0x17`（14件中13件。例外は藤奈美 0x9E）、
色違い系（B＝0x109〜0x134）では `X = B − 0x5D`（24件中24件。下位バイトだけの比較）。

- なまくら刀の X 0x18 は中道刀と同じ。見た目の鞘が同じ武器どうしで X が一致している
- 刃が同じ鍔（中道刀）でも X が違うので、X は刃で決まる
- 特殊武器は刃の3バイト目と鍔の1バイト目が `FF` なので、X は 0xFFFF

## 書き込みの確認

- 鞘（X）だけを別の鞘の値に書き換えると、ゲーム内の鞘が変わった（[U] 2026-10-05）
- X＝0xFFFF を書くと鞘なしになった（[U] 2026-10-05）
- [TS] の 3 B 値のまま書くと X の上位バイト（+0x0B）が前の武器のまま残る。和泉守兼定（X 0x162）の上に柾重を書くと X 0x1CD になり、「表にない鞘」と出た（[U] 2026-10-05）

## 結論

- X は鞘の ID。刃によって決まる
- パーツ領域は 2 B×4（刃・X・鍔・柄）で書く（U-3。ユーザー判断で決着 2026-10-06）。刃は ID と X を組で書く
- X が 0x100 以上の刃（クルセイダー 0x139・珍比羅 0x146・陸奥守吉行 0x158・虎徹 0x161・和泉守兼定・活火山・夜葬）は [TS] の 3 B 値では表せない
- [CT] にしかない刃のうち、規則で X を計算したものはゲーム内で未確認（🔶。U-3 案C、ユーザー判断 2026-10-05）。値は `src/save/weapon-ids.ts` と同じ：
  0x57 龍魔治、0x61 斬鬼丸、0x62 馬通一、0x64 凍雲小太刀、0x65 赤マムシ、0x66 村柾、0xB1 絶海、0xB2 奮発丸、0xB4 賢皇骨、0xB5 鮫肌九、0xB6 大樽生、
  0xB8 マサトシ、0xB9 真啓通、0xBA 粋逸、0xBB 断頭、0xBC 霊禍、0xBD ジョアンナ、0xBE 砕苦論、0xBF 零魂磨、0xC0 チーフテン、0xC1 斗壱、
  0xC7 迦楼羅、0xCB 浮雲小太刀、0xCC 毒マムシ、0xD2 二心
- これで [CT] にある刃はすべて X が分かった。値は `datatable/weapon/blade.csv` の `sheath_x`
