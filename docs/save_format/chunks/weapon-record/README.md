# 武器レコード

帯刀中・武器袋・武器箪笥の武器。1件 0xA0 バイトの固定長レコードで、3つの範囲が同じ構造を使う。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x00A4C2` | ✅ |
| 終了（含む） | `0x0129ED` | ✅ |
| サイズ | 0xA0 × 213件（隙間 8 B・4 B を含む） | ✅ |
| 位置の求め方 | [TS] の固定オフセット（U-1 判定待ち）。アンカー探索の目安は、0xA0 周期で攻撃力・耐久・魅力が妥当な値のレコードが続く場所 | ✅位置 ／ ❓探索（[U-1](../../../check-diff.md#u-1)） |
| 妥当性検証 | 全レコードで攻撃力 ≤ 500、耐久 ≤ 2000、魅力の個数合計 ≤ 3 | ✅ |

```text
帯刀中[n]   = 0xA4C2 + n * 0xA0   （n = 0〜2）
武器袋[n]   = 0xA6AA + n * 0xA0   （n = 0〜9）
武器箪笥[n] = 0xACEE + n * 0xA0   （n = 0〜199）
```

- 帯刀中の末尾（0xA6A1）と武器袋の先頭の間に 8 B、武器袋の末尾（0xACE9）と武器箪笥の先頭の間に 4 B の隙間がある ✅
- 帯刀中と武器袋の間の 0xA6A8〜0xA6AF は帯刀の状態（[belt-state](../belt-state/README.md)）。武器袋[0] の +0x00〜+0x05 と重なる 🔶
- 武器箪笥の200件は「武器箪笥 四」まで解放したときの件数。未解放時に200件分の領域があるかは ❓
- 帯刀中の3件は [belt-copy](../belt-copy/README.md) にコピーがある 🔶

### パーツ（+0x08〜+0x0F）

- 2 B × 4（刃・X・鍔・柄、各 u16 LE）として読み書きする ✅（[U-3](../../../check-diff.md#u-3)）
- X は鞘の ID で、刃によって決まる ✅。見た目の鞘が同じ武器どうしで同じ値になる。刃の ID からの規則で計算できない刃がある（規則と例外は blade.csv の `sheath_x` と備考）
- 特殊武器の刃は X が `0xFFFF`（刃の下位16ビットが ID）✅。特殊武器には鞘・鍔・柄の部品がなく、X・鍔・柄はすべて `0xFFFF` ✅
- 書き込みは刃 ID と X を組で書き、鍔・柄は ID だけを書く
- [TS] の 3 B 値（刃 3 B＋鍔 3 B＋柄 2 B）で書くと X の一部だけが書き換わるので使わない。既知パーツを揃えて書いたバイト列は [TS] の 3 B 値と同じになる
- ID 空間・並びの規則・未登録パーツは [datatable/README.md](../../datatable/README.md)

### 魅力（+0x24）

1組 4 B（魅力ID u16＋個数 u16）× 3組 ✅。魅力ID は [魅力](../../datatable/weapon/charm.csv)。

| 位置（+0x24 から） | 型 | 内容 |
|---|---|---|
| +0 / +2 | u16 / u16 | 1つ目の魅力ID / 個数 |
| +4 / +6 | u16 / u16 | 2つ目の魅力ID / 個数 |
| +8 / +10 | u16 / u16 | 3つ目の魅力ID / 個数 |

- 空いている組は `FF FF 00 00`
- 組の並び順は自由
- 読み出し：同じIDが2組に分かれた形も受け付ける
- 書き込み：同じIDを1組にまとめて個数で表し、使う組を前に詰める（例：重撃×2・活復×1 → `09 00 02 00 | 04 00 01 00 | FF FF 00 00`）

### 銘（+0x96）

- 形式：`<銘ID下位> 01 <番号>`。銘ID＝0x016A＋番号（u16 LE）✅
- 銘なしは `FF FF FF`
- 値は [銘](../../datatable/weapon/title.csv) の `save_bytes_le`

### 固有武器の6バイト

固有武器（流派の秘伝を持つ武器）の +0x10〜+0x15 にあるバイト列。位置・バイト列は ✅（[U-9](../../../check-diff.md#u-9)）、各 u16 の意味は 🔶。

## 編集時の注意

- 通常モードはゲーム上の範囲で拒否し、上級者モードのときだけ型で書ける範囲まで許可する
- 魅力の個数の合計は3以下（4以上で箪笥を開けなくなった報告あり）
- 武器名は17文字まで（[U-5](../../../check-diff.md#u-5)）。UTF-16LE の固定長フィールドを上書きする
- 武器袋[0] の +0x00〜+0x05（0xA6AA〜0xA6AF）は帯刀の状態と重なるので書き換えない
- 武器種は上級者モードでだけ変更できる。パーツと合わない武器種にしたときの動作は ❓
- 銘「人斬り」は `6A 01 00`。[TS] の定義値 `00 6A 01` は未知の銘として扱う（[U-2](../../../check-diff.md#u-2)）
- 完成武器のデフォルト名を書き換えても、帯刀すると元に戻るという報告がある（Wiki）
- 完成武器に変更するときは、+0x06・+0x08〜+0x15・+0x1E・+0x20・+0x22・+0x72・+0x74 をその完成武器の値（complete.csv）にそろえる。
  攻撃力・耐久・質・魅力・名前・銘などは変えない
