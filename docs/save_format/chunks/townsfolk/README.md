# 町の人の状態

店主など町の人ごとの状態（生死、鍛冶屋の後継者イベントの進み方など）を持つと考えられる u8 の並び。
ほとんどのバイトが 0 で、意味の分かったバイトが散らばっている。重要人物の生死は別の場所（[characters](../characters/README.md)）にある。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x000100` | ❓（主人公名 `0x00DC`〜`0x011B` と重なる。0 以外の値が見つかっているのは `0x0127` 以降） |
| 終了（含む） | `0x0005FF` | ❓（`0x04C0`〜`0x0B2F` は、手元のサンプルでは `0x0528` 以外すべて 0） |
| サイズ | 1,280 B（u8 の並び） | 🔶 |
| 位置の求め方 | 固定（[U-1](../../../check-diff.md#u-1)） | ❓ |
| 妥当性検証 | ファイルサイズが 0x48BB0 | 🔶 |

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x0127` | 1 B | u8 | 鍛冶屋の後継者イベントと鍛冶屋の状態 | 下の表 | ✅ |
| `0x012C` | 1 B | u8 | 用途不明（0 以外の例がある） | | ❓ |
| `0x0130`〜`0x0131` | 2 B | u8 | 用途不明（0 以外の例がある） | | ❓ |
| `0x0132` | 1 B | u8 | 堂島が鍛冶屋を継いだ | 1＝継いだ。説得に成功する（`0x0127`＝70）と 1 になる。周回をまたいで残る | ✅ |
| `0x0133` | 1 B | u8 | 用途不明。海兵隊の横暴で成否によらず立つ | 0／1 | ❓ |
| `0x0137`〜`0x013B` | 5 B | u8 | なりわいの操作ごとに1つずつ 0 → 1 になる（虎徹の会話、虎徹・薬売り・食い逃げ・おにぎりのクリア）。[occupation](../occupation/README.md) | 0／1 | ❓ |
| `0x01E0`・`0x0258` | 1 B | u8 | 用途不明（0 以外の例がある） | | ❓ |
| `0x0264` | 1 B | u8 | 堂島の死亡 | 1＝死亡 | ✅ |
| `0x02C4` | 1 B | u8 | 寿司屋の店主の死亡 | 1＝死亡。0 に戻すと生き返る | ✅ |
| `0x0444` | 1 B | u8 | 鍛冶屋のおやじ（堂島ではない）の死亡 | 1＝死亡。0 に戻すと生き返る | ✅ |
| `0x0528` | 1 B | u8 | さよ（DLC）の死亡 | 1＝死亡 | 🔶 |

上の表にないバイトは用途不明（❓）。

### 鍛冶屋の状態（`0x0127`）

| 値 | 状態 |
|---|---|
| 0 | 未会話 |
| 10 | 「そろそろやめる」という会話を聞いた |
| 20 | 堂島を探してくる |
| 30 | 鍛冶屋を継げ → 堂島の意志は固かった |
| 40 | 鍛冶屋の過去を知った |
| 50 | 堂島が鍛冶屋を拒むわけを知った |
| 60 | もう一度、堂島を説得してみよう |
| 61 | 堂島はおとなしくなった |
| 69 | 夢があった（会話後） |
| 70 | 堂島の説得に成功した（`0x0132` が 1 になる） |
| 81 | 堂島の鍛冶屋 |
| 110 | 鍛冶屋のおやじから踏み倒した |
| 119 | 堂島から踏み倒した |
| 120 | 堂島が死亡 |

- `0x0132` が 0 のまま周回すると、`0x0127` が 81 でも鍛冶屋はおやじに戻る ✅
- 表にない値（例：1）が入っているセーブがある ❓

## 編集時の注意

- 意味の分かっていないバイトは生の値として表示し、値の表から選ばせない

## 未確認・判定待ち

- ❓ 範囲の始まりと終わり。人ごとの並び（`0x02C4` と `0x0444` の間隔は 0x180）
- ❓ さよの死亡フラグを 0 に戻して生き返るか
- ❓ 生死・好感度は周回ごとにリセットされる（ゲームの仕様）。この表が周回開始時に初期化されるか（`0x0132` は残る）
