# 町の人の状態

店主など町の人ごとの状態（生死、鍛冶屋の後継者イベントの進み方など）を持つ u8 の並び。
先頭の `0x011C`〜 は「なりわいのフラグ」の配列で、なりわいの続き物の進み具合や、鍛冶屋・先生・堂島などの段階が入る。
その後ろはほとんどのバイトが 0 で、意味の分かったバイトが散らばっている。重要人物の生死は別の場所（[characters](../characters/README.md)）にある。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x00011C` | 🟢（直前の `0x00DC`〜`0x011B` は主人公名） |
| なりわいのフラグ | `0x00011C`〜（`0x011C + 番号`、番号 0〜31 まで確認） | ✅ 位置 ／ 終わりは ❓ |
| 終了（含む） | `0x0005FF` | ❓（`0x04C0`〜`0x0B2F` は、手元のサンプルでは `0x0528` 以外すべて 0） |
| サイズ | 1,280 B（u8 の並び） | 🔶 |
| 位置の求め方 | 固定（[U-1](../../../check-diff.md#u-1)） | ❓ |
| 妥当性検証 | ファイルサイズが 0x48BB0 | 🔶 |

## 構造

### なりわいのフラグ `0x011C`〜

`0x011C + 番号` の u8。[occupation](../occupation/README.md) の続き物の進み具合はここにある。

| 位置 | 番号 | 内容 | 値 | 確度 |
|---|---|---|---|---|
| `0x011D` | 1 | 道場の弟子・夜這いの相手などの段階 | 0〜100（例 50） | 🔶 |
| `0x011E` | 2 | 用途不明。「出頭命令」の受注で 0 → 4 | | ❓ |
| `0x011F` | 3 | 夜這いの相手などの段階 | 0〜3 | 🔶 |
| `0x0120` | 4 | 同心（171〜178）の続き物 | 下の「続き物の値」 | ✅ |
| `0x0121` | 5 | 極道（179〜186）の続き物 | 下の「続き物の値」 | 🟢 |
| `0x0122` | 6 | 泥棒さん（187〜194）の続き物 | 下の「続き物の値」 | 🟢 |
| `0x0123` | 7 | おっつぁん（195〜206）の続き物 | 下の「続き物の値」 | 🟢 |
| `0x0124` | 8 | 賭場の4件（163〜166）の進み具合 | 0・10・20・30 | 🟢 |
| `0x0125` | 9 | 賭場の女将の依頼（167〜170・208）の進み具合 | 0・1・10・20・21 | 🟢 |
| `0x0126` | 10 | 先生の段階 | 0〜99（例 80） | 🟢 |
| `0x0127` | 11 | 鍛冶屋の後継者イベントと鍛冶屋の状態 | 下の「鍛冶屋の状態」 | ✅ |
| `0x0129` | 13 | 道場の段階か | 0〜100（例 10） | 🔶 |
| `0x012C` | 16 | 用途不明 | 0／1 | ❓ |
| `0x0130`〜`0x0131` | 20・21 | 用途不明（21 は先生にも関わる） | 0／1／2 | ❓ |
| `0x0132` | 22 | 堂島が鍛冶屋を継いだ | 1＝継いだ。説得に成功する（`0x0127`＝70）と 1 になる。周回をまたいで残る | ✅ |
| `0x0133` | 23 | 用途不明。海兵隊の横暴で成否によらず立つ | 0〜3 | ❓ |
| `0x0135` | 25 | 四天王の話の進み具合 | 1＝続き物4系統（番号 4〜7）を全部終えた、8＝「四天王の証」を受け取った、99・100 | 🟢 |
| `0x0136` | 26 | 最後のなりわい（207・208）の進み具合 | 10〜20、99・100。99 以上で、続き物を終えた依頼主からなりわいを選び直せる | 🟢 ／ ✅ 99 未満のとき |
| `0x0137` | 27 | 汁部（DLC）と組んだ | 0／1 | 🟢 |
| `0x0138`〜`0x013B` | 28〜31 | 汁部の 209〜212 の結果 | 0＝破棄、1＝成功、2＝失敗を成功扱いにしてもらった（報酬なし）。報告すると 0 に戻る | 🟢 |

表にない番号は用途不明（❓）。

**続き物の値**（番号 4〜7）

| 値 | 意味 |
|---|---|
| 0 | 依頼主に会う前 |
| n0（10・20 … 80） | n 件目を依頼する前 |
| n1（11・21 … 81） | n 件目を依頼済み |
| 90・91・97・99 | 最後の件の前後 |
| 100 | 続き物を終えた |

- 書き換えると、依頼主の次の依頼が変わる。同心の続き物を 20 にすると、2件目「督促状」から始まった ✅
- 100 にしても、`0x0136` が 99 未満なら「さしあたり任せたい仕事は無い」と言われ、新しい依頼は出ない ✅
- どれか1つを終えたとき、ほかの3つがすべて 100 なら `0x0135` が 1 になる 🟢

### 鍛冶屋の状態（`0x0127`）

| 値 | 状態 |
|---|---|
| 0 | 未会話 |
| 10 | 「そろそろやめる」という会話を聞いた |
| 20 | 堂島を探してくる |
| 30 | 鍛冶屋を継げ → 堂島の意志は固かった |
| 40 | 鍛冶屋の過去を知った |
| 50 | 堂島が鍛冶屋を拒むわけを知った |
| 60 | もう一度、堂島を説得してみよう |
| 61 | 堂島はおとなしくなった |
| 69 | 夢があった（会話後） |
| 70 | 堂島の説得に成功した（`0x0132` が 1 になる） |
| 81 | 堂島の鍛冶屋 |
| 110 | 鍛冶屋のおやじから踏み倒した |
| 119 | 堂島から踏み倒した |
| 120 | 堂島が死亡 |

- `0x0132` が 0 のまま周回すると、`0x0127` が 81 でも鍛冶屋はおやじに戻る ✅
- 表にない値（例：1）が入っているセーブがある ❓

## 編集時の注意

- 意味の分かっていないバイトは生の値として表示し、値の表から選ばせない

## 未確認・判定待ち

- ❓ 範囲の終わり。なりわいのフラグの配列の終わり（番号 31 ＝ `0x013B` までは確認）。人ごとの並び（`0x02C4` と `0x0444` の間隔は 0x180）

- ❓ さよの死亡フラグを 0 に戻して生き返るか
