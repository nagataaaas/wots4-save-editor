# 町の人の状態

店主など町の人ごとの状態（生死、鍛冶屋の後継者イベントの進み方など）を持つ u8 の並び。
先頭の `0x011C`〜 は「なりわいのフラグ」の配列で、連続なりわいの進み具合や、鍛冶屋・先生・堂島などの段階が入る。
その後ろはほとんどのバイトが 0 で、意味の分かったバイトが散らばっている。重要人物の生死は別の場所（[characters](../characters/README.md)）にある。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x00011C` | 🟢（直前の `0x00DC`〜`0x011B` は主人公名） |
| なりわいのフラグ | `0x00011C`〜（`0x011C + 番号`、番号 0〜31 まで確認） | ✅ 位置 ／ 終わりは ❓ |
| 終了（含む） | `0x0005FF` | ❓（`0x04C0`〜`0x0B2F` は、手元のサンプルでは `0x0528` 以外すべて 0） |
| サイズ | 1,280 B（u8 の並び） | 🔶 |
| 位置の求め方 | 固定 | ✅ |
| 妥当性検証 | ファイルサイズが 0x48BB0 | 🔶 |

## 構造

### なりわいのフラグ `0x011C`〜

`0x011C + 番号` の u8。[occupation](../occupation/README.md) の連続なりわい（呼び方は occupation の冒頭）の進み具合はここにある。

| `0x011F` | 3 | 夜這いの相手などの段階 | 0〜3 | 🔶 |

**治安なりわい**（番号 8・9）

- 連続なりわいではなく、そのときの治安によって受けられるなりわいが変わり、何回でも受けられる（[U] 2026-10-07）

**連続なりわいの値**（番号 4〜7）

| 値 | 意味 |
|---|---|
| 0 | 依頼主に会う前 |
| n0（10・20 … 80） | n 件目を依頼する前 |
| n1（11・21 … 81） | n 件目を依頼済み |
| 90・91・97・99 | 最後の件の前後 |
| 100 | 連続なりわいを終えた |

- 書き換えると、依頼主の次の依頼が変わる。野戸仏の連続なりわいを 20 にすると、2件目「督促状」から始まった ✅
- 100 にしても、`0x0136` が 99 未満なら「さしあたり任せたい仕事は無い」と言われ、新しい依頼は出ない ✅
- おっつぁんは四天王の熊神（🟢）。`0x0136` の 1〜11 は熊神の病気と治療の進み具合（上の表）
- 4つの連続なりわいをすべて終えると、隠しなりわい「四天王対四人組」（207）を受けられる。熊神を治療すると（10 以上）、女将の話（12・15）を経て最終なりわい「阿弥浜八人衆」（208）に発展し、なりわい一覧には 208 が載る。発展しなければ 207 が載る（外部の攻略情報、[U] 2026-10-07 ／ 値の流れは 🟢）。阿弥浜八人衆は熊神が治っている前提
- 病院が閉じているときに治療の場面がどうなるかは ❓
- どれか1つを終えたとき、ほかの3つがすべて 100 なら `0x0135` が 1 になる 🟢

**汁部（DLC）のなりわい**（番号 27〜31）

- 汁部は 209 → 210 → 211 → 212 の順に頼む（🟢）。ただし、どこまで進んだかはこの配列にはなく、なりわいごとの状態で決まる。その状態は [occupation](../occupation/README.md) の記録（`0x33A4`〜、周回をまたぐ統計）ではない（記録の 209 が 5 のセーブでも、組むと 209 から頼まれた ✅）。位置は ❓
- 27〜31 は「組んでいるか」と「終えたばかりの仕事の結果」だけを持つ。結果は次に汁部と話すと消えるので、28〜31 のうち 0 以外になるのはふつう1つだけ（🟢）
- 汁部の仕事を受注すると、27 が 1 になり、受注中のなりわい（[occupation](../occupation/README.md) `0x45F4E`）にその ID、`0x45F55` に `FF` が入る。28〜31 は 0 のまま（✅ 209）

### 鍛冶屋の状態（`0x0127`）

| 値 | 状態 |
|---|---|
| 0 | 未会話 |
| 10 | 「そろそろやめる」という会話を聞いた |
| 20 | 堂島を探してくる |
| 30 | 鍛冶屋を継げ → 堂島の意志は固かった |
| 40 | 鍛冶屋の過去を知った |
| 50 | 堂島が鍛冶屋を拒むわけを知った |
| 60 | もう一度、堂島を説得してみよう |
| 61 | 堂島はおとなしくなった |
| 69 | 夢があった（会話後） |
| 70 | 堂島の説得に成功した（`0x0132` が 1 になる） |
| 81 | 堂島の鍛冶屋 |
| 110 | 鍛冶屋のおやじから踏み倒した |
| 119 | 堂島から踏み倒した |
| 120 | 堂島が死亡 |

- `0x0132` が 0 のまま周回すると、`0x0127` が 81 でも鍛冶屋はおやじに戻る ✅
- 表にない値（例：1）が入っているセーブがある ❓

## 編集時の注意

- 意味の分かっていないバイトは生の値として表示し、値の表から選ばせない

## 未確認・判定待ち

- ❓ 範囲の終わり。なりわいのフラグの配列の終わり（番号 31 ＝ `0x013B` までは確認）。人ごとの並び（`0x02C4` と `0x0444` の間隔は 0x180）
- ❓ なりわいのフラグのうち番号 2・16・20・21・23 の意味
- ❓ さよの死亡フラグを 0 に戻して生き返るか
- ❓ 生死・好感度が、`0x015C` より前のどこにあるか（下の「周回での初期化」で消えないもの）

## 周回での初期化 🟢

- 周回の終わりに `0x015C`〜`0x0B33` をすべて 0 にする（なりわいのフラグ 64 番以降に当たる）
- なりわいのフラグ（`0x011C + 番号`）は番号ごとに消える場面が決まっている

  | 番号 | 位置 | 0 にする場面 |
  |---|---|---|
  | 4〜14、18、19、24〜31 | `0x0120`〜`0x012A`、`0x012E`・`0x012F`、`0x0134`〜`0x013B` | 周回の終わり（どの終わり方でも） |
  | 23 | `0x0133` | クリア・立ち去りで終えたときだけ（死亡では残る） |
  | 1〜3、15 | `0x011D`〜`0x011F`、`0x012B` | 周回の途中で何度も（場面の切り替えとみられる 🔶） |
  | 17 | `0x012D` | 夜這いの場面で（確率で） |
  | 16、20〜22 | `0x012C`、`0x0130`〜`0x0132` | 消さない（周回をまたいで残る） |
  | 0、32〜63 | `0x011C`、`0x013C`〜`0x015B` | 上の処理では消さない |
