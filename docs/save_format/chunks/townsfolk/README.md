# 町の人の状態

前半はなりわいのフラグ（`0x011C`〜`0x015B`、u8 × 64）、後半は町の人（人物）ごとの 12 B のレコード（`0x015C`〜`0x0B33`、210 件）。
なりわいのフラグには、連続なりわいの進み具合や、鍛冶屋・先生・道場などの段階が入る。人物のレコードで使われているのは死亡のビットだけ。
重要人物の状態（イベントの進み具合）は別の場所（[characters](../characters/README.md)）にある。

**ぢぢいとの話の段階**（番号 13、`0x0129`）🟢

値は会話を聞いたあとの状態であり、東急流剣術の段そのものではない。20〜50 は流派の上達に応じた会話、60・70 は皆伝後の会話。

| 値 | 意味 |
|---|---|
| 0 | 師範でない |
| 1 | 道場の師範に任命された（弟子集めの説明・目録の受け取り前） |
| 10 | 弟子集めの説明を聞き、東急流剣術の目録を受け取った |
| 20 | 道場破りを倒すと、ぢぢいの技を覚えていくという話を聞いた |
| 30 | 東急流は家に代々伝わる技で、天奈の伝説の侍が元になり、ぢぢいはその末裔だという話を聞いた |
| 40 | 道場破りがやけに多く、その中に見知った者がいるという話を聞いた |
| 50 | 道場にはかつて大勢の門下生がいたが、いなくなってしまったという話を聞いた |
| 60 | 東急流を究めたと認められ、道場破りたちはぢぢいのかつての弟子だったという話を聞いた |
| 70 | 皆伝後に「まだまだわしの弟子はいっぱいいる」「油断するな」と言われた |

- この欄だけを書き換えても、目録の入手や技の習得は反映されない。書き換え後の会話は実際の流派の上達にも左右される（要ゲーム内確認）。
- 🔶 100 は通常の会話をしない値だが、使われる場面は未確認。通常モードの選択肢には出さない。
- 周回の終わりに 0 に戻る。

**治安なりわい**（番号 8・9）

- 連続なりわいではなく、そのときの治安によって受けられるなりわいが変わり、何回でも受けられる（[U] 2026-10-07）

**連続なりわいの値**（番号 4〜7）

| 値 | 意味 |
|---|---|
| 0 | 依頼主に会う前 |
| n0（10・20 … 80） | n 件目を依頼する前 |
| n1（11・21 … 81） | n 件目を依頼済み |
| 90・91・97・99 | 最後の件の前後 |
| 100 | 連続なりわいを終えた |

- 書き換えると、依頼主の次の依頼が変わる。野戸仏の連続なりわいを 20 にすると、2件目「督促状」から始まった ✅
- 100 にしても、`0x0136` が 99 未満なら「さしあたり任せたい仕事は無い」と言われ、新しい依頼は出ない ✅
- おっつぁんは四天王の熊神（🟢）。`0x0136` の 1〜11 は熊神の病気と治療の進み具合（上の表）
- 4つの連続なりわいをすべて終えると、隠しなりわい「四天王対四人組」（207）を受けられる。熊神を治療すると（10 以上）、女将の話（12・15）を経て最終なりわい「阿弥浜八人衆」（208）に発展し、なりわい一覧には 208 が載る。発展しなければ 207 が載る（外部の攻略情報、[U] 2026-10-07 ／ 値の流れは 🟢）。阿弥浜八人衆は熊神が治っている前提
- 病院が閉じているときに治療の場面がどうなるかは ❓
- どれか1つを終えたとき、ほかの3つがすべて 100 なら `0x0135` が 1 になる 🟢
- 野戸仏の 177 と泥棒さんの 187〜194 では、なりわいの報告のときにも番号 4・6 に値が書かれる 🟢

**汁部（DLC）のなりわい**（番号 27〜31）

- 進み具合は 28〜31 が持つ（🟢）。[occupation](../occupation/README.md) の記録（`0x33A4`〜、周回をまたぐ統計）は見ない（記録の 209 が 5 のセーブでも、28 が 0 なら 209 から頼まれた ✅）
- 汁部に話しかけると、28〜31 のうち**最初に 0 のもの**の仕事を頼む（🟢）。持っている DLC によって見る範囲が変わる：
  209・210 の DLC だけなら 28・29、211・212 の DLC だけなら 30・31、両方なら 28〜31（持っているかはセーブには入らない）
- 0 がなく、2（失敗を成功扱い）があれば、汁部が「あきらめた仕事があるよな」と言う。「まだ途中の仕事があった」を選ぶと 2 のものが 0 に戻り、その仕事を頼み直す（🟢）
- すべて 1（成功）なら、汁部は「さすがだな」「また仕事を見つけたら依頼する」と言い、もう仕事を頼まない。1 が 0 に戻ることはなく、最初から頼み直されることはない（🟢）
- 1 は標的（近藤・土方・ドナ・さよ）を倒したときに書かれる。破棄（「とりあえず今はやめておく」）は 0、「成功したことにしろ」は 2（🟢）
- 汁部の仕事を受注すると、27 が 1 になり、受注中のなりわい（[occupation](../occupation/README.md) `0x45F4E`）にその ID、`0x45F55` に `FF` が入る。28〜31 は変わらない（✅ 209）
- 話しかけたとき、209〜212 を受注中なら、次の仕事ではなく「何してんの」の会話（破棄・成功扱いの選択肢）になる（🟢）

### 生き返らせるとき 🟢

ビットを 0 に戻すだけで町に出てくるかは、人物によって違う（寿司屋・鍛冶屋のおやじは ✅ [U]、ほかは要ゲーム内確認）。

| 人物 | ビットだけで戻るか | 一緒に戻す値 |
|---|---|---|
| 店主（寿司屋・薬屋を除く）・依頼主・さよ・汁部など | 戻る | なし |
| 寿司屋（p 30） | 町には出るが、店とイベントは死んだ扱いのまま | [scenario-flags](../scenario-flags/README.md) の `0x37F9` も 0 |
| 薬屋（p 55） | 同上 | [characters](../characters/README.md) の `0x375C` も 0 |
| 重要人物（p 10〜23） | 戻らない（町に出る条件に「人物の状態 `0x3744 + p` が 0」もある） | [characters](../characters/README.md) の `0x3744 + p` も 0。状態は物語の進み具合も持つので、書き換えると物語と食い違う |
| 堂島（p 22） | 同上 | 上に加えて、鍛冶屋に戻すには職 `0x3799` となりわいのフラグ 22 も戻す |
| 先生（p 23） | 同上 | 上に加えて、道場に戻すには職 `0x379A` となりわいのフラグ 21 も戻す |

| 120 | 堂島が死亡 |

- `0x0132` が 0 のまま周回すると、`0x0127` が 81 でも鍛冶屋はおやじに戻る ✅
- 表にない値（例：1）が入っているセーブがある ❓

## 編集時の注意

- 書くのは、意味の分かったなりわいのフラグ（値の表から選ぶ）と死亡のビットだけ。範囲の生のバイトの編集欄は出さない
- エリア移動・ロードで 0 に戻るフラグ（1〜3・15）は、エディタで書いてもロードで消えるので扱わない
- 死亡のビットは bit0 だけを書き、ほかのビットは変えない。生き返らせるときに一緒に戻す値（上の表）を示す

## 周回での初期化 🟢

- 周回の終わりに人物のレコード `0x015C`〜`0x0B33` をすべて 0 にする（全員が生き返る）
- なりわいのフラグ（`0x011C + 番号`）は番号ごとに消える場面が決まっている

  | 番号 | 位置 | 0 にする場面 |
  |---|---|---|
  | 4〜14、18、19、24〜31 | `0x0120`〜`0x012A`、`0x012E`・`0x012F`、`0x0134`〜`0x013B` | 周回の終わり（どの終わり方でも） |
  | 23 | `0x0133` | クリア・立ち去りで終えたときだけ（死亡では残る） |
  | 1〜3、15 | `0x011D`〜`0x011F`、`0x012B` | 場面の切り替え（地域の読み込み）のたび |
  | 17 | `0x012D` | 道場破りが来ると決まったとき・終わったとき |
  | 16、20〜22 | `0x012C`、`0x0130`〜`0x0132` | 消さない（周回をまたいで残る） |
  | 0、32〜63 | `0x011C`、`0x013C`〜`0x015B` | 消さない（使われていない） |
