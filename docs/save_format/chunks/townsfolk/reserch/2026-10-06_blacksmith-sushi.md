# 鍛冶屋のおやじ・寿司屋の店主・さよの生死

- 日付：2026-10-06
- 目的：町の人（店主）の生死や鍛冶屋のイベントの状態が入るバイトを特定する
- 環境：Steam版、ファイルサイズ 0x48BB0

## サンプル

| ファイル | 操作 | ベースからの差分 |
|---|---|---|
| `sample/S4-DATA_02 copy 2` | ベース（同じ場所・同じ時間帯、所持金 2,600） | — |
| `sample/S4-DATA_02 copy 3` | 鍛冶屋のおやじ（堂島ではない）から踏み倒した直後 | 下表 |
| `sample/S4-DATA_02 copy 4` | copy 3 から鍛冶屋のおやじを殺害 | 下表 |
| `sample/S4-DATA_02 copy 5` | copy 4 から寿司屋の店主を殺害（同じ場所・時間帯、所持金そのまま） | 下表 |
| `sample/S4-DATA_03 copy 5` → `S4-DATA_04`／`03 copy 6` | なりわい「おにぎり屋の用心棒」で、さよを殺害（04）／生かした（copy 6） | — |

## 差分

鍛冶屋のおやじ：

| 位置 | copy 2 → copy 3（踏み倒し） | copy 3 → copy 4（殺害） | 解釈 | 確度 |
|---|---|---|---|---|
| `0x0444` u8 | 0 | 0 → 1 | 鍛冶屋のおやじの死亡。`S4-DATA_03` も 1 | 🔶 |
| `0x0127` u8 | 0 → `6E`（110） | — | 踏み倒しの記録。03 は 1 | ❓ |
| `0x0B58` u32 | 0 → 1 | — | 踏み倒しの回数か（`0x0B50`〜 の u32 カウンタ列）。03 も 1 | 🔶 |
| `0x0015` u8 | `2C`（44）→ `22`（34） | — | −10。治安などの候補 | ❓ |
| `0x0018` u8 | 0 → `40` | — | | ❓ |
| `0x5B40`〜、`0x6324` | 道具[0] に砥石×1、`FF FF` → `00 00` | — | 踏み倒して持ち逃げした品（買い物と同じ変化） | ✅ |
| `0x0BC8`・`0x0BCC`、`0x0C88`・`0x1C28`、帯刀の斬殺数 | — | +1 | 斬殺数 | 🔶 |

寿司屋の店主（copy 4 → copy 5）：

| 位置 | 変化 | 解釈 | 確度 |
|---|---|---|---|
| `0x02C4` u8 | 0 → 1 | 寿司屋の店主の死亡。`0x0444` と同じ表か（間隔 0x180） | 🔶 |
| `0x0B54` u32 | 0 → 1 | カウンタ。鍛冶屋のおやじの殺害では増えなかった | 🔶 |
| `0x37F9` u8 | 0 → 1 | フラグ列の中。真ルートの「寿司屋の店員を学問のすすめの前に殺すと傷心の帰国船」の条件か | ❓ |
| `0x0018` u8 | `40` → 0 | 踏み倒しで立った値が消えた | ❓ |
| 斬殺数（`0x0BC8`・`0x0BCC`・`0x0C88`・`0x1C28`・帯刀） | +1 | | 🔶 |

さよ：

| 位置 | 変化 | 解釈 | 確度 |
|---|---|---|---|
| `0x0528` u8 | 殺害した 04 だけ 0 → 1。生かした copy 6 は 0 のまま | さよ（DLC）の死亡。さよであることは [U] の判断 | 🔶 |

`0x0100`〜`0x04BF` はほとんど 0 の u8 の並びで、`0x0127`・`0x012C`・`0x0130`〜`0x0133`・`0x01E0`・`0x0258`・`0x0444` などに 0 以外が散らばる。
`0x04C0`〜`0x0B2F` は、手元のサンプルでは `0x0528` 以外すべて 0。

## 書き込みの確認

- `0x0127` を書き換えて、鍛冶屋の後継者イベントの状態が値の表（../README.md）のとおりに変わることを確かめた（[U]）
- `0x0132` を 0 のまま周回すると、`0x0127` が 81 でも鍛冶屋はおやじに戻った。1 にして周回すると堂島の鍛冶屋になった（[U]）
- `0x0264` を 1 にすると堂島が死亡扱いになった（[U]）
- 殺したセーブで `0x02C4`・`0x0444` を 0 に戻すと、それぞれ生き返った（[U]）

## 結論

- `0x0127`（鍛冶屋の状態）、`0x0132`（堂島が継いだ）、`0x0264`（堂島の死亡）、`0x02C4`（寿司屋の店主の死亡）、`0x0444`（鍛冶屋のおやじの死亡）を ../README.md に ✅ で追加した
- `0x0528`（さよの死亡）は 🔶 で追加した。これを受けてエディタの表の範囲を `0x05FF` まで広げた（終わりは未確定）
- `0x0015`・`0x0018`・`0x37F9`・`0x0B54`・`0x0B58` の意味は残った疑問
