# 道場

主人公が師範の道場の状態。弟子の名簿（20 人）、道場の評判（点と ☆ の段階）、来ている道場破りを持つ（🟢）。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x014064` | 🟢 |
| 終了（含む） | `0x01417B` | 🟢 |
| サイズ | 0x118 B | 🟢 |
| 位置の求め方 | 固定 | 🟢 |
| 妥当性検証 | 弟子の数 ≤ 20 で、名簿の空きでない枠の数と一致する。評判の段階 ≤ 5。道場破りの人数 ≤ 8 | 🟢 |

```text
弟子[i]         = 0x1406C + i * 12   （i = 0〜19）
道場破り[j]     = 0x1415C + j * 4    （j = 0〜7）
```

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x14064` | 1 B | u8 | 道場破りが来ている | 0／1 | 🟢 |
| `0x14065` | 1 B | u8 | 弟子の数 | 0〜20 | 🟢 |
| `0x14066` | 1 B | u8 | 道場の評判の段階（☆の数） | 0〜5。下の「評判」 | 🟢 |
| `0x14067` | 1 B | — | 詰め物 | 0 | 🟢 |
| `0x14068` | 2 B | u16 | 道場の評判の点 | 弟子ごとの点（+0x0A）の合計 | 🟢 |
| `0x1406A` | 2 B | i16 | 来ている道場破りの人数 | 0〜8 | 🟢 |
| `0x1406C` | 240 B | — | 弟子の名簿（12 B × 20） | 下の「弟子」 | 🟢 |
| `0x1415C` | 32 B | i32 × 8 | 来ている道場破りの種類 | 町の人の種類。空きは −1 | 🟢 |

### 弟子（12 B × 20）🟢

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `+0x00` | 4 B | i32 | 弟子の種類（町の人の種類）。性別も種類で決まる | [約束できる相手の種類](../../datatable/npc/night-visit-partner.csv) と同じ番号（女児・男児はこの表にない）。−1 ＝ 空き | 🟢 |
| `+0x04` | 4 B | i32 | 名前 | [人物の名前](../../datatable/npc/npc-name.csv)。ふつうは種類の名前（「娘」「女中」など）。空きは −1 | 🟢 |
| `+0x08` | 2 B | u16 | 見た目 | [人物の見た目](../../datatable/npc/npc-look.csv)。種類ごとの見た目の候補の1つ。空きは FFFF | 🟢 |
| `+0x0A` | 1 B | u8 | その弟子の評判の点 | 1〜5。種類で決まる。空きは FF | 🟢 |
| `+0x0B` | 1 B | u8 | 今いる地域に出した印 | 地域を移ると、空きの枠も含めて全 20 枠で 0 になる。セーブではふつう 0 | 🟢 |

- 空きの判定は +0x00 が −1 かどうかだけ 🟢。空きの枠は 12 B すべて FF か、+0x0B だけ 0（FF ×11 ＋ 00）✅
- 名簿は詰めない。弟子入りすると先頭から最初の空きに入り、破門・死亡では枠が空きになるだけ
- 弟子にできるのは、評判の点が決まっている町の人の種類（60 種類、点は 1〜5）。倒した相手に「弟子にしてやる」を選ぶと弟子になる。20 人いるときは増えない
- 弟子入りすると腕前点が増える（腕前点が 3000 未満なら +7、5999 以上なら +2、それ以外 +5）
- 道場（地域 8）では、夜で道場破りが来ていないときを除き、弟子が全員出る

### 評判（`0x14066`・`0x14068`）🟢

弟子入り・破門のたびに、点から段階を決め直す。

| 段階 | 点 | 道場破りが来る確率 | 師範がいないあいだに弟子が撃退する確率 |
|---|---|---|---|
| 0 | 0〜4 | 0% | — |
| 1 | 5〜24 | 18% | 10% |
| 2 | 25〜39 | 18% | 10% |
| 3 | 40〜54 | 18% | 10% |
| 4 | 55〜70 | 18% | 10% |
| 5 | 71 以上 | 18% | 10%（弟子が全員女性なら 20%） |

- 段階 5 で弟子が全員女性のときは、来る道場破りの組み合わせと撃退の確率が変わる（段階の値は 5 のまま）
- 段階が 5 になると、特典「先生の髪型」（[unlocks](../unlocks/README.md) の 57、`0x43351`）が解除できるようになる
- 段階が 5 以上なら、鍛冶屋の「強く」「硬く」の料金が 6 割になる（[weapon-record](../weapon-record/README.md)）
- 道場主が授業料で買った物の話（なりわいのフラグ 18、[townsfolk](../townsfolk/README.md)）は段階で進む

### 道場破り（`0x14064`・`0x1406A`・`0x1415C`〜）🟢

- 来ると決まる：弟子が 1 人以上いて、道場主との話の段階（`0x0129`）が 0 でなく、夜でないときに地域を移ると、段階ごとの確率（上の表）で `0x14064` が 1 になる
- 師範が道場の外にいるあいだ：先生が師範代（`0x379A` が 1）なら 80% で先生が追い払う。それ以外は上の表の確率で弟子が撃退する。追い払うと `0x14064`・`0x1406A`・`0x1415C`〜 が空になる
- 道場に入ると：段階ごとの組から道場破り（1〜2 人）を選び、`0x1415C`〜 と人数 `0x1406A` を書く
- 全員倒すと空になり、腕前点が増える（3000 未満なら +37、5999 以上なら +12、それ以外 +25）
- 東急流剣術の修練度は、`0x1415C`〜 の道場破りを相手にしたときだけ増える（[styles](../styles/README.md)）

### 初期値と周回 🟢

- はじめから：`0x14064`〜`0x1406B` は 0、名簿は全部 FF、道場破りは −1
- 周回の始めに 0 になるのは `0x14064`（道場破りが来ている）だけ。弟子・評判・道場破りの名簿は残る
