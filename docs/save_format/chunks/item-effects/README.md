# 時間で切れる道具の効果

お酒（30秒・攻撃200%・防御50%）のように、使うと一定時間効く道具の効果の残り時間と倍率。16 B の枠が7つと、どの枠が効いているかのビット。

**保存のときに書かれるが、読み込みでは使われない**（🟢）。ロードすると効果は消え、効果なしから始まる。書き換えてもゲームには反映されない。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x003634` | 🟢 |
| 終了（含む） | `0x0036A7`（直後の `0x36A8` からは [event-chart](../event-chart/README.md) のイベント状態 A） | 🟢 |
| サイズ | 16 B × 7 枠 ＋ 4 B | 🟢 |
| 位置の求め方 | 固定 | 🟢 |
| 妥当性検証 | なし（読み取り専用） | — |

```text
枠[n]       = 0x3634 + n * 0x10   （n = 0〜6）  🟢
効いている枠 = 0x36A4（u32、ビット n が枠 n）    🟢
```

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| 枠 `+0x00` | 4 B | float32 | 残り時間（秒） | 効いていなければ 0.0。上限 3600.0 | 🟢 |
| 枠 `+0x04` | 4 B | float32 | 倍率 | 効いていなければ 1.0（例：攻撃200% なら 2.0） | 🟢 |
| 枠 `+0x08` | 4 B | i32 | 効果を出した道具の番号 | 切れると −1。一度も使っていない枠は初期化されず、アドレス風の値が入る | 🟢 |
| 枠 `+0x0C` | 1 B | u8 | 道具の効果のうち何番目か | 切れると 0xFF。使っていない枠は同上 | 🟢 |
| 枠 `+0x0D`〜`+0x0F` | 3 B | — | 枠 0〜5 では +0x0D を使い始めに 0。ほかは用途なし | | 🔶 |
| `0x36A4` | 4 B | u32 | 効いている枠のビット | 0 ＝ どれも効いていない | 🟢 |

- 効果の種類ごとに枠が決まる（7 種類）。どの枠が攻撃・防御・活力などのどれかは ❓
- 残り時間は秒単位で、ゲームの時間で減る。切れると倍率を 1.0 に戻し、道具の「効果が切れたときの文」を出す 🟢
- 実セーブ 2 つでは、7 枠とも残り時間 0.0・倍率 1.0、`0x36A4` が 0 で、効果の切れた状態と一致した。+0x08〜+0x0F はアドレス風の値だった

## 編集時の注意

- 読み込みで使われないので、書き換えても効果は出ない。エディタでは読み取り専用にする
