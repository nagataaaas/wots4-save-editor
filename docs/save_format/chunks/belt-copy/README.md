# 帯刀武器のコピー

帯刀中の武器3本のレコード本体と帯刀の状態と同じ並びを含むブロック。帯刀のコピーではなく、`0x1A610` から始まる 0x408 B の記録の配列の一部（🟢）。乱数やメモリアドレスに見える値が混ざる。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x01A6B2` | 🔶（記録の配列としては `0x1A610`） |
| 終了（含む） | `0x01AD7B` | 🔶 |
| サイズ | 1,738 B | 🔶 |
| 位置の求め方 | [TS] の固定オフセット（U-1 判定待ち） | 🔶 |
| 妥当性検証 | 編集しない（読み取り専用） | — |

## 記録の配列 🟢

| 位置 | 幅 | 型 | 内容 | 確度 |
|---|---|---|---|---|
| `0x1A610` | 2 B | u16 | 記録の件数（上限 128） | 🟢 |
| `0x1A612 + n*0x408` | 0x408 B × 128 | — | 記録。新しい記録は件数が 128 未満のとき末尾に足される | 🟢 |

- 流派・技を扱う処理が足す記録（🟢）。どの場面の記録かは ❓（俺流の作成か 🔶。[custom-style](../custom-style/README.md)）
- 実セーブは件数 2 で、`0x1A612` と `0x1AA1A` から記録がある

## 構造

帯刀[n] のレコード（[weapon-record](../weapon-record/README.md) の +0x00〜+0x99）と完全に同じバイト列が、次の位置から始まる。後ろの組は前の組の 0x408 後ろ（＝記録1件の長さ 🟢）。

| 写しの元 | 前の組 | 後ろの組 | 確度 |
|---|---|---|---|
| 帯刀[0] | `0x1A78C` | `0x1AB94` | 🔶 |
| 帯刀[1] | `0x1A82C` | `0x1AC34` | 🔶 |
| 帯刀[2] | `0x1A8CC`、`0x1A974` | `0x1ACD4`、`0x1AD7C` | 🔶 |
| 帯刀の状態（`0xA6A8`〜）の並び | `0x1A972`〜 | `0x1AD7A`〜 | 🔶 |

- 構えている帯刀武器の番号（本体の `0xA6A9`）の写しは `0x1A973`・`0x1AD7B`
- 本体の +0x80・+0x84（手に持っていた時間）や構えている武器の番号が変わると、写しも同じように変わる
- 写しの直前 6 B は 0 とは限らず、アドレス風の値が入る（例：`00 00 40 F8 CA 48`）
- 上の表にないバイトには、乱数・アドレス風の値がある ❓
- 戦闘のあとに `0x1A618`〜`0x1A6B2` も変わる ❓（記録の先頭の部分 🟢）

## 編集時の注意

- 書き換えない。帯刀中の武器（0xA4C8〜）は帯刀の状態とともに単独で読み込まれ、この記録からは読まれない 🟢
