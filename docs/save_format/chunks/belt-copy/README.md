# 俺流の技の表

俺流（[custom-style](../custom-style/README.md)）の技の構成。件数と 0x408 B の記録 128 枠（🟢）。
記録の後半にはゲームの状態ではない値（前に使われたメモリの内容）が入り、帯刀の武器レコードと同じ並びが見えることがある。
このまとまりの名前（belt-copy）は、その並びを帯刀のコピーと見ていたときのもの。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x01A610`（件数） | 🟢 |
| 終了（含む） | `0x03AA11` | 🟢 |
| サイズ | 2 B ＋ 0x408 B × 128 枠 | 🟢 |
| 位置の求め方 | 固定 | 🟢 |
| 妥当性検証 | 件数 ≤ 128、種類 2、構え 0〜12、技の数 ≤ 128、繋がる技 ≤ 4 で表の中の技を指す。書き込みは 🟢（要ゲーム内確認） | — |

```text
俺流の技の表[k] = 0x1A612 + k * 0x408   （k = 0〜件数−1。枠は 128）
```

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x1A610` | 2 B | u16 | 件数 | 上限 128 | 🟢 |
| `0x1A612 + 0x408k` | 0x408 B | 下の表 | 俺流の技の表 1件 | | 🟢 |

1件（0x408 B）：

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| +0x00 | 2 B | i16 | 技の表の ID | 俺流の +0x48 が指す（実セーブでは 4000・4003） | 🟢 |
| +0x02 | 2 B | u16 | 種類 | 2（俺流） | 🟢 |
| +0x04 | 2 B | i16 | 構え | 0〜12 | 🟢 |
| +0x06 | 2 B | i16 | 技の数 n | 0〜128 | 🟢 |
| +0x08 + 8j | 8 B | 下の表 | 技 j（j = 0〜n−1） | | 🟢 |
| +0x08 + 8n 〜 +0x407 | | — | ゲームの状態ではない値 | 読み込みでは使われない | 🟢 |

技 1件（8 B）：

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| +0 | 1 B | u8 | 技の番号 | 構えの中の番号 0〜127（[skill-states](../skill-states/README.md) の技の番号） | 🟢 |
| +1 | 1 B | u8 | bit7：技ごとの印（意味は ❓）、bit0〜6：繋がる技の数 | 繋がる技は 0〜4 | 🟢 ／ ❓bit7 |
| +2 | 2 B | u16 | 技の ID | 技の番号とは別の番号 | 🟢 |
| +4 | 4 B | u8 × 4 | 繋がる技の番号 | 使わない分は `FF` | 🟢 |

- 「ゲームの状態ではない値」の部分は保存のたびに変わり、帯刀の武器レコード（[weapon-record](../weapon-record/README.md) の +0x00〜+0x99）や帯刀の状態（`0xA6A8`〜）と同じ並びが入っていることがある。
  帯刀の武器が変わるとここも同じように変わって見えるが、帯刀の武器はこの記録からは読まれない 🟢
- 差分を取るときは、件数と技の数の範囲の外を除いて読む

## 編集時の注意

- 技は構えごとの全技（[datatable/sect](../../datatable/README.md) の `stance-skill.csv`）から作る：技の番号、初段なら bit7、技の ID、繋がる技（`next` のうち、その表に入れた技だけ）🟢。
  この作り方で、実セーブの俺流の技の表とバイト単位で同じ並びになる（テストに定数として埋め込んだ）
- 技の数より後ろは読み込みで使われないので、書き込むときは 0 で埋めてよい 🟢
- ゲームの俺流の画面は、1 つの表（構え）の中で次を守らせる 🟢。エディタは通常モードで同じ判定をする（上級者モードは表示だけ）
  - 初段でない技は、前に出す技（`prev`）のどれかを同じ表に入れる
  - 初段の攻撃技どうしで、コマンド（[datatable/sect](../../datatable/README.md) の `skill.csv` の `command`）が同じ値にならない
  - 同じ技から続けて出す技どうしで、コマンドが同じ値にならない（別の技から続く技どうしなら同じでよい）
  - 防御技（`defense_group` がある技）は、同じ組のものを 1 つまで
  - 攻撃技を 1 つ以上入れる
- 実セーブの俺流の技の表（生きた証の写し）は、どれもこの規則に反していない。通常の流派の技の表は初段のコマンドが重なるものが多く、この規則は俺流だけのもの 🟢
- 技を 1 つの表に何個入れられるかはゲームの画面では腕前点で決まるが、読み込みの側に数の検査はない（128 まで）🟢
