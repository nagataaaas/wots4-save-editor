# 帯刀武器のコピー

帯刀中の武器3本のレコード本体と帯刀の状態の写しを含むブロック（🔶）。乱数やメモリアドレスに見える値が混ざる。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x01A6B2` | 🔶 |
| 終了（含む） | `0x01AD7B` | 🔶 |
| サイズ | 1,738 B | 🔶 |
| 位置の求め方 | [TS] の固定オフセット（U-1 判定待ち） | 🔶 |
| 妥当性検証 | 編集しない（読み取り専用） | — |

## 構造

帯刀[n] のレコード本体（+0x06〜+0x9F）と完全に同じバイト列が、次の位置から始まる。後ろの組は前の組の 0x408 後ろ。

| 写しの元 | 前の組 | 後ろの組 | 確度 |
|---|---|---|---|
| 帯刀[0] の +0x06〜 | `0x1A78C` | `0x1AB94` | 🔶 |
| 帯刀[1] の +0x06〜 | `0x1A82C` | `0x1AC34` | 🔶 |
| 帯刀[2] の +0x06〜 | `0x1A8CC`、`0x1A974` | `0x1ACD4`、`0x1AD7C` | 🔶 |
| 帯刀の状態（`0xA6A8`〜）の並び | `0x1A972`〜 | `0x1AD7A`〜 | 🔶 |

- 構えている帯刀武器の番号（本体の `0xA6A9`）の写しは `0x1A973`・`0x1AD7B`
- 本体の +0x86・+0x8A（手に持っていた時間）や構えている武器の番号が変わると、写しも同じように変わる
- 写しの +0x00〜+0x05 に当たる位置は 0 とは限らず、アドレス風の値が入る（例：`00 00 40 F8 CA 48`）
- 上の表にないバイトには、乱数・アドレス風の値がある ❓
- 戦闘のあとに `0x1A618`〜`0x1A6B2` も変わる ❓

## 編集時の注意

- 書き換えない。[TS] は帯刀中の武器（0xA4C2〜）だけを書き換えて正しく動くので、ロード時は本体が使われると考えられる（🔶）
