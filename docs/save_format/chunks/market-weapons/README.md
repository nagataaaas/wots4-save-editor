# 流通中の刀

ゲームの世界に流通している刀の記録。周回をまたいで残るデータ（生きた証）の領域にあると推定している（🔶）。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x0440D0` | ✅（ユーザーのセーブでの値） |
| 終了（含む） | ❓ | ❓ |
| サイズ | ❓ × 件数 ❓ | ❓（[U-11](../../../check-diff.md#u-11)） |
| 位置の求め方 | 実行時に探索する（DLC の有無や進行状況でずれやすいと考えられる） | 🔶 |
| 妥当性検証 | 編集しない（読み取り専用） | — |

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `+0x00` | 1件 ❓ B × ❓件 | — | 流通中の刀 | | ❓ |

- 空きの武器レコード（[weapon-record](../weapon-record/README.md) の +0x06〜+0x65）と同じバイト列が、`0x440D2` から 0xA4 刻みで15件ある（`sample/S4-DATA_00`）。🔶 0xA0 のレコード＋4 B の可能性。中身のある件では確かめていない
- PS3版の特典解除の領域（0x43030）が近い

## 未確認・判定待ち
