# 技の覚え状況

技を覚えたかどうかを、技の表ごとと構えごとの 2 通りで持つ表（🟢）。
流派は 1〜3 個の「技の表」を持ち（[styles](../styles/README.md) の +0x08〜+0x0C）、技の表は 1 つの構えに属する。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x01417C` | 🟢 |
| 終了（含む） | `0x0189FB` | 🟢 |
| サイズ | 0x84 B × 128 枠 ＋ 128 B × 13 構え | 🟢 |
| 位置の求め方 | 固定 | 🟢 |
| 妥当性検証 | ファイルサイズ、状態が 0〜3、流派の表の ID が既知 | — |

```text
技の表ごと[k]       = 0x1417C + k * 0x84       （k = 0〜127）
構えごと[c][i]      = 0x1837C + c * 0x80 + i   （c = 構え 0〜12、i = 技の番号 0〜127）
```

## 構造

技の表ごとの 1枠（0x84 B）：

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| +0x00 | 2 B | i16 | 技の表の ID | −1＝空き。その技の表で初めて技を覚えたときに、先頭の空き枠に割り当てる | 🟢 |
| +0x02 | 2 B | u16 | 状態が 0 でない技の数 | 状態を書くたびに数え直す | 🟢 |
| +0x04 + i | 1 B × 128 | u8 | 技の番号 i の状態 | 下の「状態」 | 🟢 |

構えごと（13 × 128 B）：構え c の技の番号 i の状態（1 B）。並びと値は技の表ごとと同じ 🟢。

構えの番号 🟢：0 上段、1 中段、2 下段、3 脇、4 居合い、5 片手、6 忍者、7 槍、8 二刀、9 忍者二刀、10 無手、11 拳銃、12 ライフル。

### 状態

| 値 | 意味 | 確度 |
|---|---|---|
| 0 | 覚えていない | 🟢 |
| 1 | 覚えた | 🟢 |
| 2 | 派生先の技を覚えた（派生元の技に付く） | 🟢 |
| 3 | 覚えたが、まだ俺流に組み込めない（武器での斬殺数で覚える技）。その技での斬殺数（[skill-kills](../skill-kills/README.md)）が条件に達すると 1 になる | 🟢 |

- 書き換わり方：今の値が 0 なら新しい値を書く。今が 3 で新しい値が 1 なら書く。新しい値が 2 なら必ず書く。ほかは書かない 🟢
- 技を覚えると、技の表ごとと構えごとの両方に同じ値を書く 🟢
- 構えごとの表は俺流を作る画面で使う。選べるのは状態が 1 か 2 の技（3 は選べない）。流派の書から技を写すときは状態が 1 の技だけを写す 🟢
- 技の番号は構えの中の番号（0〜127）。同じ構えのほかの技の表と番号を共有する 🟢

## 技を覚える条件 🟢

- 技ごとに、習得の条件（戦闘中の出来事の種類）、必要な段、派生元の技、覚えたときに増える腕前点が決まっている
- 条件 0 の技（基本の技）は、その流派を装備したときに覚える。習得技数・腕前点は増えない
- ほかの技は、戦闘中に条件の出来事が起き、いまの流派の段が必要な段以上で、派生元の技を覚えていれば閃く。閃くと習得技数（[styles](../styles/README.md) `0x189FC`）が +1、腕前点（`0x189FE`）が増える
- 条件の文はゲーム内の技の表に「流派が○段以上の時に …」の形で出る（「敵にとどめを刺す」「派生元の技を敵にたたき込む」「己の命が○以下の時に…」「技書・奥義の書・秘奥義の書等を使って習得する」「○○構えの攻撃を防御する」など）
- 「今 装備している武器で100人惨殺する」「つま斬り状態となり…50人惨殺する」の回数は武器レコードの +0x9A・+0x9C、「この技で20人／10人惨殺することで俺流に組み込むことが可能となる」の回数は [skill-kills](../skill-kills/README.md)

## 固有技

習得条件 51「戦闘中に今 装備している武器で100人惨殺する」・52「戦闘中につま斬り状態となり 今 装備している武器で50人惨殺する」の技（秘伝黒生・鬼神滅裂・処刑荒野・乾坤一擲・心帰一神法・血霧・くるひかぶき・面剥がし・光矢突）🟢。
技の属性は「特定の武器でしか使えない」。使える武器は [weapon-record](../weapon-record/README.md) の「固有武器の6バイト」の +0（秘伝の技の ID）で決まる（✅ [U] 2026-10-09）。
同じ固有技が、同じ構えの複数の流派の技の表に同じ技の番号で入っている（例：乾坤一擲は脇の技の表 7 つに技の番号 21 で入る）🟢。

ゲーム内での扱い [W]：

- 一部の流派には、特定の武器を使わないと覚えられない技がある。流派と武器の組み合わせが合うと、技の一覧に固有技の分の空欄が出て、そこに出る条件を満たすと覚える
- 対応する武器と刃・鍔・柄の組み合わせが同じなら、自作の武器でもよい。秘奥義書などでは覚えられない
- 一度覚えた固有技は、武器と構えの組み合わせが同じなら流派に関係なく使える
- 俺流では、上の条件を満たしても使えない。「俺流に組み込むための条件」（この技で 20 人／つま斬りで 10 人）を満たしてから、その技を入れた俺流を作る。条件を満たすと、俺流で使えるようになったというテロップが出る。ほかの流派で条件を満たしても、元の流派に戻すまでは解放されない
- 俺流に組み込んだ固有技は、武器に関係なく使える
- ver1.02 から、覚えた固有技にカーソルを合わせて ○ ボタンで条件を確認できる（俺流で使えるようになった技は確認できない）

セーブ上の動き 🟢：

- 覚えると、いまの流派の技の表ごとの表と構えごとの表の両方が 3 になる。「俺流に組み込むための条件」を満たすと両方が 1 になる（上の「状態」）
- 流派を装備したとき、その流派の技の表にある固有技について、構えごとの表が 1 か 3 なら、その値を技の表ごとの表に写す。同じ構えのほかの流派は、装備した時点で覚えた扱いになる（覚えた瞬間にすべての流派を書き換えるのではない）。
  写すときに、その技の表の枠がまだなければ枠を割り当てて ID と数（+0x00・+0x02）も書く
- 段 5（極）の判定では、習得条件 51〜54 の技を数えない 🟢（[styles](../styles/README.md)）。[W] の「全部覚えたはずなのに極にならない流派は固有技がある」と食い違う

> ❓ **判定待ち → [U-20](../../../check-diff.md#u-20)**　案A：極の判定に固有技を数えない（🟢）／ 案B：固有技を覚えないと極にならない（[W]）　**採用までの扱い**：エディタは段を自動で 5 にしないので、表示と書き込みには影響しない

## 編集時の注意

- 状態 1・2 の書き込みはゲームに反映される（✅ [U] 2026-10-09。技の表に習得済みで出て、戦闘で出せ、俺流の画面で選べた）。+0x02（0 でない値の数）も合わせて書く
- 技の表ごとの枠がない技の表は、先頭の空き枠に技の表の ID を書いて使う 🟢
- 派生先を覚えさせるときは派生元も覚えさせ、派生元は 2 にする（ゲームと同じ）
- 状態を書いても、段 5（極）の判定は技を覚えた瞬間にしか行われない 🟢。極にするには [styles](../styles/README.md) の段を書く
- 技の名前・習得条件は [datatable/sect](../../datatable/README.md)（`sheet-skill.csv`・`stance-skill.csv`）
