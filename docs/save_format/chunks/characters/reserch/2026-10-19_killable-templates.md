## 書き方

- 剣術大会のあとの3つのルートは、剣術大会直前の書き方（✅ [event-chart の調査](../../event-chart/reserch/2026-10-16_scene-template-tournament.md)）に、その先の道筋を足す

- 周回の始めに書かれ、初期化で 0 になる値（鬼怒川 `0x3756` = 2、`0x37C1`・`0x37C2` = 1）を書き戻す 🟢。剣術大会直前・なりわいのテンプレ（ゲームで確かめた書き方）には足していない
- 斬れる人の人物の状態は 0（生存）にし、町の人のレコード（`0x015C + 12 × 人物番号`）の死亡のビットも 0 にする
- 施設（`0x375D`〜`0x375F`）・`0x3760`・堂島と先生の職は書かない。どの戦いも読まない 🟢
- 堂島 `0x375A` は、道筋では堂島の職が 0 なら表彰式で 1 になるが、どの戦いも読まないので 0 のまま
- 経過日数は寄り道しない場合の日 🔶（どの開始条件にも日数はない 🟢）

### 場面ごとの要点

- **領事館斬り込み**：開始条件は段階 510、62 ≤ 2、同士救出 58 = 4、`0x378B` = 1、旅籠。真実 38 = 4 だと J.J と戦って武士の魂へ続く。4 でないとまだらと戦い、結末に入って武士の魂は起きない。62 = 2 は「準備をしてくる…」で保留した値で、赤城の前へ歩くと問いから始まる
- **願い虚しく**：鬼怒川の魔手はロードから始まらず、願い虚しくの大通りの戦いから続けて起きる。直前は「領事館でローラに報告する前」（56 = 3・`0x37A3` = 2 で報告の場面になる）。大通りの戦いの後半で赤城・小暮、鬼怒川の魔手で味方のローラ・メリンダを斬れる。ローラが倒れると 61 = 5 で討ち入りの筋に進む。`0x37A3` = 2 を最初に書く場面は 🔶
- **討ち入り**：開始条件は段階 600、69 ≤ 3、68 = 5（または 61 = 5）、`0x378A` = 1、代官所の門の外。ローラを守りきり、夕暮れの船上で断った筋（68 = 5）にした。琴吹の状態が 1 だと琴吹が出ない
- **三匹で斬る・般若党壊滅**：開始条件は段階 510、それぞれ 64 ≤ 0 と憂国の士 55 = 4、59 ≤ 0 と大老武断 54 = 4、`0x3789` = 1、神社。神社の柵（`0x37C3`・`0x3761`）と `0x37A2` は開始にも洞窟に入れるかにも効かない（段階 410 以降の幕府ルートでは配置が柵を閉じ、戦いの場面が開ける）ので、大寄せの値のまま。港から始めて神社へ移る（🔶 神社から始めたときに柵が開くかを確かめていない）
- **再起の望み**：お早い到着（71）から続けて起き、72 = 3 のときだけ、ロードしたあと小暮に近づくと選択肢が出る（72 = 0 では始まらない）。赤城を攻撃すると赤城が死に、小暮との一騎打ちになる。病院は成功の選択肢にだけ効く
- **大老暗殺計画**：開始条件は段階 200〜400、83 ≤ 3、70 = 4、`0x378E` = 2、大通り。味方の4人は状態が 0 のときだけ出る。4人とも生きたまま `0x378E` = 2 になるのは、寿司屋の店主が死んでいて傷心の帰国船（80）を戦いなしで成功させる筋だけ（J.J のところへは行かない）。寿司屋の値（`0x37F9`）は 83 が読まないので書かない。83 = 0 では大通りに入ったときに琴吹の打ち明けの場面になる
