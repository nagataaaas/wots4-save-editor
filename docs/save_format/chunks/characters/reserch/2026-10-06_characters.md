# 重要人物の状態の配列

- 日付：2026-10-06
- 目的：イベント状態 A（`0x36A8`〜`0x374D`）の直後 `0x374E`〜 が重要人物ごとの状態かを確かめ、人物を特定する
- 環境：Steam版、0x48BB0

## サンプル

| ファイル | 操作 | 見た値 |
|---|---|---|
| `sample/S4-DATA_00` | 真ルートに入った直後（三姉妹見参の直後、1日目夕。再起の望みの前） | `0x374E`＝00 |
| `sample/S4-DATA_01 copy 8` | 病院が閉じた状態で真ルートに入った直後 | `0x374E`＝00 |
| `sample/S4-DATA_01 copy 7` | 書き換えで真ルートに入り、再起の望みで赤城が死んだ | `0x374E`＝01 |
| `sample/S4-DATA_02` | 正規。赤城を病院に送ったあと | `0x374E`＝03 |
| `sample/S4-DATA_02 copy` | 正規。真ルートで赤城が死んだ直後 | `0x374E`＝01 |
| `sample/S4-DATA_01 copy 11` | 新しい主人公の2周目。赤城が死んだ | `0x374E`＝01 |
| `sample/S4-DATA_01 copy 12` | copy 11 のあと、怒りの矛先（神社最深部で小暮とタイマン）を終えた。小暮は死んだ | `0x374E`＝01、`0x374F`＝01 |
| `sample/S4-DATA_00 copy` | 周回開始直後 | `0x374E`〜 すべて 00 |
| メリンダが死んだセーブ（sample/ にない） | — | `0x3759`＝01 |

## 差分

| 位置 | 観察 | 解釈 | 確度 |
|---|---|---|---|
| `0x374E` | 再起の望みの前はすべて 00、赤城が死ぬと 01、病院に送ると 03 | 赤城。00＝生存、01＝死亡、03＝入院 | 🔶 |
| `0x374F` | 怒りの矛先のあと（01 copy 12）だけ 01 | 小暮。01＝死亡（差分1回） | 🔶 |
| `0x3756` | 阿弥浜港争乱のあとのすべてのセーブで 02、周回開始直後の 00 copy だけ 00 | 鬼怒川怨仙 | 🔶 |
| `0x3759` | メリンダが死んだセーブで 01 | メリンダ。01＝死亡（差分1回） | 🔶 |
| `0x375A`〜`0x375C` | すべてのセーブで 0 | 不明 | ❓ |

## 書き込みの確認

[U] 2026-10-06、1バイトずつ書き換えてゲーム内で確認。

- `0x3750` に 1 を書くと朱美が消えた（死亡扱いかは ❓）
- `0x3751`＝琴吹、`0x3752`＝茂呂、`0x3753`＝マユ、`0x3754`＝チカ、`0x3755`＝ユリ
- `0x3756`＝鬼怒川怨仙。[U] の推定で 0＝出現、1＝死亡、2＝まだ阿弥浜に来ていない。大老の到着イベントの前に 0 にしても出現しなかった
- `0x3757` に 1 を書くとローラが消えた
- `0x3758` に 1 を書くと J.J. がいなくなった

## 結論

- `0x374E`〜`0x375C` を重要人物の状態（u8 × 15）として ../README.md に書いた
- 周回の始めは全部 00 で、「生死フラグは周回ごとに初期化される」と合う
- 残った疑問：`0x375A`〜`0x375C` の人物、各人物の値の意味、赤城・小暮・メリンダを書き換えたときにゲーム内の生死が変わるか
