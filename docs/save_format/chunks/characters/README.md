# 重要人物の状態

シナリオに登場する重要人物ごとの状態（生死など）。1人 1 B の u8 が並ぶ。
イベント状態 A（[event-chart](../event-chart/README.md)）の直後にあり、フラグ列（[scenario-flags](../scenario-flags/README.md)）の先頭部分に当たる。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x374E` | 🔶 |
| 終了（含む） | `0x375C` | 🔶 |
| サイズ | 15 B（u8 × 15） | 🔶 |
| 位置の求め方 | 固定（U-1） | ❓ |
| 妥当性検証 | ファイルサイズが 0x48BB0 | ❓ |

## ゲーム側の仕様

- 店主など町の人の生死・好感度は周回ごとに初期化される。町の人の状態は [townsfolk](../townsfolk/README.md)
- メリンダはいつ斬ってもルートに影響しない（差分解析の被験者に向く）
- 茂呂が3日目の夜に死亡すると、幕府ルート（エンディング 破滅への道・変わり往く心）に入れない（[event.md](../../../event.md)）

## 編集時の注意

- 値の意味は人物ごとに確かめていないので、生の値として扱う。通常モードは 0〜3

## 未確認・判定待ち

- ❓ 琴吹・茂呂・マユ・チカ・ユリの値の意味（人物の位置だけ書き換えで確認）
