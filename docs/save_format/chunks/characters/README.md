### 値を条件にする場面（🟢）

- 赤城：将の器は 3、怒りの矛先は 1 のときに起きる
- 小暮：願い虚しくは 0 のとき小暮本人が、それ以外は別の人物が敵になる
- 茂呂：1 だと剣術大会の準備で建築現場にいない。大寄せで幕府ルートに入るには 1 でないことも要る（[factions](../factions/README.md)）
- J.J.：刺激が欲しいは 4 のとき起きる。1 のとき傷心の帰国船が起きうる
- 薬屋：小公女倒れるで 0 でないと、町に入った時点で失敗になる
- メリンダ・堂島：表彰式で 0 のときだけ、ほかの優勝者として並ぶ

## ゲーム側の仕様

- 店主など町の人の生死・好感度は周回ごとに初期化される。町の人の状態は [townsfolk](../townsfolk/README.md)
- 茂呂が3日目の夜に死亡すると、幕府ルート（エンディング 破滅への道・変わり往く心）に入れない（[event.md](../../../event.md)）

## 編集時の注意

- 通常モードは 0〜5（J.J. の 4・5 まで）。どの人物でも見つかっている値の範囲
- 書き換えでゲーム内の生死が変わるかは、朱美・ローラ・J.J.（1 で消える）以外は要ゲーム内確認
