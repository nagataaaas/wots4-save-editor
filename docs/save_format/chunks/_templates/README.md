<!--
記入例：

範囲の中に複数の配列があるときは、配置を式で書く：

```text
帯刀中[n]   = 0xA4C2 + n * 0xA0   （n = 0〜2）
武器袋[n]   = 0xA6AA + n * 0xA0   （n = 0〜9）
武器箪笥[n] = 0xACEE + n * 0xA0   （n = 0〜199）
```

<!--
- 位置は範囲の先頭からの相対位置（+0x..）。範囲が1つの値だけなら絶対位置で書いてよい
- 型：u8 / u16 / u32 / i16 / float32 / UTF-16LE など。不明なら「—」
- 値：列挙値が数個なら直接書く。多ければ datatable へのリンク
- 用途不明のバイトも省略せず ❓ で1行にする（隙間を作らない）
