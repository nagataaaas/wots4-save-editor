# 真ルート

真ルート（阿弥浜港争乱で大砲の般若党を倒し、三姉妹見参から入るルート）に入っているかのフラグと、その周りのバイト。
フラグ列（[scenario-flags](../scenario-flags/README.md)）の中にあり、直前は勢力ごとの記録とルート分岐（[factions](../factions/README.md)）。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x378D` | 🔶 |
| 終了（含む） | `0x37AA` | 🔶 |
| サイズ | 30 B（u8 × 30） | 🔶 |
| 位置の求め方 | 固定（U-1） | ❓ |
| 妥当性検証 | ファイルサイズが 0x48BB0 | ❓ |

範囲は、真ルートのセーブと通常ルートのセーブで違いが出たバイト（`0x378D`〜`0x37AA`）を含むように取ったもの。終わりに根拠はない。

## `0x378D` と `0x378E`

| 場面 | `0x378D` | `0x378E` | 確度 |
|---|---|---|---|
| 序章の終わり（阿弥浜港争乱の3連戦の終わりなど） | 1 | — | 🟢 |
| [三姉妹見参](../../../events/best__prologue__meeting_with_the_three_sisters.md)の成功（真ルートに入る） | 2 | 1 | 🟢 |
| 真ルートを外れる場面（下の表） | — | 2 | 🟢 |

- 1〜3日目の通常の勢力イベント（志士との出会い・代官所の面々・小公女謁見など）は、どれも開始条件が `0x378D` = 1。2 になると周回中は 1 に戻らない（🟢）
- 真ルートのイベントは、どれも開始条件が `0x378E` = 1（🟢）
- `0x378E` = 2 は真ルートを外れたこと。2 になると周回中は戻らない（🟢）
- [大老暗殺計画](../../../events/best__2_day__plot_to_assassinate_the_chief_minister.md)の開始条件は「三姉妹見参の成功（`0x36EE` = 4）かつ `0x378E` = 2 かつ大通りにいる」（🟢）

`0x378E` が 2 になる場面（🟢）：

| イベント | 2 になる場面 |
|---|---|
| 再起の望み | 小暮が死んだとき |
| 怒りの矛先 | 成功したとき |
| 伯爵に刺激を | 失敗したとき、小暮が死んでいれば |
| 運命のルーレット | J.J が死んだとき、小暮が死んでいれば |
| 闇討ち | 失敗したとき |
| 傷心の帰国船 | 成功したとき |

## 真ルートに入る条件

- `0x378E`＝1 と、三姉妹見参の成功（イベント状態 A 添字70＝`04`、[event-chart](../event-chart/README.md)）の**両方**が要る ✅
  - どちらか一方だけでは通常ルートのまま。正規の真ルートで `0x378E` を 0 にすると通常ルートに入る
  - `0x378D`・`0x379F`・`0x37AA` を正規の真ルートと同じ値にしても、ルートは変わらない ✅
- 書き換えで入った真ルートでも、進行は正規と同じように進む ✅（現地へ行けばイベントが起き、ヒントも出る）

## ゲーム側の仕様

- 真ルートでは、病院が閉じていると再起の望みで赤城が死ぬ（病院の開閉は [facilities](../facilities/README.md)、赤城の状態は [characters](../characters/README.md)）
- イベントチャートで、真ルートのイベントの**枠**は、記録 B が `04`（過去の周回で記録）か、状態 A が `03`・`04`（今の周回で進行中・成功）か、いま始められるときだけ出る（✅ B `04`・A `04` ／ 🟢 A `03`・いま始められる）。周回数（[stats](../stats/README.md) の `0x0B8C`）が 3 以上なら全部出る（🟢 要ゲーム内確認。[event-chart](../event-chart/README.md)）
  - そのため、周回数が 2 以下で真ルートを過去の周回で記録していない主人公では、正規のプレイでも、失敗したイベントや先のイベントの枠が出ない（ゲームの仕様）
  - 真ルート以外のイベントは、B が `FF` で A が `05` でも枠が出る
- 真ルートのエンディングは 希望の光（語学所・病院が開設、カジノが閉鎖などの条件）と、満たさないときの 大老は生きていた（[event.md](../../../event.md)）

## ローラの好感度（`0x3792`）

外国のイベントの成功で増え、失敗で 1 減る（🟢）。

| イベント | 成功 | 失敗 | ほか |
|---|---|---|---|
| 電信あり | +1 | −1 | |
| 病院占拠事件 | +2（説得したとき） | −1 | |
| 祝 病院開業 | +2 | −1 | 千両箱を奪うと 0 に戻る |
| お団子物語 | +3 または +1 | −1 | 好感度 3 以上で、外国と敵対していなければ場面が分かれて +3。そうでなければ +1 |
| 小公女と大老 | +2 | −1 | |
| 小公女倒れる | +2 | | |

- 全部成功させると 1＋2＋2＋3＋2＋2＝12
- 夜這いの約束（🟢）：3日目夜に、小公女倒れるが成功（イベント状態 A 添字34＝`04`）していて好感度が 10 以上なら、
  謎の鍵（アイテム `0xEE`、[items](../items/README.md)）を持って領事館のローラの部屋の扉に近づくと、鍵を1本使って約束になる。
  その夜にすでに別の相手と約束していると、鍵は減らず約束にもならない
- 謎の鍵は落し物屋で 1000 文で買える。店に並ぶ条件は ❓

## 朱美の好感度（`0x3793`）

| 場面 | 増減 | 確度 |
|---|---|---|
| 居酒屋で朱美に話しかけ、持っている魚を「欲しいならやるぞ」で渡す | 1匹ごとに +1（10 で止まる） | 🟢 |
| 海兵隊の横暴 | 成功で +1、失敗（戦闘の負けなど）で −1 | 🟢 |
| 真実・夜の墓場で | 朱美を送る流れに入ると +1 | 🟢 |

値は 0〜100 に丸められる（🟢）。

**魚を渡す**（🟢）

- 居酒屋で、2回目以降に話しかけたとき（1回目はあいさつだけ）、攘夷と敵対していなければ（[factions](../factions/README.md) `0x3788` が 1 でない）、持ち物を次の順に調べて最初に見つかったものに反応する
  1. シロギス・アナゴ・ボラ・マサバ・コイ・カツオ・ハゼ・メバル・カサゴ・アジ・ヤマメ・マダイ → 選択肢「これは渡せない／欲しいならやるぞ」
  2. タコ・ニホンザリガニ → 嫌がって受け取らない。アカヒトデ → 「かわいい」と言うだけで受け取らない
  3. 伝説の魚（3種）・ウニ → 1. と同じ選択肢
- 「欲しいならやるぞ」を選ぶと、好感度が 9 以下なら +1 され、その品が1つ減る（品が減るのは 🔶）
- 2. の品を持っていると、伝説の魚・ウニより先にそちらに反応する。1. の魚を持っていれば 2. の品は関係ない
- 何回でも渡せる。魚を 9 匹渡しておけば、ほかの増減に関係なく約束の条件を満たす

**約束になる流れ**（🟢）

- 真実（3日目夜）で「下手な芝居はよせ…」、夜の墓場で（3日目夜）で「こんなところで何をしている？」→「夜道は危険だ 送ろう」と選ぶと、朱美を送る場面に入り好感度が +1 される
- そのあと好感度が **10 以上**なら選択肢「部屋まで送るよ／礼には及ばん」が出て、「部屋まで送るよ」を選ぶと、その夜にまだ約束がなければ約束になる
- +1 のあとで判定するので、送る場面に入る前に 9 あればよい
- 選択肢の文と分岐の対応は、要ゲーム内確認

## 三姉妹の拷問のポイント（`0x3794`〜`0x3796`）

`0x3794` 万由、`0x3795` 千佳、`0x3796` 百合。値は 0〜100 に丸められる（🟢）。

**だれの拷問になるか**（🟢）：拷問が始まったときの治安で決まる。

| 治安 | 拷問 | 相手 |
|---|---|---|
| 70 以上 | 水車 | 万由 |
| 30〜69 | 吊り | 百合 |
| 29 以下 | 石 | 千佳 |

- 拷問を最後まで受け直す流れ（拷問から出たあとの続き）では、29 以下が百合、30〜69 が千佳の組み合わせになっている所がある（🟢。ゲームで起きるかは要ゲーム内確認）

**ポイントの増え方**（🟢）

- 拷問の始めに、所持金が 1000 文以上なら「保釈金1000文払おう／是非に及ばず／よっ！待ってました！」が出る。保釈金を払うと拷問を受けずに出られるが、その相手のポイントが 0 になる
- ほかの選択肢（1000 文未満なら「拙者は無罪だ！／た 助けて！／よろしくお願いします」のどれでも）で拷問を受け、終わったときの点数でその相手のポイントが増える

| 拷問の点数 | 増分 |
|---|---|
| 90000 以上 | +4 |
| 60000 以上 | +3 |
| 30000 以上 | +2 |
| それ未満 | +1 |

- 増えたあとで **10 以上**なら、その夜にまだ約束がなければ約束になり、その相手のポイントは 0 に戻る。すでに約束があると「今夜の相手はすでに決まっている」となる
- 10 にするには、同じ相手（同じ治安の帯）で 3〜10 回拷問を受ける。毎回 90000 以上なら 3 回（4＋4＋4）
- 西洋医学お断り・病院廃業の企ての終わりで拷問部屋に送られる場面では、拷問の前に 3人とも 0 に戻る
- 拷問は、捕まったときやイベントの終わり（西洋医学お断り・病院廃業の企て・士魂は屈せずなど）で始まる（🔶 捕まる条件は ❓）

## メリンダの峰打ちの点数（`0x3797`）

メリンダを峰打ちで倒す場面でだけ増える（🟢）。殺したときは増えない。

| イベント | 増える場面 | 増分 |
|---|---|---|
| 小公女謁見 | 戦闘でメリンダを峰打ちで倒す | +2 |
| 海兵隊の横暴 | 戦闘でメリンダを峰打ちで倒す（2つの戦闘のどちらでも） | +2 |
| 西洋医学お断り | 戦闘でメリンダを峰打ちで倒す（2つの戦闘のどちらでも） | +2 |
| 病院廃業の企て | 街道の戦闘に勝って千両箱を取る場面（峰打ちで倒したかどうかで分かれない） | +2 |
| 祝 病院開業 | 戦闘でメリンダを峰打ちで倒す | +2 |
| 東国の騎士 | 戦闘でメリンダを峰打ちで倒す | +2 |
| 剣術大会（攘夷） | 3回戦でメリンダに勝つ場面のうちの1つ（峰打ちで勝ったときとみられる 🔶） | +5 |

- 攻略情報の「メリンダの夜這い」の手順（小公女謁見 → 海兵隊の横暴 → 病院の3つのどれか → 剣術大会（攘夷）の3回戦。どれも峰打ち）を全部行うと 2＋2＋2＋5＝11 になる
- 夜這いの約束（🟢）：段階（[date-location](../date-location/README.md) の `0x0010`）が 500（5日目）以上で、この点数が **10 以上**のとき、
  メリンダはふだんの場所（領事館）から夜這い用の姿に入れ替わって別の地域に出て、話すと約束になる。ほかに、メリンダが生きている（`0x3759` ＝ 0）、
  `0x3790` が 1 でない、前に約束していない（`0x012F` が 1・2 でない）ことが条件。詳しくは [night-visit](../night-visit/README.md)「約束の条件」
- 攻略手順どおりなら 11 で、しきい値 10 を 1 点だけ上回る。病院のイベントを飛ばすなど、どれか1つを落とすと届かない
- 序章（阿弥浜港争乱）でメリンダを倒しても増えない（🟢）

## 編集時の注意

- `0x378E` を 1 にしても、三姉妹見参を成功にしないと真ルートには入らない。エディタは三姉妹見参の今の状態もあわせて表示する
- `0x378E` 以外のバイトは生の値として扱う。書き換えたときのゲーム内の反映は確かめていない
