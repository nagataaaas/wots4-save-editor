# 主人公名

主人公の名前。UTF-16LE の固定長フィールド。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x0000DC` | ✅ |
| 終了（含む） | `0x00011B` | ✅ |
| サイズ | 64 B | ✅ |
| 位置の求め方 | 固定（[U-1](../../../check-diff.md#u-1)） | ❓ |
| 妥当性検証 | ファイルサイズが 0x48BB0。UTF-16LE として読め、31文字以内で残りが 00 | ✅ |

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x00DC` | 64 B | UTF-16LE | 主人公名 | 最大31文字。残りは 00 で埋める | ✅ |

- [TS] が同じ位置を読み書きしている（I-1、I-3）
- ゲーム内の入力では日本語も使える。セーブを直接書き換えて日本語名にした報告もある

## 編集時の注意

- 31文字を超える名前は拒否する。名前が長すぎるとロードできなくなる
- 上書きだけで書く。残りのバイトは 00 で埋める
