# 敵の種類ごとの斬殺数の表

- 日付：2026-10-05
- 目的：イベントで敵を斬ったときに増える値を探す
- 環境：Steam版、ファイルサイズ 0x48BB0

## サンプル

| ファイル | 操作 | ベースからの差分 |
|---|---|---|
| `sample/S4-DATA_04 copy 2` → `04 copy 3` | 【阿片密売を阻止せよ】で密売人2人を斬り、町に戻ってセーブ（2日目の朝） | — |
| `sample/S4-DATA_04 copy 4` → `03 copy 6` | 【代官所潜入】で4人を斬った（木箱を1つだけ運び出す） | — |
| `sample/S4-DATA_04 copy 4` → `04 copy 5` | 【辻斬りを辻斬る】で辻斬り10人を全滅させた | — |

## 差分

| 位置 | 阿片密売 | 代官所潜入 | 辻斬りを辻斬る | 解釈 | 確度 |
|---|---|---|---|---|---|
| `0x0BC8`・`0x0BCC` u32 | +2 | +4 | +10 | 全体の斬殺数（周回中／累計） | 🔶 |
| 帯刀[0] `+0x9C` | +2 | +4 | +10 | その武器での斬殺数 | 🔶 |
| `0x0EE4`〜・`0x1E84`〜 u8 | `0x0EE4`・`0x1E84` 0 → 1 | `0x0EE8`・`0x1E88` 0 → 1 | — | | ❓ |
| `0x0F68`・`0x1F08` | 0 → 1 | — | 0 → 10（u32） | 敵の種類ごとの斬殺数 | 🔶 |

- 0x84 刻みの2か所（`0x0EE4`・`0x0F68`）が、0xFA0 離れた2組（`0x0E..`／`0x1E..`）にある
- 累計側にだけ前の周回の値（`0x1E48`＝185 など）がある。`0x0E..` が周回中、`0x1E..` が累計と考えられる
- 代官所潜入は4人斬ったが表は1しか増えていない（表にない種類もある）
- 阿弥浜港争乱の直後のセーブ（2026-10-06）でも、`0x0C84`〜 と `0x1C24`〜 が変わった。三姉妹戦の前後でも `0x0C88`〜・`0x1C28`〜 が変わった

## 結論

- 周回中 `0x0C84`〜、累計 `0x1C24`〜（0xFA0 離れた2組）の u32 の表として ../README.md に反映した（🔶）
- 表の範囲と、添字と敵の種類の対応は ❓
