# 敵の種類ごとの斬殺数

敵の種類（相手）ごとの斬殺数の表。周回中の表と累計の表が 0xFA0 離れて2つある。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | 周回中 `0x000C64`、累計 `0x001C04`（周回中＋0xFA0） | 🟢 周回中 ／ 🔶 累計 |
| 終了（含む） | 周回中 `0x001C03`、累計 `0x002BA3` 🔶 | 周回中 🟢 ／ 累計 🔶 |
| サイズ | 周回中 0xFA0 B（u32 なら 1000 件） | 🟢 |
| 位置の求め方 | 固定（[U-1](../../../check-diff.md#u-1)） | ❓ |
| 妥当性検証 | なし（読み取り専用） | — |

```text
周回中[n] = 0x0C64 + n * 4   🟢（周回の終わりに 0x0C64〜0x1C03 の 0xFA0 B をまとめて 0 にする）
累計[n]   = 0x1C04 + n * 4   🔶（周回中の位置＋0xFA0。周回の終わりに消さない）
```

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `+0x000`〜 | 4 B × ❓ | u32 | 敵の種類ごとの斬殺数（周回中） | | 🔶 |
| `+0xFA0`〜 | 4 B × ❓ | u32 | 敵の種類ごとの斬殺数（累計） | 累計側にだけ前の周回の値がある | 🔶 |

- 1人斬ると、周回中と累計の同じ添字が同時に増える（例：辻斬りを辻斬るで `0x0F68`・`0x1F08` が 0 → 10）
- 斬った人数のうち一部しか増えないことがある。表にない種類もあると考えられる 🔶
- 全体の斬殺数は [stats](../stats/README.md) の `0x0BC8`・`0x0BCC`

## 編集時の注意

- 書き込まない（表の範囲と種類が分かっていない）
