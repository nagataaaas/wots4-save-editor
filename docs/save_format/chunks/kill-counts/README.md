# 技ごとの斬殺数

技（技の ID 0〜999）ごとの斬殺数の表。周回中の表と累計の表が 0xFA0 離れて2つある。記録の画面の「得意技」は、累計の表でいちばん多い技。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | 周回中 `0x000C64`、累計 `0x001C04`（周回中＋0xFA0） | 🟢 |
| 終了（含む） | 周回中 `0x001C03`、累計 `0x002BA3` | 🟢 |
| サイズ | 0xFA0 B × 2（u32 × 1000 件 × 2） | 🟢 |
| 位置の求め方 | 固定 | ✅ |
| 妥当性検証 | なし（読み取り専用） | — |

```text
周回中[n] = 0x0C64 + n * 4   🟢（周回の終わりに 0x0C64〜0x1C03 の 0xFA0 B をまとめて 0 にする）
累計[n]   = 0x1C04 + n * 4   🟢（周回の終わりに消さない）
```

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x0C64 + 4n` | 4 B × 1000 | u32 | 技 n による斬殺数（周回中） | n は [技](../../datatable/sect/skill.csv) の ID（使われるのは 0〜961） | 🟢 |
| `0x1C04 + 4n` | 4 B × 1000 | u32 | 技 n による斬殺数（累計） | 累計側にだけ前の周回の値がある | 🟢 |

- とどめを刺した技の、周回中と累計の同じ添字が同時に増える（例：辻斬りを辻斬るで `0x0F68`・`0x1F08`（技 193 野麦越え）が 0 → 10）
- 斬った人数のうち一部しか増えないのは、技ごとに別の欄に入るため 🟢
- 全体の斬殺数は [stats](../stats/README.md) の `0x0BC8`・`0x0BCC`

## 編集時の注意

- 書き込みは、技の ID の表にある技だけにする。書き換えたときの「得意技」の表示は要ゲーム内確認
