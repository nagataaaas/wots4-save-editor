# なりわい

なりわい（サブクエスト）の状態の表と、受注中・クリア数の値。状態の表はなりわい ID を添字にした u16 の配列。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 状態の表 | `0x0033A4`〜`0x0035A3`（u16 × 256） | ✅ |
| クリアしたなりわいの数 | `0x0433A6`〜`0x0433A7` | 🔶 |
| 受注中の情報 | `0x045F40`〜`0x045F55` | 🔶 |
| 位置の求め方 | 固定（U-1） | |
| 妥当性検証 | 状態の表の全要素が `FFFF`・0・1 のどれか | 🔶 |

```text
状態[id] = 0x33A4 + id * 2   （id = なりわい ID、0〜255）
```

## 構造

### 状態の表 `0x33A4`〜

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `+id*2` | 2 B | u16 | なりわい ID ごとの状態 | `FFFF`＝未受注、`0`＝受注中、`1`＝クリア。ID は[なりわい](../../datatable/occupation/occupation.csv) | ✅ |

- 結末が分かれる「おにぎり屋の用心棒」も、どちらの結末でも 1。結末の違いは別の場所（さよの死亡 `0x0528`、[townsfolk](../townsfolk/README.md)）に残る
- 直後の `0x35A4` からは [vitals](../vitals/README.md)

### 周りの値

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x433A6` | 2 B | u16 | クリアしたなりわいの数 | | 🔶 |
| `0x45F40` | 6 B | — | クリアのたびに項目ごとに ±10 変わる | 例 `00 14 14 14 14 14` | ❓ |
| `0x45F46` | 8 B | — | 用途不明 | | ❓ |
| `0x45F4E` | 2 B | u16 | 受注中のなりわいの ID。受注していなければ 0 | | 🔶 |
| `0x45F50` | 5 B | — | 用途不明 | | ❓ |
| `0x45F55` | 1 B | u8 | 受注中だけ `FF` | | ❓ |

- 報酬の容姿は [appearance](../appearance/README.md)、装飾品は [accessories](../accessories/README.md)
- なりわいの操作ごとに `0x0137`〜`0x013B` の u8 が1つずつ 0 → 1 になる（[townsfolk](../townsfolk/README.md) の範囲。❓）

## 編集時の注意

- 状態を 1 にすると、なりわい一覧でクリア済みになる（`0xD1` で確認）。容姿・装飾品・クリア数は自動では変わらない
