# なりわい

なりわい（サブクエスト）の状態の表と、受注中・クリア数の値。状態の表はなりわい ID を添字にした u16 の配列で、
周回をまたいだ統計（なりわいごとのクリア回数）としてゲーム内に出る（✅ [U] 2026-10-07）。今の周回の進み具合ではない。
続き物（同心・極道・泥棒さん・おっつぁんなど）の進み具合は、別の場所の「なりわいのフラグ」（[townsfolk](../townsfolk/README.md) の `0x011C`〜）にある。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 状態の表 | `0x0033A4`〜`0x0035A3`（u16 × 256） | ✅ |
| クリアしたなりわいの数 | `0x0433A6`〜`0x0433A7` | 🟢 |
| 受注中の情報 | `0x045F40`〜`0x045F55` | 🔶 |
| 位置の求め方 | 固定（U-1） | |
| 妥当性検証 | 状態の表の全要素が `FFFF` か 0〜999 | 🔶 |

```text
状態[id] = 0x33A4 + id * 2   （id = なりわい ID、0〜255）
```

## 構造

### 状態の表 `0x33A4`〜

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `+id*2` | 2 B | u16 | なりわい ID ごとの記録（周回をまたぐ統計） | `FFFF`＝まだ出ていない、`0`＝出た・未クリア、`1` 以上＝これまでの周回を通してクリアした回数。ID は[なりわい](../../datatable/occupation/occupation.csv) | ✅ `FFFF`・クリア回数・統計 ／ 🔶 `0` |

- ID は 3〜212 のうち 170件（🟢）。213〜255 と、3〜212 の欠番には使われない
- 1 回クリアすると 1、同じなりわいを周回をまたいで繰り返しクリアすると増える。全 ID の値の合計がクリア数 `0x433A6` に等しい（🟢）
- ゲーム内の統計として出る（✅ [U] 2026-10-07）。手元のサンプルはどれも 209 が 5、210 が 3 で、周回をまたいで積み上がっている
- 受注しても値は変わらない。同心の「出頭命令」（171）は受注の前から 0 だった
- 結末が分かれる「おにぎり屋の用心棒」も、どちらの結末でも +1。結末の違いは別の場所（さよの死亡 `0x0528`、[townsfolk](../townsfolk/README.md)）に残る
- 直後の `0x35A4` からは [vitals](../vitals/README.md)

### 周りの値

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x433A6` | 2 B | u16 | クリアしたなりわいの数（状態の表の合計） | | 🟢 |
| `0x45F40` | 6 B | — | クリアのたびに項目ごとに ±10 変わる | 例 `00 14 14 14 14 14` | ❓ |
| `0x45F46` | 8 B | — | 用途不明 | | ❓ |
| `0x45F4E` | 2 B | u16 | 受注中のなりわいの ID。受注していなければ 0 | | ✅ |
| `0x45F50` | 2 B | — | 用途不明 | | ❓ |
| `0x45F52` | 2 B | u16 | 受注した日（経過日数 [stats](../stats/README.md) `0x0BD8` と同じ数え方） | 1日目＝0、2日目＝1 | ✅ |
| `0x45F54` | 1 B | u8 | 受注した時間帯（[date-location](../date-location/README.md) `0x0014` と同じ） | 0＝昼、2＝夜（1＝夕は未観察） | ✅ |
| `0x45F55` | 1 B | u8 | 受注中だけ `FF` | | 🔶 |

- 報酬の容姿は [appearance](../appearance/README.md)、装飾品は [accessories](../accessories/README.md)

### 受注で書かれる値

受注すると、`0x45F4E`・`0x45F52`・`0x45F54`・`0x45F55` に加えて、状態の表が `FFFF` なら 0 になる（✅ 受注の差分）。
続き物の依頼主は、受注のときになりわいのフラグ（[townsfolk](../townsfolk/README.md) `0x011C + 番号`）にも書く。

| なりわい | 受注中のフラグ | 確度 |
|---|---|---|
| 同心 171〜178 | 番号 4＝n1（n 件目。171 で 11 … 178 で 81） | ✅ 171 ／ 🟢 ほか |
| 極道 179〜185 | 番号 5＝n1（11〜71） | 🟢 |
| 極道 186（8件目） | 番号 5 は書かない（80 のまま） | 🟢 |
| 泥棒さん 187〜194 | 番号 6＝n1（11〜81） | 🟢 |
| おっつぁん 195・196・197・199・201・202・204 | 番号 7＝n1（この順に 11〜71） | 🟢 |
| おっつぁん 205（8件目） | 番号 7 は書かない（80 のまま） | 🟢 |
| おっつぁん 203・206 | 202・205 を終えたその場で受ける。番号 7 はそのときの値（61・80）のまま | 🟢 |
| 汁部 209〜212 | 番号 27＝1。28〜31 は前の結果を報告したときに 0 に戻っている | ✅ 209 ／ 🟢 ほか |
| 基本 3〜161、賭場・女将 163〜170、最後 207・208 | 書かない | 🟢 |

- 報告すると、続き物のフラグは次の件の n0 になる（同心なら 171 の報告で 20）（🟢）
- 受注を破棄したときのフラグの値は ❓

### 報酬と続き物

| 報酬・変化 | 保存される場所 | 確度 |
|---|---|---|
| 成功報酬・追加報酬（倒した数・壊した数・拾った数に応じたお金） | 所持金 `0x0008` に足される | 🟢 |
| 治安の増減 | 治安 | 🔶 |
| 次のなりわいが受けられるようになる（続き物） | なりわいのフラグ（[townsfolk](../townsfolk/README.md) `0x011C`〜） | ✅ |
| 汁部（DLC）の次の依頼（209 → 212 の順） | なりわいごとの状態（🟢）。記録 `0x33A4`〜 ではない（記録の 209 が 5 でも 209 から頼まれた ✅）。位置は ❓。フラグ 27〜31 は組んでいるかと、終えたばかりの結果だけ | 🟢 |
| 物を受け取る・人の状態が変わる（「四天王の証」、さよの生死など） | なりわいのフラグ、町の人の状態 | 🟢 |
| 容姿・装飾品 | [appearance](../appearance/README.md)・[accessories](../accessories/README.md) | |

## 編集時の注意

- 状態を 1 にすると、なりわい一覧でクリア済みになる（`0xD1` で確認）。容姿・装飾品・クリア数は自動では変わらない
- クリア数 `0x433A6` は状態の表の合計と揃えておく（揃っていないときの動作は ❓）
- 続き物を進めたいときは、状態の表ではなくなりわいのフラグを書き換える
- 受注を書くときは、受注中の情報4か所を今の日・時間帯で書き、続き物なら上の表のフラグも合わせる。書き込みの反映は ❓（要ゲーム内確認）
- 受注を外すときは、受注中の情報4か所を 0 にする。続き物のフラグ n1 を n0 に戻すのはエディタの判断（🔶）
