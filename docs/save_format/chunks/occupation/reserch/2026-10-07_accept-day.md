# 受注した日を変えた「今宵の虎徹は」の受注の差分

- 日付：2026-10-07
- 目的：受注中の情報 `0x45F52`・`0x45F54` が何で決まるかを確かめる（「出頭命令」では 3・2、1日目昼の「今宵の虎徹は」では 0・0 だった）
- 環境：Steam版、0x48BB0

## サンプル

| ファイル | 操作 | 日・時間帯 |
|---|---|---|
| 実セーブ B | 1日目昼に「今宵の虎徹は」（209）を受注（[2026-10-07_shirube-accept.md](2026-10-07_shirube-accept.md) の B） | `0x0010` 100、`0x0014` 0、経過日数 `0x0BD8` 0 |
| 実セーブ C | 1日寝たあと、2日目昼に「今宵の虎徹は」を受注 | `0x0010` 200、`0x0014` 0、経過日数 `0x0BD8` 1 |

## 差分

受注中の情報 `0x45F40`〜`0x45F55` だけを比べる（ほかは日をまたいだことによる変化）。

| 位置 | B → C | 解釈 | 確度 |
|---|---|---|---|
| `0x45F4E` u16 | 209 → 209 | 受注中のなりわいの ID | 🟢 |
| `0x45F52` u16 | 0 → 1 | 受注した日（経過日数 `0x0BD8`） | 🔶 |
| `0x45F54` u8 | 0 → 0 | 受注した時間帯（`0x0014`）か。B・C とも昼 | 🔶 |
| `0x45F55` u8 | `FF` → `FF` | 受注中だけ `FF` | 🔶 |

- 「今宵の虎徹は」と「出頭命令」で種類が違う（討伐 0、伝言・説得 3）ので、`0x45F52` が種類ではないかと考えていた。同じなりわいで日だけ変えると値が変わったので、種類ではない
- 「出頭命令」の 3・2 は、この読み方なら4日目（経過日数 3）の夜（時間帯 2）に受注したことになる。そのセーブの日・時間帯は記録していない

## 結論

- `0x45F52` を「受注した日（経過日数）」、`0x45F54` を「受注した時間帯」として ../README.md に書いた（どちらも 🔶）。期限（3日以内など）を数えるのに使うとみられる
- 確かめるには、夕か夜に受注した差分（`0x45F54` が 1・2 になるか）を取る
