# 同心の続き物「出頭命令」の受注の差分

- 日付：2026-10-07
- 目的：続き物のなりわいの進み具合を持つフラグの位置を特定する
- 環境：Steam版、0x48BB0

## サンプル

| ファイル | 操作 | ベースからの差分 |
|---|---|---|
| `sample/S4-DATA_03` | ベース。同心から「出頭命令」を受ける前 | — |
| `sample/S4-DATA_03 copy` | 同心と話して「出頭命令」（ID 171）を受注 | 299 B |

## 差分

時間で進む値、`0x363C`〜 の乱数領域、`0x5C3C`〜・`0x1A6B2`〜 の繰り返しの値は除く。

| 位置 | 前 → 後 | 解釈 | 確度 |
|---|---|---|---|
| `0x0120` u8 | 0 → 11 | なりわいのフラグ 4（同心の続き物）。11＝1件目を依頼済み | 🟢 |
| `0x011E` u8 | 0 → 4 | なりわいのフラグ 2。意味は不明 | ❓ |
| `0x45F4E` u16 | 0 → 171 | 受注中のなりわいの ID | 🟢 |
| `0x45F52` u16 | 0 → 3 | 受注中のなりわいの種類（171 は伝言・説得＝3）か | 🔶 |
| `0x45F54` u8 | 0 → 2 | 用途不明 | ❓ |
| `0x45F55` u8 | 0 → `FF` | 受注中だけ `FF` | 🔶 |
| `0x0013` u8 | 6 → 0x12 | 時間の経過か | ❓ |
| `0x48B69` u8 | 0 → 1 | 用途不明 | ❓ |
| `0x48B80`〜`0x48B82` | `08 08 08` → `06 07 07` | 用途不明 | ❓ |

変わらなかった値：

- 状態の表の 171（`0x34FA`）は受注の前から 0 のまま。0 は「受注中」ではなく、受けられるようになったがまだクリアしていない状態とみられる（🔶）

## ほかのサンプルとの照合

`0x011C + n` を「なりわいのフラグ n」として読むと、既知の位置と合う。

| 位置 | フラグ | 既知の内容（[townsfolk](../../townsfolk/README.md)） | 値 |
|---|---|---|---|
| `0x0127` | 11 | 鍛冶屋の後継者イベントと鍛冶屋の状態 | 10〜110 の段階 |
| `0x0132` | 22 | 堂島が鍛冶屋を継いだ | 0／1 |
| `0x0137`〜`0x013B` | 27〜31 | なりわいの操作ごとに1つずつ 0 → 1（汁部の会話、209〜212 のクリア） | 0／1 |

- sample の 02・04 ではフラグ 10 が 80、13 が 10、16 が 1 で、どれもフラグの値の候補に合う

## 結論

- `0x011C` から u8 の「なりわいのフラグ」の配列（🟢）。続き物の進み具合（同心 4、極道 5、泥棒さん 6、おっつぁん 7）、汁部の 27〜31、鍛冶屋 11、堂島 22 などが入る
- 同心の続き物の値は、十の位が何件目か、一の位が 0＝依頼前・1＝依頼済み。100 で完了（🟢）
- 状態の表の値 0 は、受注前から立っている（🔶 受けられる状態）
- 配列の長さ、フラグ 2 の意味は ❓
