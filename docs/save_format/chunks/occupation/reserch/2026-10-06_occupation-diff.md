# なりわいの受注・クリアの差分

- 日付：2026-10-06
- 目的：なりわいの状態がどこに保存されているかを特定する
- 環境：Steam版、0x48BB0

## サンプル

| ファイル | 操作 |
|---|---|
| `sample/S4-DATA_02` | ベース |
| `02 copy` | 人斬り汁部に初めて話しかけた |
| `02 copy 2` | 話を進め、仕事を受ける直前まで |
| `02 copy 3` | 今宵の虎徹は を受注 |
| `03` | 虎徹をクリア（街道の近藤勇を殺害） |
| `03 copy` | 薬売りを受注（同時に帯刀[0] をエディタで書き換え） |
| `03 copy 2` | 薬売りをクリア |
| `03 copy 3` → `03 copy 4` | 食い逃げ外国人を受注 → クリア |
| `03 copy 5` | おにぎり屋の用心棒を受注 |
| `04` | 03 copy 5 から、さよを殺害してクリア |
| `03 copy 6` | 03 copy 5 から、さよを生かしてクリア |

## 差分

時間で進む値、`0x363C`〜 の乱数領域、帯刀の `+0x86`・`+0x8A` は除く。

| 前 → 後 | 変化 |
|---|---|
| `02` → `02 copy` | 変化なし。`0x0BC0` だけが +297.7（プレイ時間は +64 秒） |
| `02 copy` → `02 copy 2` | `0x0137` 0 → 1 |
| `02 copy 2` → `02 copy 3` | `0x3546` `FFFF` → 0、`0x45F4E` → 209 |
| `02 copy 3` → `03` | `0x3546` → 1、`0x45F4E` → 0、所持金 +3,000、`0x3AB79` `40`、`0x3902` 1、`0x433A6` 1、`0x0138` 1、斬殺数 +2 |
| `03` → `03 copy` | `0x3548` → 0、`0x45F4E` → 210 |
| `03 copy` → `03 copy 2` | `0x3548` → 1、`0x3AB7A` `02`、`0x399C` 1、`0x433A6` 2、`0x0139` 1 |
| `03 copy 2` → `copy 3` → `copy 4` | `0x354A` 0 → 1、`0x3AB79` `C0`、`0x399D` 1、`0x433A6` 3、`0x013A` 1 |
| `03 copy 4` → `copy 5` → `04`／`copy 6` | `0x354C` 0 → 1、`0x3AB7A` `03`、`0x399E`・`0x399F` 1、`0x433A6` 4、`0x013B` 1、`0x0013` `0D` → `10`。殺害（04）だけ `0x0528` 1。生存（copy 6）だけ夜の約束が入った |

ほかに受注・クリアで変わった値：

| 位置 | 観察 |
|---|---|
| `0x45F55` u8 | 受注中だけ `FF` |
| `0x45F40`〜`0x45F45` | `00 14 14 14 14 14` → `0A 1E 1E 0A 1E 1E` → `00 28 28 14 28 28`（クリアのたびに項目ごとに ±10） |

## 対応表

表の添字と受注中の ID（`0x45F4E`）が4件とも一致した。

| ID | なりわい | 状態 | 容姿 | 装飾品の候補（🔶） |
|---|---|---|---|---|
| 209（`0xD1`） | 今宵の虎徹は | `0x3546` | `0x3AB79` bit6（近藤勇セット） | `0x3902` |
| 210（`0xD2`） | 薬売り | `0x3548` | `0x3AB7A` bit1 | `0x399C` |
| 211（`0xD3`） | 食い逃げ外国人 | `0x354A` | `0x3AB79` bit7 | `0x399D` |
| 212（`0xD4`） | おにぎり屋の用心棒 | `0x354C` | `0x3AB7A` bit0 | `0x399E`・`0x399F`（装飾品2点と一致） |

## 書き込みの確認

- 209 の状態を 1 にすると、なりわい一覧でクリア済みになった
- `0x3AB79` に `40` を立てると、容姿に近藤勇セットが出た。装飾品には出なかった

## 結論

- `0x33A4` から u16 × 256 の状態の表（`FFFF` 未受注、0 受注中、1 クリア）。`0x3546` = `0x33A4` + 209 × 2
- `0x45F4E` を受注中の ID、`0x433A6` をクリア数とした（🔶）
- 容姿は `0x3AB79`〜 のビット列（[appearance](../../appearance/README.md)）、装飾品は 1つ1バイトのフラグと推定（[accessories](../../accessories/README.md)）
- 結末の違い（さよの生死）は状態の表には残らない
- 失敗したときの値、`0x0137`〜`0x013B`、`0x45F40`〜 の意味は ❓
