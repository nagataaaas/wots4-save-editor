# 汁部（DLC）の「今宵の虎徹は」の受注の差分

- 日付：2026-10-07
- 目的：汁部の仕事を受注したときに変わるバイトを特定し、受注を書き込めるようにする
- 環境：Steam版、0x48BB0

## サンプル

| ファイル | 操作 | ベースからの差分 |
|---|---|---|
| 実セーブ A | ベース。汁部と組んでいない（なりわいのフラグ 27〜31 がすべて 0、受注中なし） | — |
| 実セーブ B | 汁部と組み、「今宵の虎徹は」（209）を受注 | 29 B |

## 差分

時間・位置で変わる値（`0x0B90`〜、`0x0BC0`〜、`0xA5E8`〜、`0x1A6B2`〜 などの繰り返しの値）は除く。

| 位置 | A → B | 解釈 | 確度 |
|---|---|---|---|
| `0x0137` u8 | 0 → 1 | なりわいのフラグ 27（汁部と組んでいる） | ✅ |
| `0x45F4E` u16 | 0 → 209 | 受注中のなりわいの ID | ✅ |
| `0x45F55` u8 | 0 → `FF` | 受注中だけ `FF` | 🔶 |

変わらなかった値：

- なりわいのフラグ 28〜31（`0x0138`〜`0x013B`）は 0 のまま
- `0x45F40`〜`0x45F4D`、`0x45F50`〜`0x45F54` は 0 のまま。「出頭命令」の受注で 3 になった `0x45F52`、2 になった `0x45F54` も 0
- 状態の表（記録）の 209 は 5、210 は 3、211・212 は 1 のまま。クリア数 `0x433A6` も 12 のまま

## 結論

- 汁部の仕事の受注で変わるのは、フラグ 27＝1、`0x45F4E`＝ID、`0x45F55`＝`FF` の3か所として ../README.md に書いた。受注中のフラグ 27〜31 は「組んだ」と同じ値になる
- 記録の 209 が 5（これまでの周回で5回クリア）でも、組むと 209 から頼まれた。汁部の次の依頼を決める「なりわいごとの状態」は記録 `0x33A4`〜 ではない。位置は ❓
- 210〜212 の受注で `0x45F52`・`0x45F54` が変わるかは ❓（211 は「出頭命令」と同じ伝言・説得）
