# 所持金・金庫

手持ちの所持金と、金庫に預けている金額。どちらも u32 の1値。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x000008` | ✅ |
| 終了（含む） | `0x00000F` | ✅ |
| サイズ | 8 B（u32 × 2） | ✅ |
| 位置の求め方 | 固定（[U-1](../../../check-diff.md#u-1)） | ❓ |
| 妥当性検証 | ファイルサイズが 0x48BB0。所持金 ≤ 99,999、金庫 ≤ 999,999 | ✅ |

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x0008` | 4 B | u32 | 所持金 | 0〜99,999（ゲーム内の上限） | ✅ |
| `0x000C` | 4 B | u32 | 金庫の金額 | 0〜999,999（ゲーム内の上限） | ✅ |

- [TS] が同じ位置を読み書きしている（I-3）。PS3版も同じ位置
- 上限はゲーム内で確認した値（[U] 2026-10-04）
- 周回の終わりに所持金は 0 になる 🟢。クリア・立ち去りのときは先に金庫に足す（999,999 で頭打ち）。死亡のときは金庫に入らず、`0x45F3C`（u32）に写す（取り戻せる額か 🔶。[date-location](../date-location/README.md)「周回の終わりの初期化」）

## 編集時の注意

- 上限を超える値は通常モードでは拒否する
