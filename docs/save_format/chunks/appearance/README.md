# 容姿

容姿設定で選べる服（上半身・下半身・足元・合羽・手甲・脚絆・前掛け）の解放ビット。服の番号（0〜241）ごとに1ビット 🟢。
特典解除で手に入る服・顔・髪型はこのビットではなく、[unlocks](../unlocks/README.md) で決まる 🟢。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x03AB5C` | ✅ |
| 終了（含む） | `0x03AB7A`（服の番号 241 のビットのあるバイト） | 🟢 |
| サイズ | 31 B（248 ビット。使う番号は 0〜241 のうち194個） | 🟢 |
| 位置の求め方 | 固定（U-1） | |
| 妥当性検証 | ファイルサイズが 0x48BB0 | |

```text
服の番号 n のビット = (0x3AB5C + floor(n / 8)) の bit (n mod 8)   （n は datatable/appearance/cloth.csv の ID）
```

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x3AB5C + n/8` bit `n%8` | 1 bit | — | 服 `n` を解放しているか（ID は [cloth.csv](../../datatable/appearance/cloth.csv)） | 1＝解放 | ✅ 32〜46・238〜241 ／ 🟢 ほか |

- `0x3AB60`・`0x3AB61` を `FF` にすると、容姿設定に燕尾服3・ベスト3・タンクトップ3・羽織6 の15着が出た（✅ [U] 2026-10-07）。服の番号 32〜46 と一致する。番号 47 の服はない 🟢
- なりわいの報酬の4セット（✅ 差分。名前は 🟢）：

| 位置 | 服の番号 | セット | なりわい |
|---|---|---|---|
| `0x3AB79` bit6 | 238 | 新撰組 近藤（新撰組の服・新撰組着物・新撰組の足袋 草履） | 今宵の虎徹は |
| `0x3AB79` bit7 | 239 | ドナドナ（桃色の着流し・ベルボトム袴・ドナドナの下駄） | 食い逃げ外国人 |
| `0x3AB7A` bit0 | 240 | さよ | おにぎり屋の用心棒 |
| `0x3AB7A` bit1 | 241 | 新撰組 土方（黒色の副長服） | 薬売り |

- 1つの番号に、上下などの複数の部品が入ることがある（DLC のセット、括り袴・手甲・脚絆など）
- 容姿のビットを立てても装飾品（[accessories](../accessories/README.md)）は増えない
- `0x3AB7B`〜`0x3AB9B` の用途は ❓（実セーブでは全部 0）

## 現在の体型・身長・肌色

服の解放とは別に現在の見た目がある。体型・身長の書き込みの反映はユーザーがゲーム内で確認済み ✅ [U]（2026-10-07）。肌色の値の意味は ✅ [U]、書き込みの反映と関連値は [U-18](../../../check-diff.md#u-18) の確認待ち。位置は固定オフセットを採用する（ユーザー判断 2026-10-07、U-1）。

| 位置（確認したセーブ） | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|
| `0x3AAD8` | u8（幅未確認） | 肌色 | 下表 | ✅ [U] 値／🔶 書き込みの反映 |
| `0x3AADC` | u8（幅未確認） | 性別に関わる値の候補 | 0・1を観測。性別名との対応は未確認 | 🔶 |
| `0x3AADD` | u8 | 体型 | 0＝ふつう、1＝細め、2＝太め | ✅ [U] |
| `0x3AAE0` | float32 LE（cm） | 身長 | 人物（容姿）ごとの身長 × 0.9＝低い、× 1.0＝ふつう、× 1.1＝高い | ✅ [U] |
| `0x4633C` | 未確認 | 体型などの関連値 | 意味未確認 | ❓ |

肌色の値：

| 値 | 肌色 | 備考 | 確度 |
|---|---|---|---|
| 0 | ふつう | | ✅ [U] |
| 1 | 褐色 | | ✅ [U] |
| 2 | 色黒 | | ✅ [U] |
| 3 | 色白 | | ✅ [U] |
| 4 | 赤 | 特典解除で選べる | ✅ [U] |
| 5 | 白 | 特典解除で選べる | ✅ [U] |
| 6 | 緑 | 特典解除で選べる | ✅ [U] |
| 7 | 青 | 特典解除で選べる | ✅ [U] |

- 身長は人物（容姿）ごとに決まっていて、低い・高いはその0.9倍・1.1倍の値が入る ✅ [U]。例：160.0の人物は144.0・160.0・176.0、175.0の人物は157.5・175.0・192.5。選べる容姿の身長は150〜200 🟢
- 上表の固定位置を使い、ファイルサイズが `0x48BB0` と一致し、各フィールドがファイル内に収まる場合だけ編集を許可する（❓ U-1）。容姿ID・性別側の値・後続の名前欄・別の見た目の写しは位置の判定に使わない。性別変更後のセーブでも位置は同じ。固定位置の採用は実装方針であり、全レイアウトで位置が同じという確定ではない。
- 身長は有限の数値であることだけを検証し、そうでない場合は身長欄を読み取り専用にする。

「主人公」ページで個別に編集する（ユーザー判断 2026-10-07）。体型・肌色は選択肢、身長は cm の数値入力。身長は有限の数値なら書き込み、ゲーム内でありうる135〜220（150×0.9〜200×1.1）の外では警告を出す（ユーザー判断 2026-10-07）。通常モードは体型0〜2・肌色0〜7、上級者モードはu8が0〜255を許可する。関連値は数値で個別に編集し、ほかの項目に連動させない。

根拠は[体型・身長・肌色の差分](reserch/2026-10-07_body-height-skin.md)、[低い・細め・褐色との比較](reserch/2026-10-07_body-height-skin-low.md)、[反映確認と性別変更後の並び](reserch/2026-10-07_gender-layout.md)、[肌色の値と身長の倍率](reserch/2026-10-07_skin-height-values.md)。
