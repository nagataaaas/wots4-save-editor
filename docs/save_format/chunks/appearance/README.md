# 容姿

容姿設定で選べる服（上半身・下半身・足元・合羽・手甲・脚絆・前掛け）の解放ビット。服の番号（0〜241）ごとに1ビット 🟢。
特典解除で手に入る服・顔・髪型はこのビットではなく、[unlocks](../unlocks/README.md) で決まる 🟢。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x03AB5C` | ✅ |
| 終了（含む） | `0x03AB7A`（服の番号 241 のビットのあるバイト） | 🟢 |
| サイズ | 31 B（248 ビット。使う番号は 0〜241 のうち194個） | 🟢 |
| 位置の求め方 | 固定（U-1） | |
| 妥当性検証 | ファイルサイズが 0x48BB0 | |

```text
服の番号 n のビット = (0x3AB5C + floor(n / 8)) の bit (n mod 8)   （n は datatable/appearance/cloth.csv の ID）
```

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x3AB5C + n/8` bit `n%8` | 1 bit | — | 服 `n` を解放しているか（ID は [cloth.csv](../../datatable/appearance/cloth.csv)） | 1＝解放 | ✅ 32〜46・238〜241 ／ 🟢 ほか |

- `0x3AB60`・`0x3AB61` を `FF` にすると、容姿設定に燕尾服3・ベスト3・タンクトップ3・羽織6 の15着が出た（✅ [U] 2026-10-07）。服の番号 32〜46 と一致する。番号 47 の服はない 🟢
- なりわいの報酬の4セット（✅ 差分。名前は 🟢）：

| 位置 | 服の番号 | セット | なりわい |
|---|---|---|---|
| `0x3AB79` bit6 | 238 | 新撰組 近藤（新撰組の服・新撰組着物・新撰組の足袋 草履） | 今宵の虎徹は |
| `0x3AB79` bit7 | 239 | ドナドナ（桃色の着流し・ベルボトム袴・ドナドナの下駄） | 食い逃げ外国人 |
| `0x3AB7A` bit0 | 240 | さよ | おにぎり屋の用心棒 |
| `0x3AB7A` bit1 | 241 | 新撰組 土方（黒色の副長服） | 薬売り |

- 1つの番号に、上下などの複数の部品が入ることがある（DLC のセット、括り袴・手甲・脚絆など）
- 容姿のビットを立てても装飾品（[accessories](../accessories/README.md)）は増えない
- `0x3AB7B`〜`0x3AB9B` の用途は ❓（実セーブでは全部 0）

## 現在の体型・身長・肌色

服の解放とは別に現在の見た目がある。体型・身長の書き込みの反映はユーザーがゲーム内で確認済み ✅ [U]（2026-10-07）。肌色と関連値は [U-18](../../../check-diff.md#u-18) の確認待ち。位置は固定オフセットを採用する（ユーザー判断 2026-10-07、U-1）。

| 位置（確認したセーブ） | 型の候補 | 内容の候補 | 値の候補 | 確度 |
|---|---|---|---|---|
| `0x3AAD8` | u8（幅未確認） | 肌色 | 0＝ふつう、1＝褐色、3＝白 | 🔶 |
| `0x3AADC` | u8（幅未確認） | 性別に関わる値の候補 | 0・1を観測。性別名との対応は未確認 | 🔶 |
| `0x3AADD` | u8 | 体型 | 0＝ふつう、1＝細め、2＝太め | ✅ [U] |
| `0x3AAE0` | float32 LE | 身長 | 性別変更前：144.0＝低い、160.0＝ふつう、176.0＝高い。性別変更後：175.0も観測（選択肢名は未確認） | ✅ [U] 位置・書き込み／🔶 175.0の意味 |
| `0x4633C` | 未確認 | 体型などの関連値 | 意味未確認 | ❓ |

上表の固定位置を使い、ファイルサイズが `0x48BB0` と一致し、各フィールドがファイル内に収まる場合だけ編集を許可する（❓ U-1）。容姿ID・性別側の値・後続の名前欄・別の見た目の写しは位置の判定に使わない。

- 身長は有限の100〜250であることを検証する。不正な場合は身長欄を読み取り専用にする。この範囲は検証用の暫定範囲で、ゲーム内の正規範囲ではない（🔶 U-18）。
- 肌色・体型・関連値は1 Bを読み、書き込み時に通常モードの観測値または上級者モードのu8範囲を検証する。
- 性別変更後の `copy 5` でも上表の位置は同じ。固定位置の採用は実装方針であり、全レイアウトで位置が同じという確定ではない。

「主人公」ページに生の値・生バイト・対応を表示して個別に編集する（ユーザー判断 2026-10-07）。通常モードは観測した値のみ（身長は144・160・175・176）、上級者モードはu8が0〜255、身長が100〜250の検証用の値を許可する。関連値は個別に編集し、ほかの項目に連動させない。肌色・関連値の反映は未確認。

根拠は[体型・身長・肌色の差分](reserch/2026-10-07_body-height-skin.md)、[低い・細め・褐色との比較](reserch/2026-10-07_body-height-skin-low.md)、[反映確認と性別変更後の並び](reserch/2026-10-07_gender-layout.md)。
