# 容姿

解放済みの容姿（着替えの候補）のビット列。1つの容姿に1ビット。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x03AB79`（見つかった最初のビット） | ❓ |
| 終了（含む） | ❓ | ❓ |
| サイズ | ❓ | ❓ |
| 位置の求め方 | 固定（U-1） | |
| 妥当性検証 | なし | |

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x3AB79` bit6 | 1 bit | — | 近藤勇セット（なりわい「今宵の虎徹は」の報酬） | 1＝解放 | ✅ |
| `0x3AB79` bit7 | 1 bit | — | なりわい「食い逃げ外国人」の報酬 | 1＝解放 | 🔶 |
| `0x3AB7A` bit0 | 1 bit | — | なりわい「おにぎり屋の用心棒」の報酬 | 1＝解放 | 🔶 |
| `0x3AB7A` bit1 | 1 bit | — | なりわい「薬売り」の報酬 | 1＝解放 | 🔶 |

- ビットの並びはなりわい ID の順ではない（🔶 容姿 ID の順）
- 容姿を立てても装飾品（[accessories](../accessories/README.md)）は増えない
