# 容姿

容姿設定で選べる服（上半身・下半身・足元・合羽・手甲・脚絆・前掛け）の解放ビット。服の番号（0〜241）ごとに1ビット 🟢。
その直前（`0x3AAD4`〜`0x3AB5B`）に主人公の現在の見た目（[主人公の見た目のレコード](#主人公の見た目のレコード)）がある。
特典解除で手に入る服・顔・髪型はこのビットではなく、[unlocks](../unlocks/README.md) で決まる 🟢。

## 範囲

| 項目         | 値                                                | 確度 |
| ------------ | ------------------------------------------------- | ---- |
| 開始         | `0x03AB5C`                                        | ✅    |
| 終了（含む） | `0x03AB7A`（服の番号 241 のビットのあるバイト）   | 🟢    |
| サイズ       | 31 B（248 ビット。使う番号は 0〜241 のうち194個） | 🟢    |
| 位置の求め方 | 固定                                           |      |
| 妥当性検証   | ファイルサイズが 0x48BB0                          |      |

```text
服の番号 n のビット = (0x3AB5C + floor(n / 8)) の bit (n mod 8)   （n は datatable/appearance/cloth.csv の ID）
```

## 構造

| 位置                      | 幅    | 型  | 内容                                                                               | 値      | 確度                         |
| ------------------------- | ----- | --- | ---------------------------------------------------------------------------------- | ------- | ---------------------------- |
| `0x3AB5C + n/8` bit `n%8` | 1 bit | —   | 服 `n` を解放しているか（ID は [cloth.csv](../../datatable/appearance/cloth.csv)） | 1＝解放 | ✅ 32〜46・238〜241 ／ 🟢 ほか |

- `0x3AB60`・`0x3AB61` を `FF` にすると、容姿設定に燕尾服3・ベスト3・タンクトップ3・羽織6 の15着が出た（✅ [U] 2026-10-07）。服の番号 32〜46 と一致する。番号 47 の服はない 🟢
- なりわいの報酬の4セット（✅ 差分。名前は 🟢）：

| 位置           | 服の番号 | セット                                                   | なりわい           |
| -------------- | -------- | -------------------------------------------------------- | ------------------ |
| `0x3AB79` bit6 | 238      | 新撰組 近藤（新撰組の服・新撰組着物・新撰組の足袋 草履） | 今宵の虎徹は       |
| `0x3AB79` bit7 | 239      | ドナドナ（桃色の着流し・ベルボトム袴・ドナドナの下駄）   | 食い逃げ外国人     |
| `0x3AB7A` bit0 | 240      | さよ                                                     | おにぎり屋の用心棒 |
| `0x3AB7A` bit1 | 241      | 新撰組 土方（黒色の副長服）                              | 薬売り             |

- 1つの番号に、上下などの複数の部品が入ることがある（DLC のセット、括り袴・手甲・脚絆など）
- 服の説明は `cloth.csv` の `description_ja`・`description_en` 🟢。複数部品の説明は重複を除いて ` / ` で区切る。194件すべてに説明がある。番号240は部品名ではなく、セットの表示名「さよ」と説明「白地に藍色のかつての少女を思い出させる色合い。」を使う（✅ 表示名・説明 [U]、🟢 番号との対応）。エディタでは説明を名前・種別の下に表示し、なりわいの取得条件はTooltipに表示する。
- 全身の服の表示名・説明は [outfit.csv](../../datatable/appearance/outfit.csv) 🟢。全身の番号と解放番号は別。さよは全身245・服240で、表示名「さよ」・種別「全身」・衣装の説明を使う。特典で手に入る全身の服も容姿ページでは衣装の名前・説明を使い、特典解除ページでは特典の名前・効果を使う。同じ特典に複数衣装がある場合は併記する。保存位置・書き込みの確度は従来どおり（特典は 🔶 U-17）。
- 容姿のビットを立てても装飾品（[accessories](../accessories/README.md)）は増えない
- `0x3AB7B`〜`0x3AB9B` の用途は ❓（実セーブでは全部 0）

## 現在の体型・身長・肌色

服の解放とは別に現在の見た目がある。体型・身長・肌色の書き込みの反映はユーザーがゲーム内で確認済み ✅ [U]（2026-10-07、[U-18](../../../check-diff.md#u-18)）。

| 位置                   | 型               | 内容         | 値                                                                                                                                     | 確度          |
| ---------------------- | ---------------- | ------------ | -------------------------------------------------------------------------------------------------------------------------------------- | ------------- |
| `0x3AAD8`              | u16              | 肌色         | 下表                                                                                                                                   | ✅ [U]（幅 🟢） |
| `0x3AADC`              | u8（幅未確認）   | タイプ       | 0＝男、1＝女（男の人物で 0、さよで 1）。2＝ローラ、3＝子供、4＝動物もある（下の「主人公の見た目のレコード」）                         | 🔶             |
| `0x3AADD`              | u8               | 体型         | 0＝ふつう、1＝細め、2＝太め                                                                                                            | ✅ [U]         |
| `0x3AAE0`              | float32 LE（cm） | 身長         | 人物（容姿）ごとの身長 × 0.9＝低い、× 1.0＝ふつう、× 1.1＝高い                                                                         | ✅ [U]         |

- 身長は人物（容姿）ごとに決まっていて、低い・高いはその0.9倍・1.1倍の値が入る ✅ [U]。例：160.0の人物は144.0・160.0・176.0、175.0の人物は157.5・175.0・192.5。選べる容姿の身長は150〜200 🟢
- 容姿設定で身長を選ぶと、`0x3AAE0` に「基準の身長 `0x46338` × 倍率」、`0x4633C` に選んだ選択肢の番号が入る 🟢。実際の身長は `0x3AAE0` で決まり、`0x4633C` は容姿設定を開いたときのカーソル位置にだけ使われる 🟢。
  これまでの差分（ふつう 0・高い 1・低い 2、`0x46338` は 160.0 のまま。人物を選び直すと 160.0 → 175.0、2 → 0）と一致する
- 上表の固定位置を使い、ファイルサイズが `0x48BB0` と一致し、各フィールドがファイル内に収まる場合だけ編集を許可する。容姿ID・タイプ側の値・後続の名前欄・別の見た目の写しは位置の判定に使わない。タイプ（男→女）変更後のセーブでも位置は同じ。
- 身長は有限の数値であることだけを検証し、そうでない場合は身長欄を読み取り専用にする。

「主人公」ページで個別に編集する（ユーザー判断 2026-10-07）。体型・肌色は選択肢、身長は cm の数値入力。身長は有限の数値なら書き込み、ゲーム内でありうる135〜220（150×0.9〜200×1.1）の外では警告を出す（ユーザー判断 2026-10-07）。通常モードは体型0〜2・肌色0〜7・身長の選択肢0〜2、上級者モードは0〜255を許可する。身長の選択肢は選択肢で個別に編集し、ほかの項目に連動させない（4 B を int32 LE で書く）。

根拠は[体型・身長・肌色の差分](reserch/2026-10-07_body-height-skin.md)、[低い・細め・褐色との比較](reserch/2026-10-07_body-height-skin-low.md)、[反映確認と性別変更後の並び](reserch/2026-10-07_gender-layout.md)、[肌色の値と身長の倍率](reserch/2026-10-07_skin-height-values.md)。

- `0x3AAD4` が人物を指していると、ロード時に部品はその人物から作り直され、部品の番号の書き換えは使われない ✅ [U]。`0x3AAD4` を `FFFF` にすると顔・髪型の書き換えが反映された ✅ [U]
- 人物を選ぶには、`0x3AAD4` に人物の番号、`0x3AAD6` に `second_id`、`0x3AADC` にタイプ、`0x3AAE0` に身長を書く。青年主人公（男→男）・さよ（男→女）で確認 ✅ [U]。
  エディタは人物を変えるとき、今の人物の基準身長に対する倍率（ふつう・高い・低い）を引き継ぎ、`0x4633C` の身長の選択肢も同じ倍率に揃える（選択肢の対応 🟢）。個別に設定しているときや倍率が分からないときは、ふつうにする。
  このときゲームは表示だけを人物から作り、保存ではレコードの部品とモデルの値を書き換えない ✅ [U]。髪の色も表示は人物の値になる ✅ [U]。主人公設定に出ないローラ・子供（男の子・女の子）の組も同じ書き方で選べた ✅ [U]。動物（猫）の組を人物として選ぶとロードでクラッシュした ✅ [U]（人物の番号だけでもクラッシュする）。上半身だけを動物の部品にするのはロードできる ✅ [U]。体の種類 4 は、人間の部品が残っていても、下半身まで外してもクラッシュする ✅ [U]。動物は上半身の部品としてだけ使え、下半身は人間の部品が要る（人の手・足が残って見える）✅ [U]。ゲームで人物を選んだセーブと同じ並びにするため、部品・モデルの値・髪の色もその人物の値で書く 🔶
- 部品を書くときは、`0x3AAD4` を `FFFF` にし、部品の番号とそのモデルの値（`save_models`）を組で書く。こうして書いた顔・髪型と、色違いの手甲・合羽・脚絆・前掛けはゲーム内に正しい色で反映された ✅ [U]。
  モデルの値が別の部品の値だと、見た目が崩れたり（髪型）、色が違ったり（手甲・合羽）する ✅ [U]。保存してもモデルの値は作り直されない ✅ [U]
- 個別に設定（`0x3AAD4`＝`FFFF`）のとき、上半身・下半身を `FFFF`（なし）にするとゲームでエラーになった ✅ [U]。ただし男の子（上半身 41、足元 19）は下半身なしでロードできた ✅ [U]。部品の組み合わせで決まるとみられる ❓。人物を選んでいる間は「なし」でも表示できる（青年主人公の下半身など）
- 上半身 53 はロードでクラッシュする ✅ [U]（部品の CSV の `crash`）
- 名前のない部品と、同じ名前の色違いの部品（下半身のさらし 60・61、コルセット 62・63 ✅ [U]）の見た目は部品の CSV の `alias_ja`（ゲーム内で確認 ✅ [U]、選べる人物の部品 🟢、推定 🔶。確度は備考）。主人公設定に出ないローラ・子供・動物の見た目の組の部品もある 🟢

- `0x3AC28` に `FF FF 00 00`、`0x3AC2C`〜`0x3AC6B` に 64 B の UTF-16LE の名前欄（観測では主人公名と同じ）がある。`0x3AC6C`〜`0x3ACF3` と `0x3DB88`〜`0x3DC0F` は、このレコードとほぼ同じ写し（`+0x12 + 12k` の値だけ違う）。写しを書き換えても見た目は変わらない ✅ [U]。
  これは主人公の見た目ではなく、町に追加で出てくる人物の記録の配列の一部 🟢。`0x3AC2C + 0xFB4·n`（名前）・`0x3AC6C + 0xFB4·n`（見た目）の3件と、`0x3DB48 + 0x34C·n`・`0x3DB88 + 0x34C·n` の組（10件か 🔶）。どの人物の記録かは 🔶（自分の記録が入っているとみられる）

### 手（部品 k＝4）🟢

- 部品 k＝4 は手のモデル。[body.csv](../../datatable/appearance/body.csv) の番号で、男の素手 7、女の素手 10、お年寄りの手 8・11（素手の色違い）、子供 12、人間豚の光沢 14。ほかは人物ごとの手（0 鬼怒川、1 ローラ、2 メリンダ、3 J.J、4 小暮、5 朱美・まだら、9 暗闇脳天、6 とぐろ（9 の色違い）、15 パツキン隊）🟢。
  2〜5・15 は素手に人物の手の部品（手袋などか 🔶）を重ねる
- 書き方は他の部品と同じ（`0x3AAD4`＝`FFFF`、`0x3AB14` に番号、`0x3AB18`〜 に `save_models`）。手を 3（J.J）にして、J.J の手で表示された ✅ [U] 2026-10-08

### 声 🟢

- 声を決める値はこのレコードにもセーブにもない。主人公の声は**顔の部品**ごとに決まる（顔の表に声の番号がある。顔が「なし」のときは上半身の部品で決まる）🟢
- 主人公3人の顔は 若年・青年・壮年それぞれの声、名前のある人物の顔はその人物の声、町の人の顔は町の人の声になる 🟢。顔を書き換えると声も変わる（要ゲーム内確認）
- 人物（`0x3AAD4`）を選んでいる間は、人物の顔の声になる 🟢

### 着替えさせられる姿 🟢

- 拷問の場面（拷問の開始・解放・最後、「士魂は屈せず」）では、見た目を人物ごとに決まった別の姿（男の大半は人間豚、女は別の人物の組）に差し替える。肌色・髪の色・体の種類・体型・身長と、顔・髪型は主人公のままにする 🟢
- 別の場面（夜這いか 🔶）でも、人物ごとの2つ目の姿（男の大半はふんどし）に差し替える処理がある
- どの姿にするかは、`0x3AAD4` の人物 → それがないか姿の指定がなければ `0x3AAD6` の人物 → それもなければ下半身の部品、の順に決まる 🟢。
  個別に設定（`0x3AAD4`＝`FFFF`）でも `0x3AAD6` は残るので、`0x3AAD6` を書き換えるとこの姿が変わる（要ゲーム内確認）

### 動作

- 動作（歩き方など）を人物ごとに変える値は、主人公には使われない 🟢。セーブから動作に関わるとみられるのは体の種類（`0x3AADC`）だけ

エディタでの扱い（ユーザー判断 2026-10-08）：

- タイプは、通常モードでは人物を選ぶと決まる表示だけにする。上級者モードでは `0x3AADC` を単独で書き換えられる（動物 4 は選択肢に出さない）
- 顔・髪型・服の選択肢は、通常モードでは主人公のタイプと同じ性別（男・女）の、名前のある部品だけを出す。
  名前のある部品はどれも男用か女用なので、タイプがローラ・子供のときは、そのタイプ用の名前のない部品を通常モードで出す（ユーザー判断 2026-10-09）。
  部品は層の形の持ち主がそのタイプのもの 🟢（見た目は ✅ [U]）で、ローラ：上半身 6・顔 5・髪型 5・足元 4、子供：上半身 41・75・76・77、顔 27・36、髪型 27・28、足元 19・23。

  上級者モードではタイプに合わない部品と名前のない部品も出し、「男」「女」の組に続けて「セット用」「未使用」の組を並べる
  - セット用：名前のない部品のうち、[person.csv](../../datatable/appearance/person.csv) の人物で使われるもの、または特典の服（`unlock_id`）・服の番号（`cloth_id`）を持つもの
  - 未使用：名前のない部品の残り
- 部品の性別は各 CSV の `gender`（男・女。空欄はどちらでもない）🟢。主人公のタイプとは別の列で、ローラ・子供の値はない。`extra.csv` の `kind` も同じ値から決まる 🟢

- 上半身・下半身の「なし」は、ほかの部品と同じ規則で選べる（通常モードでは人物に「なし」がある下半身だけ）。その項目が「なし」のときは「組み合わせによっては読み込めないかもしれない」と警告する（止めない）
- 「上裸にする」「下裸にする」のボタンで、上半身・下半身を服の層を外した体の層だけにする（体の種類が男・女のときだけ。足元は変えない。ユーザー判断 2026-10-08）。

  - 上級者モードでは、部品ごとに層1〜層4を別々に選べる。部品の番号とほかの層は変えず、人物を `FFFF` にする
  - 層の値はテクスチャの番号で、層の形（メッシュ）は部品の番号で決まる ✅ [U] 2026-10-08（幕末の志士の足元の層1に青年主人公の足の値を書くと、ブーツの形に草履のテクスチャが張られた）。
    形を層ごとに別の部品のものにすることはできない
  - そのため選べる値は「なし（`FFFF`、その層が消える）」と、その部品のその層の形の色違い（部品の CSV の `layer_textures`）だけ。各層には形の名前（`layer_meshes`）を出す。
    部品にない層・部品が「なし」のときは選べない
