# 動物の見た目の組を人物として選ぶ

- 日付：2026-10-08
- 目的：猫の見た目の組を、人物の番号の書き込みで選べるかを確かめる（U-19）
- 環境：Steam版、ファイルサイズ `0x48BB0`。男の主人公の実セーブのコピー

## 書き込みの確認

| 位置 | 値 | 内容 |
|---|---|---|
| `0x3AAD4` | `33 00 33 00` | 人物の番号 51（猫の組）、`0x3AAD6` 51 |
| `0x3AADA` | `00` | 髪の色 0 |
| `0x3AADC` | `04` | 体の種類 4（動物） |
| 上半身 | `2E 00`、モデルの値 `BF 00 FF FF FF FF FF FF` | 46（猫） |
| 下半身・顔・髪型・k＝4・足元 | `FF FF`、モデルの値 `FF` × 8 | なし |

身長 `0x3AAE0` は変えていない。

- ロードでクラッシュした [U]
- 以前、個別に設定のまま上半身だけを 46 にしたときはロードでき、猫の見た目になった [U]（[名前のない部品](2026-10-08_unnamed-parts.md)）

## 結論

- 動物の組は人物として選べない（クラッシュする）✅ [U]。原因が体の種類 4・部品の「なし」・身長のどれかは切り分けていない ❓
- エディタは動物を人物の選択肢に出さない。上半身の 46〜49（猫・犬・野犬・馬）は、上級者モードの部品として選べるままにする
