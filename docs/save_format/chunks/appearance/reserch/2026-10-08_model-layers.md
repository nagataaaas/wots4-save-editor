# モデルの値の層（体と服）

- 日付：2026-10-08
- 目的：部品の組のモデルの値（+4〜+B）を、部品の番号と別に書いて、組み合わせた見た目を作れるかを確かめる（U-19）
- 環境：Steam版、ファイルサイズ `0x48BB0`。幕末の志士を選んだ直後の実セーブのコピー（男）と、女性の主人公を個別に設定にした実セーブのコピー

## 観察

服の部品のモデルの値は「体の層 ＋ 服の層」になっている 🟢。

| 部品 | モデルの値 |
|---|---|
| 上半身 117 裸（男） | 110 |
| 上半身 118 裸 羽織（男） | 110, 176 |
| 上半身 98 コルセット（女） | 152, 180 |
| 上半身 35 黒色のさらし（女） | 152, 184 |
| 下半身 88 ふんどし（男） | 196, 255 |
| 下半身 89 トランクス（男） | 196, 252 |
| 下半身 26 さらし（女） | 233, 276 |

上半身 110・152、下半身 196・233 が男・女の裸の体の層とみられる。

## 書き込みの確認

いずれも `0x3AAD4`＝`FFFF`（個別に設定）にして書いた。結果は [U]。

| テスト | 上半身（番号：モデルの値） | 下半身 | 足元 | 結果 |
|---|---|---|---|---|
| M1 | 117：110, 181（男の体＋女のコルセット） | 95 幕末志士の着物のまま | そのまま | 上半身は裸（コルセットは出ない）、下半身が透明 |
| F1 | 98：152（コルセットの層を外す） | そのまま | そのまま | 上半身は裸、下半身が透明 |
| M2 | 117：110（部品どおり） | 95 のまま | そのまま | 正しく上半身裸 |
| M3 | 117：110 | 32 黒色の袴：196, 259 | そのまま | 下半身が黒袴になった |
| MN | 117：110 | 88：196（ふんどしの層を外す） | 40 はだし（男） | 全裸で正しく表示された |
| FN | 98：152 | 26：233（さらしの層を外す） | 61 はだし（女） | 全裸で正しく表示された |

## 結論

- 服の層を外して体の層だけにすると、裸の見た目を作れる（男・女とも ✅ [U]）
- 男の体に女の服の層を重ねると、その層は出ず、下半身が透明になった（M1）✅ [U]。F1 で下半身が透明になった原因は、組み合わせた下半身（未記録）との関係とみられる ❓。MN・FN のように上半身・下半身とも体の層にそろえると正しく表示された
- 層を自由に組み合わせる書き込みは、組み合わせによって下半身が消える。どの組み合わせが安全かは ❓
