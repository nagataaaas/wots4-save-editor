# ローラの見た目の組を人物として選ぶ

- 日付：2026-10-08
- 目的：主人公設定に出ない見た目の組（ローラ）を、人物の番号の書き込みで選べるかを確かめる（U-19）
- 環境：Steam版、ファイルサイズ `0x48BB0`。男の主人公の実セーブのコピー

## 書き込みの確認

| 位置 | 値 | 内容 |
|---|---|---|
| `0x3AAD4` | `1D 00 1D 00` | 人物の番号 29、`0x3AAD6` 29 |
| `0x3AADA` | `00` | 髪の色 0 |
| `0x3AADC` | `02` | 体の種類 2 |
| `0x3AAE0` | `00 00 0E 43` | 身長 142.0 |
| 部品の組 | 上半身 6・顔 5・髪型 5・k＝4 は 1・足元 4 と各モデルの値 | ローラの組の値 |

ローラの見た目で表示された ✅ [U]。

## 結論

- 主人公設定に出ない見た目の組も、人物の番号・`0x3AAD6`・体の種類・身長・髪の色・部品を書けば選べる（ローラ ✅ [U]）
- [person.csv](../../../datatable/appearance/person.csv) にローラ（29）と、子供の組から男の子（153）・女の子（155）を足した。`selectable` が 0 の人物はエディタの上級者モードだけで選べる
- 子供の組は10組あり、顔・髪型がゲーム内で確認した男の子・女の子の見た目と合う組を選んだ。人物としての表示は要ゲーム内確認 🔶
- 動物（猫・犬・野犬・馬）の組は、上半身だけで身長が 0 の組。人物として選べるかは未確認 ❓
