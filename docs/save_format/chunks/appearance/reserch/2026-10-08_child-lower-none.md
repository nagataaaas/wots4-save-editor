# 男の子の下半身「なし」のまま個別に設定

- 日付：2026-10-08
- 目的：人物の下半身が「なし」のまま個別に設定（`0x3AAD4`＝`FFFF`）にしてロードできるかを見る（U-19）
- 環境：Steam版、ファイルサイズ `0x48BB0`。エディタで人物「男の子」（153）を選んだ実セーブのコピー

## 書き込みの確認

男の子（上半身 41、下半身なし）を選んだあと、エディタで足元を子供の裸足（19）に変えた（`0x3AAD4` が `FFFF` になり、下半身は `FFFF` のまま）。ロードでき、表示も問題なかった [U]。

## 結論

- 個別に設定で下半身が「なし」でも、ロードできる組み合わせがある ✅ [U]。[T5](2026-10-08_animal-isolation-2.md)（猫の上半身、幕末の志士の下半身を外す）や、ユーザーが上半身・下半身を `FFFF` にしたときはエラーになった。部品の組み合わせで決まるとみられる ❓
- エディタは、人物の「なし」が残ったまま個別に設定にするときの警告を続ける（止めない）
- 男の子の人物の足元を子供の裸足（19）にした（ユーザー判断 2026-10-08。組の値は子供の草履 23）
