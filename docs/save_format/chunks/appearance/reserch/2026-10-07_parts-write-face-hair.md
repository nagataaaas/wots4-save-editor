# 顔・髪型の部品の番号の書き込み（1回目）

- 日付：2026-10-07
- 目的：部品の番号（[主人公の見た目のレコード](2026-10-07_parts-record.md)）を書き換えて、見た目に反映されるかを確かめる（U-19）
- 環境：Steam版、ファイルサイズ `0x48BB0`。容姿「幕末の志士」の実セーブのコピー

## 書き込みの確認

| 位置 | 前 → 後 | 意図 |
|---|---|---|
| `0x3AAFC` u16 | `2B 00` → `00 00` | 顔 43（幕末の志士）→ 0（青年主人公） |
| `0x3AB08` u16 | `2A 00` → `0D 00` | 髪型 42（幕末の志士の髪型）→ 13（アフロ） |

ほかの位置（人物の番号 `0x3AAD4`＝238、写し `0x3AC6C`・`0x3DB88`）は変えていない。

- ロード後の見た目は幕末の志士のままだった [U]
- ゲーム内で下半身を変えても、顔・髪型は幕末の志士のままだった [U]

## 結論

- `0x3AAFC`・`0x3AB08` だけを書き換えても、見た目は変わらない
- 考えられる理由（❓）：
  - 人物の番号 `0x3AAD4` が `FFFF` でないと、部品はその人物の定義から作り直される
  - ゲームが読むのは写し（`0x3AC6C`・`0x3DB88`）のほう
- 次は、ゲーム内で見た目を変えて保存したセーブと比べ、人物の番号と写しがどう変わるかを見る
