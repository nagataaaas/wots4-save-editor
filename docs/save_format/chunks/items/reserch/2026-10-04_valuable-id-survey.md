# 重要品の ID 調査（1回目）

- 日付：2026-10-04
- 目的：謎の鍵・拷問部屋の鍵・会談の手紙のアイテム ID を探す（U-14）。チップ・木札の ID（U-12）を確かめる
- 環境：Steam版、0x48BB0

## 方法

重要品（貴重品）の空き枠に候補 ID を個数 1 で入れ、ゲームでロードして重要品の一覧に出た名前を記録した。

候補の考え方（🔶）：貴重品は通常アイテムと共通の ID 空間で、貴重品 0x29〜0x2E の直後に置かれていると推測。
通常アイテムとして定義のない 0x2F〜0x3F、0x41〜0x4F（0x40 はソーダ水）を候補にした。

## 結果

| ID | 一覧に出た名前 |
|---|---|
| `0x2F` | チラシ |
| `0x30` | うなぎ丼 |
| `0x31` | 天丼 |
| `0x32` | 鉄火丼 |
| `0x33` | 熱燗 |
| `0x34` | ししゃも |

チラシ以外は食べ物で、通常アイテムの ID と考えられる。3つの重要品はこの範囲になかった。

## 書き込みの確認

- U-12：Steam版で `0x2D`／`0x2E`（PS3版のチップ・木札）を書き込むと、フリーズはしなかったが、ゲーム内でセーブできなくなった。
  PS3版ではセーブ画面でフリーズしたという報告がある

## 結論

- `0x2F`〜`0x34` を item.csv に追加した
- `0x2D`／`0x2E` は選択肢から外した（ユーザー判断）。すでに入っている枠はほかの ID への変更だけを許す（ユーザー判断）
- 候補を 0x60〜0x62、0x70〜0x73、0x75〜0xBF にも広げることにした
