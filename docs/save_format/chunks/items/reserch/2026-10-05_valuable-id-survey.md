# 重要品の ID 調査（2〜12回目）

- 日付：2026-10-05
- 目的：謎の鍵・拷問部屋の鍵・会談の手紙のアイテム ID を探す（U-14）
- 環境：Steam版、0x48BB0

## 方法

エディタの ID 調査モードで、重要品の空き枠に候補 ID を個数 1 で順に入れ（1回で最大10件）、`sample/` のコピーをロードして、重要品の一覧に出た名前を一覧の並び順で ID に対応づけた。

### 7回目の対応づけ

最初は一覧の並び順のまま、0x00＝がらくた、0x01＝会談の手紙、0x0D＝伯爵の寿司、0x0E＝部品箱（刃？）、0x0F＝部品箱（鍔？）、0x14＝部品箱（柄？）、0x15〜0x18＝お金袋（小〜特大）と対応づけた。

その後、次の2つの確認で、対応づけが1つずれていた（先頭の名前が最後の ID のもので、残りは1つ前の ID のもの）と分かった。

- 道具の枠に 0x00、0x0D〜0x0F、0x14〜0x19 を順に入れると、道具の一覧は 会談の手紙・部品箱×3・お金袋（小〜特大）・がらくた・お宝 の順だった
- 道具の枠に 0x01 を入れると伯爵の寿司だった（エディタの選択肢「会談の手紙」＝0x01 が伯爵の寿司と表示された）

正しい対応：0x00＝会談の手紙、0x01＝伯爵の寿司、0x0D＝部品箱（刃？）、0x0E＝部品箱（鍔？）、0x0F＝部品箱（柄？）、0x14＝お金袋（小）、0x15＝お金袋（中）、0x16＝お金袋（大）、0x17＝お金袋（特大）、0x18＝がらくた。
訂正後、重要品の枠に 0x00 を書くと会談の手紙と表示された。部品箱の「刃？」などはユーザーの推測。

🔶 ほかの回の対応づけも同じようにずれている可能性がある（8回目の 0x19＝お宝は上の確認と一致）。

## 結論

- 上の ID を item.csv に追加した。会談の手紙（0x00）は valuable.csv にも載せ、選択肢に出した（セーブ可否・イベントでの使用は要ゲーム内確認）
- 🔶 0x73〜0xC3 は「茶器」（0x1C の本来の茶器と同じ表示）が続く範囲で、未実装の ID と推測
- 0x6F〜0x72 は宿泊設備で、アイテムではない
- 謎の鍵・拷問部屋の鍵は見つからなかった。未調査は 0xA9〜0xBE の残り、0xD7〜0xFF、0x100 以上。再開するときは 0xD7 から続けるか、鍵の取得前後のセーブを比較する
