# 道具の枠の +0x04〜+0x07

- 日付：2026-10-05
- 目的：手持ちの道具の枠に新しく道具を入れるとき、+0x04〜+0x07 に何を書けばよいかを決める
- 環境：Steam版、0x48BB0

## サンプル

| ファイル | 操作 |
|---|---|
| `sample/S4-DATA_03-*`・`sample/S4-DATA_04` | 手持ち（0x5B40〜）の実例を集めた |
| `sample/S4-DATA_01`・`02` | 同じセーブ（00）から、同じ商人で砥石を1個ずつ買ったもの（買い物差分） |
| -1〜-8 | 手持ちの枠を書き換えて、店で売却一覧を開けるか試したもの |

## 実例

- 普通に手に入れた道具4件（砥石×2・打ち粉・刀油）の +0x04〜+0x07：`06 EE E8 50`、`06 E3 74 28`、`06 16 74 28`、`06 1C 74 28`。先頭はすべて `06`
- 店で続けて買った3件は、+0x04〜+0x07 を u32 として読むと差が 1536・52480 と近い。前から持っていた砥石はそれより大きい（🔶 時刻だとしても途中で 0 に戻るもの。PC の起動からのミリ秒ではなかった）
- 01・02（同じ商人で砥石を1個）では `06 16 AB 28` と `06 EC A9 28`（02 を作り直す前の版では `06 45 A9 28`）。品・店・操作が同じでも値が違う。上位バイトはどちらも 0x28
- `sample/S4-DATA_04` では、店で買った砥石が別々の2枠に個数 1 ずつ入っていた。普通に手に入れた道具はすべて個数 1
- 空き枠はすべて `FF FF 00 00 00 00 00 00`

## 書き込みの確認

| ファイル | 書き換え | 売却一覧 |
|---|---|---|
| -1 | 無編集（砥石） | ○ |
| -2 | 同じ枠をおにぎりに | ○ |
| -3 | 伯爵の寿司に | ○ |
| -4 | -3 の空き枠におにぎりを追加。+0x04〜+0x07 は `00 00 00 00` のまま | × |
| -5 | -4 の追加した枠の +0x04〜+0x07 を `06 EE E8 50` | ○ |
| -6 | 同 `01 00 00 00` | × |
| -7 | 同 `06 00 00 00` | ○ |
| -8 | 同 `00 EE E8 50` | × |

× は、店で売却一覧を開くときに `Src/UI/UIDerivation/Shop/Type/ShoSell.cpp, Expression: pItemList, message: Pointer is NULL` で落ちた。

## 結論

- 手持ちの道具の枠は +0x04＝`0x06` が必要。+0x05〜+0x07 は 0 でも売却一覧は開く。エディタは空き枠に道具を入れるとき `06 00 00 00` を書く
- +0x05〜+0x07 は 🔶 取得時刻か乱数。どちらかは未確定
- 道具は1枠1個（🔶）。エディタは道具の個数を常に 1 で書く
- 箪笥・貴重品の枠の +0x04 は未確認
