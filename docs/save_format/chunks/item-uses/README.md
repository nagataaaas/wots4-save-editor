# 道具ごとの使用回数

道具（アイテム ID）ごとに使った回数の表。周回中の表と累計の表が 0x400 離れて2つある。記録の画面の「好きな道具」は、累計の表でいちばん多い道具。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | 周回中 `0x002BA4`、累計 `0x002FA4` | 🟢 |
| 終了（含む） | 周回中 `0x002FA3`、累計 `0x0033A3`（直後の `0x33A4` からは [occupation](../occupation/README.md)） | 🟢 |
| サイズ | 0x400 B × 2（u32 × 256 件 × 2） | 🟢 |
| 位置の求め方 | 固定 | 🟢 |
| 妥当性検証 | なし（読み取り専用） | — |

```text
周回中[id] = 0x2BA4 + id * 4   🟢（周回の終わりに 0x2BA4〜0x2FA3 をまとめて 0 にする）
累計[id]   = 0x2FA4 + id * 4   🟢（周回の終わりに消さない）
```

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x2BA4 + 4 × id` | 4 B × 256 | u32 | 道具 id を使った回数（周回中） | id は [アイテム](../../datatable/item/item.csv) の ID。9,999,999 まで | 🟢 |
| `0x2FA4 + 4 × id` | 4 B × 256 | u32 | 道具 id を使った回数（累計） | 9,999,999 まで | 🟢 |

- 道具を使ったときだけ、周回中と累計の同じ添字が同時に +1 される 🟢
