## 差分

- 列の並び（幕府・外国・攘夷）と、行0＝参加・成功の回数は、それまでの解釈と合った
- 阿片密売で密売人を斬ると外国の行1・行2 が +1、見逃すと変化なし
- 行1 と行2 は同時に増えることが多い。分かれたのは剣術大会の準備（行1 だけ）と代官所潜入（行2 だけ）
- 阿弥浜港争乱で赤城・メリンダ・琴吹と戦っても表は 0 のまま
- 幕府の行0 が 2 では、大寄せで `02 02 02 01`（勢力イベントなしの 03 copy 9 と同じ）になり、公儀の剣は出なかった
- 大寄せで変わるバイトは 03 copy 9 と同じ組（`0x3761`・`0x3764`・`0x3789`〜`0x378C`・`0x37A2`・`0x37C3`・`0x37C6`・`0x37FA`〜`0x37FB`）
- 大成功と成功は A ではどちらも `04`。報酬額だけが違う
- `0x0B5C`〜`0x0B68`（u32 × 4）は戦闘ごとに増えた：剣術大会の準備で `0x0B5C`、海兵隊の横暴で `0x0B60`、幕府勢力を斬って `0x0B64`、密売人を斬って `0x0B68` が +1

## 書き込みの確認

大寄せの直前（04 copy 10）に表を書き換えて大寄せを見た結果：

| 行0（友好ポイント） | 行1（対立ポイント） | 行2（敵対状態） | 結果     |
| ------------------- | ------------------- | --------------- | -------- |
| 3                   | 0                   | 0               | 入れる   |
| 3                   | 1                   | 0               | 入れない |
| 4                   | 1                   | 0               | 入れる   |
| 3                   | 0                   | 1               | 入れる   |
| 3                   | 0                   | 5               | 入れる   |

- 攘夷の行2 を 1 に書き換えると、売国奴を斬れで門前払いされた。ほかのイベントでは「直前に敵対行為を取った」ときの選択肢が出て、謝罪してイベントを成功させると行2 が 0 に戻り、行0 が +1 された
- 大寄せのあとにルート分岐（`0x3789`〜`0x378B`）を書き換えると、ルートが変わった。`0x378C` が `01` でも、どれかの勢力が `01` だと根無し草にはならない
- ルート分岐を `01` にしても、門が閉じているとそのルートに進めなかった。閉じた状態で友好度を書き換えても門は開かなかった

## 結論

- 行0＝友好ポイント、行1＝対立ポイント、友好度＝行0 − 行1。ルートの条件は友好度 ≥ 3（[F] の「2つ以上」は誤り）
- 行2＝今その勢力と敵対しているか（bool）。ルート判定には使われない
- `0x3789`〜`0x378C` をルート分岐として ../README.md に反映した
- 門の開閉は別のフラグ（[gates](../../gates/README.md)）
- ❓ `0x3768`（幕府勢力を斬ったときに 0 → 1）の意味
