# 勢力の 3×3 表の推定

- 日付：2026-10-05
- 目的：イベントの成否で立つバイトから、勢力友好度の置き場所を探す
- 環境：Steam版、ファイルサイズ 0x48BB0。主人公「名無し侍」

## サンプル

| ファイル | 操作 | ベースからの差分 |
|---|---|---|
| `sample/S4-DATA_03 copy 3` → `copy 4` | 志士との出会い（攘夷）完了 | `0x3782` +1 |
| `sample/S4-DATA_03 copy 5` → `S4-DATA_04 copy` | 海兵隊の横暴（攘夷）成功 | `0x3782` +1、`0x3793` 1 |
| `sample/S4-DATA_03 copy 5` → `S4-DATA_04 copy 2` | 海兵隊の横暴 失敗（赤城と戦闘） | `0x3785`、`0x3788` |
| `sample/S4-DATA_04 copy 2` → `copy 3` | 阿片密売を阻止せよ（幕府）で密売人を斬る | `0x3780`、`0x3784`、`0x3787` |
| `sample/S4-DATA_04 copy 4` → `S4-DATA_03 copy 6` | 代官所潜入（攘夷）。木箱1つ | `0x3782` +1、`0x3786` |
| `sample/S4-DATA_04 copy 4` → `copy 5` | 辻斬りを辻斬る（外国）成功 | `0x3781` +1 |
| `sample/S4-DATA_03 copy 5` → `S4-DATA_04 copy 4` | 海兵隊の横暴に2回目の成功 | `0x3782` +1、`0x3793` 1（1回目と同じ） |

## 差分

| 操作 | 立ったバイト | 3×3 に並べたときの位置（行, 列） |
|---|---|---|
| 志士との出会い（攘夷）完了 | `0x3782` +1 | (0, 2) |
| 海兵隊の横暴（攘夷）成功（2回とも同じ） | `0x3782` +1 | (0, 2) |
| 海兵隊の横暴 失敗（赤城と戦闘） | `0x3785`、`0x3788` | (1, 2)、(2, 2) |
| 阿片密売を阻止せよ（幕府）で密売人を斬る | `0x3780`、`0x3784`、`0x3787` | (0, 0)、(1, 1)、(2, 1) |
| 代官所潜入（攘夷）。木箱1つ | `0x3782` +1、`0x3786` | (0, 2)、(2, 0) |
| 辻斬りを辻斬る（外国）成功 | `0x3781` +1 | (0, 1) |

- 列を 0＝幕府、1＝外国、2＝攘夷 と置くと、3勢力とも行0 が成功で立った
- 行2 は「その勢力に敵対するイベントに参加した」記録と読めた（代官所潜入 → 幕府、密売人を斬る → 外国、赤城と戦う → 攘夷）
- 行1 は行2 と同時に立つことが多いが、代官所潜入では立たなかった
- 海兵隊の横暴に成功した（海兵隊を斬った）ときは、外国の行1・行2 が立たず、`0x3793` が立った（2回とも）
- `S4-DATA_04`（1周目、別の主人公）は行1 の攘夷だけが 1
- `0x0B5C`〜`0x0B68`（u32 × 4）も戦闘ごとに増えた（別のカウンタの候補 ❓）

## 結論

- `0x3780`〜`0x3788` を勢力の 3×3 表（行0＝参加・成功、行1・行2＝敵対的な行動の記録）として ../README.md に反映した（🔶。のちに書き換えで確定）
- 列の並び（幕府・外国・攘夷）はこの時点では根拠が弱かった（のちの検証周回で裏付け）
- ❓ `0x3793` の意味
