# 勢力

3勢力（幕府・外国・攘夷）ごとの友好度と敵対状態の 3×3 表と、大寄せで書かれる剣術大会以後のルート分岐。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x003780` | 🔶 |
| 終了（含む） | `0x00378C` | 🔶 |
| サイズ | 13 B（3×3 表 9 B＋ルート分岐 4 B） | 🔶 |
| 位置の求め方 | 固定 | ✅ |
| 妥当性検証 | ルート分岐の各バイトが `00`〜`02`（無所属は `00`〜`01`） | 🔶 |

3×3 表は、行×3＋列の順に並ぶ。

```text
表[行][列] = 0x3780 + 行 * 3 + 列   （列 0＝幕府、1＝外国、2＝攘夷）
```

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x3780`〜`0x3782` | 3 B | u8 × 3 | 行0：友好度 + の回数（その勢力のイベントへの参加・成功） | 0〜 | ✅ 書き換えで大寄せの結果が変わる |
| `0x3783`〜`0x3785` | 3 B | u8 × 3 | 行1：友好度 − の回数（その勢力への不利益・敵対行為、その勢力の人物と戦う） | 0〜 | ✅ 書き換えで大寄せの結果が変わる |
| `0x3786`〜`0x3788` | 3 B | u8 × 3 | 行2：今その勢力と敵対しているか | 0／1 | ✅ |
| `0x3789` | 1 B | u8 | ルート分岐：幕府 | `00` 大寄せ前、`01` ルートに入れる、`02` 入れない | ✅ |
| `0x378A` | 1 B | u8 | ルート分岐：外国 | 同上 | ✅ |
| `0x378B` | 1 B | u8 | ルート分岐：攘夷 | 同上 | ✅ |
| `0x378C` | 1 B | u8 | ルート分岐：無所属 | `00` どれかの勢力に入れる（または大寄せ前）、`01` 無所属（根無し草） | ✅ |

行0〜2 とルート分岐は、通し番号（[../../README.md](../../README.md) §3）の 216〜228 に当たる（🟢。位置・並び・値は上の表と一致）。

### 友好度とルートの条件

- 友好度＝行0 − 行1。大寄せ（[大老の大寄せ](../../../events/other__4_day__the_chief_ministers_big_move.md)、イベント添字41）のときに勢力ごとに判定し、**行0 − 行1 ≥ 3** の勢力が `01`、それ以外が `02` になる（✅）
- 幕府は加えて、茂呂（`0x3752`、[characters](../characters/README.md)）が `01`（死亡）でないことが要る。茂呂が死んでいると友好度が 3 以上でも `02`（🟢）
- 3勢力とも `02` のとき、無所属（`0x378C`）が `01` になる（🟢）
- 行2（敵対状態）はルートの判定に使われない（1・5 でもルートに入れた ✅）
- ルート分岐は大寄せのあとに書き換えても効く（✅）。無所属（`0x378C`）が `01` でも、どれかの勢力が `01` ならその勢力のルートが優先される
- ルート分岐を `01` にしても、門が閉じているとそのルートに進めない（[gates](../gates/README.md)）

大寄せのあとにルート分岐が `02` に変わる場面（🟢。`01` に戻る場面は剣術大会以後のその勢力のイベントだけ）：

| 場面 | 変化 |
|---|---|
| 公儀の剣を引き受ける | 外国 `0x378A`・攘夷 `0x378B` = `02` |
| 東国の騎士に参加を決める | 幕府 `0x3789`・攘夷 `0x378B` = `02` |
| 志士の刀を引き受ける | 幕府 `0x3789`・外国 `0x378A` = `02` |
| 上の3つで相手に斬りかかる（戦闘になる） | その勢力のルート分岐 = `02` |
| 最後通告に逆らう | `0x3789`〜`0x378B` すべて `02`、`0x37A8` = 1（[best-route](../best-route/README.md) の範囲） |

### 行0・行1 が動く場面

- 1〜3日目の各勢力のイベントで、参加・成功で行0 +1、その勢力の人物と戦う・逃げる・不利益を与えると行1 +1（🟢）。病院の千両箱を奪う（祝 病院開業）など、行1 が +3 になる場面もある（🟢）
- 同じ失敗でも、会話で断った・追い返された場合は行1 が増えず、戦闘からの逃走や人物を倒した場合は増えることが多い（🟢。辻斬りを辻斬る・電信の失敗など）
- 魔鱗組の力では、攘夷の行0 − 行1 ≥ 3 のときだけ赤城の側に寝返る選択肢が出る（🟢）
- 阿弥浜港争乱の結末（🟢）：

| 結末 | 行1 | 行2（幕府・外国・攘夷） | 門（[gates](../gates/README.md)） |
|---|---|---|---|
| 3連勝 | 変わらない | 0・0・0 | 代官所 `0x377D`・居留地 `0x377E` = 1 |
| 般若党4人に手間取る | 攘夷 +1 | 0・0・1 | 居留地 `0x377E` = 1 |
| 琴吹に助太刀して勝つ | 攘夷 +1 | 0・0・1 | 代官所 `0x377D` = 1 |
| 「犬は好かん」で赤城と組んで勝つ | 幕府 +1・外国 +1 | 1・1・0 | 変わらない |

### 行2（敵対状態）

- 1 のあいだ、その勢力のイベントで門前払いされたり、「直前に敵対行為を取った」ときの選択肢が出たりする（✅）
- 謝罪してイベントを成功させると 0 に戻り、行0 が +1 される（✅）
- 行1 と行2 は、イベントの場面ごとに別々に決まる（🟢）。行1 と同時に増えることが多いが、会話で断ったときの失敗は行2 だけが 1 になる、など
- 三姉妹見参の成功・ローラ奪還（戦闘の前）で3勢力とも 0、武人 琴吹光の開始で幕府・外国が 0 に戻る（🟢）
- 🔶 代官所潜入で見張りに見つかると、幕府の行1 +1・行2 = 1 になる（🟢）。一方、実セーブの差分では代官所潜入のあとに幕府の行2 だけが 1 になり、行1 は増えていなかった。どの場面でそうなったかは要ゲーム内確認

### ゲーム側の仕様

| 勢力 | 主要人物 |
|---|---|
| 攘夷（般若党） | 赤城烈斗、小暮迅雷 |
| 幕府（代官所・魔鱗組） | 琴吹光、茂呂茂、鬼怒川怨仙 |
| 外国（英国使節・海兵隊） | ローラ・リータ、J.J、メリンダ |

- イベントへの参加・成功で友好度 +1、不利益を与えたり敵対行為を働いたりした勢力は −1（Wiki）
- 剣術大会の時点で友好度が 3 以上の勢力のルートに進む。どの勢力も満たさないと無所属になる
- 周回をまたいで引き継がれない
- 前の周回と同じ勢力のルートが確定すると、ロード時にフリーズすることがある（ゲームの不具合）

## 編集時の注意

- 行0・行1・行2 とルート分岐は、どれも書き換えがゲームに効く
- ルートを変えたいときは、ルート分岐だけでなく門の状態（[gates](../gates/README.md)）もそろえる
- 大寄せの前に表を書き換えて幕府ルートに入りたいときは、茂呂（`0x3752`）が `01` でないことも確かめる
