# 難易度と新しい周回の開始前の状態

- 日付：2026-10-08
- 目的：難易度の位置と、「続きから」で主人公の設定画面に進む（新しい周回を始める）状態を決めている値を特定する
- 環境：Steam版、0x48BB0

## サンプル

| ファイル | 操作 | ベースからの差分 |
|---|---|---|
| 実セーブ A | 周回の開始前（エンディング後に保存された状態）。難易度 易しい | — |
| 実セーブ B | 周回の開始前。難易度 超難しい | A から 177 B |
| 実セーブ C | B をロードし、主人公の設定を終えて大通りでセーブ | B から 424 B |

## 差分

A → B（難易度だけが違う）：

| 位置 | 前 → 後 | 解釈 | 確度 |
|---|---|---|---|
| `0x0000` u8 | 0 → 3 | 難易度 | ✅ |
| `0x363C`〜`0x36A3` | | [memory-garbage](../../memory-garbage/README.md) | — |
| `0xA548` など | | 武器レコードの +0x86（時間で進む値） | — |
| `0x1A6B2`〜 | | [belt-copy](../../belt-copy/README.md) | — |

A・B とも `0x0010`＝0（周回の終わり）、`0x0013`＝`27`（港（騒乱／希望の光用））。`0x0001`〜`0x0007` は 0。

B → C（周回を始めて大通りでセーブ）：

| 位置 | 前 → 後 | 解釈 | 確度 |
|---|---|---|---|
| `0x0000` u8 | 3 → 3 | 難易度は変わらない | ✅ |
| `0x0010` u16 | 0 → 100 | シナリオの段階（1日目昼） | ✅ |
| `0x0013` u8 | `27` → `0D` | 現在地（大通り） | ✅ |
| `0x0133` u8 | 0 → 1 | 用途不明（[townsfolk](../../townsfolk/README.md)） | ❓ |
| `0x0B90`・`0x0BC0`〜 | | プレイ時間など（[stats](../../stats/README.md)） | — |
| `0x35AE` | | 活力（[vitals](../../vitals/README.md)） | — |
| `0x36A8`（通し番号 0） | 0 → 4 | 最初のイベントの状態 | — |
| `0x3756`・`0x3762`〜`0x3763`・`0x378D`・`0x37C1`〜`0x37C2` | 0 → 1・2 | 周回の始めに立つフラグ | — |
| `0x3900` u16 | `FFFF` → 78 | [hint](../../hint/README.md) | — |
| `0x5C34`〜`0x622B` | | [memory-garbage](../../memory-garbage/README.md) | — |

## 書き込みの確認

- C の `0x0010` だけを 0 に書き換えてロードすると、「続きから」で主人公の設定画面に進み、新しい周回が始まった ✅ [U]
- 同じセーブで、スロット一覧の難易度の表示は「超難しい」だった ✅ [U]
- エディタで `0x0000` を書き換えてロードすると、ゲーム内の難易度に反映された ✅ [U] 2026-10-08（書き込んだ値は未報告）

## 結論

- `0x0000` u8 を難易度として ../README.md に追加した（易しい＝0・超難しい＝3 ✅、普通＝1・難しい＝2 🔶）
- `0x0010`＝0 が新しい周回の開始前の状態であることを [date-location](../../date-location/README.md) に追記した ✅
- 書き換えの反映は ✅。幅（u8 か u32 か）は ❓
