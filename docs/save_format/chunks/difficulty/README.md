# 難易度

周回の難易度。周回の開始前に決まり、周回中も同じ値が残る。スロット一覧の難易度の表示はこの値から出る。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x000000` | ✅ |
| 終了（含む） | `0x000000` | 🟢 |
| サイズ | 1 B | 🟢 |
| 位置の求め方 | 固定 | ✅ |
| 妥当性検証 | ファイルサイズが 0x48BB0。書き込みは 0〜3 のみ | 🟢 |

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x0000` | 1 B | u8 | 難易度 | 0＝易しい、3＝超難しい | ✅ |
| | | | | 1＝普通、2＝難しい | 🟢 |
| `0x0001` | 7 B | — | 使われていない（詰め物）。見たセーブではすべて 0 | | 🟢 |

- 超難しいで周回を始めて1日目にセーブしても 3 のまま。スロット一覧の表示も「超難しい」✅ [U]
- 周回の開始前かどうかは難易度ではなく、[date-location](../date-location/README.md) の `0x0010`（0＝新しい周回の開始前）で決まる ✅ [U]
- `0x0000` を書き換えると、ゲーム内の難易度に反映される ✅ [U]
- 周回の終わり（クリア・立ち去り・死亡のどれでも）に 1 になる 🟢。クリアのあとに保存したセーブは難易度が普通になる ✅ [U] 2026-10-09。
  次の周回の難易度は、主人公の設定の前に選び直す。周回の開始前のセーブで 1 以外の値は、書き換えたもの
- 難しい（2）は特典解除の `0x4331C`、超難しい（3）は `0x4331D` が 2（解除済み）のときだけ選べる 🟢（[unlocks](../unlocks/README.md)）
- 難易度で、周回の終わりの侍評価の係数と、得る侍点が変わる 🟢（[stats](../stats/README.md)）

## 編集時の注意

- 書くのは `0x0000` の1バイトだけ。値は 0〜3
