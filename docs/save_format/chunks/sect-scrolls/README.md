# 流派の書（持ち歩き・箪笥）

装備していない流派を「流派の書」として持つ枠。持ち歩きの 20 枠と、道場の箪笥の 150 枠がある（🟢）。
装備中の流派（構えの組ごとに 1 つ、計 6 つ）は [styles](../styles/README.md) の `0x18A00`〜 にあり、この枠には入らない。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x0048CC` | 🟢 |
| 終了（含む） | `0x0058BD` | 🟢 |
| サイズ | 24 B × 170 枠 ＋ 2 B | 🟢 |
| 位置の求め方 | 固定 | 🟢 |
| 妥当性検証 | ファイルサイズ、箪笥の件数 ≤ 150。エディタは俺流を作る・消すとき、持っていない流派を入手させるときだけ書く（🟢 要ゲーム内確認） | — |

```text
持ち歩き[n] = 0x48CC + n * 24   （n = 0〜19）
箪笥[n]     = 0x4AAC + n * 24   （n = 0〜149）
箪笥の件数  = 0x58BC（u16）
```

## 構造

1枠（24 B）：

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| +0x00 | 2 B | i16 | 流派の書の番号 | 入手物の番号（道具の ID とは別の番号。流派の書は 83 件で 411〜747）。−1＝この枠は俺流か空き | 🟢 |
| +0x02 | 2 B | i16 | 俺流の流派 ID | +0x00 が −1 のときだけ使う。[custom-style](../custom-style/README.md) の +0x00。−1＝空き | 🟢 |
| +0x04 | 20 B | UTF-16LE | 俺流の書だけ：俺流の名前の先頭 10 文字の写し。通常の流派の書は 0 | | 🟢 ／ 🔶使われ方 |

- 空き枠は `FF FF FF FF` ＋ 0 × 20 🟢
- 流派の書の番号と流派 ID は 1 対 1。番号から流派 ID を引く表は datatable に未追加（流派 ID 0・22〜99・105・106・108〜111 の書がある）🟢
- 箪笥の件数（`0x58BC`）は使っている枠の数。持ち歩き・箪笥とも、出し入れのあとは前に詰める 🟢

## 持ち歩ける数と箪笥 🟢

- 持ち歩ける流派の書は **20 まで**。装備中の 6 つは数に入らない
- 流派を手に入れたとき、装備中・持ち歩き・箪笥のどこかに同じ流派があれば何も増えない。なければ持ち歩きの最初の空きに入る。**持ち歩きに空きがなければ手に入らない**（箪笥には自動では送られない）
- 箪笥への出し入れは、道場の箪笥の画面で行う
- 流派を切り替えると、選んだ書の流派を装備し、それまで装備していた流派を書にして、選んだ書があった枠に入れる（入れ替え）
- 装備中の流派は捨てられない。俺流の書を捨てると、俺流とその技の表も消える
- 周回の終わりにこの枠は変わらない（周回をまたいで残る）。はじめからを選んだときだけ空になる
- 「取得流派数」は、6（持っていない DLC の分を引く）＋ 持ち歩きと箪笥の流派の書の数（俺流の書は数えない）。50 以上で実績が解除される
- 俺流を作るには、白紙目録と、持ち歩きか箪笥の空きが要る。作った俺流の書は持ち歩きの空き（なければ箪笥）に入る
- 俺流を作る画面で技を写せるのは、持ち歩き・箪笥の通常の流派の書と、同じ構えの組に装備中の通常の流派から（俺流からは写せない）

## エディタの「流派の入手」

持っていない流派（装備中・持ち歩き・箪笥のどこにもない、流派の書の番号がある流派）を、まだ使っていない状態で入れる。

- 持ち歩きなら最初の空き（ゲームが流派を手に入れたときと同じ）、箪笥なら件数の位置に書き、件数を +1 する。書の枠は +0x00 に書の番号、+0x02 に −1、+0x04〜 は 0
- [styles](../styles/README.md) の流派の表の修練度・段・倒した数を 0 にする（行がなければ書かない）
- [skill-states](../skill-states/README.md) のその流派の技の表の状態をすべて 0 にする（枠は残し、+0x02 も 0）。持っているほかの流派と共有している技の表は変えない。
  構えごとの状態は、同じ構えのほかの技の表で覚えていない技だけ 0 にする。固有技の構えごとの状態は残す（装備したときに技の表へ写るため）
- 主人公が手に入れられない流派（「……」）は上級者モードでだけ入れられる
