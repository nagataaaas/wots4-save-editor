# 俺流

プレイヤーが作った流派（俺流）と、生きた証の人物の流派の写しを入れる表。件数と、1件 80 B の記録 64 枠（🟢）。
技の構成は [belt-copy](../belt-copy/README.md)（俺流の技の表）にある。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x01920E`（件数） | 🟢 |
| 終了（含む） | `0x01A60F` | 🟢 |
| サイズ | 2 B ＋ 80 B × 64 枠 | 🟢 |
| 位置の求め方 | 固定（U-1） | 🟢 |
| 妥当性検証 | ファイルサイズ、件数 ≤ 64、俺流が指す技の表がすべてある（[belt-copy](../belt-copy/README.md) の検証も通る）。書き込みは 🟢（要ゲーム内確認） | — |

```text
俺流[k] = 0x19210 + k * 80   （k = 0〜件数−1。枠は 64）
```

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x1920E` | 2 B | u16 | 件数 | | 🟢 |
| `0x19210 + 80k` | 80 B | 下の表 | 1件 | | 🟢 |

1件（80 B）：

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| +0x00 | 2 B | i16 | 流派 ID | 下の「ID の範囲」 | 🟢 |
| +0x02 | 2 B | i16 | 修練度 | 0〜10000 | 🟢 |
| +0x04 | 2 B | i16 | 段 | 0〜5 | 🟢 |
| +0x06 | 2 B | i16 | その流派で倒した敵の数 | | 🟢 |
| +0x08 | 64 B | UTF-16LE | 名前 | 入力は 10 文字まで。既定は「My流」。枠は 32 文字分 | 🟢 |
| +0x48 | 2 B | i16 | 技の表の ID（1つめ） | [belt-copy](../belt-copy/README.md) の +0x00 | 🟢 |
| +0x4A | 2 B | i16 | 技の表の ID（2つめ） | −1＝なし | 🟢 |
| +0x4C | 2 B | i16 | 技の表の ID（3つめ） | −1＝なし | 🟢 |
| +0x4E | 2 B | — | 使われない | 0（保存のたびに 0 を書く） | 🟢 |

### ID の範囲 🟢

| 流派 ID | 技の表の ID | 中身 |
|---|---|---|
| 1000〜1169 | 2000〜2509 | 主人公が作った俺流。どちらも空いている最小の番号を使い、捨てた番号は再び使われる |
| 2000＋n | 4000＋n | 生きた証の記録 n 番の人物の流派の写し。その人物が町に出るときに作られ、一度入ると読み込みのたびに戻る |

- 主人公の俺流の書は [sect-scrolls](../sect-scrolls/README.md) の枠に「+0x00＝−1、+0x02＝流派 ID」として入る。生きた証の写しは書の枠に入らない 🟢
- 1件は、構え（＝技の表）を 3 つまで持てる。3 つとも同じ構えの組（[styles](../styles/README.md)）でなければならず、構えの組は 1つめの技の表の構えで決まる 🟢
- 段のしきい値は 0（修練度が増えるとすぐ伍段になる）🟢

### 作るとき 🟢

- 白紙目録を 1 つ使う。持ち歩きか箪笥に流派の書の空きが要る
- 選んだ技の腕前点の合計が、いまの腕前点（[styles](../styles/README.md) `0x189FE`）以下でなければならない。腕前点は減らない
- 選べる技は、構えごとの技の状態（[skill-states](../skill-states/README.md)）が 1 か 2 の技
- 作った俺流は流派の書になり、持ち歩きの空き（なければ箪笥）に入る。装備はしない
- 件数の上限を確かめないので、64 件を超えると次の [belt-copy](../belt-copy/README.md) を壊す（🟢 コード上。ゲームで作れる数は ❓）

### 捨てるとき 🟢

- 俺流・その技の表・書の枠が消え、件数が 1 減る
- 技の状態（[skill-states](../skill-states/README.md)）は消えない
- 周回では消えない。はじめからを選んだときだけ消える

## 編集時の注意 🟢

- 書き換えてよいのは修練度・段・倒した数・名前（10 文字まで）。名前を変えるときは、書の枠（[sect-scrolls](../sect-scrolls/README.md)）にある名前の写しも合わせる（🔶 写しの使われ方は未確認）
- 技の表の ID は、実際にある技の表を指していなければならない。ないと読み込みで落ちるとみられる 🔶
- 件数（`0x1920E` と俺流の技の表の件数）、3 つの技の表の構えの組、書の枠との対応を合わせる
- 生きた証の写し（2000 以上）は、その人物が町に出るたびに作り直されるので、書き換えても上書きされるとみられる 🔶
