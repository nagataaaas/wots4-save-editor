# 買い物・帯刀の切り替え・峰打・二刀流の差分

- 日付：2026-10-05
- 目的：買い物と帯刀の操作で変わるバイトを特定し、時間で進む値・乱数と区別する
- 環境：Steam版、ファイルサイズ 0x48BB0（すべてのファイル）

## サンプル

どれも同じスロットの別ファイル。01・02 は、どちらも 00 をロードして作った。

| ファイル | 操作 | ベースからの差分 |
|---|---|---|
| `sample/S4-DATA_00` | ベース（2026-10-03 のセーブ） | — |
| `sample/S4-DATA_01` | ロード後、商人から砥石を1個買ってすぐセーブ。約20秒 | 298 B |
| `sample/S4-DATA_02` | ロード後、同じ商人から砥石を1個買う。帯刀武器を1本目から2本目に切り替える。約1分（商人との会話10秒弱、メニュー画面で刀の確認10秒程度を含む） | 313 B |
| `sample/S4-DATA_02 copy` | 02 の状態から峰打に切り替えただけでセーブ。メニュー画面に5分弱、フィールドを歩いたのは20秒程度 | — |
| `sample/S4-DATA_02 copy 2` | 02 copy の状態から、峰打のまま2本目と3本目で二刀流にしてセーブ | — |

01 と 02 で同じ値になった変化は「買い物で決まる値」、01 と 02 の差が経過時間（約20秒／約1分）に応じて開いた変化は「時間で進む値」、それ以外は「乱数・ごみ」と判断した。
01 と 02 の違い（118 B）は、すべて下の表で説明がつく。

## 差分

**買い物で決まる変化（01・02 で同じ値）**

| 位置 | 00 → 01・02 | 解釈 | 確度 |
|---|---|---|---|
| `0x0008` u32 | 49,894 → 49,619（−275） | 所持金。砥石の代金 | ✅ |
| `0x5B40` | 空き → `10 00 01 00 06 ..` | 道具[0] に砥石（0x0010）×1。+0x04＝`06` | ✅ |
| `0x189FE` u16 | 7,873 → 7,874（+1） | 買い物1回で +1 になるカウンタ（取引回数など）。直前の `0x189FC` は 0x2E で変化なし | ❓ |
| `0x6324` u16 | `FF FF` → `00 00` | 直後に `40 00 00 00 04 00` が続く。店や商人の状態か | ❓ |
| `0x48B80`〜`0x48B82` u8×3 | `08 08 08` → `06 07 07` | 0／1 の値が並ぶ末尾近くの領域。経過時間によらず同じ値 | ❓ |

**時間で進む変化**

| 位置 | 00 → 01（約20秒）／02（約1分） | 解釈 | 確度 |
|---|---|---|---|
| `0x0B90` u32 | 19,338 → 19,356（+18）／19,403（+65） | プレイ時間（秒）。19,338 秒＝約5時間22分 | 🔶 |
| `0x0B94` u32 | 91,847 → 91,865（+18）／91,912（+65） | `0x0B90` と同じだけ増える。91,847 秒＝約25時間31分。周回内（0xB90）／累計（0xB94）の組か | 🔶 |
| 帯刀武器の `+0x86`・`+0x8A` u32 | 帯刀[0]：664 → 682（+18）／715（+51）。帯刀[1]：261 → 261／271（+10） | その武器を手に持っていた時間（秒）。2つは常に同じ値。02 では1本目が +51、切り替えた2本目が +10 | 🔶 |
| `0x35AC` float | 580 → 580／570 | 活力の現在値。約1分で 10 減った（約20秒では変化なし） | ✅位置 ／ ❓減り方 |
| `0x0BC0` float | 27,274.6 → 27,522.4（+247.8）／27,532.9（+258.3） | 経過秒ではない。ロード〜セーブで約 +244、そのあと実時間1秒あたり約 +0.22 で増えるように見える（2点からの推定） | ❓ |
| `0x0BC4` float | 642,426.3 → 642,674.6／642,684.6 | `0x0BC0` と同じだけ増える（差は常に約 615,151.7） | ❓ |

**操作で決まる変化（02 だけ）**

| 位置 | 00・01 → 02 | 解釈 | 確度 |
|---|---|---|---|
| `0xA6A9` u8 | 0 → 1 | 選んでいる帯刀武器の番号（0始まり）。帯刀を1本目から2本目に切り替えた操作と一致する | ✅読み（差分1回） |
| `0xA6A8` u8 | 3（変化なし） | 帯刀している本数か | 🔶 |

**峰打の差分（02 → 02 copy）**

| 位置 | 02 → 02 copy | 解釈 | 確度 |
|---|---|---|---|
| `0xA6AC` u8 | 0 → 1 | 峰打（1＝峰打）。ほかに状態らしき変化はない | ✅読み（差分1回） |
| `0x0B90`・`0x0B94` u32 | 19,403 → 19,701（+298）、91,912 → 92,210（+298） | プレイ時間（秒）。メニュー画面5分弱＋フィールド20秒程度と合う。メニュー画面にいる間も進む | 🔶 |
| 帯刀[1] `+0x86`・`+0x8A` | 271 → 282（+11） | 選んでいる武器。メニュー画面の時間は数えていない | 🔶 |
| 帯刀[2] `+0x86`・`+0x8A` | 77 → 78（+1） | 選んでいない武器も +1 された。操作の途中で一時的に持った可能性 | ❓ |
| `0x1A6B2`〜 のコピー領域 | 上の変化の写しと、乱数・アドレス風の値 | | 🔶 |

`0x0BC0`・`0x0BC4`、`0x35AC`（活力）、`0x363C`〜 は変化しなかった。

**二刀流の差分（02 copy → 02 copy 2）**

| 位置 | copy → copy 2 | 解釈 | 確度 |
|---|---|---|---|
| `0xA6AA` u8 | `FF` → `02` | 二刀流の左手の帯刀武器の番号（0始まり。`FF`＝なし）。3本目を持たせた操作と一致 | ✅読み（差分1回） |
| `0xA6AB` u8 | 0 → 1 | 二刀流（1＝二刀流） | ✅読み（差分1回） |
| `0xA6A9` u8 | 1（変化なし） | 右手（選んでいる）帯刀武器の番号 | ✅ |
| `0xA6AC` u8 | 1（変化なし） | 峰打のまま | ✅ |
| 帯刀[1]・[2] `+0x86`・`+0x8A` | 282 → 294（+12）、78 → 83（+5） | 持っている2本だけが増えた | 🔶 |
| `0x0B90`・`0x0B94` | +83 | プレイ時間（秒） | 🔶 |
| `0x0BC0`・`0x0BC4` float | 27,532.96 → 27,540.81（+7.85） | 02 copy では +0 だった | ❓ |

`0xA6A8`〜`0xA6AF` の並びは `03 01 FF 00 01 00 00 00`。このうち `0xA6AA`〜`0xA6AF` は [TS] の配置では武器袋[0] の +0x00〜+0x05 に当たる。
武器レコード213件のうち +0x00〜+0x05 が `00` 以外なのは武器袋[0]（`FF 00 01 00 00 00`）だけ。コピー領域にも同じ並び（`0x1A972`〜、`0x1AD7A`〜）がある。

**乱数・ごみ**

| 位置 | 値 | 解釈 | 確度 |
|---|---|---|---|
| `0x363C`〜`0x36A3` | 16 B 刻み7件の各8 B（各件の +0x08 に float 1.0 が固定） | 00 はアドレス風、01 は 0x0120 前後の u16、02 は半精度浮動小数（`00 3C`＝1.0）風。未初期化の領域か乱数 | 🔶 |
| 道具[0] の +0x05〜+0x07 | 01：`16 AB 28`、02：`EC A9 28` | 同じ店で同じ品を買っても値が違う | 🔶 |
| `0x5C3C` から 0x7C 刻みで12か所（各8 B）、`0x1A762`〜 ほか | 例 `79 73 4F 8E 24 FB 0F 01` → `FC 72 66 5C 8C F7 94 00` | 0x010FFB24・0x0094F78C のような32ビットのメモリアドレスに見える値。同じ日にプレイした 01・02 では一致し、別の日の 00 とは違う | 🔶 |
| `0x1A6B2`〜`0x1AD7B` | 下記 | 帯刀武器のコピーを含むブロック。上の値の写しと、乱数・アドレス風の値が混ざる | 🔶 |

**帯刀武器のコピー**：帯刀[0]〜[2] のレコード本体（+0x06〜+0x9F）と完全に同じバイト列が、`0x1A78C`／`0x1A82C`／`0x1A8CC`（および帯刀[2] は `0x1A974`）と、0x408 後ろの `0x1AB94`／`0x1AC34`／`0x1ACD4`（`0x1AD7C`）にもある。
コピー側の +0x00〜+0x05 は 0 とは限らない（帯刀[0] のコピーは `00 00 40 F8 CA 48` などアドレス風の値）。
帯刀武器の +0x86・+0x8A も、選んでいる帯刀武器の番号（`0x1A973`・`0x1AD7B`、本体の `0xA6A9` に当たる）も、コピー側が本体と同じように変わった。

## 結論

- チェックサムはない（01 と 02 の違いは、すべて上の表で説明がつく。ヘッダなどに検査値らしき変化はない）
- `0x0B90`・`0x0B94` をプレイ時間（秒）として [stats](../README.md) に追加した（🔶）
- `0x35AC` を活力の現在値として [vitals](../../vitals/README.md) に反映した。何で減るのかは未確定（U-4）。HP は満タンのままなので `0x35A4` の意味はこの差分では決まらない
- 帯刀の状態 `0xA6A8`〜`0xA6AF` を [belt-state](../../belt-state/README.md)、+0x86・+0x8A を [weapon-record](../../weapon-record/README.md) に反映した
- 乱数・アドレス風の領域を [memory-garbage](../../memory-garbage/README.md)、帯刀武器のコピーを [belt-copy](../../belt-copy/README.md) に反映した。コピーの用途は ❓（[TS] は 0xA4C2 側だけを書き換えて正しく動くので、ロード時は 0xA4C2 側が使われると考えられる）
- 治安：0〜99 の範囲で 1 ずつ動くような変化はなく、候補は見つからなかった（買い物では治安は変わらないと考えられる）
- 流通中の刀：空き武器レコードと同じバイト列が `0x440D2` から 0xA4 刻みで15件見つかった（[market-weapons](../../market-weapons/README.md)。中身のある件では未確認）
- `0x189FE`・`0x6324`・`0x48B80`〜`0x48B82` の意味は残った疑問
