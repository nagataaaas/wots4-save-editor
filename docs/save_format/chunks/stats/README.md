# 侍点・プレイ記録

侍点と、プレイ時間・斬殺数・経過日数などの周回中／累計の記録が並ぶ範囲。多くは u32 の値。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x000B3C` | ✅ |
| 終了（含む） | ❓（確認済みの最後のフィールドは `0x0C30`） | ❓ |
| サイズ | ❓ | ❓ |
| 位置の求め方 | 固定（[U-1](../../../check-diff.md#u-1)） | ❓ |
| 妥当性検証 | ファイルサイズが 0x48BB0。侍点 ≤ 9,999,999 | 🔶 |

  残るもの：侍点 `0x0B3C`、`0x0B94`、`0x0BC4`、`0x0BCC`、`0x0C20`〜`0x0C63`（0x44 B。実セーブで `0x0BDC`〜 と同じ並びの累計とみられる値がある 🔶）
- 斬殺数の候補 `0x0BC8`・`0x0BCC` は、帯刀武器の斬殺数（[weapon-record](../weapon-record/README.md) の +0x9C）と3回一致した
- 敵の種類ごとの斬殺数は [kill-counts](../kill-counts/README.md)
- 経過日数を書くときは [date-location](../date-location/README.md) の `0x0010`・`0x0014` も一緒に書く

## 編集時の注意

- 侍点は 9,999,999 を超える値を通常モードでは拒否する
- 周回数は 99,999（ゲームが増やすときの上限）を超える値を通常モードでは拒否する。2 → 3 にすると、イベントチャートの真ルートの枠と線が全部出る（🟢 要ゲーム内確認）
- 新しい周回を始める書き込みでは、クリア・立ち去りのどちらでも周回数を 1 つ増やす（🟢）
- 経過日数を進めると、過ぎた時間帯の未処理イベントは失敗扱いになる
