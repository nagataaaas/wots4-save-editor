# 侍点・プレイ記録

侍点と、プレイ時間・斬殺数・経過日数などの周回中／累計の記録が並ぶ範囲。多くは u32 の値。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x000B3C` | ✅ |
| 終了（含む） | ❓（確認済みの最後のフィールドは `0x0C30`） | ❓ |
| サイズ | ❓ | ❓ |
| 位置の求め方 | 固定（[U-1](../../../check-diff.md#u-1)） | ❓ |
| 妥当性検証 | ファイルサイズが 0x48BB0。侍点 ≤ 9,999,999 | 🔶 |

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x0B3C` | 4 B | u32 | 侍点 | エディタの入力上限 9,999,999（ゲーム内の上限ではない） | ✅ |
| `0x0B40` | 16 B | — | 用途不明 | | ❓ |
| `0x0B50`〜`0x0B6B` | 28 B | u32 × 7 | 戦闘・行動ごとのカウンタ | `0x0B54` 寿司屋の店主の殺害で +1、`0x0B58` 踏み倒しで +1、`0x0B5C`〜`0x0B68` は戦った相手（勢力）ごとに +1 | ❓ |
| `0x0B6C` | 32 B | — | 用途不明 | | ❓ |
| `0x0B8C` | 4 B | — | 用途不明（三姉妹戦のあとに変わった） | | ❓ |
| `0x0B90` | 4 B | u32 | プレイ時間（秒）。周回中 | メニュー画面にいる間も進む | 🔶 |
| `0x0B94` | 4 B | u32 | プレイ時間（秒）。累計 | `0x0B90` と同じだけ増える | 🔶 |
| `0x0B98` | 40 B | — | 用途不明（`0x0BAE` は三姉妹戦のあとに変わった） | | ❓ |
| `0x0BC0` | 4 B | float32 | 用途不明。時間とともに増え、イベント完了で大きく増える | | ❓ |
| `0x0BC4` | 4 B | float32 | 用途不明。`0x0BC0` と同じだけ増える（差は約 615,151.7） | | ❓ |
| `0x0BC8` | 4 B | u32 | 斬殺数。周回中 | | 🔶 |
| `0x0BCC` | 4 B | u32 | 斬殺数。累計 | | 🔶 |
| `0x0BD0` | 4 B | u32 | 魂技による斬殺数。周回中か | | ❓ |
| `0x0BD4` | 4 B | u32 | 用途不明 | | ❓ |
| `0x0BD8` | 4 B | u32 | 経過日数 | 1日目＝0 | ✅ |
| `0x0BDC` | 16 B | — | 用途不明 | | ❓ |
| `0x0BEC` | 2 B | u16 | 用途不明（海兵隊の横暴の失敗で変わった） | | ❓ |
| `0x0BEE` | 10 B | — | 用途不明 | | ❓ |
| `0x0BF8`〜`0x0C05` | 14 B | — | 用途不明（三姉妹戦のあとに変わった。戦闘の記録か） | | ❓ |
| `0x0C06` | 42 B | — | 用途不明 | | ❓ |
| `0x0C30` | 2 B | u16 | 用途不明（海兵隊の横暴の失敗で変わった） | | ❓ |

- 斬殺数の候補 `0x0BC8`・`0x0BCC` は、帯刀武器の斬殺数（[weapon-record](../weapon-record/README.md) の +0x9C）と3回一致した
- 敵の種類ごとの斬殺数は [kill-counts](../kill-counts/README.md)
- 経過日数を書くときは [date-location](../date-location/README.md) の `0x0010`・`0x0014` も一緒に書く

## 編集時の注意

- 侍点は 9,999,999 を超える値を通常モードでは拒否する
- 経過日数を進めると、過ぎた時間帯の未処理イベントは失敗扱いになる
