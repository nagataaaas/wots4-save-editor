# 侍評価・活動記録

周回の終わりの侍評価（侍度・称号・侍点）に使う値と、プレイ時間・移動距離・斬殺数・経過日数などの周回中／累計の記録が並ぶ範囲。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x000B34` | 🟢（直前の `0x0B33` までは [townsfolk](../townsfolk/README.md)） |
| 終了（含む） | `0x000C63` | 🟢（直後の `0x0C64` からは [kill-counts](../kill-counts/README.md)） |
| サイズ | 304 B | 🟢 |
| 位置の求め方 | 固定 | ✅ |
| 妥当性検証 | ファイルサイズが 0x48BB0。侍点 ≤ 999,999 | 🟢 |

### 行動の回数（`0x0B4C + 4 × i`）

| i | 位置 | 増える場面 | 確度 |
|---|---|---|---|
| 0 | `0x0B4C` | 人が落とした持ち物を、主人公が拾った | 🟢 |
| 1 | `0x0B50` | 主人公の体が当たる動作で人に当たった（持ち物を落とさせようとする。落ちなくても数える） | 🟢 処理 ／ 🔶 どの動作か |
| 2 | `0x0B54` | 戦わない町の人とみられる属性の人を倒した（イベント中は数えない）。寿司屋の店主を殺して +1 した | 🟢 処理 ／ 🔶 属性の意味 |
| 3 | `0x0B58` | 店で代金を踏み倒した（治安 −10 と同時） | 🟢 |
| 4 | `0x0B5C` | 侍らしい選択をした | 🟢 |
| 5 | `0x0B60` | 恥ずかしい選択をした | 🟢 |
| 6 | `0x0B64` | イベントの途中で、抜刀したまま相手に近づいた（抜刀していると話が変わる場面） | 🟢 |
| 7 | `0x0B68` | イベントの途中で、相手に攻撃を当てた（攻撃すると話が変わる場面） | 🟢 |
| 8 | `0x0B6C` | 使われていない | 🟢 |
| 9 | `0x0B70` | 善良ななりわいを成功した | 🟢 |
| 10 | `0x0B74` | 悪質ななりわいを成功した | 🟢 |
| 11〜15 | `0x0B78`〜`0x0B8B` | 使われていない | 🟢 |

- 評価の結果画面の「不適切な行動」は i 0〜3 の合計。i 6・7 は結果画面に出ない
- i 3 は、町の人が踏み倒しを記録する場面でも +1 される（このとき [date-location](../date-location/README.md) の `0x0018` は全ビットが立つ）

### 侍度・称号・侍点の決まり方 🟢

```text
基準 = 難易度 0〜3 ごとに 50・45・40・35
分子 0x0B44 = 基準 + 10×i4 + i6 + 3×i9
分母 0x0B48 = 基準 + i0 + i1 + i2 + 10×(i3 + i4 + i5) + i6 + i7 + i8 + 3×(i9 + i10)
侍度 0x0B38 = 分子 ÷ 分母 ×（難易度の係数 + 終わり方の係数）× 100（0〜120）
  難易度の係数：0.41・0.45・0.46・0.47
  終わり方の係数：クリア 0.75、立ち去り 0、死亡は死亡したときの段階 0x0B98 で
                  900 以上 0.40 ／ 800 0.35 ／ 700 0.30 ／ 600 0.25 ／ 500 0.20 ／ 400 0.15 ／ 300 0.10 ／ 200 0.05 ／ それ未満 0
称号 = 侍度（切り捨て）が 113・105・97・89・81・73・65・57・49・37・25・13・6・2 のどれ以上か（どれにも届かなければ 14）
侍点 0x0B40 = 下の表［難易度］［称号］（クリアなら +100）
```

## 補足

- 斬殺数 `0x0BC8`・`0x0BCC` は、帯刀武器の斬殺数（[weapon-record](../weapon-record/README.md) の +0x9C）と3回一致した
- 技ごとの斬殺数は [kill-counts](../kill-counts/README.md)
- 経過日数を書くときは [date-location](../date-location/README.md) の `0x0010`・`0x0014` も一緒に書く

## 編集時の注意

- 侍点は 999,999（ゲームが足すときの上限）を超える値を通常モードでは拒否する
- 周回数は 99,999（ゲームが増やすときの上限）を超える値を通常モードでは拒否する。2 → 3 にすると、イベントチャートの真ルートの枠と線が全部出る（🟢 要ゲーム内確認）
- 新しい周回を始める書き込みでは、クリア・立ち去りのどちらでも周回数を 1 つ増やす（🟢）
- 経過日数は u16。`0x0BDA`〜`0x0BDB` は書かない
- 経過日数だけを進めても、イベントの開始もチャートの失敗の印も変わらない（どちらも段階 `0x0010` で決まる。[date-location](../date-location/README.md)）🟢 要ゲーム内確認
