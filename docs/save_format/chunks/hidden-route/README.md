# 隠しルート

隠しルート（阿弥浜港争乱で大砲の般若党を倒し、三姉妹見参から入るルート）に入っているかのフラグと、その周りの未解析のバイト。
フラグ列（[scenario-flags](../scenario-flags/README.md)）の中にあり、直前は勢力ごとの記録とルート分岐（[factions](../factions/README.md)）。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x378D` | 🔶 |
| 終了（含む） | `0x37AA` | 🔶 |
| サイズ | 30 B（u8 × 30） | 🔶 |
| 位置の求め方 | 固定（U-1） | ❓ |
| 妥当性検証 | ファイルサイズが 0x48BB0 | ❓ |

範囲は、隠しルートのセーブと通常ルートのセーブで違いが出たバイト（`0x378D`〜`0x37AA`）を含むように取ったもの。終わりに根拠はない。

## 隠しルートに入る条件

- `0x378E`＝1 と、三姉妹見参の成功（イベント状態 A 添字70＝`04`、[event-chart](../event-chart/README.md)）の**両方**が要る ✅
  - どちらか一方だけでは通常ルートのまま。正規の隠しルートで `0x378E` を 0 にすると通常ルートに入る
- 書き換えで入った隠しルートでも、進行は正規と同じように進む ✅（現地へ行けばイベントが起き、ヒントも出る）
- 怒りの矛先のあとは `0x378E` が 2 になる 🔶。怒りの矛先のあとは大老暗殺計画へ飛ぶ（[event.md](../../../event.md)）ので、希望の光に進めない隠しルートを表すのか ❓

## ゲーム側の仕様

- 隠しルートでは、病院が閉じていると再起の望みで赤城が死ぬ（病院の開閉は [facilities](../facilities/README.md)、赤城の状態は [characters](../characters/README.md)）
- イベントチャートで、隠しルートのイベントの**枠**は、記録 B が `04`（過去の周回で記録）か状態 A が `04`（今の周回で成功）のときだけ出る ✅（[event-chart](../event-chart/README.md)）
  - そのため、隠しルートを過去の周回で記録していない主人公では、正規のプレイでも、失敗したイベントや先のイベントの枠が出ない（ゲームの仕様か不具合）
  - 隠しルート以外のイベントは、B が `FF` で A が `05` でも枠が出る
- 隠しルートのエンディングは 希望の光（語学所・病院が開設、カジノが閉鎖などの条件）と、満たさないときの 大老は生きていた（[event.md](../../../event.md)）

## 編集時の注意

- `0x378E` を 1 にしても、三姉妹見参を成功にしないと隠しルートには入らない。エディタは三姉妹見参の今の状態もあわせて表示する
- `0x378E` 以外の29バイトは意味が分からないので、生の値として扱う
