# 隠しルート

隠しルート（阿弥浜港争乱で大砲の般若党を倒し、三姉妹見参から入るルート）に入っているかのフラグと、その周りのバイト。
フラグ列（[scenario-flags](../scenario-flags/README.md)）の中にあり、直前は勢力ごとの記録とルート分岐（[factions](../factions/README.md)）。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x378D` | 🔶 |
| 終了（含む） | `0x37AA` | 🔶 |
| サイズ | 30 B（u8 × 30） | 🔶 |
| 位置の求め方 | 固定（U-1） | ❓ |
| 妥当性検証 | ファイルサイズが 0x48BB0 | ❓ |

範囲は、隠しルートのセーブと通常ルートのセーブで違いが出たバイト（`0x378D`〜`0x37AA`）を含むように取ったもの。終わりに根拠はない。

## `0x378D` と `0x378E`

| 場面 | `0x378D` | `0x378E` | 確度 |
|---|---|---|---|
| 序章の終わり（阿弥浜港争乱の3連戦の終わりなど） | 1 | — | 🟢 |
| [三姉妹見参](../../../events/hidden__prologue__meeting_with_the_three_sisters.md)の成功（隠しルートに入る） | 2 | 1 | 🟢 |
| 隠しルートを外れる場面（下の表） | — | 2 | 🟢 |

- 1〜3日目の通常の勢力イベント（志士との出会い・代官所の面々・小公女謁見など）は、どれも開始条件が `0x378D` = 1。2 になると周回中は 1 に戻らない（🟢）
- 隠しルートのイベントは、どれも開始条件が `0x378E` = 1（🟢）
- `0x378E` = 2 は隠しルートを外れたこと。2 になると周回中は戻らない（🟢）
- [大老暗殺計画](../../../events/hidden__2_day__plot_to_assassinate_the_chief_minister.md)の開始条件は「三姉妹見参の成功（`0x36EE` = 4）かつ `0x378E` = 2 かつ大通りにいる」（🟢）

`0x378E` が 2 になる場面（🟢）：

| イベント | 2 になる場面 |
|---|---|
| 再起の望み | 小暮が死んだとき |
| 怒りの矛先 | 成功したとき |
| 伯爵に刺激を | 失敗したとき、小暮が死んでいれば |
| 運命のルーレット | J.J が死んだとき、小暮が死んでいれば |
| 闇討ち | 失敗したとき |
| 傷心の帰国船 | 成功したとき |

## 隠しルートに入る条件

- `0x378E`＝1 と、三姉妹見参の成功（イベント状態 A 添字70＝`04`、[event-chart](../event-chart/README.md)）の**両方**が要る ✅
  - どちらか一方だけでは通常ルートのまま。正規の隠しルートで `0x378E` を 0 にすると通常ルートに入る
  - `0x378D`・`0x379F`・`0x37AA` を正規の隠しルートと同じ値にしても、ルートは変わらない ✅
- 書き換えで入った隠しルートでも、進行は正規と同じように進む ✅（現地へ行けばイベントが起き、ヒントも出る）

## ゲーム側の仕様

- 隠しルートでは、病院が閉じていると再起の望みで赤城が死ぬ（病院の開閉は [facilities](../facilities/README.md)、赤城の状態は [characters](../characters/README.md)）
- イベントチャートで、隠しルートのイベントの**枠**は、記録 B が `04`（過去の周回で記録）か状態 A が `04`（今の周回で成功）のときだけ出る ✅（[event-chart](../event-chart/README.md)）
  - そのため、隠しルートを過去の周回で記録していない主人公では、正規のプレイでも、失敗したイベントや先のイベントの枠が出ない（ゲームの仕様か不具合）
  - 隠しルート以外のイベントは、B が `FF` で A が `05` でも枠が出る
- 隠しルートのエンディングは 希望の光（語学所・病院が開設、カジノが閉鎖などの条件）と、満たさないときの 大老は生きていた（[event.md](../../../event.md)）

## ローラの好感度（`0x3792`）

外国のイベントの成功で増え、失敗で 1 減る（🟢）。

| イベント | 成功 | 失敗 | ほか |
|---|---|---|---|
| 電信あり | +1 | −1 | |
| 病院占拠事件 | +2（説得したとき） | −1 | |
| 祝 病院開業 | +2 | −1 | 千両箱を奪うと 0 に戻る |
| お団子物語 | +3 または +1 | −1 | 好感度 3 以上で、外国と敵対していなければ場面が分かれて +3。そうでなければ +1 |
| 小公女と大老 | +2 | −1 | |
| 小公女倒れる | +2 | | |

- 全部成功させると 1＋2＋2＋3＋2＋2＝12
- 夜這いの約束（🟢）：3日目夜に、小公女倒れるが成功（イベント状態 A 添字34＝`04`）していて好感度が 10 以上なら、
  謎の鍵（アイテム `0xEE`、[items](../items/README.md)）を持って領事館のローラの部屋の扉に近づくと、鍵を1本使って約束になる。
  その夜にすでに別の相手と約束していると、鍵は減らず約束にもならない
- 謎の鍵は落し物屋で 1000 文で買える。店に並ぶ条件は ❓

| イベント | 増える場面 | 増分 |

| 海兵隊の横暴 | 戦闘でメリンダを峰打ちで倒す（2つの戦闘のどちらでも） | +2 |
| 西洋医学お断り | 戦闘でメリンダを峰打ちで倒す（2つの戦闘のどちらでも） | +2 |
| 病院廃業の企て | 街道の戦闘に勝って千両箱を取る場面（峰打ちで倒したかどうかで分かれない） | +2 |

## チュートリアルの進み方（`0x37AA`）

阿弥浜港争乱で朱美に頼まれたときの戦い方（🟢。[阿弥浜港争乱](../../../events/other__prologue__amihama_harbor_skirmish.md)）。

| 値 | 戦い方 | 選ぶ場面 |
|---|---|---|
| 1 | チュートリアル（朱美の助言つき） | 1周目は必ず。2周目以降は「何をすればいい？」 |
| 2 | 助言なしで1人ずつ | 「口出し無用」（2周目以降） |
| 0 | 般若党とまとめて戦う | 「まとめて相手をしてやる」（3周目以降） |

## 編集時の注意

- `0x378E` を 1 にしても、三姉妹見参を成功にしないと隠しルートには入らない。エディタは三姉妹見参の今の状態もあわせて表示する
- `0x378E` 以外のバイトは生の値として扱う。書き換えたときのゲーム内の反映は確かめていない
