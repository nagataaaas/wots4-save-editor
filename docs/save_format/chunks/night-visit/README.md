# 夜の約束・夜這い

約束中の相手を表す「約束の枠」と、夜這いのたびに1件ずつ足される「夜這いの記録」。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 夜這いの記録 | `0x0137EC`〜`0x013C2F`（件数 u32 ＋ 16 B × 100件） | 🔶 件数・長さ |
| 夜這い回数のカウンタ | `0x013E34`〜`0x013E37`。ほかに `0x37C8`（[scenario-flags](../scenario-flags/README.md) の中） | 🔶 |
| 約束の枠 | `0x014038`〜`0x014063`（0x2C B × 1件） | ✅ |
| 位置の求め方 | 固定（U-1） | |
| 妥当性検証 | 約束の枠の +0x04 が `FFFFFFFF`（空）か、場所 +0x08 が `00`〜`22` | 🔶 |

```text
記録[n] = 0x137F0 + n * 0x10   （n = 0〜99）
```

## 構造

### 約束の枠 `0x14038`〜

約束すると値が入り、夜這いが終わると +0x00〜+0x23 が `FF` に戻る（年齢・血液型・+0x2A は前の値が残る）。

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `+0x00` | 2 B | u16 | 用途不明 | 町娘 0、さよ `FFFF` | ❓ |
| `+0x02` | 2 B | u16 | 約束した日（経過日数。1日目＝0） | | 🔶 |
| `+0x04` | 4 B | u32 | しゃべり方と戦闘力の型 | 例：`0x25`、`0x49`、`0x031B`（さよ）。`FFFFFFFF`＝約束なし | ✅ |
| `+0x08` | 2 B | u16 | 約束の場所（夜這いに入る扉と、その先のマップ） | [夜の約束の場所](../../datatable/place/night-visit-place.csv)。`00`〜`22` | ✅ |
| `+0x0A` | 2 B | u16 | 行き先での人と布団の配置。場所と組で正しい値がある | 組は[夜の約束の場所](../../datatable/place/night-visit-place.csv)の `layout` 列 | ✅位置 ／ 🔶意味 |
| `+0x0C` | 16 B | u16 × 8 | 用途不明 | 3例とも `0A 0B 0E 0F 0C 0D 1D 01` | ❓ |
| `+0x1C` | 4 B | u32 | 名前（または NPC の ID） | 例：`0xD7`（さよ） | ✅ |
| `+0x20` | 4 B | u32 | 見た目（モデル）と声 | 例：`0xF5`（さよ） | ✅ |
| `+0x24` | 1 B | u8 | 年齢 | `FF`＝「？」 | ✅ |
| `+0x25` | 1 B | u8 | 血液型 | 1＝A、2＝B、3＝O、4＝AB、5＝「？」 | ✅ |
| `+0x26` | 2 B | — | 用途不明 | | ❓ |
| `+0x28` | 2 B | u16 | 用途不明。空の枠では `FFFF` | 町娘 1、さよ 0 | ❓ |
| `+0x2A` | 2 B | u16 | 用途不明 | 町娘 7、さよ 0 | ❓ |

- 型・名前・見た目は別々に効く。型だけを変えると台詞と強さが、見た目だけを変えると見た目と声が変わり、メニューの名前は名前の値で決まる

### 夜這いの記録 `0x137EC`〜

| 位置 | 幅 | 型 | 内容 | 確度 |
|---|---|---|---|---|
| `0x137EC` | 4 B | u32 | 件数（夜這いの回数） | 🔶 |
| 各件 `+0x00` | 4 B | u32 | 型（約束の枠の +0x04） | 🔶 |
| 各件 `+0x04` | 4 B | u32 | 名前（約束の枠の +0x1C） | 🔶 |
| 各件 `+0x08` | 4 B | u32 | 用途不明（例：`0x217`、`0x218`） | ❓ |
| 各件 `+0x0C` | 2 B | u16 | 日付（経過日数。約束の枠の +0x02 と同じ値） | 🔶 |
| 各件 `+0x0E` | 1 B | u8 | 年齢 | 🔶 |
| 各件 `+0x0F` | 1 B | u8 | 血液型 | 🔶 |

- 空の件は `FFFFFFFF FFFFFFFF 00000000 FFFF0000`
- 夜這い回数のカウンタは `0x137EC`、`0x13E34`、`0x37C8` の3か所。夜這い回数の表示がどれから来るかは ❓

## 編集時の注意

- 場所 +0x08 だけを書き換えると、布団が宙に浮いたり壁にめり込んだりする。場所と配置 +0x0A は、確かめた組を一緒に書く
- 場所 `23` 以降は名前が空になる（🔶 定義されていない値）。選べるのは `00`〜`22` だけにする
- 約束や記録を新しく作る・消す機能は持たない（❓ の領域を書かずに済ませるため）
- 「タイトルに戻る」からロードすると夜這いのフラグが消える。テストのたびにゲームを完全に終了する

## 未確認・判定待ち

- ❓ +0x00、+0x0C〜+0x1B、+0x26〜+0x2B の意味
- ❓ 配置 +0x0A の割り振り。値は `01`〜`06` と `21`〜`25` の2群に分かれ、さよの `3D` だけ離れている。同じ場所に配置が複数あるか
- ❓ 同じ名前の場所に値が複数ある理由（🔶 同じ地区の別の扉）
- ❓ 記録の書き換えがゲームに反映されるか（要ゲーム内確認）
- ❓ `0x3DB48`〜`0x3DE8E` に、さよとの夜這いのあとで大量の値が書かれた（🔶 さよの個体データか）
