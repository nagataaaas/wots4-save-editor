# 夜の約束・夜這い

約束中の相手を表す「約束の枠」と、夜這いのたびに1件ずつ足される「夜這いの記録」、夜這いの回数のカウンタ。

## 範囲

| 項目                 | 値                                                                                            | 確度         |
| -------------------- | --------------------------------------------------------------------------------------------- | ------------ |
| 夜這い回数           | `0x0137EC`〜`0x0137EF`（u32）。約束の画面の「夜這い回数」                                     | ✅            |
| 夜這いの記録         | `0x0137F0`〜`0x013E2F`（16 B × 100件）                                                        | 🟢            |
| 段階・愛の証の回数   | `0x013E30`〜`0x013E37`（u32 × 2）                                                             | 🟢            |
| 相手ごとの夜這い回数 | `0x013E38`〜`0x013E6F`（u32 × 14）。続く `0x013E70`〜`0x014037` は使われない（0）             | 🟢            |
| 約束の枠             | `0x014038`〜`0x014063`（0x2C B × 1件）                                                        | ✅            |
| 位置の求め方         | 固定                                                                                       |              |
| 妥当性検証           | 約束の枠の +0x04 が `FFFFFFFF`（空）か、場所 +0x08 が `00`〜`22`                              | 🔶            |

```text
記録[n] = 0x137F0 + n * 0x10   （n = 0〜99）
```

## 構造

### 約束の枠 `0x14038`〜

約束すると値が入り、夜這いが終わる（またはすっぽかす）と +0x00〜+0x23 が `FF`、+0x28 が `FFFF` に戻る（年齢・血液型・+0x26・+0x2A は前の値が残る。🟢）。
+0x00〜+0x1B は、約束の相手（町の人の扉ごと、または特別な相手ごと）に決まった値の組で、+0x04 だけが相手ごとに変わる（🟢）。

| 位置    | 幅   | 型      | 内容                                                  | 値                                                                              | 確度           |
| ------- | ---- | ------- | ----------------------------------------------------- | ------------------------------------------------------------------------------- | -------------- |
| `+0x00` | 2 B  | u16     | 約束したときの段階（下の「段階」）                    | 特別な相手 `FFFF`、町の人 0〜3                                                  | 🟢              |
| `+0x02` | 2 B  | u16     | 町の人の種類ごとのまとまり（日付ではない）            | 特別な相手 0、町の人 1・2（3 の組もあるが、3 になる種類の町の人はいない）       | ✅日付でない ／ 🟢 |
| `+0x04` | 4 B  | u32     | しゃべり方と戦闘力の型。町の人の種類の ID（0〜796）   | 例：`0x25`、`0x49`、`0x0250`（先生）、`0x0314`（メリンダ）、`0x01C0`〜`0x01C2`（万由・千佳・百合）、`0x01C6`（ローラ）、`0x031B`（さよ）。`FFFFFFFF`＝約束なし。朱美 `0x01BA` | ✅ ／ 🟢 ID の範囲と朱美の値 |
| `+0x08` | 2 B  | u16     | 約束の場所（夜這いに入る扉と、その先のマップ）        | [夜の約束の場所](../../datatable/place/night-visit-place.csv)。`00`〜`22`       | ✅              |
| `+0x0A` | 2 B  | u16     | 行き先での人と布団の配置（家の中の人数と座標の組。`00`〜`3D`）。場所と組で正しい値がある | 組は[夜の約束の場所](../../datatable/place/night-visit-place.csv)の `layout` 列。`00`〜`02` は同心・岡っ引きがいる配置で、約束の組には出てこない | ✅位置 ／ 🟢意味 |
| `+0x0C` | 16 B | u16 × 8 | 用途不明。+0x18 の値だけ、夜這いの場での相手の配置に使われる | いつも `0A 0B 0E 0F 0C 0D 1D 01`                                                | 🟢値・+0x18 を使うこと ／ ❓意味 |
| `+0x1C` | 4 B  | u32     | 名前（人物のID）                                      | [人物の名前](../../datatable/npc/npc-name.csv)。例：`0xD7`（さよ）、`0x0D`（メリンダ） | ✅              |
| `+0x20` | 4 B  | u32     | 見た目（モデル）と声                                  | 例：`0xF5`（さよ）、`0x57`（先生）、`0x42`（メリンダ）                          | ✅              |
| `+0x24` | 1 B  | u8      | 年齢                                                  | `FF`＝「？」                                                                    | ✅              |
| `+0x25` | 1 B  | u8      | 血液型                                                | 1＝A、2＝B、3＝O、4＝AB、5＝「？」                                              | ✅              |
| `+0x26` | 2 B  | —       | 詰め物（使われない）                                  | `FFFF`                                                                          | 🟢              |
| `+0x28` | 2 B  | u16     | 約束した日（経過日数 `0x0BD8` の値。1日目＝0）。空の枠では `FFFF` | 8人（さよ・かえで・はるな・先生・メリンダ・三姉妹）で約束した日と一致          | 🟢              |
| `+0x2A` | 1 B  | u8      | 初めての説明を見たかのビット。空の枠でも残る          | bit0〜2：夜這いの各段階の説明、bit3〜5：拷問の3種の説明（百合 `0x20` → 万由 `0x28` → 千佳 `0x38`）。ローラとの夜這いでは立たない | 🟢              |
| `+0x2B` | 1 B  | u8      | 使われない                                            | 0                                                                               | 🟢              |

- 型・名前・見た目は別々に効く。型だけを変えると台詞と強さが、見た目だけを変えると見た目と声が変わり、メニューの名前は名前の値で決まる
- 町の人の名前・見た目・年齢・血液型は、約束のときに型ごとの候補から選ばれる（🟢）。名前は女性・男性の名前の候補から、血液型は型で決まっていなければ A〜AB から、年齢は型で決まった十の位に一の位を足して選ぶ

### 段階 `0x13E30`

| 位置      | 幅  | 型  | 内容 | 確度 |
| --------- | --- | --- | ---- | ---- |
| `0x13E30` | 4 B | u32 | 段階（0〜3）。夜這いが終わるたびに、夜這い回数 `0x137EC` から決め直す | 🟢 |

| 夜這い回数 | 段階 |
| --- | --- |
| 0〜9 | 0 |
| 10〜44 | 1 |
| 45〜84 | 2 |
| 85〜 | 3 |

町の人と約束するとき、約束の組（場所・配置）は「段階」の組から 70% で選ばれ、30% で1つ下の段階に下がる（さらに 30% で下がる…）。
段階の高い組ほど、家の中の人（家の者・用心棒）が多い配置になる（🟢）。

### 夜這いの記録 `0x137F0`〜

| 位置         | 幅  | 型  | 内容                                        | 確度 |
| ------------ | --- | --- | ------------------------------------------- | ---- |
| `0x137EC`    | 4 B | u32 | 夜這い回数（約束の画面の「夜這い回数」）。上限 9999。100 回で実績 | ✅    |
| `0x13E34`    | 4 B | u32 | 「愛の証をもらった」で終わった夜這いの回数。上限 9999（記録の件数ではない） | 🟢    |
| 各件 `+0x00` | 4 B | u32 | 型（約束の枠の +0x04）                      | 🟢    |
| 各件 `+0x04` | 4 B | u32 | 名前（約束の枠の +0x1C）                    | 🟢    |
| 各件 `+0x08` | 4 B | u32 | 入った建物の番号（`0x20C`〜`0x228`。同じ建物の扉は同じ番号。例：お屋敷 `0x218`、稲荷前 `0x217`、ローラの部屋 `0x221`） | 🟢    |
| 各件 `+0x0C` | 2 B | u16 | 夜這いした日（経過日数。約束した日と同じ日になる） | 🟢    |
| 各件 `+0x0E` | 1 B | u8  | 年齢                                        | 🟢    |
| 各件 `+0x0F` | 1 B | u8  | 血液型                                      | 🟢    |

- 空の件は `FFFFFFFF FFFFFFFF 00000000 FFFF0000`
- 記録は**最初の空いている件**（+0x00 が `FFFFFFFF`）に書かれる。件数を数える値はない。100件埋まっていると、1件ずつ前に詰めて最後の件に書く（🟢）
- 失敗した夜這い（「ちぢみ…あがってしまった…」）は記録されず、回数も増えない（🟢）
- 周回を始めると、記録・段階 `0x13E30`・`0x13E34`・約束の枠は消え、夜這い回数 `0x137EC` と相手ごとの回数 `0x13E38`〜 は残る（🔶 周回の処理と見たのは消える値の組から）。
  夜這い回数が記録の数より多いセーブ（4〜6日目で回数 1・記録 0）はこれで説明できる

特別な相手と夜這いするたびに、その相手の値が 1 増える（u32、上限 9999。🟢）。さよと町の人は数えない。記録の画面で使われる。

| --- | --- | --- | --- |
| `0x13E38` | 万由 | `0x13E54` | 茂呂 |
| `0x13E3C` | 千佳 | `0x13E58` | 赤城 |
| `0x13E40` | 百合 | `0x13E5C` | J.J |
| `0x13E44` | メリンダ | `0x13E60` | 小暮 |
| `0x13E48` | 朱美 | `0x13E64` | 琴吹 |

### 夜這いの結果と褒美

| 結果 | 表示 | 褒美 |
| --- | --- | --- |
| 成功 | 「愛の証をもらった」 | 下の順番の品。`0x13E34` が 1 増える |
| 成功（ローラ） | 「掘り出し物をいただいた」 | 下の順番の品 |
| 慰めの品 | 「慰めの品をもらった」 | 藁人形・小魚・きのこ・もち・くず鉄のどれか（15・25・30・20・10 %） |
| 失敗 | 「ちぢみ…あがってしまった…」 | なし |

褒美の順番は [scenario-flags](../scenario-flags/README.md) の `0x37C8`（1〜50 を回る。🟢）。成功のたびに 1 進み、
5 ひよこういろう、10 阿修羅きのこ、15 卸し鉄、20 技ノ書、25 秘薬、30 堂島鋼、35 奥義ノ書、40 白紙目録、45 秘奥義ノ書、50 緋緋色金。
それ以外の回は 大根・たまご・うめぼし・お酒・梅酒・ワイン・茶器（30・25・15・15・7・5・3 %）。慰めの品・失敗では進まない。
慰めの品・失敗になる条件は ❓。

## 約束の条件

どの相手も、すでに今夜の約束があると約束できない（「今夜の相手はすでに決まっている……」）。
約束したまま日付が変わると「夜這いの約束をすっぽかしてしまった…」で枠が消える。相手が死ぬと「夜這い相手が死んでしまった…」で消える（🟢）。

### 町の女性

1. 会話の最初の選択肢に「惚れた」が出るのは、相手が女性のとき、または主人公がいま夜杯流体術を使っているとき（🟢。女性かどうかは町の人の種類ごとに決まっている）
2. 一度口説いた相手には「惚れた」が出ない。種類によっては「うわあ……」で終わる（❓ どの種類か）
3. 4つの質問に答え、点の合計が **100 以上**なら約束、未満なら「断られた……」（🟢）

| 質問 | 当たりの答え | 点 |
| --- | --- | --- |
| 1 「いい天気ですね／きれいな夕日ですね／月がきれいですね」 | いまの時間帯（昼・夕・夜）に合うもの（🔶 時間帯との対応） | 20 |
| 2 褒め方（声・お召し物 など） | 相手の種類ごとに決まった1つ | 30 |
| 3 「あなたは上品な人ですね／やさしい人ですね／…」 | 相手の種類ごとに決まった1つ | 40 |
| 4 最後の口説き文句（4つ） | 毎回くじで決まる。当たり 80、外れても 40・30・0 | 80 |

- 最初に 2 点あるので、最大は 172。4問目で 80 を取れば、ほかは1問当たればよい
- 点は会話の中だけの値で、セーブには残らない（🔶）

### 男性の相手（赤城・堂島・J.J・鬼怒川・小暮・琴吹・茂呂）

選択肢の「惚れた」はなく、会話からは口説けない（🟢）。主人公がいま**夜杯流体術**を使っている状態で**相手に攻撃を当てる**と、そのたびに次の流れになる（攻撃を受けたときの反応の中にある 🔶。どの攻撃で起きるかは要ゲーム内確認）。

1. 今夜の約束がすでにあれば、断られて終わる（断られた数は増えない）
2. 1 回目のくじ：夜杯流体術の段（[styles](../styles/README.md) の流派 ID 108 の段。0〜5、修練度 300・1000・2500・4500 で 1〜4）で当たる確率が変わる（🟢）
3. 2 回目のくじ：当たれば約束。外れは 1 回目の外れと同じ扱い
4. 外れると、断られた数が段ごとの上限を超えていれば怒り、超えていなければ断られた数を 1 増やして断られる

| 段（画面の呼び名 🔶） | 1 回目 | 怒る（断られた数がこれを超えている） | 1 回の約束の確率（2 回目が 1/2 の相手） |
|---|---|---|---|
| 0（初段） | 1/8 | 10 | 1/16 |
| 1（弐段） | 1/7 | 12 | 1/14 |
| 2（参段） | 1/6 | 14 | 1/12 |
| 3（四段） | 1/5 | 16 | 1/10 |
| 4（伍段） | 1/3 | 18 | 1/6 |
| 5（極） | 1/2 | 20 | 1/4 |

- 2 回目のくじは、赤城・J.J・鬼怒川・琴吹・茂呂が 1/2、堂島・小暮が 1/5（🟢）
- 段 0 なら、11 回断られたあと、12 回目に外れると怒る。約束すると断られた数は 0 に戻る（🟢）
- 断られた数はセーブに入らない（🔶）。いつ 0 に戻るか（日付・場所の移動など）は ❓
- 堂島以外は、夜杯流体術を使わずに攻撃を当てても同じ数が 1 増え、3 以上か、命が一定より減ると怒る（🟢）
- 怒ったあとに何が起きるか（戦いになるかなど）は要ゲーム内確認

## 編集時の注意

- 場所 +0x08 だけを書き換えると、布団が宙に浮いたり壁にめり込んだりする。場所と配置 +0x0A は、確かめた組を一緒に書く
- 場所 `23` 以降は名前が空になる（🔶 定義されていない値）。選べるのは `00`〜`22` だけにする
- 約束や記録を新しく作る・消す機能は持たない（❓ の領域を書かずに済ませるため）
- 朱美・ローラ・三姉妹・メリンダとの約束の条件（好感度・拷問のポイント・峰打ちの点数）は [best-route](../best-route/README.md) の `0x3792`〜`0x3797`。どれも 10 以上（🟢）
- 約束の +0x28 を今日の経過日数と違う値にすると、日付が変わったときと同じく、すっぽかしとして枠が消えるとみられる（🔶 要ゲーム内確認）
- 「タイトルに戻る」からロードすると夜這いのフラグが消える。テストのたびにゲームを完全に終了する
