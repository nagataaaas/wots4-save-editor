# 夜の約束・夜這い

約束中の相手を表す「約束の枠」と、夜這いのたびに1件ずつ足される「夜這いの記録」。

## 範囲

| 項目                 | 値                                                                                            | 確度         |
| -------------------- | --------------------------------------------------------------------------------------------- | ------------ |
| 夜這いの記録         | `0x0137F0`〜`0x013C2F`（16 B × 100件）。件数は `0x013E34`〜`0x013E37`（u32）                  | 🔶 件数・長さ |
| 夜這い回数の表示     | `0x0137EC`〜`0x0137EF`（u32）。記録の件数とずれることがある                                   | ✅            |
| 約束の枠             | `0x014038`〜`0x014063`（0x2C B × 1件）                                                        | ✅            |
| 位置の求め方         | 固定（U-1）                                                                                   |              |
| 妥当性検証           | 約束の枠の +0x04 が `FFFFFFFF`（空）か、場所 +0x08 が `00`〜`22`                              | 🔶            |

```text
記録[n] = 0x137F0 + n * 0x10   （n = 0〜99）
```

## 構造

### 約束の枠 `0x14038`〜

約束すると値が入り、夜這いが終わると +0x00〜+0x23 が `FF` に戻る（年齢・血液型・+0x2A は前の値が残る）。
+0x00〜+0x1B は、約束の相手（町の人の扉ごと、または特別な相手ごと）に決まった値の組で、+0x04 だけが相手ごとに変わる（🟢）。

| 位置    | 幅   | 型      | 内容                                                  | 値                                                                              | 確度           |
| ------- | ---- | ------- | ----------------------------------------------------- | ------------------------------------------------------------------------------- | -------------- |
| `+0x00` | 2 B  | u16     | 用途不明                                              | 特別な相手（さよ・先生）`FFFF`、町の人 0〜3                                     | 🟢値 ／ ❓意味 |
| `+0x02` | 2 B  | u16     | 用途不明（日付ではない）                              | 特別な相手 0、町の人 1〜3                                                       | ✅日付でない ／ 🟢値 ／ ❓意味 |
| `+0x04` | 4 B  | u32     | しゃべり方と戦闘力の型。町の人の種類の ID（0〜796）   | 例：`0x25`、`0x49`、`0x0250`（先生）、`0x0314`（メリンダ）、`0x01C0`〜`0x01C2`（万由・千佳・百合）、`0x01C6`（ローラ）、`0x031B`（さよ）。`FFFFFFFF`＝約束なし。朱美 `0x01BA` | ✅ ／ 🟢 ID の範囲と朱美の値 |
| `+0x08` | 2 B  | u16     | 約束の場所（夜這いに入る扉と、その先のマップ）        | [夜の約束の場所](../../datatable/place/night-visit-place.csv)。`00`〜`22`       | ✅              |
| `+0x0A` | 2 B  | u16     | 行き先での人と布団の配置（家の中の人数と座標の組。`00`〜`3D`）。場所と組で正しい値がある | 組は[夜の約束の場所](../../datatable/place/night-visit-place.csv)の `layout` 列。`00`〜`02` は代官所の離れ（同心・岡っ引きがいる） | ✅位置 ／ 🟢意味 |
| `+0x0C` | 16 B | u16 × 8 | 用途不明                                              | いつも `0A 0B 0E 0F 0C 0D 1D 01`                                                | 🟢値 ／ ❓意味 |
| `+0x1C` | 4 B  | u32     | 名前（人物のID）                                      | [人物の名前](../../datatable/npc/npc-name.csv)。例：`0xD7`（さよ）、`0x0D`（メリンダ） | ✅              |
| `+0x20` | 4 B  | u32     | 見た目（モデル）と声                                  | 例：`0xF5`（さよ）、`0x57`（先生）、`0x42`（メリンダ）                          | ✅              |
| `+0x24` | 1 B  | u8      | 年齢                                                  | `FF`＝「？」                                                                    | ✅              |
| `+0x25` | 1 B  | u8      | 血液型                                                | 1＝A、2＝B、3＝O、4＝AB、5＝「？」                                              | ✅              |
| `+0x26` | 2 B  | —       | 用途不明                                              |                                                                                 | ❓              |
| `+0x28` | 2 B  | u16     | 約束した日（経過日数。1日目＝0）。空の枠では `FFFF`   | 8人（さよ・かえで・はるな・先生・メリンダ・三姉妹）で約束した日と一致          | 🔶              |
| `+0x2A` | 2 B  | u16     | 用途不明。約束・夜這いのたびにビットが増えていき、空の枠でも残る | 町の人の夜這いのあと 7。百合 `0x20` → 万由 `0x28` → 千佳 `0x38`       | ❓              |

- 型・名前・見た目は別々に効く。型だけを変えると台詞と強さが、見た目だけを変えると見た目と声が変わり、メニューの名前は名前の値で決まる
- 町の人の名前・見た目・年齢・血液型は、約束のときに型ごとの候補から選ばれる（🔶）

### 夜這いの記録 `0x137F0`〜

| 位置         | 幅  | 型  | 内容                                        | 確度 |
| ------------ | --- | --- | ------------------------------------------- | ---- |
| `0x137EC`    | 4 B | u32 | 夜這い回数（約束の画面の「夜這い回数」）     | ✅    |
| `0x13E34`    | 4 B | u32 | 記録の件数。次の記録はこの番号の件に書かれる | 🔶    |
| `0x13E4C`    | 4 B | u32 | 用途不明。ローラとの夜這いで 0 → 1          | ❓    |
| 各件 `+0x00` | 4 B | u32 | 型（約束の枠の +0x04）                      | 🔶    |
| 各件 `+0x04` | 4 B | u32 | 名前（約束の枠の +0x1C）                    | 🔶    |
| 各件 `+0x08` | 4 B | u32 | 入った建物の番号（`0x20C`〜`0x228`。同じ建物の扉は同じ番号。例：お屋敷 `0x218`、稲荷前 `0x217`、ローラの部屋 `0x221`） | 🟢    |
| 各件 `+0x0C` | 2 B | u16 | 約束した日（約束の枠の +0x28）              | 🔶    |
| 各件 `+0x0E` | 1 B | u8  | 年齢                                        | 🔶    |
| 各件 `+0x0F` | 1 B | u8  | 血液型                                      | 🔶    |

- 空の件は `FFFFFFFF FFFFFFFF 00000000 FFFF0000`
- 夜這い回数 `0x137EC` が記録の件数 `0x13E34` より多いセーブがある（4〜6日目で回数 1・件数 0）。そのセーブでローラと夜這いすると、回数 2・件数 1 になり、記録は1件目に書かれた
- `0x37C8`（[scenario-flags](../scenario-flags/README.md)）も夜這いで増えることが多いが、回数とも件数とも合わないセーブがある（❓）

## 編集時の注意

- 場所 +0x08 だけを書き換えると、布団が宙に浮いたり壁にめり込んだりする。場所と配置 +0x0A は、確かめた組を一緒に書く
- 場所 `23` 以降は名前が空になる（🔶 定義されていない値）。選べるのは `00`〜`22` だけにする
- 約束や記録を新しく作る・消す機能は持たない（❓ の領域を書かずに済ませるため）
- 朱美・ローラ・三姉妹・メリンダとの約束の条件（好感度・拷問のポイント・峰打ちの点数）は [hidden-route](../hidden-route/README.md) の `0x3792`〜`0x3797`。朱美・三姉妹は 10 以上で約束になる（🟢）
- 「タイトルに戻る」からロードすると夜這いのフラグが消える。テストのたびにゲームを完全に終了する
