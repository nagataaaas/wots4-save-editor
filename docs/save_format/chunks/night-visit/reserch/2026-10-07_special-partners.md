# メリンダ・三姉妹の約束

- 日付：2026-10-07
- 目的：特別な相手（メリンダ・三姉妹）と約束したときの約束の枠を集める
- 環境：Steam版、DLC あり、0x48BB0

## サンプル

| ファイル | 操作 |
|---|---|
| `sample/S4-DATA_01` | メリンダと約束（5日目） |
| `sample/S4-DATA_01 copy` | 百合と約束（5日目） |
| `sample/S4-DATA_01 copy 2` | 万由と約束（6日目） |
| `sample/S4-DATA_01 copy 3` | 千佳と約束（7日目） |

朱美は約束のあとの場面の移動で必ず昼になり、すっぽかしで枠が消える（2026-10-10 補足）ので、サンプルはない。

## 約束の枠

| 相対位置 | メリンダ | 百合 | 万由 | 千佳 | 先生（`S4-DATA_02`） |
|---|---|---|---|---|---|
| +0x00 u16 | `FFFF` | `FFFF` | `FFFF` | `FFFF` | `FFFF` |
| +0x02 u16 | 0 | 0 | 0 | 0 | 0 |

| +0x08 u16 | `0x20` | `0x1D` | `0x1D` | `0x1D` | `0x11` |
| +0x0A u16 | `0x1E` | `0x1B` | `0x19` | `0x1A` | `0x20` |
| +0x0C〜+0x1B | `0A 0B 0E 0F 0C 0D 1D 01` | 同じ | 同じ | 同じ | 同じ |

| +0x25 u8 | 3（O） | 1（A） | 4（AB） | 2（B） | 5（？） |
| +0x26 u16 | `FFFF` | `FFFF` | `FFFF` | `FFFF` | `FFFF` |
| +0x28 u16 | 4 | 4 | 5 | 6 | 5 |
| +0x2A u16 | 0 | `0x20` | `0x28` | `0x38` | 0 |
| `0x0BD8`（経過日数） | 4 | 4 | 5 | 6 | 5 |

- +0x28 は、5人とも約束したセーブの経過日数と同じ。以前のさよ（0）・かえで（1）・はるな（1）も、約束したセーブの経過日数と同じだった
- +0x2A は 百合 → 万由 → 千佳 の順に `0x20` → `0x28` → `0x38` とビットが増えた。町の人の系統では、さよとの夜這いのあと 0 → 7 になった
- 約束した相手の拷問のポイントは 0 に戻っていた（百合の約束で `0x3796`、万由で `0x3794`、千佳で `0x3795`）
- 名前の ID は [人物の名前](../../../datatable/npc/npc-name.csv) の 13 メリンダ、6〜8 万由・千佳・百合、15 先生と一致した
- どのサンプルも `0x137EC`＝1、`0x13E34`＝0 で、記録の1件目は空

## 結論

- +0x28 を「約束した日（経過日数）」🔶 として反映した（8人で一致。書き換えの効果は未確認）
- メリンダ・三姉妹の型・見た目と、場所と配置の組（`20`＋`1E`、`1D`＋`19`／`1A`／`1B`）を反映した
- +0x2A は約束・夜這いの相手ごとのビットらしい（❓）
