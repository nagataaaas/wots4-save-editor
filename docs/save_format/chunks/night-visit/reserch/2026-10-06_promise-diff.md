# 夜の約束と夜這いの差分

- 日付：2026-10-06
- 目的：夜の約束と夜這いの記録の位置と構造を特定する
- 環境：Steam版、DLC あり、0x48BB0

## サンプル

| ファイル | 操作 |
|---|---|
| `sample/S4-DATA_03 copy 5` | おにぎり屋の用心棒の受注中 |
| `03 copy 6` | おにぎり屋の用心棒で、さよを生かした。夜の約束（町・お屋敷、年齢？、血液型？、夜這い0回） |
| `03 copy 7` | そのまま夜這い（2日目に入った） |
| `03 copy 8` | かえで（女中、24歳、O型、町・長屋の稲荷前、夜這い1回）と約束 |
| `03 copy 9` | そのまま夜這い（3日目に入った） |
| `03 copy 10` | 2日目からやり直し、はるな（娘、22歳、O型、稲荷前）と約束 |

## 差分

| 前 → 後 | 変化 |
|---|---|
| `03 copy 5` → `copy 6` | `0x1403A`〜 に値が入った |
| `03 copy 6` → `copy 7` | 約束の枠が `FF` に戻った。`0x137EC` 0 → 1、`0x137F0`〜 に1件目。`0x3DB48`〜`0x3DE8E` に大量の値（❓ さよの個体データか） |
| `03 copy 7` → `copy 8` | `0x14038`〜 に値が入った |
| `03 copy 8` → `copy 9` | `0x137EC` 1 → 2、`0x13800`〜 に2件目。`0x13E34`、`0x37C8` も 1 → 2 |

### 約束の枠の値

| 相対位置 | さよ（お屋敷） | かえで（稲荷前） | はるな（稲荷前） |
|---|---|---|---|
| +0x00 u16 | `FFFF` | 0 | 0 |
| +0x02 u16 | 0 | 1 | 1 |
| +0x04 u32 | `0x031B` | `0x25` | `0x49` |
| +0x08 u16 | `0x10` | `0x0C` | `0x0C` |
| +0x0A u16 | `0x3D` | `0x06` | `0x06` |
| +0x0C〜+0x1B | `0A 0B 0E 0F 0C 0D 1D 01`（u16 × 8） | 同じ | 同じ |
| +0x1C u32 | `0xD7` | `0x1BA5` | `0x1B69` |
| +0x20 u32 | `0xF5` | `0x1C` | `0x5D` |
| +0x24 u8 | `FF` | `0x18`（24） | `0x16`（22） |
| +0x25 u8 | `05` | `03` | `03` |
| +0x28・+0x2A u16 | 0, 0 | 1, 7 | 1, 7 |

- +0x02 は約束したセーブの `0x0BD8`（経過日数）と3人とも一致した（さよ 1日目、かえで・はるな 2日目）。以前は夜這い回数と一致して見えたが偶然だった
- +0x28（`0x14060`）は空の枠では `FFFF`
- +0x1C の値はファイル中のほかの場所には出てこない。約束の画面に職業は出ない

### 夜這いの記録

| 件 | 内容 |
|---|---|
| 1件目 `0x137F0` | `0x031B`、`0xD7`、`0x218`、0、`FF`、`05`（さよ） |
| 2件目 `0x13800` | `0x25`、`0x1BA5`、`0x217`、1、`0x18`、`03`（かえで） |

並びは 🔶 型（u32）、名前（u32）、❓（u32）、日付（u16）、年齢（u8）、血液型（u8）。記録の画面に「1日目」などと出るので、+0x0C の u16 は日付と考えた。

## 書き込みの確認

| 書き換え（はるなのセーブ） | 結果 |
|---|---|
| +0x02 を変える | 夜這い回数の表示は変わらなかった |
| +0x04 `0x49` → `0x031B` | 台詞がさよと同じ「・・・」になり、体力・攻撃力が町娘とは思えないほど高くなった。見た目・声・メニューの名前は変わらない |
| +0x08 だけを変える | 場所の表示は変わるが、布団が宙に浮いたり壁にめり込んだりした |
| +0x08 `0C`、+0x0A `07` | 2回とも布団がおかしくなった。`06` に戻すと直った |
| +0x1C → `0xD7` | 名前がさよになった |
| +0x20 `0x5D` → `0xF5` | 見た目と声がさよになった。台詞・強さ・名前は変わらない |
| +0x24 → `0x30` | 48歳と表示された |
| +0x25 | 1＝A、2＝B、3＝O、4＝AB。5 は「？」（さよ） |

### 場所 +0x08 の名前

`0x14040` を `00`〜`22` に書き換えて、約束の画面に出る場所の名前を見た（一覧は [夜の約束の場所](../../../datatable/place/night-visit-place.csv)）。`23` 以降は名前が空になった。

同じ名前の場所に複数の値がある（長屋 `09`〜`0B`、稲荷前 `0C`〜`0F`、代官所の離れ `1D`・`1E`）。
[U] の解釈（🔶）：+0x08 は夜這いに入る扉と、その先のマップ（扉の数より少ない）。+0x0A はマップの中の人と布団の配置。

### 場所と配置の組（約束の実データから集めた）

| 場所 +0x08 | 配置 +0x0A | 場所の名前 | 出典 |
|---|---|---|---|
| `00` | `03` | 港　ほったて小屋 | [U] |
| `09` | `21` | 町　長屋 | [U] |
| `0A` | `05` | 町　長屋 | [U] |
| `0B` | `22` | 町　長屋 | [U] |
| `0C` | `06` | 町　長屋　稲荷前 | かえで・はるな。書き換えでも正常 |
| `0E` | `23` | 町　長屋　稲荷前 | [U] |
| `10` | `3D` | 町　お屋敷 | さよ（DLC）。ほかのセーブへの書き込みは未確認 |
| `18` | `25` | 大通り　呉服屋の向かい | [U] |
| `1D` | `01` | 代官所　離れ | [U] |

配置は場所の順に並んでいない（`09`→`21` と `0A`→`05` など）。「場所の順に増える」という仮説は外れた。

## 結論

- 約束の枠 `0x14038`〜（0x2C B）の型・場所・配置・名前・見た目・年齢・血液型を ../README.md に反映した
- 夜這いの記録 `0x137F0`〜（16 B）と件数 `0x137EC`（🔶）を反映した
