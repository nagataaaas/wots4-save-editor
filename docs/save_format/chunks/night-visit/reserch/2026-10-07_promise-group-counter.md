# 約束の +0x02 と夜這い回数の表示

- 日付：2026-10-07
- 目的：約束の枠の +0x02 が日付かどうかと、約束の画面の「夜這い回数」がどのカウンタから来るかを確かめる
- 環境：Steam版、DLC あり、0x48BB0

## サンプル

| ファイル | 操作 |
|---|---|
| （残していない） | 1日目に町の人と約束した |
| （残していない） | 約束中のセーブで `0x137EC` を `0x10`、`0x13E34` を `0x30` に書き換えた |
| `sample/S4-DATA_02` | 5日目に先生と約束した |

## 結果

| 確かめたこと | 結果 |
|---|---|
| 1日目（経過日数 0）に町の人と約束したときの +0x02（`0x1403A`） | `01`。日付ではない |
| `0x137EC`＝16、`0x13E34`＝48 | 約束の画面の夜這い回数は 16 → 表示は `0x137EC` |

### 先生の約束（`sample/S4-DATA_02`）

| 相対位置 | 値 |
|---|---|
| +0x00 u16 | `FFFF` |
| +0x02 u16 | 0（5日目） |
| +0x04 u32 | `0x0250` |
| +0x08 u16 | `0x11`（提灯の掛かった家） |
| +0x0A u16 | `0x20` |
| +0x0C〜+0x1B | `0A 0B 0E 0F 0C 0D 1D 01` |
| +0x1C u32 | `0x0F` |
| +0x20 u32 | `0x57` |
| +0x24・+0x25 | `FF`、`05`（年齢・血液型とも「？」） |
| +0x26・+0x28・+0x2A | `FFFF`、5、0 |

- このセーブは `0x137EC`＝1 なのに、記録の1件目は空。`0x13E34`＝0、`0x37C8`＝0
- 以前の差分（2026-10-06）の `sample/S4-DATA_03 copy 10` では、記録 1件・`0x137EC`＝1・`0x13E34`＝1 に対して `0x37C8`＝2

## 結論

- +0x02 は日付ではない。特別な相手（さよ・先生）は 0、町の人は 1（🟢 町の人は 1〜3）。記録の +0x0C も同じ値なので、日付とは言えない
- 夜這い回数の表示は `0x137EC`
- `0x37C8` は夜這いの回数と合わないセーブがある。意味は ❓
- 先生の型・名前・見た目と、場所 `0x11`＋配置 `0x20` の組を反映した
