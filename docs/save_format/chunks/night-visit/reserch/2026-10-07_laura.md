# ローラとの約束と夜這い

- 日付：2026-10-07
- 目的：ローラと約束したときの約束の枠と、夜這いのあとの記録・カウンタを見る
- 環境：Steam版、DLC あり、0x48BB0

## サンプル

| ファイル | 操作 |
|---|---|
| `sample/S4-DATA_02 copy` | ローラと約束した（3日目） |
| `sample/S4-DATA_01 copy 4` | そのままローラと夜這いした（4日目に入った） |

## 約束の枠（`02 copy`）

| 相対位置 | 値 |
|---|---|
| +0x00 u16 | `FFFF` |
| +0x02 u16 | 0 |
| +0x04 u32 | `0x01C6` |
| +0x08 u16 | `0x1C`（領事館 二階ローラの部屋） |
| +0x0A u16 | `0x3A` |
| +0x0C〜+0x1B | `0A 0B 0E 0F 0C 0D 1D 01` |
| +0x1C u32 | `0x0B`（ローラ） |
| +0x20 u32 | `0x1D` |
| +0x24・+0x25 | `FF`、1（A） |
| +0x26・+0x28・+0x2A | `FFFF`、2、0 |

+0x28＝2 は約束したセーブの経過日数（`0x0BD8`＝2）と同じ。

## 夜這いのあと（`02 copy` → `01 copy 4`）

| 位置 | 前 | 後 |
|---|---|---|
| `0x137EC` | 1 | 2 |
| `0x13E34` | 0 | 1 |
| `0x13E4C` | 0 | 1 |
| `0x37C8` | 0 | 1 |
| 記録の1件目 `0x137F0` | 空 | `C6010000 0B000000 21020000 0200 FF 01` |
| 約束の枠 | ローラ | +0x00〜+0x23 が `FF`、+0x28 が `FFFF`、+0x2A が 0 → 7 |

- 記録は1件目に書かれた。`0x137EC` は 1 → 2 なので、記録の件数（次に書く位置）は `0x13E34` のほうと考えられる
- 記録の +0x0C は 2。約束の枠の +0x28（約束した日）と同じで、+0x02（0）とは違う。以前のさよ（0）・かえで（1）も約束した日と一致する
- 記録の +0x08 は `0x221`（ローラの部屋の建物の番号）
- `0x3DB48`〜 の領域にも、さよのときと同じように値が書かれた。さよだけのデータではない

## 結論

- 記録の件数は `0x13E34`（🔶）、夜這い回数の表示は `0x137EC`（✅）。両者はずれることがある
- 記録の +0x0C は約束した日（🔶）
- ローラの型・見た目と、場所 `0x1C`＋配置 `0x3A` の組を反映した
