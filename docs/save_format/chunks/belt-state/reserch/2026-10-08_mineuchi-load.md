# 峰打がロード時に読まれるか

- 日付：2026-10-08
- 目的：峰打（`0xA6AC`）を書き換えてロードしたとき、ゲームに反映されるかを確かめる。🟢 では「保存のたびに書かれるが、読み込みでは使われない」と判定していた
- 環境：Steam版、0x48BB0

## 書き込みの確認

- `0xA6AC` を書き換えたセーブをロードしても、峰打の状態は反映されなかった（[U] 2026-10-08、ユーザー報告「峰打ちは読まれなかった」）

## 結論

- `0xA6AC` は読み込みでは使われない（✅）。../README.md の峰打の行を ✅ にし、エディタでは表示だけにした
- 同じく 🟢 で読まれないと判定した `0xA6AD`（保存したときの構えが無手か）は未確認のまま
