# 帯刀の状態

帯刀中の武器の本数、どれを構えているか、二刀流・峰打かを表す 8 B。帯刀中の武器（[weapon-record](../weapon-record/README.md)）と武器袋の間にある。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x00A6A8` | ✅ |
| 終了（含む） | `0x00A6AF` | 🟢 |
| サイズ | 8 B | 🟢 |
| 位置の求め方 | 固定オフセット（U-1 判定待ち）。帯刀[2] の直後 | ✅ |
| 妥当性検証 | 本数が 0〜3、帯刀武器の番号が 0〜2 または `FF`、二刀流が 0／1 | 🟢 |

どの武器レコードとも重ならない 🟢（武器レコードは完成武器ID から始まり、帯刀[2] は `0xA6A7` で終わり、武器袋[0] は `0xA6B0` から始まる）。

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0xA6A8` | 1 B | u8 | 帯刀している本数 | 0〜3。武器のある枠を前に詰めて保存するので、帯刀[0]〜[本数−1] に武器があり、残りは空き | 🟢 |
| `0xA6A9` | 1 B | i8 | 右手（構えている）帯刀武器の番号 | 0始まり。`FF`＝何も構えていない | ✅読み ／ 🟢読み込み ／ ❓書き込みの反映 |
| `0xA6AA` | 1 B | i8 | 二刀流の左手の帯刀武器の番号 | 0始まり。`FF`＝なし | ✅読み ／ 🟢読み込み ／ ❓書き込みの反映 |
| `0xA6AB` | 1 B | u8 | 二刀流 | 0／1 | ✅読み ／ 🟢読み込み ／ ❓書き込みの反映 |
| `0xA6AC` | 1 B | u8 | 峰打 | 0／1。読み込みでは使われない | ✅（[U] 2026-10-08 書き換えても反映されない） |
| `0xA6AD` | 1 B | u8 | 保存したときの構えが無手か | 0／1。読み込みでは使われない | 🟢 |
| `0xA6AE` | 2 B | — | 使われない | 常に 0 | 🟢 |

### 読み込み時の扱い 🟢

- 帯刀[0] から「本数」件の武器を作る。本数より後ろの帯刀のレコードは読まれない。本数が 0 なら帯刀なしになる
- 右手の番号の枠に武器がなければ、右手・左手を「なし」、二刀流を 0 にする
- 二刀流が 0、または左手の番号の武器を左手に持てなければ、左手を「なし」、二刀流を 0 にする
- 峰打（`0xA6AC`）と無手（`0xA6AD`）は保存のたびに書かれるが、読み込みでは戻さない。ロード直後は峰打でない状態になる ✅
- 帯刀の本数が 0 で、武器袋と武器箪笥もすべて空のときは、ゲームが武器を1本渡して右手に持たせる

## 書き換えられるもの

| 書き換え | 効果 | 確度 |
|---|---|---|
| 本数を減らす（例：3 → 2） | 帯刀[2] が読まれず、ロード後に帯刀から消える（次の保存で空きのレコードになる） | 🟢（要ゲーム内確認） |
| 本数を増やす | 帯刀の空きのレコードは武器として作られない。武器のレコードを書いてから本数を合わせる | 🟢（要ゲーム内確認） |
| 右手の番号 | ロード後に構える武器が変わる | 🟢（要ゲーム内確認） |
| 左手の番号＋二刀流 | 二刀流で始まる。左手に持てない組み合わせなら二刀流にならない | 🟢（要ゲーム内確認） |
| 峰打・無手 | 効果なし（読まれない） | ✅峰打 ／ 🟢無手 |

## 編集時の注意

- 帯刀[n] に武器を置いたり消したりするときは、本数（`0xA6A8`）と前詰めの並びを合わせる
- 右手・左手は、本数の内側にある空きでない武器だけを選ぶ
- 峰打・無手は編集しない（読まれない）
- [belt-copy](../belt-copy/README.md) に同じ並びがある（帯刀のコピーではない別の記録 🟢）
