# 帯刀の状態

帯刀中の武器のうちどれを構えているか、二刀流・峰打かを表す 8 B。帯刀中の武器（[weapon-record](../weapon-record/README.md)）と武器袋の間にある。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x00A6A8` | ✅ |
| 終了（含む） | `0x00A6AF` | 🔶 |
| サイズ | 8 B | 🔶 |
| 位置の求め方 | [TS] の固定オフセット（U-1 判定待ち）。帯刀中の武器の直後 | ✅ |
| 妥当性検証 | 帯刀武器の番号が 0〜2 または `FF`、二刀流・峰打が 0／1 | 🔶 |

0xA6AA〜0xA6AF は、[TS] の配置では武器袋[0] の +0x00〜+0x05 に当たる。武器レコード213件のうち +0x00〜+0x05 が `00` 以外なのは武器袋[0] だけなので、武器レコードの一部ではなく帯刀の状態と考えている（🔶）。

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0xA6A8` | 1 B | u8 | 帯刀している本数 | 実例は常に 3 | 🔶 |
| `0xA6A9` | 1 B | u8 | 右手（構えている）帯刀武器の番号 | 0始まり。`FF`＝何も構えていない | ✅読み ／ ❓書き込み |
| `0xA6AA` | 1 B | u8 | 二刀流の左手の帯刀武器の番号 | 0始まり。`FF`＝なし | ✅読み ／ ❓書き込み |
| `0xA6AB` | 1 B | u8 | 二刀流 | 0／1 | ✅読み ／ ❓書き込み |
| `0xA6AC` | 1 B | u8 | 峰打 | 0／1 | ✅読み ／ ❓書き込み |
| `0xA6AD` | 3 B | — | 用途不明 | すべての例で 0 | ❓ |

## 編集時の注意

- 武器を書き込む機能では 0xA6AA〜0xA6AF（武器袋[0] の +0x00〜+0x05）を書き換えない。レコードを丸ごとコピーすると峰打などの状態が変わる
- 書き込みがゲームに反映されるかは要ゲーム内確認
- [belt-copy](../belt-copy/README.md) に同じ並びのコピーがある（`0x1A972`〜、`0x1AD7A`〜）
