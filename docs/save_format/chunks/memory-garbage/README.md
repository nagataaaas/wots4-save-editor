# 乱数・メモリのごみ

ゲームの状態ではなく、保存時のメモリの値（アドレス風の値や未初期化の値）がそのまま書かれていると考えられる範囲。
差分を取るときに除外するために記録する。帯刀武器のコピーを含むブロックは [belt-copy](../belt-copy/README.md)。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始・終了 | `0x00363C`〜`0x0036A3`（104 B） | 🔶 |
| 開始・終了 | `0x005C3C` から 0x7C 刻みで12か所、各 8 B（`0x005C3C`〜`0x006197`） | 🔶 |
| 位置の求め方 | 固定 | 🔶 |
| 妥当性検証 | なし（読み取り専用） | — |

```text
0x363C 側[n] = 0x363C + n * 0x10   （n = 0〜6）。各件の +0x08 に float 1.0
0x5C3C 側[n] = 0x5C3C + n * 0x7C   （n = 0〜11）。各 8 B
```

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x363C`〜 の各件 `+0x00` | 8 B | — | アドレス風の値、0x0120 前後の u16、半精度浮動小数（`00 3C`＝1.0）風の値などが混ざる | | 🔶 |
| `0x363C`〜 の各件 `+0x08` | 4 B | float32 | 常に 1.0 | | 🔶 |
| `0x5C3C`〜 の各件 | 8 B | — | 32ビットのメモリアドレスに見える値（例：0x010FFB24・0x0094F78C） | 同じ日にプレイしたセーブどうしでは一致し、別の日のセーブとは違う | 🔶 |

- `0x363C`〜 の直後 `0x36A8` からは [event-chart](../event-chart/README.md) のイベント状態 A
- `0x5C3C`〜 はアイテム（[items](../items/README.md)、`0x58C0`〜`0x5BDF`）の後ろにある

## 編集時の注意

- 書き込まない。差分解析では除外する

## 未確認・判定待ち

- ❓ `0x5C3C`〜 の12か所の間（0x7C 刻みの残り）の用途
