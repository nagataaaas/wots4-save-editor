# 日付の段階・時間帯・現在地

シナリオの段階、時間帯、次のロードで進める時間帯の保留量、現在地（ロード時の開始地点）、治安。
経過日数そのものは [stats](../stats/README.md) の `0x0BD8` にある。

役割の分担：

- 経過日数 `0x0BD8`：ゲーム内の日数の表示 ✅
- 時間帯 `0x0014`：昼・夕・夜。4日目以降も進む ✅
- 段階 `0x0010`：イベントが起きるかどうかの判定に使う。周回の開始前かどうかもこれで決まる ✅

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x000010` | ✅ |
| 終了（含む） | `0x000018` | 🔶 |
| サイズ | 9 B | 🔶 |
| 位置の求め方 | 固定（[U-1](../../../check-diff.md#u-1)） | ❓ |
| 妥当性検証 | ファイルサイズが 0x48BB0。時間帯が 0〜2、保留量が 0・10 | 🔶 |

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x0010` | 2 B | u16 | シナリオの段階 | 下の「段階の値」 | ✅ 0〜400 ／ 🟢 410 以降 |
| `0x0012` | 1 B | u8 | 時間帯を進める保留量 | イベント完了で 10 が入り、エリア移動・ロードのときに `0x0010` に足されて 0 に戻る | ✅ |
| `0x0013` | 1 B | u8 | 現在地（ロード時の開始地点） | [開始地点](../../datatable/place/start-location.csv) | ✅ |
| `0x0014` | 1 B | u8 | 時間帯 | 0＝昼（朝）、1＝夕、2＝夜。4日目以降も進む | ✅ |
| `0x0015` | 1 B | u8 | 治安。書き換えるとゲーム内の治安に反映される | 0〜99（下の「治安の段階」）。鍛冶屋で踏み倒すと −10。1日目のセーブで 0 の例がある | ✅ 位置 ／ 🔶 範囲 |
| `0x0016` | 2 B | — | 用途不明 | | ❓ |
| `0x0018` | 1 B | u8 | 用途不明 | 鍛冶屋で踏み倒すと `40`、寿司屋の店主を殺すと 0 | ❓ |

### 段階の値

| 値 | 段階 | 確度 |
|---|---|---|
| 0 | 序章。「続きから」で難易度と主人公の設定に進む。エンディング後のセーブがこの状態。序章のイベントが始まるには、船上の侍（通し番号 0）も 00 である必要がある（下の「編集時の注意」） | ✅ |
| 100・110・120 | 1日目 昼・夕・夜 | ✅ |
| 200・210・220 | 2日目 朝・夕・夜 | ✅ 200 ／ 🟢 210・220 |
| 300・310・320 | 3日目 昼・夕・夜 | 🟢 |
| 400 | 4日目以降（剣術大会の前）。日数・時間帯が進んでも 400 のまま | ✅ |
| 410・420 | 4日目以降（ローラの決意、ローラ奪還・士魂は屈せず） | 🟢 |
| 500・510・520 | 剣術大会のあと | 🟢 |
| 600 | 鬼怒川の魔手のあと（夕暮れの船上・討ち入り） | 🟢 |
| 999 | 結末 | 🟢 |

- 1〜3日目は「日×100＋時間帯×10」で、日数・時間帯から決まる。4日目以降は 400 で止まる。この範囲を「日数・時間帯と連動している」と呼ぶ
- 410 以降と 0 は話の進み具合で決まり、日数・時間帯とは連動しない
- 日数は `0x0010` の日の部分では変わらず、`0x0BD8`（[stats](../stats/README.md)）で決まる ✅
- `0x0010` と `0x0014` を一緒に書くと時間帯がゲームに反映される。4日目以降の昼 → 夕で変わるのは `0x0014` だけ ✅
- 過ぎた時間帯の未処理イベントは、ゲームがロード時に日数から失敗と表示する（セーブのイベント状態は書き換わらない）✅
- 座標は保存されていない（ロード時は決まった地点から始まる）🔶

### 治安の段階

[W] の仕様：0〜99、初期値 50。とても良い 90〜99／良い 70〜89／普通 30〜69／悪い 10〜29／とても悪い 0〜9。周回をまたいで引き継がれる。
セーブの値とゲーム内の段階の表示の照合はしていない 🔶

## 編集時の注意

- 日数・時間帯を変えるときは `0x0BD8`・`0x0014` を書き、段階が連動しているときだけ `0x0010` も合わせて書く。連動していない段階（0・410 以降）は変えない
- 段階だけを変えるときは `0x0010` だけを書く。一覧にない値は書かない
- `0x0010` だけを 0 にすると、難易度と主人公の設定には進むが、序章のイベントは始まらずセーブした場所から始まる ✅
- 船上の侍（`0x36A8`）も 00 にすると、序章のイベントが始まる ✅
- 周回の途中のセーブで新しい周回を始めるときは、周回ごとに初期化されるとみられる値をエンディング後のセーブの値にそろえる。下の表をまとめて書くと新しい周回として遊べる ✅。
  個々の値が必要か・この値でよいかは表の確度のまま（範囲はエンディング後のセーブ1件から推定。エンディングの前後の差分では確かめていない）

  | 位置 | 値 | 確度 |
  |---|---|---|
  | `0x0010` 段階 | 0 | ✅ |
  | `0x0012` 保留量・`0x0014` 時間帯 | 0 | 🔶 |
  | `0x0013` 現在地 | `27`（港（騒乱／希望の光用））。必要かは ❓ | 🔶 |
  | [stats](../stats/README.md) `0x0B90`・`0x0BC0`・`0x0BC8`・`0x0BD0`・`0x0BD8` | 0 | 🔶（`0x0BC0`・`0x0BD0` は意味 ❓） |
  | [kill-counts](../kill-counts/README.md) 周回中の表 `0x0C84`〜`0x1C23` | すべて 0 | 🔶 |
  | [event-chart](../event-chart/README.md) イベントの状態 A `0x36A8`〜`0x374D` | 通し番号 2・10・14・16・19・25・32・53〜56・59〜61・64〜69・74・76・80・83・93〜96・99〜165 が FF、ほかは 00 | 🔶 |
  | [scenario-flags](../scenario-flags/README.md) `0x374E`〜`0x3837` | 0。施設 `0x375D`〜`0x375F`（周回をまたぐ 🔶）と堂島の職 `0x3799`（エンディング後のセーブでは 1。引き継ぎか初期値か ❓）は変えない | 🔶 |
  | [hint](../hint/README.md) `0x3900` | `FFFF` | 🔶 |

  変えないもの：難易度、記録 B、所持品・特典・容姿、町の人となりわい（`0x0133` は周回の始めに 0 → 1 になるが、エンディング後の値と同じ 0 にはしない ❓）、夜這いの記録、治安、累計の記録
- 日を進めると、過ぎた時間帯の未処理イベントは失敗扱いになる
- 現在地のうちクラッシュが報告されている値（`00`、`13`、`24`、`28`、`29`、`2C`〜`C4`）は選択肢に出さない
- `14`（代官所・牢屋）でセーブしたデータは、ラスボス戦の後に落ちる
