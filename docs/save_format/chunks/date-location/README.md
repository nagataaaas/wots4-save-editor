# 日付の段階・時間帯・現在地

シナリオの段階、時間帯、次のロードで進める時間帯の保留量、現在地（ロード時の開始地点）、治安。
経過日数そのものは [stats](../stats/README.md) の `0x0BD8` にある。

役割の分担：

- 経過日数 `0x0BD8`：ゲーム内の日数の表示 ✅
- 時間帯 `0x0014`：昼・夕・夜。4日目以降も進む ✅
- 段階 `0x0010`：イベントが起きるかどうかの判定に使う。周回の開始前かどうかもこれで決まる ✅

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x000010` | ✅ |
| 終了（含む） | `0x0000DB`（`0x001C`〜 は予約の領域） | 🟢 |
| サイズ | 204 B | 🟢 |
| 位置の求め方 | 固定 | ✅ |
| 妥当性検証 | ファイルサイズが 0x48BB0。時間帯が 0〜2、保留量が 0・10 | 🔶 |

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x0010` | 2 B | u16 | シナリオの段階 | 下の「段階の値」 | ✅ 0〜400 ／ 🟢 410 以降 |
| `0x0012` | 1 B | u8 | 時間帯を進める保留量 | イベント完了で 10 が入り、エリア移動・ロードのときに `0x0010` に足されて 0 に戻る | ✅ |
| `0x0013` | 1 B | u8 | 現在地（ロード時の開始地点） | [開始地点](../../datatable/place/start-location.csv) | ✅ |
| `0x0014` | 1 B | u8 | 時間帯 | 0＝昼（朝）、1＝夕、2＝夜。4日目以降も進む | ✅ |
| `0x0015` | 1 B | u8 | 治安。書き換えるとゲーム内の治安に反映される | 0〜99（下の「治安の段階」）。鍛冶屋で踏み倒すと −10。1日目のセーブで 0 の例がある | ✅ 位置 ／ 🔶 範囲 |
| `0x0016` | 2 B | — | 使われていない（詰め物） | 0 | 🟢 |
| `0x0018` | 4 B | u32 | 代金を踏み倒した店のビット（ビット n が店の番号 n。下の「店の番号」） | 踏み倒すとその店のビットが立つ（鍛冶屋は番号 6 で `0x40` ✅）。町の人が踏み倒しを記録する場面では全ビットが立つ。地域を読み込むとき（エリア移動・ロード）と周回の終わりに 0 | 🟢 |
| `0x001C` | 192 B | i32 × 48 | 使われていない（予約）。常に −1（`FF`） | 新しいデータと周回の終わりに `FF` で埋められる | 🟢 |

- `0x0018` が 0 でなく、今いる場所が屋内で、そこに踏み倒しを咎める人（寿司屋・そば屋・めし屋・旅籠・レストラン・病院・カジノ・黒船の用心棒、居酒屋の客、呉服屋の店主）が倒れずに残っていると、地域の出口からも地図の画面からも移動できない（地図では「それどころでは無い」と出る）🟢。
  用心棒は、`0x0018` が 0 でないと主人公を襲う。屋外の露店（鍛冶屋など）で踏み倒したときは、このしくみでは止められない

### 段階の値

| 値 | 段階 | 確度 |
|---|---|---|
| 0 | 序章。「続きから」で難易度と主人公の設定に進む。エンディング後のセーブがこの状態。序章のイベントが始まるには、船上の侍（通し番号 0）も 00 である必要がある（下の「編集時の注意」） | ✅ |
| 100・110・120 | 1日目 昼・夕・夜 | ✅ |
| 200・210・220 | 2日目 朝・夕・夜 | ✅ 200 ／ 🟢 210・220 |
| 300・310・320 | 3日目 昼・夕・夜 | 🟢 |
| 400 | 4日目以降（剣術大会の前）。日数・時間帯が進んでも 400 のまま | ✅ |
| 410・420 | 4日目以降（ローラの決意、ローラ奪還・士魂は屈せず） | 🟢 |
| 500・510・520 | 剣術大会のあと | 🟢 |
| 600 | 鬼怒川の魔手のあと（夕暮れの船上・討ち入り） | 🟢 |
| 999 | 結末 | 🟢 |

- 1〜3日目は「日×100＋時間帯×10」で進む。4日目以降は 400 で止まる。410 以降と 0 は話の進み具合で決まる
- メインイベントが起きるかどうかは段階で決まり、日数・時間帯は影響しない
- 日数は `0x0010` の日の部分では変わらず、`0x0BD8`（[stats](../stats/README.md)）で決まる ✅
- `0x0010` と `0x0014` を一緒に書くと時間帯がゲームに反映される。4日目以降の昼 → 夕で変わるのは `0x0014` だけ ✅
- 各イベントは自分の段階でしか始まらない。段階が進むと、前の段階で済ませていないイベントは起きなくなる（大老 鬼怒川怨仙は 300〜400、真ルートの一部は 200〜400 の段階で起きる）🟢
- 段階が進むと、前の段階で済ませていないイベントの枠はチャートで失敗と表示される。セーブのイベント状態は書き換わらない（寝て日を飛ばした実セーブで ✅）。失敗の印は段階とチャートで到達した枠から決まり、日数は見ない 🟢
- 日数・時間帯だけを書き換えても、起きるイベントとチャートの失敗の印は変わらない 🟢 要ゲーム内確認
- 座標は保存されていない（ロード時は決まった地点から始まる）🔶

### 治安の段階

[W] の仕様：0〜99、初期値 50。とても良い 90〜99／良い 70〜89／普通 30〜69／悪い 10〜29／とても悪い 0〜9。周回をまたいで引き継がれる。
セーブの値とゲーム内の段階の表示の照合はしていない 🔶

## 編集時の注意

- `0x0018`（踏み倒した店）はエリア移動・ロードで 0 に戻るので、エディタで書いても意味がない。扱わない
- 日数・時間帯を変えるときは `0x0BD8`・`0x0014` だけを書き、段階（`0x0010`）は変えない。段階と日数・時間帯が合っていなくても警告しない
- 段階だけを変えるときは `0x0010` だけを書く。一覧にない値は書かない
- `0x0010` だけを 0 にすると、難易度と主人公の設定には進むが、序章のイベントは始まらずセーブした場所から始まる ✅
- 船上の侍（`0x36A8`）も 00 にすると、序章のイベントが始まる ✅
- 周回の途中のセーブで新しい周回を始めるときは、下の「周回の終わりの初期化」（クリアか立ち去り）をまとめて行う。
  エンディング後のセーブの値にそろえる書き込み（初期化の一部）で新しい周回として遊べたことは ✅。全部を行う書き込みのゲーム内での確認は要ゲーム内確認

### 周回の終わりの初期化 🟢

物語が終わると、終わり方（[stats](../stats/README.md) `0x0BBA`：1 死亡、2 町を立ち去った、3 クリア）に応じて引き継ぎの処理をしてから、共通の初期化をする。保存されるのは初期化のあとの中身。

引き継ぎ：

| | クリア・立ち去り | 死亡 |
|---|---|---|
| 帯刀 | 残す（次の主人公が持つ） | 町の人に持ち去られる（流通の武器の記録 `0x440D8`〜 に入れ、帯刀を空にする） |
| 武器袋 | 武器箪笥の空き枠へ（本数 `0x129F4` +1）。箪笥がいっぱいなら袋に残る | 同じ |
| 手持ちの道具 `0x5B40` | 道具の箪笥 `0x58C0` へ（同じ品で 99 個未満の枠か空き枠）。入りきらない分は手持ちに残る | 持ち去られる（流通の道具の記録 `0x44A74`〜）。手持ちは空 |
| 持っている部品（刃 `0x6326`・鍔 `0x6A2E`・柄 `0x6EDE`、各 100 件） | 部品の箪笥（刃 `0x738E`・鍔 `0x88A6`・柄 `0x96B6`、各 300 件）へ | 持ち去られる（流通の部品の記録）。持っている部品は空 |
| 所持金 `0x0008` | 金庫 `0x000C` に足す（999,999 まで） | `0x45F3C` に写す |
| 回数 | クリアは難易度ごとのクリア回数 `0x43398 + 難易度×2`（u16、1000 まで）+1。立ち去りは立ち去った回数 `0x46340`（u32、99,999 まで）+1 | — |
| [townsfolk](../townsfolk/README.md) | なりわいのフラグ 4〜14・18・19・23〜31 を 0 | 同じ（23 `0x0133` だけは残す） |

どの終わり方でも：記録 B を更新する（[event-chart](../event-chart/README.md)「A と B の関係」）。流通の記録の経過の数を +1 し、古い武器は確率で消える。

- 段階を進めると、前の段階の未処理イベントは起きなくなり、チャートで失敗と表示される（上の「段階」）

- `14`（代官所・牢屋）でセーブしてロードすると、真ルートのラスボス戦後に落ちる報告がある。必ず起きるわけではなく、原因は未確認
