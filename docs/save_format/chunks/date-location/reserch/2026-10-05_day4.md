# 4日目以降の日付の差分

- 日付：2026-10-05
- 目的：4日目以降に `0x0010`・`0x0014`・`0x0BD8` がどう動くかを確かめる
- 環境：Steam版、ファイルサイズ 0x48BB0

## サンプル

| ファイル | 操作 | ベースからの差分 |
|---|---|---|
| `sample/S4-DATA_03 copy 2` | 嵐の後のあと、港でセーブ（1日目昼） | — |
| `sample/S4-DATA_03 copy 7` | そのまま港で 5日目昼まで寝た（大老 鬼怒川怨仙の待ち） | — |
| `sample/S4-DATA_03 copy 8` | 大老 鬼怒川怨仙のあと町でセーブ（5日目夕） | — |
| `sample/S4-DATA_03 copy 9` | 大老の大寄せの直後、町でセーブ（6日目昼、剣術大会会場） | — |
| `sample/S4-DATA_04 copy 10` | 新規周回。3日目に大老 鬼怒川怨仙、剣術大会の準備の導入を見て神社でセーブ（3日目夜） | — |
| `sample/S4-DATA_04 copy 11` | 墓地で雑魚寝して大寄せを見た直後、神社でセーブ（4日目昼） | — |

## 差分

| ファイル | `0x0010` | `0x0014` | `0x0BD8` | イベント状態 A の変化 |
|---|---|---|---|---|
| 03 copy 2 | 100 | 0 | 0 | — |
| 03 copy 7 | 400 | 0 | 4 | なし（未処理の1〜3日目イベントは `00` のまま） |
| 03 copy 8 | 400 | 1 | 4 | 添字28 `00` → `04` |
| 03 copy 9 | 400 | 0 | 5 | 添字41 `00` → `04` |
| 04 copy 10 | 320 | 2 | 2 | 添字28 `04`、添字36 `00` → `01` |
| 04 copy 11 | 400 | 0 | 3 | 添字41 `04` |

- `0x0010` は 4日目以降 400 で止まり、時間帯の部分も 0 のまま。4日目ちょうども 400（04 copy 11）
- 日数は `0x0BD8`、時間帯は `0x0014` だけが進む
- `0x0013` は copy 7（港）で `01`
- 寝て日を飛ばしただけでは、未処理の1〜3日目イベントの A は `00` のまま。それでもロードするとチャートでは失敗と表示された（[U]）

## 書き込みの確認

- 03 copy 5（1日目夕）をエディタで 5日目（`0x0010`＝400、`0x0BD8`＝4）に書き換えると、大老 鬼怒川怨仙が発生した（✅ [U]）

## 結論

- `0x0010` は「シナリオの段階（1〜3日目の日と時間帯、4＝4日目以降）」として ../README.md に反映した（🔶）
- 過ぎた時間帯の未処理イベントの失敗は、セーブの A ではなく日数からゲームが決めて表示している
- 7日目以降の値は未確認
