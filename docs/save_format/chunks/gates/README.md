# 門・柵

代官所・居留地・神社の門・柵の配置条件。フラグ列（[scenario-flags](../scenario-flags/README.md)）の中に飛び飛びにある。
開放の条件と閉鎖の条件は別のバイトで、現在の見た目そのものを保存した値ではない。段階・ルート・イベント中の開閉も関わる（🟢）。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x003761` | ✅ |
| 終了（含む） | `0x0037FB` | ✅ |
| サイズ | 飛び飛びの u8 × 8（下の表） | ✅ |
| 位置の求め方 | 固定（U-1） | ❓ |
| 妥当性検証 | 通常の値は各バイトが 0／1 | 🔶 |

## 構造

| 位置 | 幅 | 型 | 内容 | 通常の値の効果 | 確度 |
|---|---|---|---|---|---|
| `0x3761` | 1 B | u8 | 神社の洞窟内の柵を閉じる条件 | 1＝柵が降り、通行を塞ぐ。0に戻したときの上昇・通行の回復は未確認 | ✅対象・1で下降して通行不可 ／ 🟢適用条件 |
| `0x3764` | 1 B | u8 | 居留地の外門を閉じる条件 | 1＝閉じる。段階の制限なし | ✅対象・0/1 ／ 🟢適用条件 |
| `0x377D` | 1 B | u8 | 代官所の初期の門配置・幕府からの勧誘 | 段階 ≤100：1＝表門を開く、0＝閉じる。裏門はどちらでも閉じる | ✅表門・0/1 ／ 🟢適用条件 |
| `0x377E` | 1 B | u8 | 居留地の外門・領事館内の扉の初期の開放条件 | 段階 ≤100：1＝開く、0＝閉じる | ✅外門・0/1 ／ 🟢内扉・適用条件 |
| `0x377F` | 1 B | u8 | 神社入口・洞窟内の柵の初期の開放条件 | 段階 ≤100：1＝開く、0＝閉じる | ✅入口の柵・0/1 ／ 🟢洞窟内の柵・適用条件 |
| `0x37C3` | 1 B | u8 | 神社入口の柵を閉じる条件 | 1＝閉じる。段階の制限なし。洞窟内の柵は別の条件 | ✅対象・0/1 ／ 🟢適用条件 |
| `0x37FA` | 1 B | u8 | 代官所の表門を閉じる条件 | 1＝閉じる。段階の制限なし | ✅対象・0/1 ／ 🟢適用条件 |
| `0x37FB` | 1 B | u8 | 代官所の裏門を閉じる条件 | 1＝閉じる。段階の制限なし | 🟢（要ゲーム内確認） |

通常配置の閉鎖条件は値 ≥1、初期の開放条件は値 =1（それ以外は閉じる）で判定する（🟢）。0/1以外の値を編集に使うことは推奨しない。

### 適用条件と優先順 🟢

段階は [date-location](../date-location/README.md) の `0x0010`。以下は該当する場所の通常配置の条件で、イベント中の開閉は別に行われる。

1. **段階 ≤100（序章〜1日目昼）**：`0x377D`〜`0x377F` の初期開放条件を使う。代官所の裏門は開放条件が1でも閉じる。
2. **段階 ≥110（1日目夕以降）**：外門・神社の柵・代官所の表門と裏門は、まず開く配置になる。`0x377D`〜`0x377F` はこの配置判定では読まれない。
3. **段階の制限なし**：`0x3761`・`0x3764`・`0x37C3`・`0x37FA`・`0x37FB` が1なら、対応する門・柵を閉じる。初期開放の条件より優先する。0は閉鎖を指定しない値であり、それだけで必ず開くとは限らない。
4. **段階 ≥410**：外国ルート分岐 `0x378A` =2 なら居留地の外門、攘夷 `0x378B` =2 なら神社の2か所の柵、幕府 `0x3789` =2 なら代官所の表門・裏門を閉じる。閉鎖条件のバイトを0にしても、この条件が残ると開かない。

大寄せで閉鎖条件が立つことと、初期開放条件を使わなくなる時点は別。大寄せ前でも閉鎖条件は有効で、初期開放条件の適用は1日目昼まで。

領事館内の扉は段階 ≥110 かつ夜以外で開く配置になり、`0x3765`（通し番号189）が1なら閉じる。神社の洞窟内の柵は `0x3761`（185）が1なら降りて通行を塞ぐ（✅）。柵自体は普段から存在し、降りた状態を見たことがなかったとのゲーム内報告。どちらも初期の開放条件とは別の閉鎖条件（🟢）。

### 読まれる場面と反映の限界 🟢

- ロード・配置更新時に、その現在地に対応する門・柵の条件が判定される。別の場所の門の条件を常時読み続けるものではない。
- 条件に該当しても対象の門・柵がない配置では変化しない。通常の居留地と、別の開始地点の同名エリアを同じ条件とみなさない。
- イベントの導入・戦闘・演出が、その場の門を別に開閉する場合がある。フラグから見た最終状態を全場面で保証しない。
- 通常配置で読まれない初期開放条件でも、イベントの発生や拷問からの解放の判定に使われることがある。

### 通し番号と 1 になる場面

通し番号（[../../README.md](../../README.md) §3。番号 N が `0x36A8 + N`）での位置と、値が 1 になる場面（🟢）。

| 位置 | 番号 | 1 になる場面・他の用途 |
|---|---|---|
| `0x3761` | 185 | 大寄せで攘夷ルートに入れないと1。同士救出・般若党壊滅の成功でも1 |
| `0x3764` | 188 | 大寄せで外国ルートに入れないと1。鬼怒川の魔手でローラが死んだとき・夕暮れの船上で断ったとき・傷心の帰国船の成功でも1 |
| `0x377D` | 213 | 阿弥浜港争乱の結末（3連勝・琴吹に助太刀）と三姉妹見参の成功で1。そのあとで1になる場面はない。代官所の面々は1のときだけ起きる。拷問からの解放の判定にも使う |
| `0x377E` | 214 | 阿弥浜港争乱の結末（3連勝・4人に手間取る）と三姉妹見参の成功で1。小公女謁見は1のときだけ起きる |
| `0x377F` | 215 | 阿弥浜港争乱では立たない。志士との出会いの導入と三姉妹見参の成功で1 |
| `0x37C3` | 283 | 大寄せで攘夷ルートに入れないと1。同士救出の成功・般若党壊滅の成功でも1 |
| `0x37FA` | 338 | 大寄せで幕府ルートに入れないと1。拷問からの解放の判定にも使う |
| `0x37FB` | 339 | 同上。表門とは別地点の裏門の両扉を閉じる。0にしても表門は変わらない |

`0x377D` は幕府からの勧誘を兼ねる（🟢）。`0x377E`・`0x377F` が外国・攘夷の勧誘そのものを表すかは未確認（🔶）。

### 大寄せでルートに入れない勢力に立つフラグ

大寄せでは、ルートに入れなかった勢力（ルート分岐が2。[factions](../factions/README.md)）ごとに次のフラグが立つ（🟢）。

| 勢力 | 立つフラグ |
|---|---|
| 幕府 | 代官所の表門 `0x37FA` =1、裏門 `0x37FB` =1 |
| 外国 | 居留地の外門 `0x3764` =1、`0x37C6` =1 |
| 攘夷 | 神社入口の柵 `0x37C3` =1、洞窟内の柵 `0x3761` =1、`0x37A2` =2（[best-route](../best-route/README.md)） |

根無し草では表の4つの閉鎖条件がすべて1。幕府ルートでは `0x37FA`・`0x37FB` だけ0。初期の通常配置には敵対状態（[factions](../factions/README.md) の行2）を直接使う条件はない。

### 神社の柵 `0x377F` と志士との出会い ✅

- 阿弥浜港争乱では立たず、閉じた神社の柵に近づくと、志士との出会い（イベント添字6）の導入が流れて柵が開き、添字6の状態Aが `03` になる。セーブすると `0x377F` が1になる。
- この確認時の状態で、添字6を `03` のまま `0x377F` を0にすると柵は閉じ、近づいても導入は流れない。添字6を `FF` に戻すと、導入が流れて柵が開く。

### 拷問からの解放 🟢

次のいずれかが成立すると、写真家がいなくなる判定と、代官所の表門・裏門を閉じる演出の判定に使われる。ゲーム内での結果は要ゲーム内確認。

- `0x37FA` または `0x37FB` が ≥1
- 段階 ≥410 かつ幕府ルート分岐 `0x3789` =2
- 段階 ≤100 かつ幕府からの勧誘 `0x377D` =0
- 隠しルート `0x378E` =1 かつローラの決意の導入 `0x36FC` =4

この判定による門の演出では、閉鎖条件のバイト自体は書き直されない。

## エディタの表示

「門・柵のフラグ」は次の順で表示する。

- **初日勧誘（1日目昼のみ影響）**：`0x377D`〜`0x377F` の初期開放条件。
- **閉鎖（1日目夕～大老の大寄せまで）**：`0x3761`・`0x3764`・`0x37C3`・`0x37FA`・`0x37FB`。
- **大老の大寄せ以降**：「剣術大会以後のルート分岐」への画面内リンクと、対応する勢力の値が `02` になった段階で門・柵が閉じる説明。

グループ名は進行時期の目安であり、適用期間を限定するものではない。初期開放条件は序章にも影響し、閉鎖条件は初日昼以前・大寄せ以降も有効（🟢）。実際の条件は「適用条件と優先順」を参照。

## 編集時の注意

- ルート分岐を書き換えても、閉鎖条件が残っていると進めない場合がある。対応する門・柵の閉鎖条件とルート分岐を両方確認する。攘夷側の洞窟内の柵は `0x3761` も関わる。
- 代官所の表門・裏門は独立した条件。両方開けたい場合は `0x37FA`・`0x37FB` を両方0にする。段階 ≤100 の裏門はそれだけでは開かない。
- 神社の柵を開けるときは、志士との出会いの状態（[event-chart](../event-chart/README.md) 添字6）にも注意する。
- イベント中の演出を含めた見え方、未確認の対象については要ゲーム内確認。

## 未確認・判定待ち

- `0x37C6` は居留地への移動を不許可にする条件（🟢。[scenario-flags](../scenario-flags/README.md)）。外門の開閉とは別で、移動時の表示・実際の反映は要ゲーム内確認
- ❓ `0x37FB` を0にしたときの裏門のゲーム内の反映
- ❓ 段階 ≥410 のルートによる閉鎖・拷問解放後の開閉のゲーム内確認
