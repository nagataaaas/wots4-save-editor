# 門

代官所・居留地・神社の門の開閉。大寄せ（イベント添字41）の前と後で、別のバイトが門を決める。どれもフラグ列（[scenario-flags](../scenario-flags/README.md)）の中に飛び飛びにある。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x003764` | ✅ |
| 終了（含む） | `0x0037FB` | ✅ |
| サイズ | 飛び飛びの u8 × 7（下の表） | ✅ |
| 位置の求め方 | 固定（U-1） | ❓ |
| 妥当性検証 | 各バイトが 0／1 | 🔶 |

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x3764` | 1 B | u8 | 居留地の門（大寄せ以降） | 1＝閉じる | ✅ |
| `0x377D` | 1 B | u8 | 代官所の門（大寄せ前） | 1＝開く | ✅ |
| `0x377E` | 1 B | u8 | 居留地の門（大寄せ前） | 1＝開く | ✅ |
| `0x377F` | 1 B | u8 | 神社の門（大寄せ前） | 1＝開く | ✅ |
| `0x37C3` | 1 B | u8 | 神社の門＝神社入口の柵（大寄せ以降） | 1＝閉じる | ✅ |
| `0x37FA` | 1 B | u8 | 代官所の表門（大寄せ以降） | 1＝閉じる | ✅ |
| `0x37FB` | 1 B | u8 | 代官所の裏門（大寄せ以降）。`0x37FA` と同じく根無し草で 1、幕府ルートで 0。0 にしても表の門は変わらない | 1＝閉じる | 🟢意味 ／ 🔶値 |

### 通し番号と 1 になる場面

通し番号（[../../README.md](../../README.md) §3。番号 N が `0x36A8 + N`）での位置と、値が 1 になる場面（🟢）。

| 位置 | 番号 | 意味・1 になる場面 |
|---|---|---|
| `0x3764` | 188 | 居留地の門（大寄せ以降）。大寄せで外国ルートに入れないと 1。鬼怒川の魔手でローラが死んだとき・夕暮れの船上で断ったとき・傷心の帰国船の成功でも 1 |
| `0x377D` | 213 | 代官所の門（大寄せ前）・幕府からの勧誘。阿弥浜港争乱の結末（3連勝・琴吹に助太刀）と三姉妹見参の成功で 1。そのあとで 1 になる場面はない。代官所の面々は 1 のときだけ起きる |
| `0x377E` | 214 | 居留地の門（大寄せ前）。阿弥浜港争乱の結末（3連勝・4人に手間取る）と三姉妹見参の成功で 1。小公女謁見は 1 のときだけ起きる |
| `0x377F` | 215 | 神社の門（大寄せ前）。阿弥浜港争乱では立たない。志士との出会いの導入と三姉妹見参の成功で 1 |
| `0x37C3` | 283 | 神社入口の柵（大寄せ以降）。大寄せで攘夷ルートに入れないと 1。同士救出の成功・般若党壊滅の成功でも 1 |
| `0x37FA` | 338 | 代官所の表門（大寄せ以降）。大寄せで幕府ルートに入れないと 1 |
| `0x37FB` | 339 | 代官所の裏門（大寄せ以降）。同上 |

- 大寄せ前の門は、勢力からの勧誘のフラグが兼ねている（`0x377D` が幕府の勧誘 🟢）。`0x377E`・`0x377F` は並びから外国・攘夷の勧誘とみられる（🔶）

### 大寄せでルートに入れない勢力に立つフラグ

大寄せでは、ルートに入れなかった勢力（ルート分岐が 2。[factions](../factions/README.md)）ごとに次のフラグが立つ（🟢）。門のほかのフラグは [scenario-flags](../scenario-flags/README.md)。

| 勢力 | 立つフラグ |
|---|---|
| 幕府 | 代官所の表門 `0x37FA` = 1、裏門 `0x37FB` = 1 |
| 外国 | 居留地の門 `0x3764` = 1、`0x37C6` = 1 |
| 攘夷 | 神社入口の柵 `0x37C3` = 1、`0x3761` = 1、`0x37A2` = 2（[best-route](../best-route/README.md) の範囲） |

### 大寄せ前と大寄せ以降

- 大寄せ前は `0x377D`〜`0x377F`（1＝開く）が門を決める。大寄せ以降は `0x37FA`・`0x37FB`・`0x3764`・`0x37C3`（1＝閉じる）が決め、`0x377D`〜`0x377F` を書き換えても門は動かない
- 大寄せのときの値：ルートに入れなかった勢力の門が 1（閉）になる。根無し草では4つとも 1。幕府ルートでは `0x37FA`・`0x37FB`（代官所の表門・裏門）だけ 0（開）
- 大寄せ前の門は、敵対状態（[factions](../factions/README.md) の行2）からは決まっていない

### 神社の門 `0x377F` と志士との出会い

- 阿弥浜港争乱では立たず、閉じた神社の門に近づくと、志士との出会い（イベント添字6）の導入が流れて門が開き、添字6 の状態 A が `03` になる。セーブすると `0x377F` が 1 になる
- 添字6 が `03` のまま `0x377F` を 0 にすると、門は閉じ、近づいても導入は流れない。添字6 を `FF` に戻すと、導入が流れて門が開く

## 編集時の注意

- ルート分岐（[factions](../factions/README.md)）を書き換えても、門が閉じているとそのルートに進めない。大寄せ以降は `0x37FA`・`0x37FB`・`0x3764`・`0x37C3` もそろえる。代官所の表門 `0x37FA` と裏門 `0x37FB` は同じ値にする
- 神社の門を開けるときは、志士との出会いの状態（[event-chart](../event-chart/README.md) の添字6）との組み合わせに注意する
