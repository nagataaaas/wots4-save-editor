# 門

代官所・居留地・神社の門の開閉。大寄せ（イベント添字41）の前と後で、別のバイトが門を決める。どれもフラグ列（[scenario-flags](../scenario-flags/README.md)）の中に飛び飛びにある。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x003764` | ✅ |
| 終了（含む） | `0x0037FB` | ✅ |
| サイズ | 飛び飛びの u8 × 7（下の表） | ✅ |
| 位置の求め方 | 固定（U-1） | ❓ |
| 妥当性検証 | 各バイトが 0／1 | 🔶 |

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x3764` | 1 B | u8 | 居留地の門（大寄せ以降） | 1＝閉じる | ✅ |
| `0x377D` | 1 B | u8 | 代官所の門（大寄せ前） | 1＝開く | ✅ |
| `0x377E` | 1 B | u8 | 居留地の門（大寄せ前） | 1＝開く | ✅ |
| `0x377F` | 1 B | u8 | 神社の門（大寄せ前） | 1＝開く | ✅ |
| `0x37C3` | 1 B | u8 | 神社の門＝神社入口の柵（大寄せ以降） | 1＝閉じる | ✅ |
| `0x37FA` | 1 B | u8 | 代官所の門（大寄せ以降） | 1＝閉じる | ✅ |
| `0x37FB` | 1 B | u8 | 代官所の裏門（大寄せ以降）。`0x37FA` と同じく根無し草で 1、幕府ルートで 0。0 にしても表の門は変わらない | 0／1 | 🟢意味 ／ ❓値 |

### 通し番号と 1 になる場面

通し番号（[../../README.md](../../README.md) §3。番号 N が `0x36A8 + N`）での位置と、値が 1 になる場面（🟢）。

| 位置 | 番号 | 意味・1 になる場面 |
|---|---|---|
| `0x377D` | 213 | 幕府からの勧誘。序章で 1 |
| `0x377E` | 214 | 序章で 1 |
| `0x377F` | 215 | 序章と志士との出会いで 1 |
| `0x37FA` | 338 | 代官所の表門。大寄せでルートに応じて 1 |
| `0x37FB` | 339 | 代官所の裏門。同上 |

- 大寄せ前の門は、勢力からの勧誘のフラグが兼ねている（`0x377D` が幕府の勧誘 🟢）。`0x377E`・`0x377F` は並びから外国・攘夷の勧誘とみられる（🔶）

### 大寄せ前と大寄せ以降

- 大寄せ前は `0x377D`〜`0x377F`（1＝開く）が門を決める。大寄せ以降は `0x37FA`・`0x3764`・`0x37C3`（1＝閉じる）が決め、`0x377D`〜`0x377F` を書き換えても門は動かない
- 大寄せのときの値：根無し草では3つとも 1（閉）。幕府ルートでは `0x37FA`（代官所）だけ 0（開）
- 大寄せ前の門は、敵対状態（[factions](../factions/README.md) の行2）からは決まっていない

### 神社の門 `0x377F` と志士との出会い

- 閉じた神社の門に近づくと、志士との出会い（イベント添字6）の導入が流れて門が開き、添字6 の状態 A が `03` になる。セーブすると `0x377F` が 1 になる
- 添字6 が `03` のまま `0x377F` を 0 にすると、門は閉じ、近づいても導入は流れない。添字6 を `FF` に戻すと、導入が流れて門が開く

## 編集時の注意

- ルート分岐（[factions](../factions/README.md)）を書き換えても、門が閉じているとそのルートに進めない。大寄せ以降は `0x37FA`・`0x3764`・`0x37C3` もそろえる
- 神社の門を開けるときは、志士との出会いの状態（[event-chart](../event-chart/README.md) の添字6）との組み合わせに注意する
