# 大寄せ以降の門

- 日付：2026-10-06
- 目的：ルート分岐を `01` にしても進めない原因の「門の開閉フラグ」を探す
- 環境：Steam版、ファイルサイズ 0x48BB0

## サンプル

| ファイル | 操作 | ベースからの差分 |
|---|---|---|
| `sample/S4-DATA_03 copy 9` | 大老の大寄せの直後（根無し草） | — |
| `sample/S4-DATA_04 copy 11` | 大寄せの直後（根無し草）。代官所・領事館・神社の3つの門がすべて閉じている | — |
| `sample/S4-DATA_04 copy 12` | 大寄せの直後（幕府ルート） | 04 copy 11 から、表とルート分岐のほかに変わったのは `0x37FA`・`0x37FB` だけ |

## 差分

| 位置 | 大寄せの前 | 根無し草（03 copy 9・04 copy 11） | 幕府ルート（04 copy 12） |
|---|---|---|---|
| `0x37FA` | 0 | 1 | 0 |
| `0x37FB` | 0 | 1 | 0 |
| `0x3764` | 0 | 1 | 1 |
| `0x37C3` | 0 | 1 | 1 |
| `0x3761`・`0x37C6` | 0 | 1 | 1 |
| `0x37A2` | 0 | 2 | 2 |

## 書き込みの確認

04 copy 11 で書き換えた結果：

| 書き換え | 結果 |
|---|---|
| `0x37FA` → 0 | 代官所の門だけが開いた |
| `0x37FB` → 0 | 何も変わらない |
| 両方 → 0 | 代官所の門だけが開いた |
| `0x3764` → 0 | 居留地の門が開いた |
| `0x37C3` → 0 | 神社の門（神社入口の柵）が開いた |
| `0x3761`・`0x37C6`・`0x37A2` → 0 | どの門も変わらない |

## 結論

- `0x37FA`＝代官所の門、`0x3764`＝居留地の門、`0x37C3`＝神社の門（どれも 1＝閉じる）として ../README.md に反映した
- ❓ `0x37FB`・`0x3761`・`0x37C6`・`0x37A2` の意味（[scenario-flags](../../scenario-flags/README.md)）
