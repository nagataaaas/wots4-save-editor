# 装飾品

装飾品の所持フラグと、装着・調整値の記録。所持は装飾品 ID（0〜157）ごとに1バイトが ID の順に並ぶ 🟢。装着の記録は所持フラグと別に保存される 🟢。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x003902` | ✅ |
| 終了（含む） | `0x00399F` | ✅ |
| サイズ | 1 B × 158 | ✅ |
| 位置の求め方 | 固定 | |
| 妥当性検証 | ファイルサイズが 0x48BB0 | |

```text
所持フラグ[id] = 0x3902 + id   （id = 0〜157、datatable/accessory/accessory.csv）
```

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x3902 + id` | 1 B | u8 | 装飾品 `id` を持っているか（ID は [accessory.csv](../../datatable/accessory/accessory.csv)） | 0＝なし、1＝所持 | ✅ |

- 全部を 1 にしてロードすると、装飾品設定に思ったとおりの装飾品が出た（✅ [U] 2026-10-07）

- ID と、ゲーム内の装飾品の一覧の並び順は一致しない（ID 0 は新撰組の鉢金。一覧の並び順は accessory.csv の `menu_order`）🟢
- なりわいの報酬で 1 になる位置（✅ 差分）と装飾品（🟢）：

| 位置 | ID | 装飾品 | なりわい |
|---|---|---|---|
| `0x3902` | 0 | 新撰組の鉢金 | 今宵の虎徹は |
| `0x399C` | 154 | 袖章 | 薬売り |
| `0x399D` | 155 | マラカス | 食い逃げ外国人 |
| `0x399E` | 156 | 三味線 | おにぎり屋の用心棒 |
| `0x399F` | 157 | おんぶさよ人形 | おにぎり屋の用心棒 |

- ID 152（龍馬の脇差）は DLC の特典。なりわいでは増えない 🟢
- 店で買えない装飾品（accessory.csv の `shop` が 0）は、DLC の6件（ID 0・152・154〜157）と、特典の解除で手に入る14件（鬼怒川の烏帽子・メリンダの兜とピアス・まだらのお面・茂呂の帽子・ローラの帽子と人形・J.J のイヤーカフス・三姉妹の髪飾り・暗闇脳天の鉄仮面）🟢
- 直前の `0x3900`〜`0x3901` は [hint](../hint/README.md)
- なりわいとの対応は [occupation](../occupation/README.md)

## 装着・調整値の保存 🟢

| 項目 | 先頭 | サイズ | 確度 |
|---|---|---|---|
| 現在付けている装飾品 | `0x39CC` | `0x280`（64 B × 10枠、末尾 `0x3C4B`） | 🟢 |
| 俺のおしゃれ5組 | `0x3C4C + 0x280 × n`（n＝0〜4） | 各 `0x280`、全体の末尾 `0x48CB` | 🟢 |

現在の枠 k の先頭は `0x39CC + 0x40 × k`（k＝0〜9）。「俺のおしゃれ」も同じ64 Bの枠が10個並ぶ。

### 装飾品ごとの標準の取り付け先 🟢

各装飾品には**標準の取り付け先と標準の位置・回転・大きさ**がある。顔と頭、胸と背中は別の取り付け先番号ではなく、同じ部位を基準に標準の位置で置き分ける。取り付け先は変更可能で、装飾品ごとの固定制限を表すものではない。

全158件の対応は [accessory.csv](../../datatable/accessory/accessory.csv) の `default_attachment_id`・`default_attachment_ja`。標準の位置は `default_position_x/y/z`、標準回転（度）は `default_rotation_x/y/z`、標準の一様サイズは `default_size` 🟢。既存の `part` は分類用であり、装着枠 `+0x3C` に書く標準番号は `default_attachment_id` を使う。

| 番号 | 基準部位 | 標準でこの部位を使う件数 | 例 |
|---|---|---:|---|
| 0 | 頭 | 94 | きつね面、眼鏡、帽子 |
| 1 | 胸・背中 | 38 | 番傘、勲章、おんぶさよ人形 |
| 2 | 腰 | 10 | ひょうたん、猫しっぽ、龍馬の脇差 |
| 3 | 右肩 | 1 | 腕輪 |
| 4 | 左肩 | 1 | 袖章 |
| 5 | 右腕 | 0 | — |
| 6 | 左腕 | 0 | — |
| 7 | 右足 | 0 | — |
| 8 | 左足 | 0 | — |
| 9 | 右ひざ | 0 | — |
| 10 | 左ひざ | 0 | — |
| 11 | 右手 | 12 | ちょうちん、日傘、マラカス |
| 12 | 左手 | 2 | ボクシンググローブ(左)、猫ハンド（左） |

例：きつね面（ID 1）は基準部位0、標準位置は約 `(0, 0.82, 1.35)`。番傘（ID 8）は基準部位1、標準位置は約 `(0, 0, -1.52)`、標準回転は `(0, 0, -33度)`。セーブの位置・回転が0でも、この標準値があるので顔・背中に配置される。標準の位置と軸の見た目の対応は要ゲーム内確認。

### 1枠の内容

位置・回転・大きさの調整値を2組持つ。状態番号0（A）＝**納刀**、1（B）＝**抜刀** 🟢。浮動小数点数はすべて32 bit、リトルエンディアン 🟢。

| 枠先頭から | 幅・型 | 内容 | 確度 |
|---|---|---|---|
| `+0x00` | 4 B | 意味未確認 | ❓ |
| `+0x04`・`+0x08`・`+0x0C` | f32 × 3 | 位置補正A（x・y・z） | 🟢 |
| `+0x10`・`+0x14`・`+0x18` | f32 × 3 | 位置補正B（x・y・z） | 🟢 |
| `+0x1C`・`+0x20`・`+0x24` | f32 × 3 | 回転補正A（x・y・z、度） | 🟢 |
| `+0x28`・`+0x2C`・`+0x30` | f32 × 3 | 回転補正B（x・y・z、度） | 🟢 |
| `+0x34` | f32 | 大きさ補正A | 🟢 |
| `+0x38` | f32 | 大きさ補正B | 🟢 |
| `+0x3C` | i8 | 取り付け先の番号（0〜12） | 🟢 |
| `+0x3D` | 1 B | 意味未確認 | ❓ |
| `+0x3E` | i16 | 装飾品ID（0〜157）、`FFFF`（−1）＝空き枠 | 🟢 |

- 最大10個。空き枠は全補正0・ID `FFFF`で初期化される 🟢。
- 位置・回転・大きさは、装飾品の標準値に足す**補正値**。大きさは軸ごとの3値ではなく、各状態に1値ずつ 🟢。
- **大きさの画面表示＝保存した補正値＋1.0**。保存値0.0は標準から変更なしで、表示1.0に相当する。表示値をそのまま保存しない 🟢。
- ゲーム内の調整範囲は、位置の各軸 −10〜10、回転の各軸 −180〜180度、大きさの表示 0.2〜5.0（保存する補正は −0.8〜4.0）🟢。範囲外の値を読み込んだ際の安全性は ❓。
- **「共通」を選んだ時点で、納刀の位置・回転・大きさ（7値）が抜刀へコピーされ、抜刀の独自の調整が失われる** 🟢。この挙動はゲーム内のユーザー報告とも一致（[U] 2026-10-09）。
- 共通を選択中の調整では両組に同じ変化量が加わる 🟢。「共通」用の3組目の調整値があるわけではない。装飾品ID・取り付け先・未知バイトはこのコピーでは変わらない 🟢。
- 手元の実セーブでは現在と「俺のおしゃれ」の空き枠の並びが一致。
- 装着中の実セーブの1枠目（`0x39CC`）は、補正値がすべて0、`+0x3C`＝1、`+0x3E`＝157。おんぶさよ人形を標準設定で1個付けた状態と読み取り、ユーザーから「合っていそう」と回答があった（[U] 2026-10-09）。🟢の読み取りとの整合を確認した段階で、個別項目を✅には上げない。
- 調整値を変更した前後の差分は未確認であり、書き換えの反映は**要ゲーム内確認**。

## 編集時の注意

- 容姿（[appearance](../appearance/README.md)）のビットとは別。容姿のビットを立てても装飾品は増えない
- 所持フラグを1にしても装着の記録は増えない。所持と装着を別々に扱う
- 装着の記録を編集する場合は未知の `+0x00`・`+0x3D` を維持し、位置・回転・大きさには有限の値だけを用いる。装着中の実セーブとの照合前に書き込みを対応済みとして扱わない

## エディタの装着画面

サイドバーの「主人公」グループ内の「容姿」で、見た目・人物・顔・髪型・服とともに、現在の装着と「俺のおしゃれ」5組の各10枠を編集する。「容姿・特典」内の「装飾品」画面は所持フラグ用で、そのまま残す。

- 装飾品ID・取り付け先・納刀／抜刀／共通の位置・回転・大きさを編集する。取り付け先は名称と番号で表示する。
- 共通への切り替えでは上書き確認を出し、承認したときだけ納刀の7値を抜刀へコピーする。キャンセル時は値・選択状態を変えない。共通選択中の入力は両方へ反映する。
- 記録・枠・読み込んだファイルが変わったら、共通の選択と確認待ちを破棄して納刀の編集へ戻る。
- IDの変更では新しい装飾品の標準部位を自動設定し、納刀・抜刀の補正を0に戻す。所持フラグは変更しない。
- 各装飾品の標準位置・回転・サイズを表示する。「標準設定に戻す」は確認後に標準部位と補正0へ戻す操作であり、標準位置そのものをセーブへ書き込まない。
- 「なし」はIDだけを `FFFF` にする。未知バイトを含め、他の値は維持する。
- ファイルサイズ・枠の境界・ID・部位番号・調整値の検証に落ちた枠は読み取り専用にする。レイアウトの検査はモードに依存させず、位置は各軸 −100〜100、大きさの表示は0〜100、回転は各軸 −180〜180度で検査する。通常の調整範囲を超える値は警告する。
- 通常モードの入力はゲーム内の調整範囲に制限する。上級者モードでは位置を各軸 −100〜100、大きさの表示を0〜100（保存補正 −1〜99）とする（ユーザー指定）。回転は各軸 −180〜180度のまま。上級者モードで書いた値は通常モードでも表示し、通常範囲の値への変更や標準設定への復帰を許す。納刀から抜刀へコピーする値も、そのときのモードの入力範囲で検証する。非有限値はどちらのモードでも拒否する。空き枠は装飾品を選択してから調整する。
- 画面は「要ゲーム内確認」と表示する。書き換え後のゲーム内反映を確認済みとするものではない。
