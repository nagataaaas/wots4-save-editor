# 装飾品

🔶 装飾品の所持フラグ。1つの装飾品に1バイトと推定。表の始まりと終わりは分かっていない。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x003902`（見つかった最初のフラグ） | ❓ |
| 終了（含む） | `0x00399F`（見つかった最後のフラグ） | ❓ |
| サイズ | ❓ | ❓ |
| 位置の求め方 | 固定（U-1） | |
| 妥当性検証 | なし（読み取り専用） | |

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x3902` | 1 B | u8 | なりわい「今宵の虎徹は」の報酬の装飾品 | 1＝所持 | 🔶 |
| `0x3903`〜`0x399B` | 153 B | — | 用途不明 | | ❓ |
| `0x399C` | 1 B | u8 | 「薬売り」の報酬の装飾品 | 1＝所持 | 🔶 |
| `0x399D` | 1 B | u8 | 「食い逃げ外国人」の報酬の装飾品 | 1＝所持 | 🔶 |
| `0x399E`・`0x399F` | 2 B | u8 × 2 | 「おにぎり屋の用心棒」の報酬の装飾品2点 | 1＝所持 | 🔶 |

- 直前の `0x3900`〜`0x3901` は [hint](../hint/README.md)
- なりわいとの対応は [occupation](../occupation/README.md)
