# 流派

習得技数・腕前点、構えの組ごとに装備している流派、流派ごとの修練度・段・斬殺数の表（🟢）。
持ち歩いている流派の書は [sect-scrolls](../sect-scrolls/README.md)、技の覚え状況は [skill-states](../skill-states/README.md)、技ごとの斬殺数は [skill-kills](../skill-kills/README.md)、俺流は [custom-style](../custom-style/README.md)。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x0189FC` | 🟢 |
| 終了（含む） | `0x01920D` | 🟢 |
| サイズ | 16 B ＋ 2 B ＋ 16 B × 128 枠 | 🟢 |
| 位置の求め方 | 固定（U-1） | 🟢 |
| 妥当性検証 | ファイルサイズ、件数 ≤ 128、流派 ID が既知。修練度 0〜10000・段 0〜5 | — |

```text
流派の表[k] = 0x18A0E + k * 16   （k = 0〜件数−1。枠は 128）
```

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x189FC` | 2 B | u16 | 習得技数 | 戦闘中に技を閃くたびに +1。流派を装備したときに覚える基本の技は数えない | 🟢 |
| `0x189FE` | 2 B | u16 | 腕前点 | 0〜9999。技を閃くと、その技ごとに決まった点（1 以上）が増える | 🟢 |
| `0x18A00 + 2s` | 2 B × 6 | u16 | 構えの組 s に装備している流派の ID | s＝0 刀（構え 上段・中段・下段・脇・居合い・片手・忍者）、1 槍、2 無手、3 拳銃、4 ライフル、5 二刀・忍者二刀。はじめからは 32 無心流剣術・85 激勝流槍術・98 適闘流体術・105 アルスター式銃術・106 セイラー式長銃術・90 二示現流剣術 | 🟢 |
| `0x18A0C` | 2 B | u16 | 流派の表の件数 | 全流派（実セーブでは 110）。俺流は含まない | 🟢 |
| `0x18A0E + 16k` | 16 B | 下の表 | 流派 1件。ID の小さい順 | | 🟢 |
| 件数の後ろ〜`0x1920D` | | | 使われない枠 | | 🟢 |

1件（16 B）：

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| +0x00 | 2 B | i16 | 流派 ID | | 🟢 |
| +0x02 | 2 B | i16 | 修練度 | 0〜10000 | 🟢 |
| +0x04 | 2 B | i16 | 段 | 0〜5（画面では 0 初段・1 弐段・2 参段・3 四段・4 伍段・5 極） | 🟢 ／ 🔶表示 |
| +0x06 | 2 B | i16 | その流派で倒した敵の数 | 敵を倒すたびに、そのとき使っている流派の値が +1 | 🟢 |
| +0x08 | 2 B | i16 | 技の表の ID（1つめ） | 流派ごとに決まった値 | 🟢 |
| +0x0A | 2 B | i16 | 技の表の ID（2つめ） | −1＝なし | 🟢 |
| +0x0C | 2 B | i16 | 技の表の ID（3つめ） | −1＝なし | 🟢 |
| +0x0E | 2 B | — | 使われない | 0 | 🟢 |

- 読み込みで使われるのは +0x00〜+0x07 だけ。+0x08〜+0x0C は流派ごとに決まった値で、保存のたびに書かれる 🟢
- 構えの組の装備（`0x18A00`〜）は、読み込みで流派 ID から流派を引き、その流派の構えの組に装備する。並びの位置ではなく流派の構えで入る場所が決まる 🟢
- 修練度は攻撃の種類ごとに 1・2・3・5・15・20 増える（上限 10000）。修練度が流派ごとの 4 つのしきい値に達すると段が 1〜4 に上がる（下がらない）🟢。夜杯流体術（ID 108）のしきい値は 300・1000・2500・4500
- 段 5（極）：その流派の技の表（最大 3 つ）のすべての技を覚えたとき（俺流用の技を除く）。技を覚えた直後に判定する 🟢。東急流剣術（ID 48）を極めると実績が解除される 🟢
- 東急流剣術の修練度は、道場の門下生を相手にしたときだけ増える 🔶
- 修練度・段・倒した敵の数は、はじめからを選んだときだけ 0 になる。周回では消えない 🟢
- 実セーブで修練度 0・段 5 の流派（ID 14・107）は、名前が「……」の流派（主人公が手に入れられない流派）🟢
- 腕前点が 9999 に達したとき、習得技数が 1・100 に達したときに実績が解除される 🟢

## 編集時の注意
