# 流派

通常の流派の名前・修練度・段・斬殺数があると推定している範囲（🔶）。構造は分かっていない。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x018BC0` 付近 | 🔶 |
| 終了（含む） | ❓ | ❓ |
| サイズ | ❓ | ❓ |
| 位置の求め方 | ❓ | ❓ |
| 妥当性検証 | 編集しない（読み取り専用） | — |

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x18BC0` 付近 | — | — | 通常流派の名前・修練度・段・斬殺数（[TS] の解析メモにある言及のみ。[TS] は読み書きしていない） | | 🔶 |
| `0x18D40` | — | — | 戦闘のあとに変わった | | ❓ |

PS3版でだけ分かっている位置（PC版では未検証。PS3版はビッグエンディアン）：

| PS3でのアドレス | 内容 | 型 | 確度 |
|---|---|---|---|
| `0x186AA` | 腕前 | u16 | 🟡 |
| `0x186CC`〜 | 流派書の経験値 | u16 の配列 | 🟡 |
