# 流派

流派ごとの修練度と段を持つ表（🟢）。1件 16 B で、流派 ID の順に並ぶ。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x018A0C`（件数） | 🟢 |
| 終了（含む） | `0x0190ED`（件数 110 のとき） | 🟢 |
| サイズ | 2 B ＋ 16 B × 件数 | 🟢 |
| 位置の求め方 | 固定（U-1） | ❓ |
| 妥当性検証 | 編集しない（読み取り専用） | — |

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x18A0C` | 2 B | u16 | 件数 | 実セーブでは 110 | 🟢 |
| `0x18A0E + 16k` | 16 B | 下の表 | 流派 1件 | | 🟢 |

1件（16 B）：

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| +0x00 | 2 B | i16 | 流派 ID | 0〜 | 🟢 |
| +0x02 | 2 B | i16 | 修練度 | 0〜10000 | 🟢 |
| +0x04 | 2 B | i16 | 段 | 0〜5（画面では 0 初段・1 弐段・2 参段・3 四段・4 伍段・5 極 とみられる） | 🟢 ／ 🔶表示 |
| +0x06 | 2 B | i16 | 用途不明（よく使う流派で大きい。斬殺数か） | | 🔶 |
| +0x08〜+0x0F | 8 B | | 用途不明（流派ごとに決まった値に見える） | | ❓ |

- 段は 0 から始まり、修練度が流派ごとの 4 つのしきい値に達すると 1〜4 に上がる（🟢）。夜杯流体術（ID 108）のしきい値は 300・1000・2500・4500
- 実セーブには修練度 10000 で段 5 の流派、修練度 0 で段 5 の流派がある。段 5 になる条件は ❓
- 周回の始めに、すべての流派の修練度・段・+0x06 が 0 になる（🔶）
- 段の呼び名は「初段・弐段・参段・四段・伍段・極」の 6 つで、値 0〜5 と同じ数（🔶 対応は要ゲーム内確認）

PS3版でだけ分かっている位置（PC版では未検証。PS3版はビッグエンディアン）：

| PS3でのアドレス | 内容 | 型 | 確度 |
|---|---|---|---|
| `0x186AA` | 腕前 | u16 | 🟡 |
| `0x186CC`〜 | 流派書の経験値 | u16 の配列 | 🟡 |
