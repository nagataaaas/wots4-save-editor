- サイズ・境界・状態値の検証に落ちた場合は読み取り専用。前後のバイト列は位置判定に使わない。固定位置の採用は実装方針であり、全レイアウトで位置が同じという確定ではない。J.J. の顔はゲーム内で解除した前後の差分だけ確認済み。エディタからの書き込みは、ライフルの免許への2の変更以外、反映のゲーム内確認が必要
