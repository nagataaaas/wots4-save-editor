  部品の定義の特典の番号は 1 から数える（朱美の着物＝64 は unlock.csv の 63 朱美の着物 上、魔鱗組着物＝80 は 79 魔鱗組の着物）🟢

## 取得に伴う追加効果とエディタの動作

- 🟢 特典0〜3を新たに取得済みにすると、武器箪笥の容量 `0x129F6`（10本単位）へそれぞれ3・4・5・6を加算し、上限20（200本）にする。取得済みを再指定しても再加算しない。一括変更でも同じ特典を重複して加算しない。
- 🟢 特典85〜99を取得済みにすると、装飾品の所持 `0x3902+ID` を1にする。対応する装飾品IDは順に77・78・89・92・93・79・80・81・153・90・94・95・96・68・82。以前の編集で取得状態だけが2の場合も、再指定で所持を補う。
- 未取得・非表示へ戻しても、容量を縮めたり装飾品を取り上げたりしない。装飾品は別の入手経路もあるため、逆操作による巻き戻しは行わない。箪笥を再び未取得から取得済みにすれば、その取得に伴う加算を行う。
- 侍点は減らさない。実績の操作や、ゲーム中の人物に対する流派・装備更新は行わない。
- 容量が2〜20の範囲外の場合、箪笥を新たに解除する操作を拒否し、一括指定したほかの特典も含めて変更前の状態を保つ。

## 編集時の注意

- サイズ・境界・状態値の検証に落ちた場合は読み取り専用。前後のバイト列は位置判定に使わない。J.J. の顔はゲーム内で解除した前後の差分だけ確認済み。エディタからの書き込みは、ライフルの免許への2の変更以外、反映のゲーム内確認が必要
- 全部を解除済みにすると、Steam の実績「すべての容姿設定を解除」などが取れる可能性がある（取れた実績は戻せない）
