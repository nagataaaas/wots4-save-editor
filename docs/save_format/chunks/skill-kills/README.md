# 技ごとの斬殺数

一部の技について、その技で倒した敵の数を数える表。技を俺流に組み込めるようになる条件（「この技で20人惨殺する」「つま斬り状態となり この技で10人惨殺する」）に使う（🟢）。画面には出ない。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x03AA12` | 🟢 |
| 終了（含む） | `0x03AAD1` | 🟢 |
| サイズ | 6 B × 32 枠 | 🟢 |
| 位置の求め方 | 固定 | 🟢 |
| 妥当性検証 | 編集しない（読み取り専用） | — |

```text
枠[k] = 0x3AA12 + k * 6   （k = 0〜31）
```

`0x3AAD2`〜`0x3AAD3` は隙間で、`0x3AAD4` から [appearance](../appearance/README.md)。

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| +0 | 2 B | i16 | 技の ID | −1＝空き。技の番号（[skill-states](../skill-states/README.md)）とは別の番号 | 🟢 |
| +2 | 2 B | i16 | その技で倒した数 | つま斬り中の分も含む。20 以上で組み込みの条件を満たす | 🟢 |
| +4 | 2 B | i16 | その技でつま斬り中に倒した数 | 10 以上で組み込みの条件を満たす | 🟢 |

- 数えるのは、俺流に組み込むのに回数が要る技だけ（秘伝黒生・鬼神滅裂・処刑荒野・乾坤一擲・心帰一神法・血霧・くるひかぶき・面剥がし・光矢突 とその続きの技）🟢
- 主人公が敵を倒したとき、最後に当てた技を数える。表にない技は先頭の空き枠に入れて 1 から数える 🟢
- いくつかの技は代表の技の ID にまとめて数える（4 組）🟢
- 上限はない（i16 として増え続ける）。20・10 を超えても、倒すたびに条件の判定が起きる 🟢
- 32 枠が埋まると、新しい技は数えられない 🟢
- 周回では消えない。はじめからを選んだときだけ空になる 🟢

### 組み込みの条件との関係 🟢

- これらの技の習得条件は「今 装備している武器で100人惨殺する」か「つま斬り状態となり…50人惨殺する」。固有武器（[weapon-record](../weapon-record/README.md) の固有武器の 6 バイトの流派）でその流派を使い、武器の +0x9A が 100（つま斬りは +0x9C が 50）に達すると覚え、技の状態は 3 になる（[skill-states](../skill-states/README.md)）🟢。習得条件の番号のうち、この流れで覚えるのがどれか（55・56 は確認、51〜54 は 🔶）
- 状態 3 の技は俺流に組み込めない。この表の回数が 20（つま斬りの技は +4 が 10）に達すると、状態が 1 になり組み込めるようになる 🟢（組み込み画面で 3 を選べないことは 🟢、回数で 1 になって選べるようになるかは要ゲーム内確認）

## 編集時の注意

- 状態 3 の技をこの表の回数で 1 にできるかは要ゲーム内確認
