# 施設

病院・カジノ・語学所の開閉。1施設 1 B の u8 が3つ並ぶ。フラグ列（[scenario-flags](../scenario-flags/README.md)）の中にあり、直前は重要人物の状態（[characters](../characters/README.md)）。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x375D` | ✅ |
| 終了（含む） | `0x375F` | ✅ |
| サイズ | 3 B（u8 × 3） | ✅ |
| 位置の求め方 | 固定 | ✅ |
| 妥当性検証 | ファイルサイズが 0x48BB0、各値が 0／1 | 🔶 |

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x375D` | 1 B | u8 | 病院 | 0＝閉、1＝開 | ✅ |
| `0x375E` | 1 B | u8 | カジノ | 0＝開、1＝閉 | ✅ |
| `0x375F` | 1 B | u8 | 語学所 | 0＝閉、1＝開 | ✅ |

- 3つとも 0 が初期状態（病院・語学所は閉、カジノは開）
- 通し番号（[../../README.md](../../README.md) §3）の 181〜183 に当たる（🟢）
- 並びはイベントの添字順（病院・語学所・カジノ）ではない
- 周回をまたいで引き継がれる 🔶（施設のイベントが未発生の周回でも、前の周回で変えた値が残っていた）

## ゲーム側の仕様

### 値を変える場面

| 施設 | 開く | 閉じる | 変わらない | 確度 |
|---|---|---|---|---|
| 病院 `0x375D` | 【病院占拠事件】の成功（どの決着でも） | 【病院廃業の企て】で千両箱を奪って報告する、【祝 病院開業】で千両箱を奪う | 【西洋医学お断り】（閉じたまま）、【病院廃業の企て】で一行を通す（開いたまま） | 🟢 |
| カジノ `0x375E` | 【カジノ再建を急げ】の成功、【カジノ再建断固阻止】で寝返る・伯爵との戦闘から逃げる | 【カジノを破壊せよ】の成功 | 【ライジングサン】（開いたまま）、【カジノを破壊せよ】で寝返る（開いたまま） | 🟢 |
| 語学所 `0x375F` | 【講師ご到着】で講師を送り届ける | 【語学所開設】で講師が殺される、【講師を亡き者に】で講師を斬る | 【語学無用】（閉じたまま）、【講師を亡き者に】で講師に逃げ切られる（開いたまま） | 🟢 |

- 状態が変わるのは2日目のイベント。周回をまたいで引き継がれる（[event.md](../../../event.md)）
- 開始地点（[date-location](../date-location/README.md)）で閉鎖中の施設にも入れるので、施設の状態はマップとは別のフラグ

### 値で分かれるイベント

2日目の各枠は、施設の値で起きるイベントが入れ替わる（🟢）。

| 施設 | 枠 | 値 0 | 値 1 |
|---|---|---|---|
| 病院 | 幕府・昼 | 【西洋医学お断り】 | 【病院廃業の企て】 |
| 病院 | 外国・昼 | 【病院占拠事件】 | 【祝 病院開業】 |
| 語学所 | 幕府・夕 | 【講師ご到着】 | 【語学所開設】 |
| 語学所 | 攘夷・夕 | 【語学無用】 | 【講師を亡き者に】 |
| カジノ | 外国・夜 | 【ライジングサン】 | 【カジノ再建を急げ】 |
| カジノ | 攘夷・夜 | 【カジノを破壊せよ】 | 【カジノ再建断固阻止】 |
| カジノ | 真ルート・夕 | 【運命のルーレット】 | 【伯爵に刺激を】 |

真ルート（[best-route](../best-route/README.md)）では、前の周回から引き継いだ値で次のように分かれる（🟢）。

- 病院が 1 のときだけ、【再起の望み】で「英国の病院に連れて行こう」が出る。0 だと赤城を助ける方法がない
- 語学所が 1 のときだけ、【闇討ち】で「赤城のようになりたくないのか？」が出る。0 だと成功できない
- カジノは2日目夕までに変わる場面がない
- 【希望の光】に進むには、病院・語学所が開き（1）、カジノが閉じている（1）必要がある。どれか1つでも欠けると途中で大老暗殺計画の側へ外れる
