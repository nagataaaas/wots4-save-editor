# シナリオのフラグ列

イベント状態 A（[event-chart](../event-chart/README.md)）の直後から記録 B の直前までの、小さな値（多くは 0／1）の u8 が並ぶ領域。人物・施設・門・勢力・ルートの状態がこの中にあり、意味の分からないフラグも多い。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x00374E` | 🟢 |
| 終了（含む） | `0x003837` | 🟢 |
| サイズ | 234 B（u8 の並び） | 🟢 |
| 位置の求め方 | 固定 | ✅ |
| 妥当性検証 | — | |

イベント状態 A からこの領域までは、1バイトの値が並ぶ一続きの領域で、通し番号で数える（[../../README.md](../../README.md) §3）。
**番号 N の値は `0x36A8 + N`** にあり、0〜165 が A、166〜399 がこの領域、400〜 が記録 B に当たる（🟢）。

`0x37C5`〜`0x37C7` は進行状態の初期化で 0 に戻る場合がある（🟢）。恒久的な解除・完了の印として扱わない。

#### チュートリアルの助言とフラグ

チュートリアル（`0x37AA` = 1）の戦いの中で次の状況になると、朱美が助言して対応するフラグを 1 にする（🟢）。

| 状況 | 1 になるフラグ |
|---|---|
| 戦いが3分続く | `0x3767`（191） |
| 2回攻撃を受ける | `0x376D`（197） |
| 命が8割まで減る | `0x3774`（204） |
| 命が4割まで減る | `0x3776`（206） |
| 武器の耐久が9割まで減る | `0x3777`（207） |
| 連殺ゲージが半分たまる | `0x377A`（210） |

### 意味の分からないフラグ

上の範囲に入らないもの、または範囲の中でも意味の分からないもの。どれも差分で値の変化を見ただけ。
「関わるイベント」はそのバイトの値が変わるイベント（🟢。意味は ❓）。

| 位置 | 型 | 観察 | 関わるイベント | 確度 |
|---|---|---|---|---|
| `0x376B` | u8 | 嵐の後で 0 → 1、志士との出会いの開始で 1 → 0 | 嵐のあと、序章 | ❓ |
| `0x377C` | u8 | どのセーブでも 0 | なし | ❓ |
| `0x37A2` | u8 | 大寄せで攘夷ルートに入れないと 2（🟢）。0 にしても門は変わらない。best-route の範囲の中 | 大寄せ、真ルートのイベント | ❓ |
| `0x37AF` | u8 | 代官所潜入で 0 → 1 | 代官所潜入 | ❓ |
| `0x37B2`〜`0x37BD` | u8 × 12 | 0／1 の並び。嵐の後で `01×8, 00, 01×3` になり、志士との出会いの完了ですべて 0。寝て5日目にすると 0、大老 鬼怒川怨仙のあとは `01 01 00 01 01 01 01 01 01 00 01 00`。🔶 時間帯ごとのイベントの発生可否か | 一部だけ（`0x37B2`・`0x37B3` は再起の望み・売国奴を斬れ、`0x37B5` は魔鱗組の力、`0x37B7`〜`0x37B9` は拷問、`0x37BB`・`0x37BC` は小公女と大老。上の表）。ほかは時間の経過で変わるとみられる | ❓ |
| `0x37B5` | u8 | 上の並びの1つ。海兵隊の横暴・代官所の面々で立ち、日付が変わると消えた | 上の行 | ❓ |
| `0x37C5` | u8 | 志士との出会いの完了で 0 → 1、時間帯が進むと 1 → 0。🔶 この時間帯のイベントを完了済みか | 志士との出会い、欺きの代価、売国奴を斬れ | ❓ |

## 編集時の注意

- 意味の分からないフラグは生の値の表示にとどめ、通常モードでは書かない
- 1 になる場面の分かったフラグのうち `0x3760`〜`0x3763`・`0x37AB`・`0x37C0`・`0x37C6`・`0x37F7`・`0x37F8` は、エディタでは生の値と候補（その場面で現れる値）で出す。書き換えたときの反映は要ゲーム内確認
