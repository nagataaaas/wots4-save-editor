# シナリオのフラグ列

イベント状態 A（[event-chart](../event-chart/README.md)）の直後から記録 B の直前までの、小さな値（多くは 0／1）の u8 が並ぶ領域。人物・施設・門・勢力・ルートの状態がこの中にあり、意味の分からないフラグも多い。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x00374E` | 🟢 |
| 終了（含む） | `0x003837` | 🟢 |
| サイズ | 234 B（u8 の並び） | 🟢 |
| 位置の求め方 | 固定（U-1） | ❓ |
| 妥当性検証 | — | |

イベント状態 A からこの領域までは、1バイトの値が並ぶ一続きの領域で、通し番号で数える（[../../README.md](../../README.md) §3）。
**番号 N の値は `0x36A8 + N`** にあり、0〜165 が A、166〜399 がこの領域、400〜 が記録 B に当たる（🟢）。

## 構造

### 意味の分かった範囲（別のまとまり）

| 位置 | 内容 | まとまり |
|---|---|---|
| `0x374E`〜`0x375C` | 重要人物の状態 | [characters](../characters/README.md) |
| `0x375D`〜`0x375F` | 施設（病院・カジノ・語学所） | [facilities](../facilities/README.md) |
| `0x3764`、`0x377D`〜`0x377F`、`0x37C3`、`0x37FA`、`0x37FB` | 門 | [gates](../gates/README.md) |
| `0x3780`〜`0x378C` | 勢力の 3×3 表とルート分岐 | [factions](../factions/README.md) |
| `0x378D`〜`0x37AA` | 隠しルートのフラグとその周り（好感度・職なども含む） | [hidden-route](../hidden-route/README.md) |
| `0x37C8` | ❓ 夜這いのたびに増えることが多いが、夜這いの回数と合わないセーブがある | [night-visit](../night-visit/README.md) |

|---|---|---|---|
| `0x3767`〜`0x377A` の一部 | 191・197・204・206・207・210 | 序章（阿弥浜港争乱）で港・町・大通り・街道・神社・墓場の出口を塞ぐフラグ | 🟢 |
| `0x37A9` | 257 | 周回数か（序章で 1 になる） | 🔶 |
| `0x37AC` | 260 | 代官所潜入で盗んだ武器 | 🟢 |
| `0x37AD` | 261 | 代官所潜入で見つかった回数（代官所潜入で 0 → 2 の観察と合う） | 🟢 |
| `0x37AE` | 262 | イベントの中で使い回す汎用のフラグ | 🟢 |
| `0x37F9` | 337 | 寿司屋の状態（寿司屋の店主を殺すと 0 → 1 の観察と合う）。伯爵に刺激を・傷心の帰国船の開始条件に関わる。隠しルートの「寿司屋の店員を学問のすすめの前に殺すと傷心の帰国船」の条件とみられる | 🟢 |
| `0x37FC` | 340 | 汎用のフラグ（2つ目） | 🟢 |

### 意味の分からないフラグ

上の範囲に入らないもの、または範囲の中でも意味の分からないもの。どれも差分で値の変化を見ただけ。
「関わるイベント」はそのバイトの値が変わるイベント（🟢。意味は ❓）。

| 位置 | 型 | 観察 | 関わるイベント | 確度 |
|---|---|---|---|---|
| `0x3761` | u8 | 大寄せで 0 → 1。0 にしても門は変わらない | 大寄せなど | ❓ |
| `0x3768` | u8 | 阿片密売を阻止せよの導入で幕府勢力を斬ると 0 → 1 | 阿片密売、ライジングサンなど | ❓ |
| `0x376B` | u8 | 嵐の後で 0 → 1、志士との出会いの開始で 1 → 0 | 嵐のあと、序章 | ❓ |
| `0x377C` | u8 | どのセーブでも 0 | なし | ❓ |
| `0x37A2` | u8 | 大寄せで 0 → 2。0 にしても門は変わらない。hidden-route の範囲の中 | 大寄せ、真ルートのイベント | ❓ |
| `0x37AF` | u8 | 代官所潜入で 0 → 1 | 代官所潜入 | ❓ |
| `0x37B2`〜`0x37BD` | u8 × 12 | 0／1 の並び。嵐の後で `01×8, 00, 01×3` になり、志士との出会いの完了ですべて 0。寝て5日目にすると 0、大老 鬼怒川怨仙のあとは `01 01 00 01 01 01 01 01 01 00 01 00`。🔶 時間帯ごとのイベントの発生可否か | 一部だけ（`0x37B2`・`0x37B3` は再起の望み・売国奴を斬れ、`0x37B5` は魔鱗組の力、`0x37B7`〜`0x37B9` は拷問、`0x37BB`・`0x37BC` は小公女と大老）。ほかは時間の経過で変わるとみられる | ❓ |
| `0x37B5` | u8 | 上の並びの1つ。海兵隊の横暴・代官所の面々で立ち、日付が変わると消えた | 上の行 | ❓ |
| `0x37C5` | u8 | 志士との出会いの完了で 0 → 1、時間帯が進むと 1 → 0。🔶 この時間帯のイベントを完了済みか | 志士との出会い、欺きの代価、売国奴を斬れ | ❓ |
| `0x37C6` | u8 | 大寄せで 0 → 1。0 にしても門は変わらない | 大寄せ、小公女倒れる | ❓ |
