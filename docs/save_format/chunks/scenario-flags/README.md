# シナリオのフラグ列

イベント状態 A（[event-chart](../event-chart/README.md)）の直後から記録 B の直前までの、小さな値（多くは 0／1）の u8 が並ぶ領域。人物・施設・門・勢力・ルートの状態がこの中にあり、意味の分からないフラグも多い。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x00374E` | 🔶 |
| 終了（含む） | `0x003837` | 🔶 |
| サイズ | 234 B（u8 の並び） | 🔶 |
| 位置の求め方 | 固定（U-1） | ❓ |
| 妥当性検証 | — | |

A も 200 B 分を確保していて、この領域の先頭 34 B を A が使っている可能性もある（❓）。

## 構造

### 意味の分かった範囲（別のまとまり）

| 位置 | 内容 | まとまり |
|---|---|---|
| `0x374E`〜`0x375C` | 重要人物の状態 | [characters](../characters/README.md) |
| `0x375D`〜`0x375F` | 施設（病院・カジノ・語学所） | [facilities](../facilities/README.md) |
| `0x3764`、`0x377D`〜`0x377F`、`0x37C3`、`0x37FA` | 門 | [gates](../gates/README.md) |
| `0x3780`〜`0x378C` | 勢力の 3×3 表とルート分岐 | [factions](../factions/README.md) |
| `0x378D`〜`0x37AA` | 隠しルートのフラグとその周り | [hidden-route](../hidden-route/README.md) |
| `0x37C8` | 🔶 夜這いの回数のカウンタの1つ | [night-visit](../night-visit/README.md) |

### 意味の分からないフラグ

上の範囲に入らないもの、または範囲の中でも意味の分からないもの。どれも差分で値の変化を見ただけ。

| 位置 | 型 | 観察 | 確度 |
|---|---|---|---|
| `0x3761` | u8 | 大寄せで 0 → 1。0 にしても門は変わらない | ❓ |
| `0x3768` | u8 | 阿片密売を阻止せよの導入で幕府勢力を斬ると 0 → 1 | ❓ |
| `0x376B` | u8 | 嵐の後で 0 → 1、志士との出会いの開始で 1 → 0 | ❓ |
| `0x377C` | u8 | どのセーブでも 0 | ❓ |
| `0x3793` | u8 | 海兵隊の横暴に成功すると 0 → 1（2回再現）。hidden-route の範囲の中 | ❓ |
| `0x37A2` | u8 | 大寄せで 0 → 2。0 にしても門は変わらない。hidden-route の範囲の中 | ❓ |
| `0x37AD`・`0x37AF` | u8 | 代官所潜入で 0 → 2、0 → 1 | ❓ |
| `0x37B2`〜`0x37BD` | u8 × 12 | 0／1 の並び。嵐の後で `01×8, 00, 01×3` になり、志士との出会いの完了ですべて 0。寝て5日目にすると 0、大老 鬼怒川怨仙のあとは `01 01 00 01 01 01 01 01 01 00 01 00`。🔶 時間帯ごとのイベントの発生可否か | ❓ |
| `0x37B5` | u8 | 上の並びの1つ。海兵隊の横暴・代官所の面々で立ち、日付が変わると消えた | ❓ |
| `0x37C5` | u8 | 志士との出会いの完了で 0 → 1、時間帯が進むと 1 → 0。🔶 この時間帯のイベントを完了済みか | ❓ |
| `0x37C6` | u8 | 大寄せで 0 → 1。0 にしても門は変わらない | ❓ |
| `0x37F9` | u8 | 寿司屋の店主を殺すと 0 → 1。🔶 隠しルートの「寿司屋の店員を学問のすすめの前に殺すと傷心の帰国船」の条件か | ❓ |
| `0x37FB` | u8 | 根無し草で 1、幕府ルートで 0（[gates](../gates/README.md)） | ❓ |

## 編集時の注意

- 意味の分からないフラグは生の値の表示にとどめ、通常モードでは書かない
