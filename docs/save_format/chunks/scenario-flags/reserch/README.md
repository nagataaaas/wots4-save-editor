# シナリオのフラグ列 に関する調査

## 洞窟内の柵のゲーム内確認（2026-10-09）

実セーブのコピーで `0x3761` を `01`、`0x37C3` を `00` に変更したところ、神社の洞窟内で柵が降りたとの報告。最初は普段のゲームプレイでは見たことがない柵との報告だったが、後に「柵自体は通常からあった。降りた状態を見たことがなかった」と訂正された。

- ✅ `0x3761`（1 B、通し番号185）の対象は洞窟内の柵。入口の柵 `0x37C3` とは別。
- ✅ 上記の組で洞窟内の柵が下降し、通路を通れなくなったとの追加報告。
- ❓ `0x3761` を0に戻したときの上昇・通行の回復、通常のイベント進行での見え方は未確認。
- 比較用の `0x3761=00`・`0x37C3=01` の組の結果はまだ報告されていない。
