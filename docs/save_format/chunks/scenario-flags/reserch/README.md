# シナリオのフラグ列 に関する調査

このまとまりだけを対象にした調査はない。フラグの変化は次のまとまりの調査で見つけた。

- [event-chart](../../event-chart/README.md)：シナリオ差分（周回の始め〜2日目朝）。`0x376B`、`0x37B2`〜`0x37BD`、`0x37C5`、`0x3793`、`0x37AD`・`0x37AF` など
- [factions](../../factions/README.md)：勢力の表の推定と検証周回。大寄せで変わる `0x3761`・`0x37A2`・`0x37C6`、`0x3768`
- [gates](../../gates/README.md)：大寄せ以降の門・大寄せ前の門。`0x377C`・`0x37FB`
- [hint](../../hint/README.md)：ヒントの差分で `0x37B5`〜`0x37B9` が変わった
- `0x37F9` は寿司屋の店主の殺害の差分（[townsfolk](../../townsfolk/README.md)）、`0x37C8` は夜這いの差分（[night-visit](../../night-visit/README.md)）で見つけた
