# HP・活力

主人公の HP と活力。float32 の並び。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x0035A4` | ✅ |
| 終了（含む） | `0x0035B3` | ✅ |
| サイズ | 16 B（float32 × 4） | ✅ |
| 位置の求め方 | 固定（[U-1](../../../check-diff.md#u-1)） | ❓ |
| 妥当性検証 | ファイルサイズが 0x48BB0。最大HP・活力の最大値が 0〜99,999 | 🔶 |

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x35A4` | 4 B | float32 | 用途未確定。現在HPの可能性（PS3版の並び） | | ❓（U-4） |
| `0x35A8` | 4 B | float32 | 最大HP | エディタの入力上限 99,999 | ✅ |
| `0x35AC` | 4 B | float32 | 活力の現在値。時間とともに減る | | ✅ |
| `0x35B0` | 4 B | float32 | 活力の最大値 | エディタの入力上限 99,999 | ✅ |

- 並び（HP 現在／最大、活力 現在／最大）は PS3版と同じ
- 入力上限 99,999 はユーザー指定の暫定値（ゲーム内の上限ではない）
- 直前の `0x33A4`〜`0x35A3` は [occupation](../occupation/README.md) のなりわいの状態の表

## 編集時の注意

- エディタは最大HP（`0x35A8`）と活力の最大値（`0x35B0`）だけを扱う。`0x35A4`・`0x35AC` は意味が確定するまで表示も編集もしない（ユーザー判断 2026-10-04）

## 未確認・判定待ち

- ❓ **判定待ち → [U-4](../../../check-diff.md#u-4)**　`0x35A4` の意味。案A：現在HP（PS3版の並び）／案B：[TS] の名前どおり活力。**採用までの扱い**：表示も編集もしない
- ❓ 活力の現在値が何で減るのか。実時間では減るが、メニュー画面にいるだけでは減らない。`0x0BC0`（[stats](../stats/README.md)）に連動している可能性がある 🔶
- 🟡 PS3版では直後の `0x35B4`／`0x35B8` が魂技ゲージ（現在／最大、float）。PC版では未検証
