# HP・活力・つま斬りゲージ

主人公の HP・活力・つま斬りゲージの現在値と最大値。float32 の並び。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始 | `0x0035A4` | ✅ |
| 終了（含む） | `0x0035BF` | 🟢 |
| サイズ | 28 B（float32 × 6 ＋ 4 B） | 🟢 |
| 位置の求め方 | 固定 | ✅ |
| 妥当性検証 | ファイルサイズが 0x48BB0。最大HP・活力の最大値が 0〜99,999 | 🔶 |

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| `0x35A4` | 4 B | float32 | 現在HP | 最大HP以下。0 以下のときは 1.0 で保存される | 🟢（U-4 案A） |
| `0x35A8` | 4 B | float32 | 最大HP | エディタの入力上限 99,999 | ✅ |
| `0x35AC` | 4 B | float32 | 活力の現在値。時間とともに減る | 活力の最大値以下 | ✅ |
| `0x35B0` | 4 B | float32 | 活力の最大値 | エディタの入力上限 99,999 | ✅ |
| `0x35B4` | 4 B | float32 | つま斬りゲージの現在値 | つま斬りゲージの最大値以下 | 🟢 |
| `0x35B8` | 4 B | float32 | つま斬りゲージの最大値 | | 🟢 |
| `0x35BC` | 4 B | u32 | 主人公の状態の印（ビット 0 だけを読む） | 0・1 | 🟢位置 ／ ❓意味 |

- 並び（HP 現在／最大、活力 現在／最大）は PS3版と同じ
- 主人公がいないときの既定値は 1000.0（つま斬りゲージの現在値だけ 0.0）🟢
- つま斬りゲージは、続けて斬った数が 25 の倍数になるたびに最大値の 20% ずつ溜まり、50% 以上で発動できる 🟢
- 実セーブ 6 つで、どれも現在値が最大値以下だった（HP 1000/1000、活力 900〜1000/1000、つま斬りゲージ 0〜81/1000）
- 入力上限 99,999 はユーザー指定の暫定値（ゲーム内の上限ではない）
- 直前の `0x33A4`〜`0x35A3` は [occupation](../occupation/README.md) のなりわいの状態の表

## 編集時の注意

- エディタは最大HP（`0x35A8`）と活力の最大値（`0x35B0`）だけを扱う。`0x35A4`・`0x35AC` は意味が確定するまで表示も編集もしない（ユーザー判断 2026-10-04）
- 読み込みでは、各現在値を最大値で頭打ちにする。ただし、比べるのは最大値を読み込む前のキャラの最大値なので、現在値を大きく書いたときの結果は要ゲーム内確認 🟢

## 未確認・判定待ち

- ❓ 活力の現在値が何で減るのか。実時間では減るが、メニュー画面にいるだけでは減らない。`0x0BC0`（[stats](../stats/README.md)）に連動している可能性がある 🔶
- ❓ `0x35BC` の印の意味
