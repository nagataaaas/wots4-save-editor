# イベントチャート

イベントチャートの各イベントの状態。周回中の状態 A と、周回をまたぐ記録 B の2つの配列があり、どちらも添字＝イベント番号の u8 配列。

A は通し番号（[../../README.md](../../README.md) §3）の 0〜165 に当たり、添字＝ゲーム内のイベントID（🟢）。
番号 N は `0x36A8 + N` にあり、166 以降は [scenario-flags](../scenario-flags/README.md) に続く。

## 範囲

| 項目 | 値 | 確度 |
|---|---|---|
| 開始（A：周回中の状態） | `0x0036A8` | 🟢 |
| 終了（A、含む） | `0x00374D` | 🟢 |
| サイズ（A） | 166 B（u8 × 166） | 🟢 通し番号 166 から重要人物の状態（[characters](../characters/README.md)）が始まる |
| 開始（B：周回をまたぐ記録） | `0x003838` | 🟢 |
| 終了（B、含む） | `0x0038FF` | 🟢 |
| サイズ（B） | 200 B（u8 × 200） | 🟢 |
| 位置の求め方 | 固定 | ✅ |
| 妥当性検証 | 全バイトが既知の値（A：`00`〜`05`・`FF`、B：`00`・`03`・`04`・`05`・`FF`） | 🔶 |

```text
A[n] = 0x36A8 + n   （n = 0〜165）
B[n] = 0x3838 + n   （n = 0〜199）
```

## 構造

| 位置 | 幅 | 型 | 内容 | 値 | 確度 |
|---|---|---|---|---|---|
| A `+n` | 1 B | u8 | 添字 n のイベントの周回中の状態 | 下の「A の値」。添字は [イベント](../../datatable/event/event.csv) | ✅ 値 `05`・`FF` ／ 🟢 `01`〜`04` ／ 🔶 `00` |
| B `+n` | 1 B | u8 | 添字 n のイベントの記録（チャートに名前を出すか） | 下の「B の値」 | ✅ `FF`・`04` ／ 🟢 チャートでは `04` かどうかだけを見る |

### A の値

| 値 | 意味 | 確度 |
|---|---|---|
| `FF` | 未到達（周回開始時、B が `FF` の添字はこの値になる） | ✅ 表示は未到達 ／ 🔶 初期化の規則 |
| `00` | 未到達 | 🔶 |
| `01` | 導入を見た（剣術大会の準備で確認） | 🟢 |
| `02` | 導入を見て断った・保留した。もう一度話しかけると誘い直しの会話になる。実データでは未確認 | 🟢 |
| `03` | 引き受けた・進行中（会話・移動のあと、戦闘の前） | 🟢 |
| `04` | 成功・完了。大成功と成功はどちらも `04`（報酬額だけが違う）。護衛の相手を死なせても `04` になるイベントがある（講師ご到着・語学所開設・ガイジンとゲイシャ） | 🟢 |
| `05` | 失敗（逃走・主要人物の死亡など） | ✅ |

- イベントが始まる条件は、ほとんどが「A の値 ≤ `02`」（🟢）

### B の値

| 値 | 意味 | 確度 |
|---|---|---|
| `FF` | チャートの枠は出るが、イベント名などが隠れる | ✅ |
| `04` | 結果どおりに出す（成功・失敗の区別は A が持つ） | ✅ |
| `00`・`03`・`05` | 周回の終わりに A から写った値（下の「A と B の関係」）。チャートの表示では `FF` と同じ | 🟢 |

### チャート表示の規則

チャートの升（枠と線）の並びはゲームに固定されている（[datatable/event/chart-cell.csv](../../datatable/event/chart-cell.csv)）。行は上から攘夷・幕府・外国・共通（無所属）・真ルートの順。剣術大会（47〜50）・67・84 など、升のないイベントは出ない（🟢）。
真ルートの行（行 8）の横線のうち 4 本（列 15・17・34・44）だけは隠しの印がなく、真ルートを知らなくても出るとみられる（🟢 要ゲーム内確認）。

**枠の表示**（A・B から決まる。🟢）

| A・B | 枠の見え方 |
|---|---|
| A ＝ `03` | イベント名を出し、緑の枠で囲む |
| A ＝ `04` | イベント名を出し、緑の枠で囲む |
| A ＝ `05` | 失敗の印。イベント名は B ＝ `04` のときだけ出し、それ以外は「？？？」 |
| A ＝ `00`・`01`・`02`・`FF` で B ＝ `04` | イベント名を出す（過去の周回の記録） |
| A ＝ `00`・`01`・`02`・`FF` で B ≠ `04` | 「？？？」 |

- 緑の枠（薄い緑、半透明）は A が `03`・`04` の枠だけに付き、`03` と `04` で見え方は変わらない。B ＝ `04` だけの枠や、いま始められるだけの枠には付かない（🟢）
- いま始められるイベントの枠は、名前が分からなくても「？？？」を濃い字で出す。B ＝ `04` でもいまは始められない枠は、名前を灰色で出す（🟢）
- 時間帯を過ぎたイベントは、A が `00` のままでも失敗の印が付く。後ろの段階のイベントに到達する（A が `03`〜`05`、またはいま始められる）と、それより前の段階で何も到達しなかった段階の、たどってきた勢力の行の枠に失敗の印を付ける。最初は共通の行をたどり、到達した枠が別の勢力の行にあればその行に移る（🟢）。日数を進めると次の段階のイベントが始められるようになるので、日数から失敗と表示されるように見える（✅）

**今の時間帯の紫の箱**（🟢）

- 段階（[date-location](../date-location/README.md) の `0x0010`）と同じ段階の枠を全部囲む四角形を、枠と線の下に紫（半透明）で描く。枠の外側に少し余白をとる
- 囲む枠は、真ルートのフラグ（[best-route](../best-route/README.md) の `0x378E`）が `0` なら真ルート以外の行の枠、`0` 以外（`1`・`2`）なら真ルートの行の枠だけ。枠が出ているかどうかは見ない
- 同じ段階の枠が1つもなければ描かない（`0x378E` が `0` 以外で、その段階に真ルートの枠がないときも出ない）
- 日数（`0x0BD8`）・時間帯（`0x0014`）は見ない

**真ルートの枠が出る条件**（🟢）

- 真ルートの行の枠と線は、ふだんは枠ごと出ない
- 枠は、A が `03`・`04` か、B が `04` か、いま始められるときに出る。A が `05`（失敗）だけでは出ない（✅ B ＝ `FF`・A ＝ `05` で出ないことを確認）
- 周回数（[stats](../stats/README.md) の `0x0B8C`）が 3 以上なら、真ルートの枠と線を全部出す（要ゲーム内確認）
- 線は、出ている真ルートの枠から左へたどって、出ている枠に着く道の線だけを出す。共通の行から真ルートの行へ下りる分かれ目の線は、真ルートの枠が1つでも出ているときだけ下へ伸びる

**先の日の枠が見えないこと**（🟢、要ゲーム内確認）

- 先の日の枠を隠す処理はない。カーソルは、到達した枠（A が `03`〜`05`、B が `04`、いま始められる、時間帯を過ぎて失敗）のうち最も右の列より右へは動かず、画面はカーソルに合わせてスクロールする
- 左右のスクロールと縮小表示は、クリア回数（[date-location](../date-location/README.md) の難易度ごとのクリア回数）の合計が 1 以上のときだけ使える。上下のスクロールはいつでも使える
- そのため、一度もクリアしていない主人公では、到達した列より先の枠は画面に入らない

**線が赤くなる条件**（🟢）

- 線はふだん黒。今の周回で到達した枠（A が `03`・`04`・`05`、いま始められる、時間帯を過ぎて失敗）から右へ線をたどり、別の到達した枠に着く道を赤くする。分かれ道では、到達した枠へ向かう側だけが赤くなる
- B が `04` なだけの枠（過去の周回の記録）と、A が `01`・`02` の枠は、到達した枠に入らない（いま始められるときを除く）
- 出ていない枠（真ルートの隠れた枠）へ向かう線は赤くならない

### A と B の関係

- 周回の終わりに A の内容が B に写り、A は `00` に戻る（✅ 差分1回）
  - 写す規則 🟢：添字 0〜165 で、A が `00`〜`05` かつ B が `04` でなければ B ← A。B は一度 `04` になると変わらず、それ以外は最後の周回の A の値になる（A が `00` なら B も `00` に戻る）。A が `FF` なら B は変えない
  - A は `FF` でなければ `00` にし、`FF` はそのまま残す 🟢。一度でも到達したイベントは、以後の周回でも A が `00` から始まる
- 周回の途中でも B が書かれることがある（日が変わるときなど。🔶）
- 周回開始時、B が `FF` の添字は A も `FF`、それ以外は `00` になる（🔶。上の2つの規則から、正規のプレイではそうなる 🟢）
- B は通し番号では 400＋添字に当たる（🔶）

## 編集時の注意

- 次の添字は、通常の編集対象にしない
  - 47〜50 剣術大会（幕府／外国／攘夷／無所属）：チャートには出ない。出場した勢力の1つだけが `03` になり、優勝で `04`、負け・降参で `05`（🟢）
  - 67 悲しみのローラ：未実装のイベントとみられる（[U] 2026-10-06）
  - 84（名前不明）：ローラの決意（85）の前半の導入。人間湯通しの恐怖に続く場面が始まると `04` になり、85 の開始条件が「84 = `04`」。チャートには名前が出ない（🟢）
  - 100 以降（116 を除く）：対応するイベントがない（🟢）。102 はガイジンとゲイシャで `03` のときの別の会話があるが、値が書かれる場面がない（使われていない）
- B の `00` は意味が分からないので、読むだけにし、通常モードでは書かない
- 日を進めるときは A を書き換えなくてよい（ゲームが日数から失敗を表示する）
