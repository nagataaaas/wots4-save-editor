# イベントチャート に関する調査

- `./2026-10-05_scenario-diff.md`: 周回の始めから1日目夜・2日目朝までのイベントの前後で差分を取った。A（0x36A8〜）・B（0x3838〜）の位置と、A の値 `00`／`03`／`04`／`05`／`FF` を推定。のちに A の `FF` は「隠れている」ではなく未到達と判明（→ `./2026-10-05_chart-write.md`）
- `./2026-10-05_chart-write.md`: A・B を書き換えてチャートの表示を確かめた。B が名前の表示を決め、A は結果を持つ。日数の書き換えで未処理イベントが失敗表示になる。のちに B `FF`＋A `04` でも出ることが判明（2026-10-06 追記分）
- `./2026-10-06_event-index.md`: 添字とイベント名の対応をゲーム内のチャートで確かめた（0〜46、51〜99、116）
- 真ルートでのチャート表示（枠ごと出ない）と、周回の終わりに A が B へ写ることは [best-route](../../best-route/README.md) の調査で分かった
- 4日目以降の日数と A の関係は [date-location](../../date-location/README.md) の調査で分かった
