# 場面のテンプレ：剣術大会直前（2026-10-16）

決まった戦いの直前（ロードしてその場所へ行くとイベントが始まる状態）に、周回の進み具合を書き換えるテンプレの1つ目。
書き方はユーザー判断（2026-10-16）で「周回の進み具合を初期化してから、その場面までの決まった道筋を書く」。武器・道具・お金・主人公・町の人・なりわい・夜這いには触れない。
