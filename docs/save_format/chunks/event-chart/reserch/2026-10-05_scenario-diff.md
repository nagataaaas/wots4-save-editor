# シナリオ差分（周回の始め〜2日目朝）

- 日付：2026-10-05
- 目的：イベントの進行で変わるバイトを特定し、イベントの状態の置き場所を探す
- 環境：Steam版、ファイルサイズ 0x48BB0。主人公「名無し侍」（累計プレイ約19時間）

## サンプル

### 別セーブとの比較

- 名無し侍の周回開始時（copy）は、A の `FF` の位置が B と完全に一致する（添字 2, 10, 14, 16, 19, 25, 32, 53〜56, 59〜61, 64〜69, 74, 76, 80, 83, 93〜96, 99〜165）。copy の A は添字0 が `04`、ほかは `00`／`FF`
- `S4-DATA_04`（1周目）は A の添字 0, 1, 6 が `04`、ほかはすべて `FF`。B はすべて `FF`
- B は名無し侍の3ファイルで同じ値。使用中の添字のほとんどが `04`、添字 13, 21, 24, 48 だけが `00`。copy → copy 2 でも変化しない
- A の直後（`0x374E`〜）は 0／1 のフラグ列。A と B の間隔は 0x190

## 結論

- A＝`0x36A8`〜（周回中のイベント状態）、B＝`0x3838`〜（周回をまたぐ記録）として ../README.md に反映した（🔶）
- A の値：`00` 未到達、`03` 進行中、`04` 成功・完了、`05` 失敗。`FF` はこの時点では「隠れているイベント」と考えた（のちに未到達と判明）
- 添字：3＝嵐の後、6＝志士との出会い、9＝海兵隊の横暴（2回再現）、10＝阿片密売を阻止せよ、11＝辻斬りを辻斬る、12＝代官所潜入
- 勢力の記録の候補 `0x3780`〜 は [factions](../../factions/README.md) へ、`0x377F` は [gates](../../gates/README.md) へ
- ❓ `0x376B`、`0x37B2`〜`0x37BD`、`0x37C5`、`0x3793` などは意味不明のまま（[scenario-flags](../../scenario-flags/README.md)）
