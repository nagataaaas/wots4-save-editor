# 場面のテンプレ：真ルートの三姉妹戦（2026-10-19）

真ルートの三姉妹との戦いの前後に、周回の進み具合を書き換えるテンプレ。
書き方は剣術大会直前（[2026-10-16_scene-template-tournament.md](2026-10-16_scene-template-tournament.md)）と同じで、周回の進み具合を初期化してから、その場面までの決まった道筋を書く。
武器・道具・お金・主人公・町の人・なりわい・夜這いには触れない。施設（病院 `0x375D`・カジノ `0x375E`）も周回をまたいで残る値なので書かない（ユーザー判断 2026-10-19）。

## 三姉妹との戦いの位置 🟢

- 三姉妹との戦いは、ローラの決意（85）ではなく、続けて起きる士魂は屈せず（86）の後半にある。85 の戦いの相手は魔鱗組
- 85 で門の前のローラについて行くと、代官所の中での戦い → 捕らえられる → 拷問3回 → 処刑台の場面 → 丸腰で三姉妹と戦う → 茂呂・小暮が加わって三姉妹を倒す、まで続けて起きる。間にセーブできる時点はない
- そのため「直前」はローラの決意の開始前（三姉妹と戦うイベントが始まる前）にした
- `0x3760`（まだらが味方）が 1 だと、処刑台の場面でまだらに助けられ、三姉妹との戦いも自由に動ける時間もなく、ローラ奪還（87）へ続く。周回をまたいで残る値なので、両方のテンプレで明示的に 0 を書く
- 三姉妹を倒したあとの値は、戦い方で分かれない
