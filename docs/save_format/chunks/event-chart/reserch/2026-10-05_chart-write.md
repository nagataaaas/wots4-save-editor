# イベントの状態 A・記録 B の書き換え

- 日付：2026-10-05（2026-10-06 の確認を含む）
- 目的：A・B を書き換えたときのイベントチャートの表示を確かめ、各値の意味を決める
- 環境：Steam版、ファイルサイズ 0x48BB0

## サンプル

| ファイル | 操作 | ベースからの差分 |
|---|---|---|
| `sample/S4-DATA_03 copy`〜`copy 5`、`04 copy`〜 | [2026-10-05_scenario-diff.md](2026-10-05_scenario-diff.md) のセーブをエディタで書き換えてロード | — |
| `sample/S4-DATA_03 copy 7` | 03 copy 2 から港で 5日目昼まで寝た | `0x0BD8` 0 → 4。未処理の1〜3日目イベントの A は `00` のまま |
| `sample/S4-DATA_01 copy 12` | 隠しルートを過去の周回で記録していない主人公で、怒りの矛先を終えたセーブ（[U] 2026-10-06） | — |

## 書き込みの確認

| 書き換え | ゲーム内の表示 | 判定 |
|---|---|---|
| A を `05`（B が `04` のイベント） | チャートに失敗のマークがついた | ✅ |
| 代官所潜入（B＝`04`）の A を `04` → `FF` | 「未達成」と表示された。A の `FF` は未到達 | ✅ |
| 阿片密売（B＝`FF`）の A を `FF` → `05` | チャートで名前が隠れたまま失敗扱いになった | ✅ |
| 03 copy の阿片密売（A＝`FF`）の B を `FF` → `04` | チャートに「未達成」で出た | ✅ |
| B の値いろいろ | チャート表示に効くのは `FF`・`04` だけ。`00` は効かない | ✅ |
| B を `FF` にしたイベントで A を `04` | チャートに出た（[U] 2026-10-06） | ✅ |
| 03 copy 5（1日目夕）の `0x0BD8`（＋`0x0010`・`0x0014`）を2日目に | 2日目になり、2日目昼までに済ませていないイベントはすべて失敗表示 | ✅ |
| 寝て日を飛ばした 03 copy 7 をロード | A は `00` のままだが、チャートでは失敗表示 | ✅ |
| 01 copy 12 で B 添字70・71 を `04`、72 を `05` | 再起の望み（A＝`05`）はチャートに出なかった | ✅ |
| 同じく B 添字72 を `04` | 失敗として出た | ✅ |
| 大老暗殺計画（添字83）の B を `04` | チャートに出た | ✅ |
| 隠しルート以外で B＝`FF`・A＝`05` | チャートに出る | ✅ |

## 結論

- イベント名を出すかは主に B が決める。B の `04` は「結果どおりに出す」、`FF` は名前を隠す。成功・失敗の区別は A が持つ
- A が `04` なら B が `FF` でも出る。A の `FF` と `00` はどちらも未到達として表示される
- 隠しルートのイベントだけは、B が `FF` で A が `04` 以外だと枠ごと出ない
- 過ぎた時間帯の未処理イベントの「失敗」は、A ではなく日数からゲームが決めて表示している
- B の `05` を書いても出ない（02 copy の実データで B に `05` が入っていた理由は ❓）
- ❓ A が `01`・`03` のときの表示
