# アイテム表

- [item.csv](item.csv)：通常アイテム。`kind` と `max_stack` は [datatable の説明](../README.md) を参照。
- [valuable.csv](valuable.csv)：貴重品。同じアイテム ID を使う（🔶）。

## 使用時の分類候補

`item.csv` の `use_action` は、使用時の分類候補の値（🔶）。セーブのフィールドではなく、アイコン表示のために使う。書き込みの可否・使用効果の判定には使わない。

| 値 | 分類候補 | 表示するアイコン | 確度 |
|---|---|---|---|
| `0x00D5` | 食べる。食べ物・きのこ・魚・秘薬など | 食べ物・食べて使うもの | 🔶 |
| `0x00D8` | 飲む。酒・ワイン・ソーダ水・西洋医学の水など | 飲み物 | 🔶 |
| `0x00D9` | 読む。技ノ書・奥義ノ書・秘奥義ノ書 | 読み物 | 🔶 |
| `0x00F7` | 刀に塗る。打ち粉・刀油 | 使用アイテム | 🔶 |
| `0x00F8` | 砥石を使う | 使用アイテム | 🔶 |
| `0xFFFF` | その場で使わない物 | 汎用のアイテム | 🔶 |

分類別のアイコンを付けるのは `kind=0`（道具）の上記5つの値だけ。ほかの値・料理・宿・手に入る経路のない品・未知の ID は、分類を追加せず汎用の「アイテム」（箱）アイコンを表示する。空き枠・未読み込みにはアイコンを付けない。名前や説明文から別の分類を推測しない。例えば目録や部品箱は、名前や説明に「書物」「使用」とあっても独自に読み物・使用アイテムに分類しない。

料理・宿にも値があるが、道具と同じ意味ではないため、この分類には使わない。
